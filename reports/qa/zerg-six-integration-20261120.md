# 虫族六单位 R2 本地集成 · 2026-11-20

第一阶段六场试玩已获用户确认。第二阶段已接入正式战役并验证正常取得流程。第三阶段已接入正常战役和无尽的敌方六单位，以及走独立队列、结算和救援规则的体验敌。按下列实测范围交接。

## 变更范围

- 友方使用试玩与正式战役共用的 World 机体、武器、自动施法与子体实现。补齐 16 家族、5 个基础选用槽、关卡与进化方向前置、正式训练／补员、武器研究与装备资格、模型／声音／图标预加载和保存。正常局虫族发展、研究、训练与补员免费。脚本化教学的固定资源操作及旧已付订单收据继续按原流程执行。
- 敌方六种是正常母体并走既有奖励路径，使用敌方成长、能力与预警；敌感染虫只施加 DOT，敌飞蛇提供预警减速。原正常主力、首领与特殊名单保留。体验敌独立标识、队列、计数及到期，输出统一 20%，没有普通奖励、掉落随机数或成长进度。只有普通波伴随体按来源迁移，任务守军留在原角色。正常敌、救援和关键对象优先；体验体不会阻挡或攻击受保护对象，可在缺位时退场腾位。
- 旧档保留当前波次和已付收据，下一关／下一轮启用新排程。开发留在主线工作区。仅本地构建和验证。
- 合流时连同数据、模拟、呈现和资源登记保留。主要入口见 [正式家族](../../src/data/races.ts)、[六者战斗执行器](../../src/simulation/combat/zerg-six.ts)、[敌方排程](../../src/data/zerg-six-encounters.ts)、[入场与容量](../../src/simulation/zerg-encounters.ts)、[正式资源校验工具](../../tools/zerg-six-assets.mjs)。

## 实际战场、计划与性能

种子 17，同一个 World 的旧排程模式与 R2 对照。普通样本每族 5 家、每家 2 名、无装备，保留移动和战斗规则，持续到战败或 62 秒。困难／地狱样本每家 4 名、无装备。实际体验入场包含已迁入体验层的旧伴随体。未打完整关的样本只计算实测期间数据。

| 难度与关卡 | 新正常／新体验计划 | 实际新正常 | 实际体验 | 同屏敌峰值 旧→R2 | R2 体验击杀 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 普通6 虫族 | 1／122 | 1 | 183 | 20→26 | 178 |
| 普通12 虫族 | 9／381 | 2 | 221 | 61→94 | 162 |
| 普通18 虫族 | 21／768 | 0 | 224 | 83→129 | 144 |
| 普通18 人族 | 21／768 | 0 | 183 | 70→112 | 112 |
| 普通18 神族 | 21／768 | 0 | 220 | 69→127 | 142 |
| 困难18 虫族 | 34／1274 | 0 | 271 | 100→179 | 159 |
| 地狱18 虫族 | 43／1459 | 0 | 226 | 70→191 | 86 |

普通12 虫族的实测空场时间从 12.58 秒降到 5.98 秒，也从 49.37 秒提前到 41.68 秒战败。困难／地狱第 18 关阵型均在 31 秒内失败，样本在新正常母体计划到点前结束。固定 300 敌人、每组 240 步、三对模拟 p95 为 30.062→26.288、23.531→22.534、19.453→18.133 ms。自然增量的普通12虫族模拟 p95 为 2.454→3.144 ms，地狱18虫族为 3.173→5.905 ms。实测压力增长先作为平衡观察记录。本轮沿用 R2 数值。

## 复现入口

- 本地正式入口 [127.0.0.1:15302](http://127.0.0.1:15302/)，原来的 [独立试玩](http://127.0.0.1:15302/preview/zerg-six-20261120/) 仍可重开。在本工作区运行 `npm run dev -- --host 127.0.0.1 --port 15302 --strictPort` 可启动。
- 将 `SC2_WEB_OUTPUT` 指向这次验证专用目录后运行 `npm run build:web`。将 `SC2_ZERG_WEB` 指向该目录，然后运行 `node --import tsx tools/qa-zerg-six-campaign.mts` 与 `node --import tsx tools/qa-zerg-enemy-web.mts`。正式敌群脚本从第12关合法阵型存档开始，模拟逻辑使用真实固定步。
- 运行 `node --import tsx tools/qa-zerg-six-encounters.mts` 复现自然增量。设置 `SC2_QA_SEATS=4` 加 `--late` 复测后三种难度第18关，传 `--fixed` 复测300敌对照。
