## 本轮发现并修复

| 路径 | 复现与修复后的行为 |
| --- | --- |
| 孢子刷新与传播 | 原实现可能选择已标记的近邻而漏掉未标记敌人；孤立标记也不刷新。现在合格物理主目标命中可刷新，传播只选最近未标记合法敌人，无传播目标不消耗随机数或传播冷却；酸液、毒液、派生和体验敌边界保持。 |
| 临时战斗身体与终局 | 原实现正式兵全灭后即判负，即使本分支蟑螂／宿主仍能作战。现在这些身体持续作战至战死或有限寿命结束；空周期计时器仍不能阻止失败。 |
| 复活胜者与装备回收 | 卡牌先复活时会遗留相位投影，并提前消耗未使用的生存者救援次数。现在先预留、胜出才提交，失败候选释放次数并退掉投影。原生→装备→分支的同刻优先级、第二次实际战死和旧档已扣次数的迁移均有回归。 |
| 正式兵资格 | 同家族装备独立兵和受控敌人曾被纳入正式来源。现在明确排除，不再抬高 R、播种或触发正式战损与密集资格。 |
| 扎加拉双体 | 同一死亡原来给两体各记一份孵化进度、各自拥有六只爆虫上限。现在使用共享击杀进度和一个六只上限，召唤来源随存档保留。 |
| 德哈卡双体 | 成长原来只留在各自身体，单体离开范围或重新生成后产生差异。现在死亡精华按身份只记一次、同步面板，替换身体和存档恢复接续共享成长；身体自身的储备与适应状态仍独立。 |
| 寄生／感染死亡效果 | 尼雅德拉双体对同一目标会重复死亡回血，斯托科夫重复生成治疗池。现在同一身份、同一敌人只结算一份，普通独立装备投影的既有身份不合并。 |
| 双体光环 | 利维坦分体未成为原生光环来源。现在覆盖两体范围并集，同名效果只取一次，关闭装备时仍生效。 |

新增回归先复现上述偏差，再验证修复。正式编制与六单位子体仍分开；精英克隆保留允许的战斗身份，不复制独立装备槽、在途弹体和正式复活资格。

## 优化规则复核

- 固定 60 Hz 战斗推进、原画质、原版单位／技能资源、正常敌群和独立体验敌群保持。没有通过减少敌人、降画质或改变模拟速度获得性能数字。
- 临时母体与独立兵共用 60／90 上限；周期投放每来源最多一批等待，实际开始入场后保留既定六秒释放期限；原生子虫仍使用自己的共享池。附近防御查询沿用空间索引与 0.25 秒刷新，不新增每帧全场排序。
- 孢子传播改为一次遍历选择最近目标；双英雄身份查询只读取两具身体，共享计数有上限。新增持久字段存入现有出征状态，旧档缺省值不重复累加旧身体的收益。
- HUD 尺寸缓存和音画回执 WeakMap 索引保持，追加／裁剪／读档失效规则有既有回归；本轮不重报此前局部约 16% 索引收益为整场提升。
- 正式加载路径准备虫卵、主脑和坑道模型，并沿现有材质、HDR、阴影与着色器检查预热。试玩的代表帧预热保留；没有据此宣称所有正式战场首帧耗时或 60 FPS 达标。
