## 验证结果

最终正式网页构建标识为 `a7e879361da6d6e34c413455e6eb78ad7b3516d1b9251f88d909a5dc2ecb5d57`。清单核验 4080 项资源、3978 个文件。类型、数据文档、锁定 XML 的机体／升级生成结果，以及全量 3387 项测试通过，失败、跳过均为零。

新增定向回归覆盖逐家族零资源解锁、阵亡后补员、训练中存取档与回执防重。战斗用例核对双幽灵分标、每周期共享干扰与真实治疗／胆汁时钟、独立技能弹道、雷的重装、飓风丢失视野、双解放者分区、炮台寿命、跨战巡大和预留和跳跃后的原有状态。另用已经命中的纳米弹校验三个持续伤害跳数，确认沿用原伤害且不二次放大。

正式 Chrome 页面通过设置导入隔离的测试档。桌面从零矿气点击解锁幽灵，进入第 13 关，实际产出一份补员。桌面操作用例在渡鸦修复前的正式构建 `36dc016e26e7` 上完成。最终构建另在 844×390 和 390×844 视口完成购卡、下一关、战斗、保存、导出和重新载入。横屏 4 秒战斗记录 49 次射击，观察到反装甲导弹、大和炮、解放者对空及部署对地的原版演出。竖屏记录 33 次射击。两个视口分别有 86／69 次正在运行的 Web Audio 播放带有非零 PCM 信号，解码错误为零。

最终构建还在 1440×900 桌面复验了累计购卡组合。通过真实交易取得 BIO-W02、M-W01、W04、BIO-W03、BIO-W01，并按需领取强制节点。9.82 秒时实战已发射 100 次，出现弱点射击、猎犬、飓风与炮击演出。默认鼠标操作下达撤退指令，观测到镜头跟随点实际移动 5.02 个世界单位。在导出档中核对三支已购卡，再从正式入口重新导入，确认五家族与在途检查点时刻恢复。209 次运行中的 Web Audio 声源具有非零信号，页面与解码错误均为零。

已查看桌面、横屏和竖屏实战画面。桌面单位栏在下方，触屏横竖布局保留虚拟摇杆，竖屏单位栏位于右侧。在 844×390 的密集接敌画面，靠近上沿的普通战巡有部分舰体出框，仍沿用现有镜头和模型比例。移动端结果来自 Chrome 触摸模拟视口，声音核验在浏览器音频输出端完成。

- 战斗、弹道、敌方时钟、卡牌身份与存档在 `src/simulation/combat`、`world.ts`、`types.ts`、`persistence/run-fields.ts`。原有检查点格式继续可读。新增状态随实体、弹道、炮台保存。D05 在关间保存正式检查点，同页返回标题后可继续现场。Chrome 从战斗中导出并跨页面读取时，按检查点记录的时刻恢复。在途武器、重装、转移和部署回放由可导入的中途快照独立检验。
- 演出和预加载在 `src/render`、`src/app/battle-preload-plan.ts`、`src/app/audio-preload-plan.ts`、`src/assets`。有 UV1 的原版模型与实例姿态共用 WebGL2 顶点属性时，炮塔朝向、军衔和生化表面值打包进同一个实例属性。渡鸦可生产或在队时，`src/app/armed-preload-plan.ts` 会在开战前准备自动炮台的本体、动画和死亡资源。
- 原版来源和导入工具见 `tools/terran-six-*.json`、`tools/terran-six-assets.mjs`、`tools/prepare-terran-six-effects.mjs`、`tools/append-armed-audio.py`、`tools/t01/audio-plan.mjs` 及现有 CASC／M3 工具的定向修改。203 个模型、贴图与图标输入及 109 个音频输入已逐个核对 SHA-256。两张同名不同层的陆战队员血迹贴图另路径保存。
- 资源接回按 `deploy/runtime/terran-six-assets.json`、`combat-effects.json`、`combat-audio.json` 各记录的 `gitPath` 取内容哈希文件，再带相应生成索引。第一份含 12 个模型／形态／死亡条目和 6 个图标。对照主线实际清单，本轮增加 18 个模型和图标条目、57 个音频条目、44 个特效资源条目。三组分别对应 17／57／44 个唯一内容文件。后两份是累计清单，需保留已有条目。项目运行必需的源素材和正式资源继续保留。新增验证由 `test/terran-six-units.test.ts` 和两个下述 QA 入口复现。

```powershell
npm run typecheck
npm run docs:check
node tools/build-expansion-unit-data.mjs --check
node tools/build-expansion-upgrades.mjs --check
npm test
$env:SC2_WEB_OUTPUT='dist/terran-six-20261119'
npm run build:web
$env:SC2_TERRAN_WEB=$env:SC2_WEB_OUTPUT
node --import tsx tools/qa-terran-six-packaged.mts
$env:SC2_QA_CUMULATIVE='1'
node --import tsx tools/qa-terran-six-packaged.mts
$env:SC2_DPS_SECONDS='90'
foreach($roster in 'ground','air'){
  $env:SC2_DPS_ROSTER=$roster
  $env:SC2_TERRAN_QA_OUTPUT="reports/local/terran-six-20261119/$roster"
  node --import tsx tools/qa-terran-dps.mts
}
```
