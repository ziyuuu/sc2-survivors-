# 检查结果与本地产物

- qa/：长期保留的简要机器结论，包括版本、范围、实际结果、失败/限制及复现入口。
- local/：当前进行的检查、交付及必需输入；其余可重建截图、视频、详细日志、缓存和旧构建在工作结束后清理。

执行规则见 [ARTIFACT_RETENTION](../docs/project/ARTIFACT_RETENTION.md)。旧报告可能指向已按规则删除的原始产物，不能因此重写当时结论，也不应为保持历史链接而永久保存大文件。需要复现时使用对应工具和版本。

当前重点是 T01 r33 与 V04 的活跃交付/输入；真实玩家存档、生产数据库和账号不得放入公共报告。qa 中已经通过的旧验证不是对后来源码变更的自动背书。
