非官方、非商业玩法验证工程。项目名称为暂定同人名称，不代表 Blizzard 官方产品。

## 最新范围

- 人族：陆战队员、恶火、攻城坦克、医疗运输机。
- 虫族：跳虫、蟑螂、爆虫、破坏者。
- 保留 12 关、每关 60 秒；独立单位血量、武器、护甲、移动和治疗向锁定版本的 SC2 数据对齐。
- 付费建造生产建筑、付费排队生产；每个完成的生产任务产生一个降落仓救援事件。
- 降落仓落地即被虫群围攻，救援限时 30 秒，超时或被摧毁即失败。
- 回合结束三选一，支持消耗资源刷新。
- 模型、兵种/建筑/科技/技能图标、地形与界面素材都进入来源清单，不能用占位图冒充原版。
