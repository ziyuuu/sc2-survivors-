基于 Three.js、TypeScript、Vite 的单人小队动作生存游戏。玩家控制方向／目的地和技能，小队独立移动、自动索敌与走射；生产出的增援需要救援才能加入。项目目录：`D:\星际`。

当前可玩增量为 **M2（三族18关天赋版）**：三族各10普通单位、各5英雄候选、40精英方向；五槽换兵、持续生产、发展与免费强化三选一、18关战役已接入。三族各有资源管理、强化士兵、军队管控、微操四线，共165个节点定义；所有线共用80级／80点，按层支付永久资源并可全额洗点。战局冻结开局配点；旧开发战局不可续玩，只能核验后导入永久本金。三族空中英雄、90款精英最终表现、无尽新入口和包体优化仍属于后续阶段。实际验证见[QA](docs/QA.md)和[项目状态](docs/project/README.md)。

## 开始试玩

- 已构建单文件：`D:\星际\dist\SC2-Survivors-Demo.html`，双击离线运行。
- 主菜单“部署小队”开始新局；有存档时“继续战局”恢复后先暂停。
- 暂停、设置或关间可保存／导出；返回标题保留续局。部署新一局会替换当前续局，仍保留轮换备份。
- 本地档案受浏览器和页面来源限制。移动 HTML、换浏览器或换电脑前，请导出完整存档；在目标环境标题界面导入。
- 本游戏非官方、非盈利；原始 SC2 资源属于 Blizzard Entertainment。美术只在本机处理，截图和运行缓存留本地。仓库已有离线HTML的LFS追踪，本轮沿用既有策略；来源核验与分发许可分别记录。

## 开发与验证

需要 Node.js 22+（当前本机24.14.0）；原素材管线另外使用 PowerShell 7.4+、Python、Git。首次资源准备需要联网读取已锁定的公开来源，后续使用本地资源。所有美术处理在本机进行。

```sh
npm install
npm run dev
```

开发地址为 `http://127.0.0.1:5173/`。素材缺失时按 [原素材准备](docs/ASSET_DOWNLOAD_REQUIRED.md) 和 [地图管线](docs/MAP_PIPELINE.md) 操作，不用几何体代替缺失单位。

```sh
npm test
npm run typecheck
npm run docs:check
npm run build
```

`npm run build` 同时生成 Web 构建和完整离线 HTML。文件大小、SHA-256、实际测试结果以 [STATUS.json](reports/STATUS.json) 为准。离线包无损还原全部内嵌原资源，不依赖在线解码器，不含修改状态的开发 API。

```sh
npm run test:save
npm run test:browser:save
npm run test:offline:save
npm run docs:data
```

浏览器检查需要已启动的本地开发服务；离线检查需要最新构建。本机脚本使用安装的 Chrome，截图只写入 `reports/local/`。`npm run lab` 是保留的历史素材实验页，不是当前游戏。

## 操作

| 输入 | 行为 |
| --- | --- |
| 电脑鼠标模式 | 左／右键前往点击位置；点到敌人也只记录当时位置 |
| 电脑键盘模式 | WASD／方向键移动 |
| 手机 | 设置中选虚拟摇杆或轻点前往；当前轮无手机真机验收 |
| Space／E／T | 推进／兴奋剂／全队手动架炮、收炮 |
| 1／2／3 | 雷诺／泰凯斯／诺娃技能 |
| F | 天赋解锁后的空运 |
| 手柄 | 左杆移动，右杆选六方向技能，A／X施放，B清除，Menu暂停 |
| Escape | 暂停或返回设置 |

操作偏好、画质和手柄校准单独保留。暂停／关间／模型解码期间冻结模拟。自动索敌不生成追击指令，也不移动小队锚点。

## 当前内容

- 一名枪兵、一座兵营、50矿／0气开局。五种友军、五种普通虫族，15种唯一友军精英、3名英雄。
- 英雄参战时有原头像、实时生命／技能状态和专属颜色信标；主动技能短显施放者与名称。友军精英保持紫色次级识别。
- 基础普通编制25，已有天赋可到35，英雄另占3席；SCV和临时支援按现有规则另计。未来新局严格五系各五席，旧35席战局通过明确版本规则保留。
- 十二关按三关一组持续60／120／180／240秒，共30分钟；末关必须毁巢并撑到时限。
- 简单／普通／困难／地狱；敌方章节成长、精英I–V、四次固定Boss、随机领主、状态效果及地狱扩张虫巢。
- 关间建筑界面可为兵营／重工厂／星港各选一至两种本轮产出，轮换只影响下一批；继续自动合批生产、多乘员降落仓、可被摧毁的救援、资源拾取、两轮关间商店与按实际价格结算。
- 旧12关兼容天赋为55节点、四线七层，历史满树价格258资源点；新三族天赋目标按层收费，完整价格见设计稿。
- 胜利后可选 Acropolis LE 独立无尽地图，带入小队／资源／生产，中央四地堡加一修理设施，每轮240秒。
- 战局与永久档案原子保存；每10秒战斗时间及关键边界自动保存，主档加两份备份，无离线推进。
