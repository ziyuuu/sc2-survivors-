# 原地图与十二个开放范围

当前母地图为 **Kairos Junction LE / 2019 Season 2**，来源是 [DI-star 固定提交中的 SC2Map](https://github.com/opendilab/DI-star/blob/12b1c69350ad41e17895c602a66a52d98dd58452/distar/envs/maps/Ladder2019Season2/KairosJunctionLE.SC2Map)。1,443,073 字节，SHA-256 `bc54ccf150f40935c5df1309a041144be2fce7a3861d4e4bceda8a36e852b2f2`。不执行原图脚本、不生成对战开局部队。十二关共用这个真实地图；不是十二张独立地图。

原顶点 153×169，可玩边界 SC2 [16,14,136,154]。出生点 [31.5,140.5]；转换为 Three X = SC2 X −31.5、Z =140.5−SC2 Y；高度减8，横向比例始终为1。原高度、八层纹理权重、UV tiling、16 坡道记录、原崖壁及物件的坐标/朝向/比例保持。地图并非此前手工 Char 布局；其原地貌是 Mar Sara / 工业设施。

本地转换292种模型（186物件、106崖壁变体），4,956处模型摆放、2,473块原崖壁。使用原标准材质、复合岩石标准表层、原地面投影贴花；无游戏菌毯时不显示动态菌毯覆层。106种崖壁按绝对角点等级选原文件和原旋转，0变体替代；基座取最低角点等级，避免把 B/C/D 级崖壁压进地下。图形原图摆放中的竞争玩家 Logo 不用于此游戏。

## 转换及复现

```powershell
npm run assets:map
npm run build
```

Node 22+ / Python / PowerShell 7.4+ / Git。脚本本地安装固定 mpyq 0.2.5 到 `.cache/map-tools`，校验原图后提取。`tools/map-dependencies.json` 锁定511个模型/贴图源文件的下载URL、精确落盘路径、长度、SHA-256与CASC版本验证标记；不把镜像文件冒充已验证的暴雪构建。已核对的CASC素材使用5.0.16.97563；规则数值继续为5.0.15。仅在匹配原哈希时接受缓存；错误页不能作为模型或贴图。

公共镜像失败时，已验证CASC的依赖由共用 `fetch-sc2-casc.ps1` 从锁定包读取；仍缺项写入 `reports/local/map-missing.json`，不生成可交付假地图。模型材质转换修复都在版本管理内，刷新转换器源码不会覆盖修复。

读取依据为 [原格式研究](https://github.com/sc2-arcade-watcher/sc2-file-format-docs)，包含 HMAP、SMAP、MASK、CellAttribute、cliff/ramp 与 Objects。解析先核对两出生高台的高度差 <0.01；全图渲染/同步高度差最大10.04保留报告，不能对崖壁焊接/低谷假设全图完全相等。当前用同一份渲染高度驱动模拟脚下高度。

292个GLB中重复图片按SHA-256合并为179张共享图片；保留原最高mip像素，地表支持DXT1/DXT3/DXT5。运行模型以语义图片ID引用共用纹理，离线解析器映射到内嵌data URI；不会从file://跨域取贴图。地图静态姿势烘焙后按原几何实例化；按视野和开放关卡裁剪。原文件和截图均只存本地。

## 通行与范围

地形在半格上派生碰撞：原手绘通行位、高差、原pathing blockers、静态物件占地与身体半径。未提供精确可用Footprint的静态单位暂用类型尺寸代理；这不是SC2客户端完整寻路器。边界按身体半径封闭；空中使用独立层。A*只在直线被挡时运行，按半径缓存通路；生成点沿半格通路验证，避免旧两格格点漏掉窄坡道。

开放面积按原关卡面积比逐步增长，保留完整相交坡道和两端通路。面积（平方SC2单位）：741.75、1248.5、1831.75、2558.5、3473、4375.25、5527.5、6718.5、8008.75、9510.25、10234.5、11869.5。每关保留旧区域、实体与未解决仓；第12关虫巢靠近对侧原出生点，不再生成在我方高台。

本地跨图四兵种120秒行军诊断已通过：无战斗/经济干扰，四单位最终到各自编队槽约0.08单位；保持车辆、枪兵和医疗艇原始速度、有限转向与最多22%追赶。它是寻路回归，不是普通难度自动通关证据。
