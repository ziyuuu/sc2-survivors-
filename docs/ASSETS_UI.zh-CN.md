# 原版素材与界面接入约定

## 来源与状态

主要目录来源是维护者公开的 SC2Mapster Asset Explorer：
https://github.com/sc2-arcade-watcher/asset-explorer

目录根路径：`site/list/`；模型下载候选：`models-glb/`。按钮目录中的源文件可能是 DDS，预览图是 PNG。清单分别记录源资源与预览 URL，不将两者混同。

本次只确认 42 个目标槽位，其中一些已在目录中观察到，一些仍是待匹配名称。八个战斗模型的链接返回 403。不能把“有清单”统计成“下载了 42 项”。

状态顺序：目标槽位 → 精确索引匹配 → 文件结构与哈希 → 人工视觉核验 → Blender/动画核验 → 手机运行验证。文件检查不授予素材再分发许可。

## 地图

用户要求原版地图风格和素材。暂提出三个选材组：玛·萨拉、克哈、查尔，分别作为 1—4、5—8、9—12 关的候选环境；这是待验证的设计分组，不是从原游戏提取的十二张地图。

每张可玩地图需要独立的高程/地面网格、通行网格、地表材质、装饰物、边界、导航目标和小地图。目录中的 `Mar Sara Dirt`、`Korhal Concrete`、`Char Lava Cracks` 是预览候选，当前不得直接标成完整原版地图。

降落仓位置需满足可达、可见警告、足够抵达时间；危险来自围攻规模、仓体耐久与攻击节奏，而不是在玩家脚下无预警生成。具体敌群数、仓体 HP 和通行路径未在当前验收页实现或平衡。

## 图标与科技

兵种、建筑、科技、主动技能各用稳定 ID 绑定原图标。科技树前置条件和数值应从同一个锁定版本导入；不能混用战役、合作和对战数值，也不能在未核实前将肾上腺等更高科技前置省略后称为原作科技树。

候选冲突时人工选择，不用名称子串随意选皮肤。原图标未取得时显示缺失状态，不使用 Emoji 或色块替代后宣称完成。

## 标志、名字、字体

暂定同人名称：星际争霸 II：幸存者 / SC2 SURVIVORS。原版 StarCraft 标志作为独立图像资源，不通过下载一款“类似字体”伪造已取得原标志。

参考站已读取到三个 CSS 字体别名：SC2 Chinese、SC2 Eurostile、SC2 Extended；尚未验证其内部名称、授权和字形覆盖。代码使用这些本地名称并回退至系统中文/等宽字体，不包含或分发字体文件。

## 参考站与布局

参考：https://starcraft-shooter-2026.pages.dev/

已经取得 HTML、部分 CSS 元数据和加载画面截图；未核实加载后的战斗 HUD。当前 CSS 的深色面板、蓝色描边和金色强调属于本项目的临时风格实现，不能称为对参考站的像素级复刻或原版 UI 贴图。

移动端只对战场 Canvas 禁用浏览器触摸手势；菜单保留纵向滚动，文字禁选与输入/复制区域分开处理。真实移动摇杆、多指输入及 12 关战斗不在本验收页内。

## 下一实现关口

先取得一个来源明确、允许当前用途的 Marine GLB/M3，完成网格、贴图和待机/移动/攻击/死亡动画的实际加载验证；同一流程再扩展其余单位。数据版本和地图资产通过后，接入现有规则模块、真实围攻 AI、三选一回合流程与手机性能测试。源服务 403 时记录失败，不绕过访问限制。
