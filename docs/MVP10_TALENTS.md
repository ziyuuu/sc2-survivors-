## 3. 经济天赋与关间卡片的唯一推荐适配

本节已随M0 r6获批准；原稿中全部属于TAL-D03—05候选；实施时与三族共用，不在运行时保留“旧商店模式”。

### 3.1 免费卡、免单与精英特约

1. 每个有强化阶段的关间生成固定3张牌。零天赋免费领取1张。R09一级／二级令本窗口总免费领取上限为2／3张，只能领取同组尚未领取的卡，不补位、不重新生成。每张仍通过合法性及预付款容量校验；一张卡领取后使另一张失效时，失效项灰显，剩余次数可放弃，不变现。领取记录逐张保存。
2. 首次领取前可按R06和基础额度刷新。首次领取后本组不能再刷新；离开窗口余下免单次数消失，不结转。未领取时退出再进入不重抽。
3. A10在完成战役第3／6／9／12／15关、选择进入无尽的最终整备，以及无尽每第4轮后的强化阶段，另列**精英特约栏**。一级1张、二级2张本族合法紫色精英牌，不占基础三张，不冲掉第6／9／12关英雄保底。第18关先结算一次胜利奖励并选择撤离／进入无尽整备；只有选择后者才打开最终强化和A10，窗口ID为`runId:endless-entry`。这个窗口不再发一遍第18关奖励，返回或读档也不重开一组。选择撤离不强制选牌。
4. 特约只针对已入编家族；同组不同家族，无未满级合法对象就减少实际张数，不发假牌、不按钱包筛除。已锁变体只出该变体；同家族多变体不提高家族抽中权重。已存活同款用于升级；死亡后重招按一级，不复活旧精英。
5. 每张基础价为该家族**完整普通生产配方矿气×5**，包含爆虫／破坏者／潜伏者的前置身体费用，跳虫按一身体完整价；升级和招募同价。再应用R12购买折扣。例：枪兵50/0→250/0，劫掠者100/25→500/125，坦克150/125→750/625。已付款队列和培养容量仍可能拒绝购买；购买前先出替换预览，确认后一次扣款。
6. 特约每张只可购买一次，不补货、不刷新、不消耗或接受R09免单次数。玩家可买0／1／2张，不能重复买同卡。免费主组结束后仍可买特约，按“继续”统一结束关间。保留原版寻找精英的“得到购买机会而非自动得到精英”。

### 3.2 刷新与价格

基础每章建筑／强化各一次免费刷新不变。R06额外提供每次关间1／2／3次两阶段共享免费刷新。刷新先花本章对应类别免费次数，再花本窗口共享次数，最后花本类唯一一次付费刷新。每窗口建筑／强化仍各最多1次付费刷新；天赋增加的免费次数不受该付费次数限制。不因免费刷新增加下次报价。

设章序c，R03等级r，R04等级b，R12等级d。建筑刷新矿价`max(10, ceil((50+10(c−1)−20r)×(1−0.1d)))`；强化刷新矿价把50换为30。R04只作用实体设施建造及孵化设施层级升级，不作用研究、刷新或维修。普通建造每资源报价`base×(1−0.15b)×(1−0.1d)`，向上取整；基础为0仍是0，正数最终至少1。R12适用于未来新下单生产、建筑／研究、付费卡、复活、驻地生命维修；不追溯已经付费的订单，不对永久资源消费打折。

### 3.3 建筑免费、双建与一次完工

购买时先验证至少能支付第一座显示价，固定请求ID；R07免费、R10双建独立各掷一次，R13对实际建成的每座分别掷一次。免费命中免第一座；第二座若双建命中、为可重复生产设施、未达设施上限且还能支付一座报价，则扣第二座价并建第二座。否则只建第一座。不对研究、唯一科技设施、孵化场升巢穴／蜂巢事件做双建；这些不适用项不掷双建骰。一次购买仍只耗本窗口1次建筑行动。

R13候选如下：每座实际建成的生产设施命中概率33%／66%／99%，每次至多完成1项；无合法项目时不掷骰、不留次数、不赠矿气。先找与当前已开启生产输出关联的项目，再找所属线的其他项目；同组用下表列出的顺序，常规三级研究只前进一步。三族常规研究二级/三级仍要求完成第6/12关，特色仍要求对应科技建筑。免费研究不额外消耗本窗口建筑行动，完成后全局效果只应用一次。

## 5. 需要写入模拟层的完整解释

### 5.1 出金大师不是卡池加权

本节以TAL-D08推荐联合分布为前提：同一合格死亡收据分别使用奖励RNG流做橙色、紫色Bernoulli判定，概率R14一级0.005/0.01、二级0.01/0.02。两次独立，可同时掉两枚；不与普通掉落概率相加，不从白色扣除。单色概率和不改普通掉率已确认，同次双掉已随M0 r6确认，尚未实施。每个掉落保存来源`talent.rarity_master`和敌人死亡收据。拾取后走同品质合法奖励选择，不出现强制付费商城，不因钱包不足卡死。暂无合法同品质效果时按普通卡系统该品质补给兜底，来源标明。

R14产生的奖励不吞掉每章1张基础地图强化预算，也不受该基础预算截断；不会为减少强度偷偷改成每章只能触发一次。效果上限仍共享，超过武器/生命等上限的卡不能发。满级R14每1000次合格击杀期望10橙＋20紫（随机结果不保证），这是原意产生的显著经济优势，必须记录到试玩，不可在实现阶段擅自减概率。卡面与地面掉落可以合批渲染，但实际奖励收据逐个保留。

### 5.2 精英乘员与晋升容量

R15每个正常付费**身体**恰判定一次，先验证合法精英路径、家族席位和接收位置。命中且该家族没有永久精英：把该乘员作为一级同家族精英交付；精英占这名乘员已有席位，不加人数、不追加扣款。家族已有精英、路径不可用或精英培养冲突时，最多回退为普通Rank 5；只有统一培养容量能容纳到5的全部增量才给到5，否则保持原乘员等级，不挤占别人的预付款。不能把概率命中变成免费精英升级卡。

先处理R15最终身份，再处理A01：R15成为紫精英时A01不再给它普通军衔；仍为普通身体时A01可加一级，但不超过S14上限／预付款容量。换兵继承、普通培养卡、击杀晋升、R15回退、A01救援都使用同一容量入口。五槽满的新家族仍在安全出舱时换兵，不因为获得精英就跳过家族替换。

A02/A05/A08只做一次晋升概率判定：`p=0.01*A02+0.01*A05+(同家族永久精英活着?0.03*A08:0)`，最高0.12。A05未投资时候选为击杀者；已投资时为同家族最低军衔合法普通身体（含击杀者）。没有合法候选不掷骰。英雄、临时兵的击杀不转给普通身体白领军衔；截击机先归因母航母，母体是普通身份且满足本段合法容量时按母体一次判定，不给子机军衔。完整归属见5.6。

### 5.3 免费补员及救援事件

A03在冷却结束且存在合法已入编家族时才掷骰；家族优先缺员数最多，再比存活普通成员平均军衔较低，再按familyId。生成一名普通最终体，使用该关卡固定救援守军表。免费救援不退款、不算S16的付费进化票，不给新家族，不因本族配方双生而多送身体。

A14每个工人救援目标只判定一次，跟R01多救出几名工人无关。成功产生当前已入编家族的同族精英救援权，优先尚无精英、剩余容量合法的家族；若全部家族已有活精英则仅允许合法同款升级权，满级排除。保存具体候选与领取收据，不允许关页面重抽。需要普通成员替换时明确暂停预览，支持取消本次领取、保存和返回标题，不把玩家困在购买界面。

### 5.4 盾、分担、保命与叠加

1. 数值计算保持项目批准的军衔／科技顺序；同一属性同类天赋百分比先加后乘一次。例如人族满S01/S02/S11的普攻伤害天赋系数为`1+0.15+0.15+0.30=1.60`，不是三个节点复乘。攻速同理换算周期，不能重置当前冷却。卡牌同属性也内部相加，天赋层与卡牌层按既有次序相乘。
2. S01“伤害”同时影响英雄主动伤害；S02/S11/A11/S05只作用表述的普通武器。英雄主动治疗在S01合法治疗范围，神族原生回盾额外按P-S01适配。冷却由M03修改但总倍率不低于0.5。英雄基础增强以本轮英雄设计稿为准，不在此再暗增一层英雄倍数。
3. 伤害处理：合法性→普通直接攻击闪避→临时护障→原生/天赋盾及盾护甲→生命护甲→S03减伤→S10分担→生命扣除→致死保护。无原生盾的生物天赋盾以0盾护甲承伤；神族S06并入原生盾只过一次盾护甲。敌伤命中盾也重置脱战计时；自耗生命不算敌伤。
4. S10仅转移最终准备扣生命的部分，伙伴需半径8内、同族同家族、不是临时兵／正在死战。均摊后以`sharedDamage`直接扣伙伴生命，不能再次过伙伴护甲／盾／S03或再次转移；可正常触发伙伴保命。本体＋所有伙伴的扣血请求总额等于未分担时总额。英雄没有familyId不分担。
5. 致死顺序：A04降军衔→S09护符→S15死战，前者成功后不继续后者。A04/S09保护相关计数按每个战役关／无尽轮重置，跨关不回血。A04与S09每个判定成功后该关不再抽；失败不消耗成功名额，但S15若启动不再受上述保护。S15到期走必死结算，不能被新关、治疗、回盾、升级或形态切换取消。
6. 更新最大生命/护盾保留已损失量，`newCurrent=max(0,newMax-(oldMax-oldCurrent))`，生命活体下限1；不会因退天赋、切形态、读档免费回血或填盾。永久配置局内冻结，因此不能战斗中反复洗点刷上限。
7. 伤害分享、溅射、反伤、DoT和临时支援都带原始攻击/死亡ID。每次合法击杀最终只发一次奖励，不因APM两发、多人分担、弹射或同帧多伤重复记账。

### 5.5 战术进阶I—V：保留投入七名增援的主机制

**以下订单用途、预约和失败结算是已批准的TAL-D06实施合同，尚未落地。** 关间绑定一个活着、普通、军衔≥5、非紫精英且未到进阶V的同家族身体及方向，显式开启“后续付费同类乘员投入进阶”。每名实际付费、训练完成、能够安全接收的同家族最终体贡献1票；每7票进一阶，最高V。跳虫按一只实际付款身体一票；爆虫等完整进化配方只计最终体一次。

#### 5.5.1 满编进阶订单

复用现有生产订单、设施、空投和逐乘员支付账本，乘员新增`purpose=body/rankTraining/tacticalProgress`。进阶用途还保存`targetEntityId/targetGeneration/familyId/tacticalTierAtOrder/direction`；代次防止复用实体ID误给新身体。不是第二套生产系统。

| 项目 | 精确规则 |
| --- | --- |
| 开启条件 | 每家族同时绑定1名合法目标；目标不能正在死战。只有该家族身体和培养缺口扣除已有付款预约后均为0，才把尚未付款的下一份产出设为进阶用途 |

| 失败 | 最终落点/状态校验失败则全体原位，解除限制，不耗冷却；不能先改一半位置再失败 |
| 冷却修正 | 成功时应用并锁定M03冷却修正，总倍率不低于0.5；P-M05只改准备时长，不再次缩冷却 |
| 保存 | 保存origin/方向/目标/mapId/开放区域版本、参与ID、原命令、剩余准备时长及成功收据；读档暂停恢复，不推进离线准备，不读取新UI选点 |

运输不回血/回盾/回能、不清仇恨、不清负面状态，不以运输动画回调发伤害或决定成功。World完成唯一验证与位置提交；渲染只播放对应事件。

### 5.9 APM双击与武器模式边界

一次完整主武器AttackEvent正常生成原模式攻击，再追加同等单发直接伤害一次。每个原生完整周期共享`rootAttackId`，原生多击用`hitIndex`区别，APM追加包标`apmDuplicate`；渲染子事件不能再次调用伤害执行器。追加只命中本次主目标，目标在追加时死亡或失去合法性则落空；不改追踪坐标。近战用第二道短斩/撕咬反馈；火焰、线穿、巨像热能只追加主目标命中，不重画第二条范围；异龙不重复弹射；坦克不再炸第二次圈；多管武器按“整个攻击事件”增加一份原直接伤害包而非每个子事件再翻倍。无普通武器的支援单位不因此获得武器。爆虫自爆、技能、治疗、精英额外弹和持续伤害完全排除。

与[英雄稿](MVP10_COMBAT_ASSETS.md)一致的验算：阿塔尼斯原生双刀34＋34，APM只追加一包68，合计136基础主目标伤害；共用一次冷却和一次暴击判定。原生两刀按各自hitIndex生成各一次已批准范围，APM的68不再有范围、暴击后衍生伤害或命中特效链。菲尼克斯普攻72且附带35%时，暴击＋APM主目标两包各108，附带每目标仍25.2一次，之后分别结算防御。

航母母体不发攻击事件，截击机读取母体APM标记一次；不能母体倍率×2再由截击机第二发×2变四倍。连续光束以原本完整attackPeriod为结算窗，在该周期末追加一份该周期实际普通直接伤害，不按每个渲染tick重复追加。一次完整攻击的两包共用暴击结果，分别正常计算目标护甲；只产生一份合法击杀收据。

### 6.2 单活跃方案、九预设、资源守恒

每族保存3份预设，共9份；预设是配点蓝图，不预扣资源。全档只有一个激活种族/预设有实际投资账本；切到另一预设（含跨种族）按一次事务重算：

```text
newTotal = Σ(新主树等级×层价) + Σ(新微操等级×微操层价)
available = wallet + Σ(旧活跃方案每笔已付永久资源)
validate(race, ranks, predecessorGraph, mainTotal+microTotal<=80, microTotal<=17, available>=newTotal)
成功：wallet=available-newTotal；替换activeAllocation与investmentLedger；playerLevel=新主树点数＋新微操点数
失败：wallet、旧方案、玩家等级和所有账本完全不变
```

免费洗点可选主树、微操或全部；只退被清空部分的全部实际历史付款，另一部分不动。买一级每次先校验余额与前置再扣款，不能先扣款后发现第81点；撤销底层节点时只能连同失去前置的后代一起预览退款，一次确认全部处理。资源余额不截断、不换成经验，未消费余额一直保存。

| 事务例 | 结果 |
| --- | --- |
| 余额10，活跃主树投资97，切换110资源方案 | 107不足110，失败；仍余额10/原方案，绝不先洗空再失败 |
| 余额20，活跃主树投资97，切换110资源方案 | 成功，余额7；主树等级按新方案重算为80 |
| 活跃完整一条主线41点/59资源，洗该主线 | 退59资源，已投入主树点减41；不是退41，也不是退123 |
| 完整微操17级/64资源，单独洗微操 | 退64资源；三条主线配点不变，当前玩家等级下降17级，并释放共享80点中的17点 |

开局将所选种族、精确节点等级、规则版本和计算后投资摘要冻结到runSnapshot。局外之后切方案不能追溯改变已有战局。读档只读取该战局冻结天赋和difficulty，不读取新游戏界面的当前种族/难度/预设。旧开发档如何导出和停止支持由主计划决定；不能为了导入旧档在World保留两套战斗系统。
