状态：**M0 r6已获用户确认／待实施，2026-09-24**。本文件是首版实施基线，尚未改变运行规则、模型、存档或构建。真实SC模型、明显弹道、英雄增强与三族各一空中英雄已纳入确认范围；文内旧PROPOSED／待确认标签的首版数值随r6确认，后续改动须写变更记录。与[完整迭代主计划](MVP10_ITERATION_PLAN.md)及[运行流程设计](MVP10_RUNTIME.md)配套；地图几何、无尽入口和保存流程由运行方案定义。

## 1. 已核验的问题与边界

### 1.1 当前实现证据

- `src/render/units/animated-batch.ts` 对英雄、友方精英统一叠加金／紫色边缘发光；`battle-renderer.ts` 再画双环、竖线和英雄光环；`friendly-labels.ts` 常驻英雄大条幅、精英姓名。这正是本次需要替换的表现结构。
- `src/render/effects/battle-effects.ts` 目前主要按 `unitType` 发射效果，英雄／精英只额外添加金／紫枪口闪光。15名英雄分别使用不同模型，但多位仍借基础家族弹道，无法表达独立火力。
- 当前 `HeroDefinition` 已含15名英雄；`ELITES` 已含40个精英身份。普通攻击和技能真值必须由模拟事件给出，不能用特效增加命中、虚构多发或虚假数字。
- 当前15个英雄运行GLB均有文件、`available`记录及动画名；这只证明“有文件并可解析”。本次没有进行逐人物人工外观、逐动作、枪口及客户端对照验收。
- 本机最新正式包三族第一关短测约57.84／58.11／58.14 FPS，P95均16.8ms，但最大帧183—233ms。高压25普通＋3英雄＋300敌军约33.9—37.7 FPS。普通60+和高压60帧都不能据此宣称完成。证据：`reports/qa/ground-sparse-optimization-20260924.json`。

### 1.2 模型与战斗分离

1. 下表 `S` 是相对该身份当前已校准模型的**视觉倍率**，不是原 M3 的 `sourceScale`，不能与来源缩放重复相乘；碰撞、移动、射程、弹道半径、伤害均保持独立。
2. 模型沿原骨架挂点发射。挂点缺失必须登记并定向修正，不能把枪口永久放在脚底、模型中心或任意世界坐标。
3. 保留原材质、法线、阵营涂装和皮肤细节；取消按精英等级把全身染紫。可调发光限于炮口、反应堆、翅膜、刀刃等原有局部，默认不超过可见表面15%。
4. 不新造巨大附件来遮住原模型。附件优先使用原模型已有骨骼/子网格；新增实体附件必须有独立原素材ID、来源和人工确认。表中的流火、电弧、尾迹是渲染效果，不是假冒原模型。
5. 默认关闭常驻姓名条和大光环。精英：选中／悬停／手柄聚焦时显示名称、等级、效果；英雄：脚下极小槽号符号1/2/3，头顶生命／护盾细条，固定HUD保留头像与冷却。危险预警覆盖优先于友方标记。
6. 英雄名称提示只在首次招募、升级、阵亡和玩家聚焦时出现。技能按实际出手显示0.6秒的小图标提示，不再弹出遮挡头顶的长标题。
7. 镜头震动默认强度30%，可完全关闭；只对玩家英雄的重技能触发，位移最多1.5屏幕像素、100ms，全队合并间隔至少0.2秒。不开全屏闪白，不暂停模拟制造打击感。

## 2. 共用表现语法与性能合同

表中宽度、半径是世界单位；`W`表示纯视觉轨迹宽度。没有特别写入英雄战斗表的面积均**不造成范围伤害**。

| 通道 | 统一规则 |
| --- | --- |
| 普通子弹 | 枪口40—60ms；飞行曳光40—120ms；命中60—120ms。路径来自同一次真实射击，远近改变画面长度，不增加射程 |
| 实体炮弹 | 原弹体／可核实SC效果体＋一条尾迹；飞行跟随模拟速度，碰撞时消失；命中核心90ms、碎片最多250ms |
| 近战刀光 | 从原武器挂点沿攻击动作采样，最多6段，80—160ms；扇面伤害若存在，范围从模拟事件读取 |
| 治疗/回盾 | 源到每个实际受益者一条细束；无实际恢复不出治疗束，末端小脉冲；能量与生命回复仍模拟结算 |
| 范围技能 | 前摇只画细边界／方向提示；真正命中使用中心冲击＋向外消退的轮廓；0.35秒后消散，不以巨大常驻光圈代替弹道 |
| 控制技能 | 目标自身小轮廓／时停碎片，仅在实际控制期间持续；Boss抗性在效果强度与HUD说明中对应 |
| 永久外观 | 每精英最多1个低频局部装饰发射器；每英雄最多2个。静止不持续喷满屏粒子；高处尾迹不遮地面预警 |
|声音|使用已核实SC原音效、按英雄武器配置；同类自动攻击声音合并上限每秒8次，技能各一次，整个场景同时24路；没有专属源时列待核验，不伪称原专属语音|

**建议预算（PROPOSED，M4在目标机测定后冻结）**：

- 保留池化与批量绘制，普通/精英特效共享材质图集，禁止每发子弹新建材质或纹理。
- 活跃装饰/命中精灵总量上限仍以现有1280为上界；其中英雄保留160、精英160，其余960可共享借用，不能凭新方案无限增大池。
- 常驻特殊身份发射器精英每名≤4个可见精灵、英雄每名≤8个；发射频率≤8Hz。非视口内停止装饰生成。
- 飞行轨迹最多384条：英雄预留96、精英64，其余224。普通高射速火器可合并为每0.1秒一条连续视觉束，**伤害事件一发不少**。每条束仅展示原实际命中点，不能扫向未射击敌人。
- 英雄/精英新增特效总计≤12个额外draw calls；新增CPU提交P95≤1ms，GPU增量P95≤1.5ms（独立计时可用时）。达不到先减碎片/尾迹段数，不删主弹道、技能范围边界、敌方预警。
- 渲染优先级：敌方致命预警 > 英雄正在飞行的主弹体与命中 > 玩家主动目标提示 > 精英主弹道 > 普通命中 > 装饰余烬。降级只动表现，不动敌人数、攻击次数或60Hz模拟。
- 单精英持久外观透明覆盖≤其投影包围盒的20%；单英雄≤25%；每个普通攻击命中特效总透明面积≤1.5倍目标投影，重技能按真实范围例外但不得用不透明平面遮地。

## 4. 原15名英雄的战斗强化（一级值，全部PROPOSED）

### 4.1 统一规则

- 三族各六名候选；本局仍招最多三身份、三个技能槽1/2/3、每英雄等级1—5。只强化既有主动技能，不新增第二套技能键、自动召唤军队或英雄能量。
- 沿用 `heroStats` 成长：生命/护盾每级+20%；普攻理论DPS每级+25%，攻速每级+8%，单发以现有公式拆分；技能伤害/治疗/护盾每级+25%。控制时长、范围、冷却不随等级增长。
- 基础攻击新增范围只在本节逐行写明的英雄生效。每次主武器攻击有唯一 `rootAttackId`，原生多击以 `hitIndex` 区分；同一原生击的范围扩散对同目标至多一次。主目标100%，附带目标按表中倍率；附带目标同阵营合法敌人、同目标层、可攻击地形，不跨悬崖；选取按距主目标近→实体ID。
- 普攻不能据隐藏目标定位，也不能从隐形目标开始弹射；已经确认的范围伤害可击中区域内隐形敌人，且不显形。技能选点必须可见，固定范围飞出后不持续偷跟隐藏坐标。
- 暴击与APM共用[天赋设计5.4及5.9](MVP10_TALENTS.md#54-盾分担保命与叠加)的主武器事件合同：每个 `rootAttackId` 只掷一次暴击，原生主目标直接命中和APM追加包共享结果；新增衍生溅射／扇面不暴击、不再次生成溅射、弹射或命中特殊效果。衍生量从已应用英雄等级与获准属性层、但尚未乘暴击且尚未过目标防御的原始直接伤害按比例生成，各目标各自计算防御，不能拿主目标已扣血再乘一遍属性。
- APM只为整个原生攻击事件追加一份同威力主目标直接伤害包，共用原攻击冷却；额外包不扩散、不穿透、不弹射、不再触发APM。技能、持续伤害、治疗、回盾完全排除。阿塔尼斯原生两刀各34、同周期总68：无其他修正时APM只加一包68给原主目标，不给两刀各追加两包；原生两刀已有范围照各自hitIndex处理一次，APM不新增范围。菲尼克斯普攻72、附带35%：暴击/APM全有时主目标两包各108，附带仍每目标25.2一次，之后各自过护甲；不能变成附带37.8或两次附带。
- 衍生伤害保留 `rootAttackId/sourceId/damageKind`；APM额外包另有 `apmDuplicate` 标记；每个敌人的死亡收据只一次。英雄击杀不转送普通兵晋升，不因范围、APM或同帧多包递归奖励。渲染可为两包画两次真实反馈，不能用视觉子事件再次调用攻击执行器。伤害分享等独立系统照原规则。
- 英雄受统一主天赋影响时，从英雄基表→英雄等级→获准天赋/科技顺序组合，卡牌按项目既有属性层次处理；同属性同类天赋先加后乘一次。不能因 `baseFamily` 再吃一次普通家族成长、精英模板或家族专属增益；每一来源是否适用由天赋/卡牌的明确对象决定。首次招募升场使用新基础HP，局中提升最大HP/护盾保留已损失量。
- 天赋只读取本局 `runSnapshot` 冻结的种族与节点等级。新招募、英雄升级、读档和派生缓存重建均从基表及同一冻结配置重新计算，禁止在已经加成的实体数值上再乘一次。局外洗点/切预设不能改变本局英雄。主天赋S01对英雄主动伤害/合法治疗、神族对应回盾只应用一次；S02/S11/A11/S05不再覆盖技能；M03冷却修正一次、总倍率不低于0.5。上述边界与天赋稿同步审批。
- 无合法对象仍不耗冷却；原付费复活机制不变；能力/视觉事件保存各自阶段，读档不重发伤害或额外回满冷却。

### 4.4 强度验证而非单看倍率

- 三族每位英雄各在一级/三级/五级做单体、5目标、混合地空、护甲、Boss、空目标八类固定夹具；记录10/30/60秒伤害、有效治疗/回盾、控制秒数、攻击利用率。零天赋先测，冻结天赋后再加满足前置的合法80点方案样本；三主线不能同时点满；微操占用同一个80点上限，英雄夹具使用合法混合配点。
- 设计目标：输出英雄一级30秒单体DPS较其当前实现提高35%—65%；范围英雄5目标实际总输出提高但最多不超过新单体理论DPS的2.5倍（技能另列），支援英雄按有效救治与存活贡献评估。不是承诺所有英雄同时35%—65%；低于/超过目标必须在平衡记录中说明并由策划批准调整。
- 任何英雄不能以“对Boss无限控制”“无消耗全队瞬间满血”“对建筑无视限制”满足强度。三个英雄共享控制按同类取强/刷新不加时，Boss始终按表减免。
- 用户实玩验收必须能回答：谁在攻击、主弹体朝哪里飞、命中了谁、其英雄职责是否比普通兵明显。数值夹具不能替代这四项。

### 9.5 截击机及代码实现依赖

### 9.6 玩家爆虫自爆后停顿5秒

- 仅玩家普通／精英爆虫自爆后保留原身体、生命、军衔和精英身份；跳虫不获得自爆。敌方爆虫照旧自爆死亡，章节敌波预算不改。判别使用team=player且race=zerg，不能把旧owner=zerg当玩家虫族。
- 爆炸照既有半径、目标层、护甲、地形和科技只结算一次。玩家爆虫不对自己施加自爆致死伤害，不产生死亡、退役、返矿、重招或免费培养收据；敌方攻击仍能将其击杀。
- 写入recoveryUntil = simulationTime + 5秒。期间零移动、零普攻、零主动能力、零追击；仍可受伤、被治疗、被索敌，不回满生命。原命令保留，期满重新校验；下次爆炸还须满足原武器冷却。不能利用APM、目标变化、精英特化或读档重复爆炸。
- 暂停、关间、加载不推进计时；读档恢复剩余时间。友方爆炸保留模型，用原Flail或短缩身动作与实际爆芯反馈，不能播放死亡动画；恢复期被敌军杀死才播死亡。敌方仍播死亡。HUD以小型倒计时显示恢复。
- 普通/精英各爆一次、同帧多爆虫、恢复期被杀、关间保存恢复须单次结算；第300个60Hz模拟步后恢复。友方精英baneling.2的＋25%只给一次真实爆炸。
