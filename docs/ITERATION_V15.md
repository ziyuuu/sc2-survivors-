# V15：合批、五兵种、精英与英雄

## 敌方精英与 Boss

原波次按兵种预算保留，时间事件从预算内抽取普通个体升格；简单波量与守军累计减半，精英事件单独累计减半，Boss 两档相同。原四种普通敌人预算不变，刺蛇从第七关第三波出现。四次 Boss 在 3/6/9/12 关固定登场，存活者保留 HP、技能冷却跨关。

预警和弹道由固定模拟计时。冲锋方向锁定、扇形针刺同轮每目标至多一次命中、胆汁落点不追踪；技能检查地形。Boss 独立于虫巢胜利目标。死亡资源与单位奖励只结算一次；精英 40% 掉卡，Boss 必掉紫／橙单位奖励，情报影响之后抽取。

本轮明确的网页适配参数：冲锋长度 10、速度 12；酸液扇区距离 7、半角 0.6 弧度；针刺距离 10、速度 16、相邻弹道夹角 0.2 弧度；胆汁散布中心及半径 2.2 的固定点。不是 SC2 多人原数值。模型轮廓光是网页效果，原模型及动作保持不变。

完整规则见 [DESIGN.md](DESIGN.md)，最终测试、浏览器、离线与性能证据见 [QA.md](QA.md)。阶段测试不代表人工视觉批准。

## 本轮阶段

1. 劫掠者/刺蛇原数据、动画和资源管线。
2. 三组批次、整批筹资、参与建筑快照、多人仓及简单累计减半。
3. 15 个唯一精英、替换容量与差异化技能、补给情报。
4. 三位额外席位英雄、主动技、同卡晋升和关间付费复活。
5. 四种预算内敌方精英、四次 Boss、预警和一次性奖励。
6. 原武器表现、按需资源/暂停恢复、窄边带路由、多人仓辨识、触屏布局、独立素材读取和整体验证。

没有重新加大旧普通敌军预算，没有加入按阵容自动降难度，没有用自动操作通关来定义普通难度。
