## 1. 固定范围与循环

沿用 TypeScript＋Three.js＋Vite、World 单一玩法状态、60 Hz 固定模拟。开局三族选一，本局固定。每族10普通家族，最多五家族、每家族五身体，普通军衔1—5。英雄、工人、召唤和模式不重复计数；精英占家族普通席，每家族最多一个；当前运行15英雄按种族五选三，身份登记后阵亡也不腾名额；1.0目标每族各追加一名高阶空中英雄：人族战列巡洋舰、虫族HotS利维坦、神族净化者航母；三族各6候选，本局仍最多招3。

开局：人族1枪兵、兵营、50矿；虫族2跳虫、孵化场／血池、50矿；神族1狂热者、传送门、0矿，均0气。身体＋钱包100矿，不假定战力完全相同。虫族默认满足菌毯，仅应用自身实际菌毯效果一次。零天赋具有全部普通配方、基础支援和主动侦测入口。

完整循环：选择种族／难度／天赋→战斗与持续生产→实际接收新家族且满槽时暂停换兵→关卡结算／下一关威胁→付费发展三选一最多买一项→未来生产／驻地服务→免费强化三选一取一张→下一关。第18关胜利后撤离或无尽。关间冻结训练、冷却、能量；伤损、敌军、订单和空投跨关保留。

### 战斗与英雄

- 死神跳崖、巨像越崖、飞行和闪烁使用各自查询，仍受开放边界、碰撞和合法落点限制；不能共用忽略地形。手动架收、埋出、变形不重置伤损／能量／培养／当前冷却，不自动变形解堵。
- 医疗艇生物全效、机械1/3；科技球机械全效、生物1/3。双属性主系取一次，按实际恢复生命耗能，排除自身、建筑、尸体。
- 原生护盾、临时护障、生命分开；盾甲／血甲、受击延迟分别保存；回盾不回血。敌伤含持续伤害及护盾受击，中断脱战恢复；自耗生命不算敌伤。
- 截击机由母体管理，无独立编制／培养／奖励；初始数、死亡、付费补机和时间遵守完整配方。多虫后／医修／胆汁／风暴共享目标或效果预约。
- 女妖研究后手动隐形，潜伏者埋地隐形，泽拉图／沃拉尊先天隐形。其他英雄不顺带扩职责。未侦测不能普攻、指向或自动范围选点，既定范围可伤隐形但不显形；失去可见性不能继续追踪隐藏坐标。
- G初始主动侦测：锚点静态半径12、8秒、20秒冷却，无资源费；三族仅表现不同。第4关起固定侦察守军，Boss／主巢半径12、6秒、18秒固定周期扫描，提前1秒预警，不读隐藏玩家位置触发。
- 英雄等级1—5，技能数值每级+25%，范围／冷却／控制不成长。无合法目标或受益者不耗冷却、不改移动目的地。按招募顺序绑定1／2／3，阵亡升级不复活。复活250矿／100气×[1＋0.25×(等级−1)]，下关部署、完整冷却。菲尼克斯机械，其余新增英雄生物。

## 3. 持续生产与空投换兵

配置与编制分开：每线两个输出按顺序交替、单线一批训练／在途；小开关只影响未来未付款批次。新家族可先生产，训练＋在途预留最多五身体；全灭仍占家族槽。单批最多五乘员／五培养，统一容量覆盖身体军衔、付款预占、未消费继承和已承诺奖励。

虫族每设施只参与基础／进化／飞行之一，同时三序列需三设施，忙碌设施不双计。爆虫／破坏者／潜伏者按基础体＋进化完整价格与时间；跳虫双生、尾单可单体付款但配方时间不变。

触发换兵在首名新家族实际安全出舱前：空槽自动登记，满五槽冻结全模拟；无出口不先删旧兵。按准备时间、舱ID、乘员序号处理。可替换一个旧家族，或拒绝本批并关闭未来生产，后者不退款、不删除别的已付舱。

继承公式 `1 + floor((旧等级 - 1) / 2)`：1→1、2→1、3→2、4→2、5→3。存活普通每人一份，精英仅一级，死亡及旧未出舱成员不提供。记录按继承等级降序／旧ID消费，当前已付款身体立即用一份，其余后续正常付费新身体使用，不能给同体重复加级。再次转型，存活与未消费记录合计最多五份再折损；死亡不返还。

旧订单：训练中／完成未投放退实际逐人付款；投放未出舱弃置不退、守军保留；出舱者退役，不触发击杀奖励；免费领取权结清不造现金。关闭旧生产并移除输出，保留建筑／科技／家族被动，换回不还原身体军衔。其他四家族和英雄完整状态不变。

换兵先重验请求、版本、出口，再一次结清付款、退役、登记、消费、收据、通知／保存；失败无副作用，重复请求不重复退款／培养。旧总价按原乘员顺序分摊余数，合计严格一致。暂停／选择／失焦／加载恢复均重置墙钟，不补跑。与关卡结束同刻时先处理必要选择，再结算一次。

## 4. 发展、强化与Build

发展A优先目标／当前可执行前置；B缺能力×4／深化×2；C新分支×4／扩产×2；未标目标时A关联上场／未来产出×4。同组去重，不足三项显示实际数；买不起仍展示缺额。标记变化不重抽当前窗口。常规三级研究125/50、200/100、275/150，二级6关后、三级12关后；特色125/75。雷神／雷兽／航母完成9关可配置、第10关生产。

每章各一次免费发展／强化刷新，不结转；每窗口各类最多另付费一次，发展50＋10×(章−1)矿，强化30＋10×(章−1)矿。复活和生命修复不占发展动作；修复完整配方×军衔×缺血率×40%，各资源向上取整，英雄以复活价为基准，提交重验，只修生命。

强化先筛种族、科技、对象、互斥、上限、付款容量。第一张立即收益；第二／三张核心50%、协同30%、通用／未来20%，类别内上场×3、开启未来×2、其他×1。未入编仅生产支持，不发普通新兵／培养。同组去重且不全为同类纯数值；近两窗口未选×0.25，上次可叠效果×0.5，同家族多精英变体不提高该家族机会。

白绿蓝紫橙：1—5关45/35/16/4/0；6—11关25/40/27/7/1；12—17关15/35/35/12/3。三窗口未展示蓝以上，下次至少蓝；6／9／12关保证英雄候选、另两张至少蓝；满身份仅升级原身份，全满合法橙替代；15关至少紫。刷新不推进保底且仍满足指定品质。6／12 Boss预算并入本窗口，不多送卡。
