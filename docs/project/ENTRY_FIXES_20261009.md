## 实施边界

- 加载器使用单次入场的递增进度，将资源、完整部队、音效、地图/GPU 和最终校验依次呈现。音效仍可并行准备，但不能倒退可见步骤；未改变显示百分比的细碎回调不再反复重建 HUD。
- 原有完整种族部队、敌军、精锐、英雄及变形/死亡资源保持；同一组原模型先批量准备字节，再交由原加载器解析。新场景只提前准备本局选中的原地图，并显式保留无尽地表依赖。已经缓存的模型不额外等待动画帧。
- 原生取消逻辑继续废弃未提交票据；HUD 同时清除失效的检查存档预览并返回读取存档页，重新选档后仍须走原校验与提交，不放宽票据验证。
- 投递建筑的原血条内层被旧 margin 推出 3px 高容器，现归零并保留真实血量比例；补充生命读数语义。未改生命、伤害、落地、接收或死亡规则。
- 菜单覆盖层统一计算逻辑画幅。手机横屏在至少 1280×720 的参考画幅上等比缩放，竖屏在 480px 逻辑宽度上重排并缩小；战场摇杆、技能及其他战场操作区仍使用原布局。
- 商店/建设/休整为页头、可滚动内容区、独立页脚；“返回前线”保留原标签和动作。卡面包含原图、身份/增益、名称、类别、说明、价格、操作及折扣/状态；竖屏额外服务有明确行，长详情仍由原展开/滚动交互访问。
- 作战部署沿用正式细框，显示“当前续局”、真实概况、覆盖说明与“导出当前续局”。导出和新局行为不变。
- 离线打包仅在原 GLB JSON 与二进制体边界增加无损共享分块。保留所有源字节和填充、模型、动作、贴图、声音、UI 原画；最终体积以实际生成文件测量，不用理论去重值代替。
