## 流程

三族共用16个教学目标及旗舰收尾，补齐必要的原生页面入口点击。实际点击数以本轮三族录屏为准；满血时使用原“返回”承认无需修复。

1. 出发后先询问，接受才准备训练场。救工人时展示自动攻击→击败跳虫→击败工蜂→留出观察掉落时间→拾取100矿50气，突出真实增加量并展示约0.5秒后关间。
2. 正常关间首页查看发展说明、建基础设施→玩家点击“设施调整”并应用→点击“前往补给”→购买两席基础兵卡→下一段。页面可停留阅读，没有催促计时。
3. 第二段先等10秒，再实际扣一席训练费用、准备原生载体→守护到士兵真实入队→击杀精英蟑螂，固定两件白装→观察掉落、拾取并展示入包结果约0.5秒后关间。字幕不提前宣告掉落数量或品质。
4. 正常关间首页点击休整→原报价修复或承认满血→返回→点击背包，查看并穿散件→返回并撤离→从原旗舰、仓库入口找到并安装同件模块→完成结果展示后结束。
