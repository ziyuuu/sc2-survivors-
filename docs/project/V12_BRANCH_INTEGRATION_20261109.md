- 原画质首战原先会一次准备 1,924 个音效，Chrome 在 Blob 驻留约 591.5 MiB 时报告 `ERR_BLOB_OUT_OF_MEMORY`。现在按当关声音组准备，其他声音在实际使用时读取。原画质首战和刷新续局均进入战场，准备完成时的 Blob 驻留分别为 368.5 和 368.4 MiB。冷启动出现部分磁盘缓存未写入提示，检查点保存和恢复成功。
- 离线 HTML 打包器曾把 82 条教学 MP3 标为 PNG。修复后，Web 和离线构建共用媒体类型判断。已从最终 HTML 解码并核对 82 条 MP3、3 张顾问头像的类型、长度和 SHA-256。断网 Chrome 播放了人族邀请语音并进入首战。
