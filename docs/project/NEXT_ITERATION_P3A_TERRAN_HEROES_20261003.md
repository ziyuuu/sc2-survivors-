应用层只读采样画布、相机投影和实际可见固定HUD区域，转换为地面/空中各自四边形与遮挡多边形。World仅接收纯数字 `BattleView` DTO，验证后选可见/可射击敌人并冻结ID。无有效DTO不施放、不耗冷却。之后折叠、旋转、移动相机、侦测变化不追加对象；敌人在命中前死去则不重复伤害。键盘、按钮、触控及标准手柄都通过共用指令网关注入当前视野。
