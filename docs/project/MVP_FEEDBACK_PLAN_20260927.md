## 二、动作与性能档

### 2.1 正确播放，而不是伪造缺失帧

新增逐模型`AnimationProfile`，明列移动、攻击起手、发射标记、收招、持续施法、死亡及形态。普通神族10家族、死神及其三型精英逐项核验；原模型缺少的动作必须标记，不以`attack=idle`通过验收。

- 攻击可视时钟由稳定的`shotSequence/attackId`和模拟发射时刻启动，独立于下一步的idle/move；既有枪兵/劫掠者叠层纳入同一策略。
- 前摇姿态对齐真实开火，后摇只影响表现。命中冷却、移速、玩家移动命令、实际锁定窗口不因修动画增长。
- 使徒等长片段核对原actor/动作段后定义有效区间；巨像显式使用准备/开火/方向行走；高阶圣堂分别配置灵能弹和风暴；虚空分起手/通道/结束；航母由真实截击机输出，不添加母舰普通炮。
- 同时移动且允许开火：优先原上身叠层；不支持叠层的模型用短促射击姿态/真实弹口过渡，角色位置继续插值，不重置行走命令。
- 死亡、埋地/变形和爆虫恢复态优先，不能在死模型上补播射击。读档恢复未结束姿态时间，不重放已播枪口光。

### 2.2 两个动作档独立于清晰度

| 设置 | 性能模式·完整动作（默认） | 节能模式·降低动作更新 |
| --- | --- | --- |
| 原动作片段 | 完整保留 | 同样完整保留 |
| 姿态采样 | 现有24Hz骨骼烘焙＋每显示帧插值 | 用同一骨骼数据按15Hz显示姿态，关闭姿态帧间插值 |
| 移动/镜头 | 每显示帧插值 | 每显示帧插值 |
| 主弹道/命中/敌预警 | 每显示帧，跟真实事件 | 同左，不跳掉出手和预警 |
| 模拟/判定 | 60Hz | 60Hz |

启动、攻击、受击、死亡及模式切换的事件首帧立即呈现，不等待下一次15Hz配额。暂停冻结动画时钟。档位只存用户设置，不进战局难度/天赋；切换不重新加载World。UI说明“完整动作”不等于源素材60帧，也不保证设备60FPS；原清晰度设置单列，避免混淆。

## 三、三族救援与投放

| 种族 | 救援成功的经济单位 | 空投载体候选 | 出兵表现 |

经济单位计数改为中性的`rescuedWorkers`，其显示身份从`RunConfig.race`派生；若当前持久化需要字段调整只升当前schema并明确开发档失效，不构建兼容树。各族零天赋每名收益保持当前0.1725矿/秒、0.046气/秒，实际收益仍走现有天赋解释器和难度修正。死亡/救援失败不重复记账，敌方经济工蜂与获救友方工蜂区分阵营。

素材门槛：核验SCV/工蜂/探机与三个载体的锁定来源、动作、材质、出口挂点及发行散列。当前probe/pylon/barracks可玩主体尚未在本次确认；现有静态hatchery不能当作完整孵化动作证据。新增原模型进入资源闭包和加载协调器，缺失时留在可重试加载页。不得用别的单位改名或几何体交付。

## 四、简单难度：生命与数量拆开

**用户纠正直接落地的前关合同：同关普通最大生命×0.5。**本稿建议将这一合同一致应用于全部18关和无尽的普通敌人、守军、精英、Boss/领主及敌建筑；这样没有第7关突然取消半血的隐藏规则。扩展范围列为待审参数，不据此先改代码。

```text
ordinaryReference = 普通难度下同关/同种/同阶/同出生来源/同无尽成长序号的最大生命
easyMaxHp = ordinaryReference × 0.5
```

保留浮点精度，UI再格式化；不能显示9血实际仍18。护甲、攻击力、攻速、敌人数、奖励保持各自原难度合同。本轮不把普通难度调高制造“减半”。当前简单较低的章节生命成长从生命参考路径中移除，防止再乘一次导致低于50%；非生命成长不连带改变。

将普通波次、空投跳虫重写、特殊敌人独立HP、主巢/扩张巢、无尽连乘都接到唯一生命入口。`nativeStatScale`存应用后的合法比例，刷新属性/读档不二次乘。后续精英晋级按同一参考顺序计算。友军、英雄、救援载体与获救工人不受敌方50%影响。

首轮自动验收至少覆盖1—6关全部可生成类型，以及18关×四难度的代表矩阵；普通难度改前改后逐项相等。例：第一关跳虫18→9，第四关蟑螂153.7→81.2（同关普通162.4）。数量预算仍简单0.5/普通0.9，明确不是生命倍率。

## 五、关间完整流程与交易

### 5.1 状态机

```text
首次关间：方向选择 → 发展三选一（可跳过） → 随机付费商店 → 下一关
后续关间：已记住方向的发展三选一 → 随机付费商店 → 下一关
                            ↓ 改变方向
                         方向选择 → 回到发展
```

第一次发展购买/明确跳过后立即切到商店；资源加载或必要精英选择按统一暂停处理。商店必须有“继续战斗”，可0购离开，不强制买完。维修、复活、生产配置继续可操作，不冒充三张随机商品或额外建筑行动。无尽整备/轮末使用同一个窗口机制；不重复发战役奖励。

方向是未来发展候选的筛选，不是拆掉其他建筑或停掉其他产线。每族三方向：人族兵营/重工/星港；虫族基础/地面进化/飞行；神族传送门/机械台/星门。第一次主动选择，无自动暗选。每次只执行一个具体发展动作，R10合法双建仍属该动作的一次结算。

### 5.3 随机购物

- 生成3张付费商品，每张可买一次，三个都可买；买后原格显示售罄，不自动补货。
- 玩家主动刷新才生成下一页。可无限刷新，但每次先校验付款；买过1/2/3张都能刷新，刷新会丢弃未买项，已买效果保留。退出重进/读档不补货。
- 候选遵守本族、科技、席位、培养预付容量、效果上限；不因钱包不足隐藏。某项购买导致另一项无效时给出原因，可刷或继续，不吞钱。

### 5.4 刷新和原天赋

候选恢复原版递增：同一关间发展/购物共享`refreshCount=n`，首次50矿，此后90/130/170…；每次成功刷新，包括使用免费天赋，都使n增加1。新窗口归零，读档不归零；改变方向和取消都不算刷新。

```text
付费刷新 = max(10, ceil((50 + 40*n - 20*R03等级) * (1 - 0.1*R12等级)))
```

发展页保留每窗口最多一次付费刷新；购物页取消付费刷新上限。该次数安排是候选细则，用户只明确购物无限刷新。R06每次关间1/2/3次免费刷新两页共享，使用时价格为0并明确显示天赋来源，不再额外每章送2次。发展付费刷新次数与方向共用，不靠切换方向增加。

| R06 | 每次关间1/2/3次共享免费刷新，成功刷新也推进n | 等级、层价、前置 |

## 六、Boss战场掉落

触发在Boss真实死亡，显示落点/品质与短提示；拾取直接获得已生成的合法奖励，需要精英选型/容量决定时进入可取消的拾取事务，不能跳关间购物。第6/12关提前击杀即可掉落，不等关末。主巢只在真实毁灭时结算一次；队长不因同属特殊单位变成Boss必掉。

**用户已明确确认：每次1件，80%紫／20%橙，橙替代紫。**这部分不再待定。每个Boss死亡先独立决定品质，再从合法奖励池生成一件。不恢复不存在于当前玩法的旧情报升级。

生成时确定奖励与随机结果，以`runId + enemyId + deathSequence + source`保存收据；重复伤害、死亡回调、APM、读档不再发。R14独立来源可以额外产生掉落，但不能冒充Boss原本掉落。

奖励按本族合法精英/英雄/高品质强化生成；全部合法目标满额时，候选兜底为250矿/100气（旧Boss兜底数量），标注“满额兑换”，不扣钱。关末未拾取奖励保留，关间列出待领取；最终撤离/无尽换场前允许领取或明确放弃，避免清地图静默吞掉奖励。无需空间选择的奖励也不重复发放。

### 7.2 体型

候选所有大型空中英雄平面最长边上限5.5世界单位，在姿态范围核验后取固定模型系数；不是每帧按包围盒缩放。现待机基准大和约8.908→5.5（乘0.6174），利维坦约9.810→5.5（乘0.5607），净化者约5.03保持。英雄仍大于常规尺寸队员，不要求大于雷神/雷兽。身体碰撞、实际射程/伤害范围不变，弹口与标签跟随新模型变换。

### 7.3 真正的发射→飞行→命中

- 每个普攻/技能有稳定ID、起点、目标点/目标ID、目标层、发射/命中时间。命中效果由真实命中事件驱动，命中前不能先爆出火花。
- 瞬时判定武器用当帧曳光/光束；不画慢弹体后在到达前扣血。现有真实飞行技能复用其在途状态和命中集合；需要改变弹速/判定的另立数值变更，不藏在renderer里。
- 以世界矩阵求挂点，含朝向、英雄比例、模型高度、飞行高度；退化挂点明确配置，不在地面生成飞船炮口。目标死亡时的后续飞行/消失遵循真实弹体规则。
- 友方技能不再把巨大圆环当主体。必要范围提示只在瞄准/短暂施放出现，真实命中以弹体、切割、火焰/冰霜/核爆表现；敌方危险预警保持最高可读性。
- 效果池优先级：敌方预警/主弹道/实际命中核心优先，外围碎片与烟尘先降；按池统计各类丢弃，不能只看总数。控制同屏透明叠加，不全局盲目把尺寸/寿命翻倍。
- 保存只记录影响未来模拟的在途物/收据，纯视觉缓存重建；已经结算的光效不在读档后重播。
