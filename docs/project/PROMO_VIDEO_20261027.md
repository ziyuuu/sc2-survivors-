# 四分钟宣发视频 · 第一版

状态：待验证（第一版已导出，待用户观感审阅）。2026-10-27 用户批准《从求生，到反攻》四分钟方案，并允许使用游戏内英雄语音表达情绪。无画外音，实机为主；本轮制作本地可审阅视频，不发布。

编号 PROMO-01。独立宣传制作，不增加 MVP 功能包，不修改 V05/V06 验收结论。

## 制作范围

- 1920×1080 横屏，240 秒；真实游戏渲染、游戏战斗声及英雄原声，少量标题与短字幕。
- 使用隔离内存账户、独立浏览器和录制入口；不读写真实玩家存档，不改正式游戏 UI、玩法数值、镜头默认设置。
- 可编排合法规模的代表阵容及遭遇以拍摄，保持原有战斗/渲染代码。编排镜头不作为自然游玩、性能或平衡验证证据，不宣传为一镜到底自然通关。
- 制作源码放 tools/promo-video；录制/中间材料放 reports/local/promo-video-20261027；当前审阅成品放 dist/promo-video-20261027。

## 验证与收尾

核对时长、视频尺寸、可解码、画面与字幕、音画同步、英雄语音来源及播放音量。只记录实际执行检查；用户对第一版观感的反馈保持待验证。

## 制作过程中的修正

- 首轮人族遭遇过密导致很快战败，改用合法规模的较高军衔阵容及较小遭遇批次重拍；没有改伤害、耐久或冷却。
- 独立入口连续切换场景时漏调正式入口同用的 `view.resetRun()`，出现上一场特效残留。仅修正录制入口的生命周期并重拍受影响片段；不将此记录当成正式产品缺陷。
- 舰装菜单无战斗声时使用静音底轨配乐，不伪造界面音效。英雄原声来自既有 `combat-audio.json` 音库及当前发行资源，逐条来源保存于制作输入。
- 配乐由 `tools/promo-video/score.py` 原创合成，仅器乐，无人声；所有游戏画面由本地浏览器实时渲染录制。视频输出帧率不作为游戏实时 FPS 指标。
