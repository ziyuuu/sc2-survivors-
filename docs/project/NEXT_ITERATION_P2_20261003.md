# P2 战斗操作与商店诊断 · 2026-10-03

用户明确要求“开始p2。除了维京还要查其他按键入口”，随后批准实施方案。范围是全部战斗操作入口、方向输入绕行、模式状态及商店合法池诊断；菜单、天赋、保存界面的全入口重设计不在本阶段。

## 指令入口

点击、触控合成点击、键盘和手柄均通过 `ui/controls/battle-actions.ts` 的只读状态与统一施放入口，再由 World 验证并执行。对应存活普通/精英存在时显示家族指令；英雄、临时单位、未到达乘客不触发这些按钮。未解锁、冷却、能量不足、阵亡、转换中、混合模式、落地受阻使用同源状态显示。常用指令按钮保持 DOM 身份，冷却更新不重建；保留原肖像/图标、小键标、倒计时及简短标记，详细原因按需查看。

战斗控制台/小地图的普通焦点不吞全部热键。输入框、下拉框、文本编辑、修饰键及模态决策不泄漏战斗操作；保留队伍箭头导航。按住重复事件不施放。回车确认选点，Esc优先取消选点、取消已提交转移、关闭查看器、再暂停。闪烁、转移、战略及神族战术均有可见确认/取消面板。新选点清除旧选点和旧点击命令；移动、旋转、失焦、暂停、读档及素材准备清除方向缓存。

手柄保留原六扇区首页（推进、单位操作、侦测、三个英雄槽），按在场可见指令增加六扇区分页。现有标准 LT/RT previous/next 映射翻页，A/X确认、B取消；末页空扇区不映射到其他动作。失去单位清除选择，翻页不自动施放。转移选成员/调整落点与原校准保存格式不变。被选中的滚动区按钮自动滚入可见范围。

## 模式与移动边界

模式请求与实际模式分别保留；未完成切换可返回当前实际模式并立即取消计时，已完成切换的反向操作继续使用原转换时间。切换不改 HP/原生盾、能量、下一次射击时间、武器周期、原技能金额/冷却。维京只在当前位置用真实地面半径检查边界、地形、障碍、地面身体、投送舱、堡垒、虫巢、经济目标和投送预留。受阻保持飞行并等待；没有找空位瞬移。多架维京的依次完成检查防止叠落。非法模式、技能、兴奋剂或移动在验证前不取消已有合法转移。

方向输入沿实际速度做0.5秒短距离前探，受阻时使用原可达路径查询与邻近候选；缓存最多0.25秒，方向变化超过30度、地形/关卡/速度变化或到达即重算。缓存不成为点击目的地、不消耗随机数、不保存。松开不继续走缓存，也不恢复旧点击目标；空中/死神/巨像的原独立单位通行能力和地面小队锚点保持原边界。

## 商店合法池与诊断

实际路径是 `draftContext → reinforcementPool/candidateWeight → supplyEligibility/canSupply`。检查种族、生产设施、研究、数量、活体席位、已付款未到达容量及立即部署位置；提供只读原因和数值。检查不耗随机数、不看钱包、不中断付款。跳虫按双体的一对席位计预留。

事实修复：原商店救援空投把“同产线任意未结批次”当作禁入条件。实际账本支持多个独立 shop-supply awaiting/risk 投送，设施训练及自动生产串行规则没有被改写。专项验证两笔同产线付款各保留原金额，独立生成投送舱、各释放一次，重复释放拒绝，满席位仍禁入。因此仅移除商店这项误过滤；不改训练、退款、毁舱损失、家族替换及免费投送。

`tools/diagnose-next-p2-shop.mts` 记录三族×基础/中期/满员/已付途中四夹具×种子1..1000，共12000页。完整候选ID、合法原因、按品质条件权重、桶、家族合并出现次数和页内重复率写在本地报告。每种子以0资源及999999资源反事实对照，商品、折扣和价格完全相同。报告权重是该品质合法池的条件权重，不能读成无条件最终概率。

品质先抽、合法趣味牌25%/其他75%、原70/20/10桶、补兵50/35/15层级权重、精英分摊及历史惩罚保持原式。家族合并只用于诊断；数量、投送/直接形式仍按原历史key。重复权重的重设计未实施，不能从诊断擅自降低或保底某家族。
