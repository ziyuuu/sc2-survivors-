## 1. 现状与设计目标

当前已经有原版武器路由、专属英雄攻击、精英火焰和飞弹、热量／过载状态，以及末日改装层。因此本次是沿这些真实表现补充辨识，不把它们判定为完全缺失。源码盘点能证明接点存在，不能代替当前画面的人工验收。

主要接点：

- `src/data/combat-fx-routes.json`、`src/render/effects/combat-fx-profile.ts`：原武器、形态、弹体及效果归属。
- `src/data/terran-elites.ts`、`src/simulation/combat/terran-elite-runtime.ts`：30 类精英的真实攻击、蓄力、变形强化、减益和恢复。
- `src/render/effects/terran-elite-effects.ts`、`terran-elite-materials.ts`：现有弹线、火面、火箭、残火和局部亮点。
- `src/data/heroes.ts`、`hero-upgrades.ts`、`src/render/effects/hero-basic-effects.ts`：六英雄及已确认的 III/V 级攻击变化。
- `src/data/terran-doomsday*.ts`、`src/render/effects/doomsday-*.ts`：机械改装、超原上限培养、节点、巨械与光剑。

目标是普通镜头下看清三个问题：**谁在开火、打出的是什么、命中后发生了什么**。普通部队有清楚的轻量反馈；精英靠自己的专长动作与弹形形成区别；高级精英有更凝实的火力质感。

## 2. 共用的视觉规则

1. **发射短而明确。** 炮口闪光、后坐和排烟来自本次真实开火。高攻速时随真实节拍变化，不常亮成一团，也不为了表现加一次蓄力等待。
2. **弹体有形。** 枪弹为短针，榴弹为粗短弹头，火箭带独立推进尾迹，炮弹有重心，喷焰保留真实线形或扇形。弹道与命中时刻沿现有规则，不人为延迟命中以便看清。
3. **命中有方向。** 实弹是定向碎屑，重炮是爆心加低矮尘浪，穿甲是窄入射闪，电击是逐段分支，幽能是内缩裂隙，纳米是附着后的脉冲。
4. **图形表达真实能力。** 只削甲的攻击不能画成穿过多人的长线；单体弹不能冒出范围冲击圈；只有真实持续伤害才保留可见的伤害场。装饰烟尘与可伤害区域分开。
5. **形状先于颜色。** 普通实弹沿暖黄／橙白，穿甲偏钢蓝，医疗偏绿白，纳米偏青白片状颗粒，幽能为炭黑／深靛紫细边。高军衔不统一染金，也不把整机染成发光色。
6. **轻量起步。** 新增普通命中叠层建议约 0.12–0.20 秒，精英关键命中约 0.20–0.35 秒；这些是调表现的起始值，原效果、真实持续状态和攻击时序按各自规则。大爆炸的亮核先退，烟尘低矮而通透。

不在本稿为尚未接入的幽灵、渡鸦等规划新的实装内容。地堡、行星要塞及临援机械沿真实拥有的武器使用对应方案。

## 5. 高军衔的递进

只调整相同武器上的表现密度和质感，不新增弹数、技能、命中次数或范围。下列分组是本稿的视觉档位，不改现有中文军衔、升级规则或培养上限。

| 军衔 | 普通攻击的拟表现 | 专长技能 |
| --- | --- | --- |
| I–II | 最清楚的基本弹形，单层短枪火和单次接触反馈 | 已有专长从合法条件生效，不能因为低级隐藏真实技能 |
| III–V | 弹芯更凝实，命中碎屑方向更明确，枪口可多一层很薄的压缩边 | 按真实升级／机制加强；既有英雄 III/V 的分支、发数和 DOT 必须逐个可见 |
| VI–IX | 同一弹体增加窄双边或断续热纹，炮口与武器局部有更强的开火反应 | 强调本专长：过载更灼热、穿甲更锐利、医疗更集中；效果边界保持原判定 |
| X 及实际极化强化 | 达标时武器与胸甲各扫亮一次；随后使用该身份更紧实的弹芯和命中边缘 | 只在 N03 的真实强化已经取得时显示对应强化反馈；不因等级文字达到 X 就伪造另一种技能 |

高攻速单位优先缩短多余尾烟的寿命，不靠一再提高亮度来表示强度。普通镜头辨识优先于放大镜下的细小纹理。治疗与辅助精英按治疗束、修复片和真实技能表达高军衔，不强行安排攻击。

## 7. 与卡牌叠加时怎么组合

同一真实弹体由一个渲染入口负责主体。其他层修改材质、尾迹或附着点，不能再复制一份原弹体或重复播放原发射音。

| 来源 | 负责的视觉内容 | 组合示例 |
| --- | --- | --- |
| 武器家族 | 主弹形、炮口、发数、路径、爆区 | 破甲精英仍是一枚粗短榴弹；维京仍是导弹 |
| 精英专长与实际状态 | 六连发、预热、过载、真实震击、治疗束等 | 末日过载只在实际过载时发热，金属风暴排热时停枪火 |
| 高军衔 | 同一弹芯、炮口和接触瞬间的质感 | 更凝实、更锋利；保持同一轮攻击和实际范围 |
| 幽能怒火 | 暗核、细灰紫边、向内收拢的裂隙 | 精英杀手的钢蓝细矛改成暗芯细矛，穿甲轮廓仍清楚；爆炸仍按真实范围 |
| 纳米弹 | 真正装填那一轮的青白颗粒，以及目标上的真实持续伤害脉冲 | 不把所有子弹都附纳米；命中后按各次真实 DOT 起伏 |
| 电容、贯穿、子母、节点补炮 | 各自真实新增的弹体或效果 | 先有主命中，再按既定时序出现电弧／子弹／后方补炮；真实同时发生的事件不人为错开 |

例如：**X 级末日过载雷神＋幽能＋纳米**，双炮与发数仍属于雷神；过载热光留在炮口和机械部位；在途是凝实暗核；只有实际纳米弹带少量青白颗粒；命中暗裂隙与其后 DOT 各按自身时刻显示。无需三层大爆球同时覆盖目标。

高达的粉红光剑继续从右臂炮口出刃，沿已修正的粗细与动作；近战接触是定向切口。幽能附着采用窄暗裂，纳米附着采用点状脉冲，剑芯仍可见。蓝白红装甲、正面红胸甲及原体型保持。绝望堡垒保留五列三排的真实推进节拍，爆心之间留空隙。

武装支援沿已验收／待验收的空投、炮击、核击和原载具执行器延伸：地堡只有真实双枪，行星炮台只有真实炮次，普通战巡与大和英雄分开。P05 装甲设备目前只阻敌／提供光环，不因本稿增加射击表现。射击以外的入场、出兵和退场沿原方案。

## 9. 资源、性能与事件边界

优先用已核实的 SC2 模型、骨架挂点、原武器与原声音资源。现有通用光片／程序火花、纳米网格、暗裂和新增材质属于本作制作或项目既有衍生素材，需沿原来源登记，不称作“原版精英专属”。本稿没有申请下载、上传或替换私有原资源。

原声音可保留其枪械、炮击、火箭和命中的质感。若叠加专属音色，后续先试听；不改变当前主音量／战场音量，不让高军衔仅仅更响。射击、命中和持续技能声音各按真实事件去重，暂停、后台、死亡和退场沿既有生命周期。

表现代码只读真实攻击、在途弹体、命中、状态与已保存计数。命中后闪光可按事件消退，持续技能可从当前状态重建；不把渲染队列写成伤害时钟。缺少可观察事件时，增加只读的表现事件而不改变战斗 RNG、攻击顺序或奖励。

性能方案优先复用现有批次、纹理与对象池；不为每发弹添加实时灯光、不复制整机残影，也不每击新建材质。既有画质设置下，关键弹体／有效范围／实际额外攻击均要保持可辨。若装饰粒子超出预算，先测量并提出具体取舍，不擅自降画质、漏画重要效果或减少结算。

敌方危险预警保持最高可读优先级，友方炮火不覆盖其边界。普通镜头、亮暗地面、单人射击与有限组合战场都要核对；不以孤立特写或全目录截图替代真实可读性。
