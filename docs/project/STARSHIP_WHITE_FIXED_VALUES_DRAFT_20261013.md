## 低品质整数属性的限制

白色招募瓦斯优惠与培养瓦斯优惠原范围均只有1。保持已确认范围时，单条、双条与三条都会显示减1气，无法体现单条专精。现稿保留原值并将这两项列为待定，不暗改步长、扩大区间或删除候选；可在确认实际组合时单独决定其数值。少数70分项和60分项也会因整数步长显示相同值，已按实际成品去重。

污染装备同品质优秀和更高合法套装率的目标保留，固定白字组合如何体现优秀结果继续另定；不能增加白字总分，也不重启分数保底。
