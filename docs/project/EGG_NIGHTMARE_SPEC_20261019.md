# 虫卵噩梦：完整编码规格 R2

日期：2026-10-19。MVP 包 2。状态：READY（推荐编码规格，未实现／运行验收）。依据：[趣味原稿](RANDOM_EVENTS_ITEMS_CONCEPT_20261009.md)、[公共调度与农民营救](ESCORT_WORKERS_SPEC_20261019.md)、[最新掉落规则](LOOT_ELITES_20261019.md)。

原稿数量与概率沿用、最新敌群按用户修订：12—18 枚卵；每枚 35% 一名农民、65% 释放 2—4 只匹配当前关卡强度的跳虫／毒爆精英；生成时固定内容；真实战斗破卵；三族农民外形可出现且收入统一；范围攻击可同时破卵，核弹包不打开中立卵。以下精确生命、比例、时序、接取和队列均为推荐初值，不冒充用户逐项确认。

## 1. 玩家流程与公共规则

远处发现一片虫卵，小地图标记区域与剩余数量。完整卵只能看到相同的脉动与听见声音，不能直接查看隐藏内容。玩家带队靠近，通过原整队控制和自动战斗破卵；每枚可能救出农民，也可能释放真实敌群。

靠近任一完整卵外沿 6 单位内且至少一名正式队员同样在范围并地面连通，或玩家归属攻击首次对任一卵造成正伤害，即接取整组。只出现不自动开卵，没有按键领奖或独立单兵操作。所有卵均已处理且待释放成员全部实际入场后完成，不要求清空敌群；没有额外完成奖品。

- 战役第 4—18 关，公共唯一槽、每关 10 秒宽限、每 15 秒 15% 抽签和终态 30 秒 GCD；无尽不生成、不承接。未接取也占槽，同关结束后可再次抽中。
- 未接取进入下一普通关时失效；已接取跨普通关保留。无整项倒计时、无单卵 30 秒期限、无定时自孵化；玩家可以留卵后续处理。
- 关间／暂停／特殊地图挂起冻结全部模拟；第 18 关结局先处理本步有效破卵和已成立农民奖励，再取消未完成内容。战败／撤离不补发完整卵内容。
- 所有实际收益随开卵分别取得，无须完成全组才能保留；后续任务取消不会撤销已经正式增加的农民。

## 2. 场地与实体

| 参数 | 推荐值 |
| --- | --- |
| 总卵数 | 12—18 整数等概率 |
| 区域中心 | 距当前控制点可走路径 12—20 单位 |
| 分布 | 中心半径 7 单位内，卵中心间距至少 2 单位 |
| 合法落点 | 每枚可地面接近，有可攻击位置与至少一个内容物出口；不堵死必经路线 |
| 完整卵属性 | 24 HP、0 甲、无盾、不回血、不移动；半径 0.65，Biological／Structure |
| 候选尝试 | 最多 32 组，完整放下全部卵才提交，否则不占槽、不触发 GCD |

24 HP／0.65 复用当前普通经济虫卵基准，不按玩家火力或关卡动态增厚，后期范围攻击会更容易一次开很多卵。实际使用原 egg 模型、站立和破裂资源，半径是世界单位，不再重复乘缩放。

使用独立任务卵集合与 taskId，不调用 `spawnEconomic('egg')`：该接口自带必出农民、30 秒到期、workersLost、精英救援和空数组转化调用，会产生错误语义。原普通经济卵保持既有行为。

模拟身份为可被玩家攻击的中立可救目标。现有 Body.owner 没有中立值，实施可沿原经济卵使用 zerg 的底层目标兼容，但必须增加 taskEgg 目标分类：敌方普通 AI 不攻击它、玩家普通武器可攻击它、核弹包和敌方伤害排除它。不能只用 owner 判断阵营或收益。

## 3. 隐藏内容与确定性

生成时对每枚稳定序号独立抽取：

- `u < 0.35` 为 1 名基础农民；外形在 SCV／工蜂／探机中等概率固定，与玩家种族无关。
- 否则敌群数量 2／3／4 等概率固定。每个位置按精英跳虫 80%、精英毒爆 20% 选择，毒爆每枚最多 1 只，已有毒爆后余位均为精英跳虫。这是推荐配比；2—4 数量暂沿原稿，需验证全精英压力。
- 每枚独立，没有至少一名农民保底，也不强制整组精确 35%。极端全坏／全好均合法；期望基础农民为 4.2—6.3 名，不代表必得人数。
- 敌人兵种／数量生成时固定，强度在该枚卵实际破裂时读取当前难度／关卡／进度，density=1、elite；破裂后队列快照固定，等待空位或跨关不重新强化。
- 存储结果，不靠再次运行随机序列重建；菜单、暂停、渲染与 WebGL 恢复不抽签。完整卵的 UI、血条、模型、碰撞和音效不暴露 payload；脉动／声音变体与内容独立抽取，上帝之眼不提前揭示。

只有场地完整验证通过后提交抽取与实体；失败候选不产生可用内容或奖励。整组固定内容仅是模拟内部数据，不预创建农民、敌人或收益收据。

## 4. 破卵与范围攻击

- 玩家正式单位、合法临时协战和玩家归属召唤物的对地普通攻击、技能、持续伤害、范围伤害均可打卵，仍遵守射程、视线、结构／地面目标资格。敌方普通攻击、毒爆自爆和敌方环境伤害不替玩家开卵。
- 原稿“爆炸可开卵”指玩家归属合法爆炸；核弹包属于清除敌方战斗单位的特殊道具，显式排除完整任务卵。已有手动战略打击仍按其普通合法范围伤害规则，可破卵，不能把核弹包排除误套到所有爆炸技能。
- 卵在原半自动索敌中为合法目标，但不置于所有活战斗敌人之上的强制优先级。近处已有战斗威胁时沿现有目标评分作战；实际验证移动到区域一侧能逐枚／少量破卵。
- HP 首次降到 0 时仅执行一次 crack，立即移除碰撞和可攻击资格，固定破裂位置、当前敌人强度及适用装备效果快照，加入待解析队列。重复弹体命中死壳无任何新收益。
- 同一伤害事件先冻结目标列表，按稳定 ID 处理破卵；新出现的敌人不倒插入导致它们刚生成就吃到“打开自己的那一次爆炸”。后续独立攻击或下一次持续伤害脉冲正常可命中。
- 破裂动画不决定结算。伤害／破卵处理后统一解析内容；多人同时打同枚也只有一份内容。禁止死亡回调里递归开卵／生成／再次处理同一爆炸。

## 5. 农民结果与真实入账

农民卵破裂即完成一次普通农民营救事务，基础输入 1 名。该农民不是新的护送任务，不要求走到主基地，也没有可被杀死的二次逃跑阶段。显示已固定种族的真实农民出壳、短暂移动及汇合反馈后退出表现；入账不等待动画结束。

- 增加本局共享 workers，与玩家本族经济统一；SCV／工蜂／探机外形不解锁异族家族、设施或订单，不加入战斗编制。
- 复用现行普通营救资格和有效救援装备效果，正常允许 worker_rescue、rescue_double、虫卵救援增援等产生其真实规定结果。装备附带身份／协战沿原规则，不把它当任务固定额外奖励；不凭任务重新启用已退出正式入口的旧天赋。
- `stats.workersRescued` 每枚实际农民卵加 1；装备使 workers 增加更多时，仍不是救出多具场景身体。完整隐藏卵取消不计 workersLost，不提前泄露农民内容。
- 无额外固定矿气、无虫巢精英装备奖、无卡牌。农民基础持续收入读取 ECONOMY.perWorker，目前每战斗秒 0.1725 矿／0.046 气；后续原经济修正正常应用，地面气体 +50% 不再乘到农民收入。
- 用 `runId:taskId:eggId:worker` 包住 workers、统计、营救装备触发和表现事件的整个事务。`equipmentWorkerRescue` 的现有内部收据不能防止外部 workers 重复相加；World.atomicMutation 也不提供回滚。先做合法计划，再一次提交并写收据；失败重试同计划，不能重抽装备效果。

## 6. 敌群结果、容量与装备转化

坏卵实际释放 2—4 名任务精英，采用第 3 节固定成员，guardOrigin=true；资源采用守军表且倍率 1；这些任务精英及其衍生物显式禁止装备和卡牌，不能继承精英装备保底或资源三倍。卵壳本身不掉矿气／装备／卡牌，不计敌兵击杀或精英击杀。

- 裂卵中心附近、壳外沿 0.5—2 单位寻找合法落点，必要时扩到 4 单位；依真实身体半径、地形及占用检查。找不到则排队，不瞬移到远方、穿墙或重叠。
- 破裂后 0.5 有效秒出土预警才开始投放；农民即时入账不等待此敌人预警。每个有效步全任务最多投放 8 名，按破裂顺序、卵 ID、成员序号稳定处理。
- 共用 300 敌人上限及 Boss 预留，主波优先，任务使用余量；最多 18×4=72 名待投放，成员各入场一次，未入场不算敌人、不掉落、不触发击杀。
- 待入场队列属于任务，最后一枚破裂后状态为 resolving；全部真实投放完成才能结束任务、释放唯一槽。满场只延迟投放，不吞掉坏结果或自动换农民；正常战斗可释放容量。
- 在场敌人正常追击我方，离开区域不停战，任务结束不清场。跨关保留已入场任务敌人和未投放快照；全局战役结束则取消余队，没有补发资源。

### 颜色与专属精英规则（最新用户决定）

普通经济虫卵统一绿色系；只有本任务完整虫卵使用统一紫色，不能根据农民／敌人内容变色。普通卵渲染函数 rescueEggMaterial 已移除紫色 apparition；紫色独立为 nightmareEggMaterial，待任务渲染接入。源身体、动画与地雷／战略卵模型保持。

精英跳虫复用现有猎杀跳虫技能、当前难度／进度成长与精英上限。精英毒爆用户明确为高生命、高护甲、周期爆炸但不自爆；当前 SpecialType 排除 baneling，不能类型强转调用 bossFor 获得不存在的数据。

精英毒爆拟新增 taskEliteKind='pulseBaneling'，推荐基线：

- 同进度精英蟑螂 profile 为耐久基准：HP 等于其 HP，护甲等于其护甲，移动速度使用普通毒爆当前进度速度。使用蟑螂 Boss 作为明确耐久参考上限（生命 30%、护甲不超过其 Boss），不是声称已经存在毒爆 Boss。与普通毒爆相比为高耐久，不额外叠普通兵成长。
- 无普通自爆攻击，也不新增啃咬普攻。实际入场后 3 秒首次脉冲，此后每 3 个有效战斗秒一次；每次前 0.6 秒原地蓄能预警，结束以当时位置中心造成半径 2.2 的对地范围爆炸。蓄能期间停止移动，范围内没有合法目标也正常消耗本周期，不储存补发。
- 单次基础伤害为 SC2_UNITS.baneling.attackDamage（当前 16）乘同进度精英蟑螂 profile.skillDamage，不附加对轻甲 19 点加伤；单次伤害上限为同进度蟑螂 Boss 吐酸基础 60×其 skillDamage×0.6。走真实护甲、减伤、受击、死亡与归属规则，每次每目标最多命中一次；不伤卵、不伤友军、不伤空军。
- 爆炸不扣自身 HP、不创建单位死亡、不更换实体、不重复出生。死亡立即取消未结算预警，死亡不再附送一次伤害爆炸；只播放原死亡表现。禁止进入普通 baneling 自爆分支，不能以死后复活模拟不自爆。
- 普通硬控依现有控制资格生效；命中时若仍被禁止行动则本次脉冲取消，照常等待下一周期，不解除控制或积压多次；暂停／关间冻结，恢复不立即补发历史周期。

装备／卡牌禁止标记在创建时写入权威来源，并覆盖 dropEnemyEquipment、旧 tryRewardDrop、装备击杀奖励（如掠夺额外装备／单位卡）及衍生子代。它们仍是真实精英，可正常受到战斗效果；不得把敌人改成普通级来绕过掉落。资源沿上面的守军倍率 1 规则，只有真实合格击杀掉落。

现有 egg_conversion 明确排除 enemyTier，因此本任务坏卵改为精英后不接受该装备转换，不偷偷去掉它的精英限制。农民卵仍可触发合法的虫卵救援增援；完整卵无额外保底。R1 针对普通子代的转化适配提案撤回，保留原快照供追溯。

## 7. 跨关与终态

状态 offered→active→resolving→succeeded；offered→expired；任何非终态→cancelled。最后一枚是农民且无待入场敌人时同一步完成。没有要求额外杀完所有释放敌人，也没有“至少救到一名农民”成功门槛。

已接取跨普通关保留完整卵 HP／隐藏内容、破裂状态、收据、待投放成员／强度／装备快照和敌人状态。已破卵不复原、已获农民不重发。暂挂特殊地图时整个任务留在原地图，回来继续；不让 prepareStage 清理逻辑误删。

未接取进入下一普通关失效时移除完整卵，无隐藏收益或损失统计。整局取消时清空完整卵和未投放内容，已取得农民沿本局原结算，已入场单位随世界正常退出。成功／失效／取消收据只写一次，GCD 只启动一次。

## 8. 数据与接点

以下为拟新增类型，当前尚无对应任务实现：

```ts
type EggPayload =
 | {kind:'worker'; appearance:'scv'|'drone'|'probe'}
 | {kind:'enemies'; types:('zergling'|'baneling')[]};
type NightmareEgg = {
 id:number; taskId:string; payload:EggPayload;
 state:'intact'|'cracked'|'resolved'; releasePlan:EggReleasePlan|null;
 workerReceipt:string|null; childReceipts:string[];
};
type EggNightmareTask = {
 id:string; sourceStage:number;
 state:'offered'|'active'|'resolving'|'succeeded'|'expired'|'cancelled';
 eggIds:number[]; enemyIds:number[]; openedCount:number;
 releaseQueue:EggReleasePlan[]; endReceipt:string|null;
};
```

HP／位置只有一份 Body 权威值；EggReleasePlan 保存裂卵位置、0.5 秒余步、当前强度、固定成员、剩余序号、掉落禁止标记、任务精英状态及收据。任务内容 RNG 属模拟，装备副作用沿共享装备 RNG 并保存计划。统计 openedCount 只由首次 crack 增加；enemyIds 清理死亡成员，不积累无限历史。

实现接点：

- `World.spawnEconomic`／updateEconomy 及 `World.hit` 的 economic egg 分支保持原普通卵规则，另增任务卵解析入口；不要伪造 expiresAt 或 status 绕过 30 秒逻辑。
- `World.body`、空间哈希、碰撞、攻击目标查询、英雄显式结构枚举增加任务卵；目标分类同时用于范围攻击与未来核弹包过滤。
- `World.addUnit`、enemyStamp 及守军掉落复用；任务敌人来源和 childIndex 明确，不触发独立随机精英配额或全局波次预算修改。
- `equipmentWorkerRescue` 抽出可防重共享营救事务；`convertEquipmentEggEnemies` 保持精英排除；任务精英另加掉落禁止标记与周期爆炸控制器，不把任务角色塞入 economicTargets 冒充普通救援卵。
- 原 scv-rescue 表现目前读玩家本族配置，需要支持本次真实 appearance 参数；模拟只加共享 workers，不能为显示探机而切换玩家种族。
- endStage／prepareStage／nextStage 和地图挂起纳入任务实体／队列保留；运行内恢复覆盖完整计划，WebGL 只恢复模型，不重算内容。正式存档仍延期。

## 9. 表现与验收

HUD 显示“已打开 5/15”、基础救出农民数及已释放敌人数；容量阻塞时显示“虫群正在破壳”，不提前报已全部处理。小地图只给未开卵相同图标，不标哪枚有农民。守军资格与模型使用真实源资源，农民收益发生后显示对应外形的救出反馈，不逐枚弹阻挡卡片。

| 类别 | 必须验证 |
| --- | --- |
| 调度 | 第 4 关起唯一槽、无尽零任务、靠近／受伤接取、未接取跨关失效 |
| 随机 | 12／18 边界、35% 独立判定、全好／全坏、2—4 人、毒爆每卵最多 1、固定内容不重抽 |
| 战斗 | 三族自动索敌可逐枚开；正常范围可多开；敌方与核弹包不打开；手动战略伤害沿正常资格 |
| 顺序 | 同枚多次致死只一次；新敌人不吃原开壳爆炸；后续脉冲正常受击；出土预警真实冻结 |
| 收益 | 三种农民外形统一经济、不解锁异族、装备增益一次、统计实际身体、无额外矿气装备卡牌 |
