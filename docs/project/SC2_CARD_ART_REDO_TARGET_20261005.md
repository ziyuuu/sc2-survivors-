# 关间卡片立绘重做目标 · 2026-10-05

用户在核对 R10 后明确要求「请确定目标并重做」。R10 的几何矢量人物及共用种族背景未达到此前要求。本轮以实际画面识别、绘画质感和背景融合为目标；文件数量、ID 覆盖或布局检查不能作为美术目标达成的证据。

## 画面标准

1. 延续已确认的 SC2 方向：写实比例的厚重动力装甲、异虫的有机甲壳、神族的精密圣堂装甲；有可读的金属、皮肤、骨刃、晶体材质及完整明暗。使用绘画立绘，不沿用 R10 的几何人物，不以游戏模型渲染代替封面。
2. 隐藏名称和说明后仍能认出兵种。身份依靠完整轮廓、标志性武器和动作；辅助图标不得代替主要立绘。
3. 每个兵种有自己适合的环境、镜头及光影：步兵破口、喷焰路面、炮阵、空战、菌毯、酸雾、地刺、圣堂遗迹、风暴或舰队空间。禁止继续只按三族复用同一幅场景。
4. 精英在保留兵种身份的前提下，至少改变两种可见信息：武器/装甲结构、姿势/战斗动作、其效果作用于环境的方式。只改配色、描边、光晕或小挂件不合格。以当前卡片的实际效果为依据，不创造新玩法。
5. 人物与环境共用主光、反光和空气透视。脚部/下缘通过尘土、酸雾或灵能辉光过渡，画面下方渐暗融入面板；避免剪贴贴纸、硬黑底和满屏同亮度发光。
6. 援军严格显示实际战士数量。1/2/3 人及跳虫 2/4/6 只，在同一屏幕布局中保持相同的单体比例；队形展开且主要头部、武器可读。不得通过缩小单体塞入卡片。
7. 文案、价格和确认按钮使用真实 DOM，图内不画文字、徽章、UI 或数字。横屏与竖屏独立排版，大立绘可滚动，不能压住决策信息。
8. 动效仅用于发牌、选择、详情与确认。绘画主体保持稳定，不让持续闪烁、浮动或强烈发光掩盖轮廓；尊重关闭动效和 reduced-motion。

## 检查与保留

- 在实际大小的横屏/竖屏卡片里看图，而非仅放大看原图；同家族三个精英并排、隐藏文字后检查。
- 援军展示 1/2/3 人及跳虫 2/4/6 只；核对单体尺寸相同、计数正确和主体不被文案遮挡。
- 检查价格、详情、取消、购买、已购和不足状态，以及短横屏内部滚动。
- 使用新版本文件，保留 R8/R9/R10、所有已接受封面和地图。当前战斗规则、模型、存档、数值、英雄效果和 OPEN 验收不属于本次静态美术范围。
