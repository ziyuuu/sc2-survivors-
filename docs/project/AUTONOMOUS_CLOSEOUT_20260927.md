## 验证方法与完成条件

动作修复不能改战斗时序或数值。每个确认缺陷有失败复现和修复后回归。控制器只走合法公开操作，不直接写生命/钱包/科技/波次/阶段；控制器错误、实现错误与平衡疑点分开。未通过正常流程取得的状态一律标为受控夹具。

自然性能：P95≤16.9ms、P99≤20ms、>20ms帧≤1%；180秒新增模拟欠账≤0.1秒且不积累。包含开战十秒；相同硬件/种子/场景前后对照。60Hz呈现只报告稳定60档。素材/规则/视觉/硬件证据不互相替代。

确实需要策划改值时只出差异建议，不临时调数以取得通关结果。必要素材无法取得时写明具体来源/缺失项，不伪造模型。达不到自然战役/性能门槛则保持相应任务开放，不将MVP或M7签收。
