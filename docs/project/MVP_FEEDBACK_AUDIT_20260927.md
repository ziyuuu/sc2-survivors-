## 3. 动作证据

| 模型 | 当前动作映射 | 诊断 |
| --- | --- | --- |
| 死神 | Attack约1.499秒；Walk约1.332秒 | 原攻击动作存在；出手播放生命周期不成立 |
| 狂热者 | Attack 2秒 | 实際命中后action多为idle |
| 使徒 | Attack约7.833秒 | 长动作应核验有效片段/出手标记，不能整段强塞进一个攻击周期 |
| 追猎者 | Attack约2.333秒 | 夹具8次开火均可见状态覆盖 |
| 哨兵 | Attack 2秒 | 有8条动作通道；需实看动作幅度，不凭名字宣称足够 |
| 不朽者 | Attack约2.333秒 | 夹具9次开火；有动作但播放状态不稳定 |
| 高阶圣堂 | attack回退Stand；有Spell约1.999秒 | 需核验普通灵能弹与风暴分别对应的原动作，不把idle回退计作攻击验收 |
| 巨像 | 当前选到Attack Ready Channel，而非Attack 02 | 需显式区分准备、开火/通道及方向移动 |
| 凤凰 | Attack 1秒，1条通道 | 可能本来主要靠武器表现，须结合实际弹口验收 |
| 虚空辉光舰 | Attack约0.767秒，另有通道/结束动作 | 应组合起手→持续→结束，不能每次伤害tick从头重播 |
| 航母 | 没有母舰Attack | 母舰不凭空添加炮击；检查机库/截击机及其攻击 |

`World`前摇结束时记录`lastShotAt/shotSequence`，随后同一步可能写入idle/move；renderer通常只在`action=attack`时采样攻击姿态。枪兵/劫掠者有额外射击叠层，其余单位未得到同样保障。修复需兼顾移动、死亡、手动部署和持续通道，不能延长实际攻击锁定来凑动画。
