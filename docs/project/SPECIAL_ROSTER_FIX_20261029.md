## 根因与修复

[此前调查](SPECIAL_ROSTER_INSPECTION_20261029.md)已复现：5枪兵加1雷兽，受伤并带生命装备进挑战关时，4枪兵无战斗归零。装备前属性保存在以实体对象为键的WeakMap中，克隆成员时不会自动跟随，返回时又删除旧缓存；属性刷新遂把装备生命池的已损生命扣在较小的原生池上。

现在在进场和返回两端迁移对应原生基准，覆盖原成员、撤离成员、新生双生跳虫、截击机和阶段复生投影。正常场景仍恢复原World对象关系；装备层按既有规则重算，伤势、真实战损和死亡不被重置。躲避关仍使用停放的原身体并按原规则结算培养。
