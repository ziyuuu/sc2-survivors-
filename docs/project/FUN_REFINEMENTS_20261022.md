## 实际变化

- 毒爆恢复原模型尺寸；弹体判定半径0.42，队伍中心白点0.18。组合留缝织流、旋转扇形、自机狙、交叉、收束和尾段换型，每轮约1–1.6秒间隔、0.3秒提示，速度7.2–8米/秒按小队速度适配。保留60秒、四成员、五次命中、1秒保护及原升降级。正常镜头与鼠标不变。
- 编排参考东方常见弹幕形式，并为原尺寸毒爆、四人小队及普通镜头重新设计，不声称逐关复刻。视觉参考入口：[红魔乡](https://www16.big.or.jp/~zun/html/th06.html)、[妖妖梦](https://www16.big.or.jp/~zun/html/th07.html)。60秒无碰撞清理对照由2770发减为285发，中心固定条件峰值250减为44；这是发射/存活数量比较，不是FPS结论。
- 横穿改成16段原版Char岩壁组成的三条分段通道，包含横向岔口、堵死支路和绕行选择。8处固定守军共124只，其中32只蟑螂；敌人留在通道中，接近或受击后局部追击，离开后归位，清除后不重刷。警戒逻辑保留，所有可见警戒圈删除。可以绕行或打穿，终点仍需实际存活成员逐个抵达。地形碰撞、视线、原岩石模型使用同一布局。
- 试玩默认强化为12名5级成员，并使用合法满级全队火力/防御卡牌；护送用4机枪、4恶火、2医疗运输机、2科学船。毒爆仍用原四人阵容；感染自爆项移除治疗者，医疗净化入口保留。强化仅用于试玩配置，不变更自然战役开局。
- 吞噬者破土出现时立即吞入选定三分之一普通席位，吸入视觉约0.58秒；完整原生出土动作与30秒救援/消化同时运行，不再等完整出土后逐个吞。击杀可救回，超时按原规则处理。
