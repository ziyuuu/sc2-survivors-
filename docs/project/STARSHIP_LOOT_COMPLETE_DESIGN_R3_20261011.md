## 旗舰和永久仓库

三族分别用人族战列巡洋舰、虫族利维坦、神族净化者旗舰承载局外装备页。旗舰是装备载体，效果作用于合法本族队员；战场继续由玩家当前部队作战。

通用舰装和改造材料存入共享永久仓库；专属装备标明适用种族。每族保留三个配装预设，预设引用具体物品。一件通用装备可被不同种族预设引用，在同一次出征中只能占一个对应槽。

战场拾取后舰装加入永久仓库，失败保留已入库舰装、材料与制造进度。出征时冻结十二槽的属性、能力和套装计数。本局拾取的新舰装供之后配装使用，军衔、部队容量、订单和采购次数按本次出征快照继续结算。

舰装永久保存，英雄、精英和普通兵仍按照当前局内规则获取和成长。装备可提供开局英雄与额外单位来源，不在本稿额外建立局外英雄收藏或永久带兵系统。

## 一件装备包含什么

| 属性层 | 内容 | 玩家追求 |
| --- | --- | --- |
| 白字 | 该底座的基础属性，按物品等级成长 | 更好的底座与基础数值 |
| 绿字 | 从合法词条池抽出的随机数值和条件属性 | 适合当前队伍与构筑的词条、较好的数值 |
| 固定能力 | 指定传奇的一种机制，可具有明确强度区间 | 开启或改变某种玩法 |
| 套装归属 | 一个系列的二／四／六件组合能力 | 获取、培养、联动的构筑路线 |

白字、绿字是属性的显示层，与白色、绿色装备品质分别定义。生命、攻击、攻速、暴击等属性主要交给白字和绿字；套装阈值用来开启机制，而不是再次发一组普通攻防百分比。

传奇能力的类型固定。例如精英招生信标始终提供合法产线转精英，不会因为掉落随机数变成整队召回；它的数值词条和明确标注的能力强度可以随机。

| 品质或类别候选 | 随机词条数 | 特殊属性 |
| --- | --- | --- |
| 白色基础件 | 0 | 底座白字 |
| 绿色精良件 | 1 | 底座白字 |
| 蓝色稀有件 | 2 | 底座白字 |
| 紫色史诗件 | 3 | 较好的底座白字 |
| 橙色传奇散件 | 3 | 一个指定固定能力 |
| 套装件 | 3 | 一个指定套装归属 |

套装是物品类别，品质和套装标志分开展示。初版套装件不另附完整独立传奇能力，使套装与传奇散件存在实际槽位取舍。八个组件可以六加二、四加四、四加二加二、四组两件，也可以搭配传奇散件。

装备层总数值上限需按三加一加八结构统一计算，具体总预算待试玩确定；装备详情应能显示合法总效果、上限与溢出。

## 舰载核心

舰载核心承接R01、R02、R04、R05、R07、R08、R10、R11、R13。基础属性和绿字提高运营效率，固定能力提供不同经营方式。

| 固定能力候选 | 效果 | 原机制边界 |
| --- | --- | --- |
| 拓荒授权 | 真正救援一个农民目标时，额外获得本族农民 | 一个真实目标一次，额外农民不复制救援触发 |
| 信用工程 | 合法建造／解锁购买有概率免单 | 先满足原支付资格，保留原项目范围 |
| 并联建设 | 合法重复设施购买有概率再建一座 | 第二座仍需支付完整折后价，保留独立产能与种族排除 |
| 科研统筹 | 新设施有概率完成本路线合法科研项目 | 原项目顺序，无项目时不抽 |

一件传奇核心以一个固定能力为主。农民仍是实际救援得到的经济单位；随机守卫任务的建筑仍通过按农民数量守护回血获得，完成后进入本局真实生产设施。核心不会把建筑收益改成临时光环或装备材料。

## 核心反应堆

核心反应堆承接R03、R06、R09、R12，以及R14普通强化结果分支，另新增核武供给候选。精英、英雄身份结果进入八组件机制。

| 固定能力候选 | 效果 | 取舍 |
| --- | --- | --- |
| 商情刷新 | 原整备窗口提供共享免费刷新 | 同一窗口计数，不跨窗口结转 |
| 采购授权 | 原窗口随机购物获得免单机会 | 保留原资格与精英特约排除 |
| 强化供给 | 获得额外普通强化品质结果的机会 | 只承接R14分流后的普通强化 |
| 核武供给 | 自动补充战略核弹，供玩家主动选点使用 | 与购物、刷新版本竞争同槽固定能力 |

核武供给试玩参数为每180战斗秒补一枚，自动供给以库存两枚为目标；已付费库存超过两枚时保留库存，只停止自动补充。现有战略打击基线为三秒抵达、3000伤害、半径8，供后续评审使用。MOSS的手动技能冷却不改变反应堆的供给计时。

核武供给是新增机制。地图随机核弹包按先前设计拾取后清理视野内敌人，战略核弹则需要主动选点；两者各自保留道具身份和使用方式。

## MOSS系统

MOSS承接全部七项原微操语义。随机词条负责射程、追赶、手动技能回复、合法部署耗时；固定能力决定控制方式。

| 固定能力候选 | 效果 | 保留条件 |
| --- | --- | --- |
| 机动瞄准 | 提高瞄准转向，允许原合法移动开火 | 原武器周期、近战接触、攻城模式与光束锁定 |
| 战场转移 | 本族空运／地下转移／召回 | 合法前方落点、准备阶段，保留生命伤损和技能冷却 |
| 双重执行 | 本族原APM追加直接命中包 | 不复制范围、穿透、弹射、技能、治疗或掉落 |

非法转移目标不消耗冷却；神族部署词条附于实际有召回能力的版本，原准备耗时最短0.25秒。一件MOSS以一个固定控制能力为主，八组件继续提供基础移动等数值。

## 舰炮

舰炮拥有独立周期支援词条池，以一个自动支援能力为主。A13提供本族火力与恢复联动基础，A15提供临时精英援军周期基础。

| 舰炮候选 | 周期支援 | 动画与效果表现 |
| --- | --- | --- |
| 轰炸炮 | 合法敌群位置有限范围打击 | 炮弹／导弹飞行与落地冲击，真实伤害结算 |
| 联动炮 | 原A13周期开始后持续8秒分次火力与恢复 | 人族炮击医疗、虫族胆汁哺育、神族热能回盾 |
| 医疗炮 | 对合法受伤友军恢复生命或原生盾 | 治疗包／治疗束，按实际恢复对象呈现 |
| 援军弹舱 | 按原A15周期投送一名80秒Rank V临时精英 | 投送舱／虫囊／折跃为表现候选 |

A13原天赋周期为75／50／35秒，支援等级有一／二／三阶段强度，可作为不同舰炮能力强度的参照。援军弹舱可用原A15的180／90秒参数试算。它们需要各自平衡，不与MOSS手动技能冷却共用周期属性。

周期支援不消耗新增操作按钮。英雄套的主动护卫与援军弹舱如何共享临援，见套装参数。

## 五套机制型候选

每个系列都提供八种槽位版本。一件只属于一个套装，阈值为二／四／六件；第七、第八件不设新的强制奖励。以下为首批套装候选。

| 系列 | 二件：打开路线 | 四件：形成循环 | 六件：形成主要打法 |
| --- | --- | --- | --- |
| 精英学院 | 指定正常付费基础兵种有概率转为同家族永久精英 | 按战斗时间培养一名最低等级、未满V的永久精英 | 活着的同家族精英充当教官；普通击杀有概率培养同家族最低军衔普通兵 |
| 英雄统御 | 开局选择一名本族II级地面英雄 | 合格击杀开启额外英雄卡掉落通道，可获取新身份或培养已有英雄 | 已拥有英雄成功施放主动技能时，召来一名Rank V临时精英护卫 |
| 老兵进阶 | 普通合格击杀有概率晋升，优先同家族最低合法军衔 | 普通兵军衔上限开放到VII | V级以上普通兵可消耗正常付费同家族增援名额，完成原I—V战术进阶 |
| 战场征召 | 合格击杀有概率生成需解救的普通乘员 | 合格击杀有概率召来30秒Rank V普通临援 | 每家族身体容量由5开放到7，精英仍占家族名额 |
| 战地搜寻 | 成功救出农民目标时，有概率获得精英救援权 | 原指定整备窗口增加付费精英特约 | 合格击杀开启额外紫色精英卡掉落通道 |

精英学院与老兵进阶可以共享同一普通晋升机制，但不叠两次晋升判定。前者需要永久精英作为导师，后者自身提供基础培养、VII上限和普通战术进阶。重叠部分合并概率并遵循一次成功只培养一名的原流程。

### 参数与来源

- 精英学院二件可先以R15的20%试算；保留三族原产线与兵种排除、虫族最终体一次结算。四件先以A09的120秒、一名最低等级永久精英试算，无目标跳过不存次数。六件复用A02／A05／A08的合并培养，永久精英导师才有资格，临时精英不作导师。
- 英雄统御二件直接沿用R16。四件来自R14身份分支的重新分配，英雄结果池与掉率尚待独立平衡。六件是新增触发联动：成功开始英雄主动技能才有召兵资格，取消选点或非法目标不触发；全队共享90战斗秒冷却，一名护卫存活80秒，使用A15原本族已解锁候选。它不复制英雄技能、不自动施法，不消耗额外主动按钮。
- 老兵进阶二件复用A02／A05，四件复用S14，六件复用S16。战术进阶依然需要真实付款与五名额收据；它改变普通身体的战术方向，不变成紫色精英。
- 战场征召二件先以A03的2%和成功后45战斗秒冷却试算，仍需击败守军。四件先以A12的2%、30秒、同时两名试算，保留本族候选及临时身体的资源／培养排除。六件复用A16，不提高五家族或三英雄身份上限。
- 战地搜寻二件先以A14的10%试算，一个真实农民目标一次；核心额外获得的农民不再各自掷骰。四件先以A10每个原指定窗口额外一张付费精英特约试算。六件的精英池来自R14分流，概率单独平衡。

英雄护卫与舰炮援军弹舱共用同一个精英临援资格、冷却和容量，本稿暂定全队同时一名该机制的临时精英；装上二者不产生两套独立召兵。英雄六件让玩家用实际主动技能选择临援时机，选此路线时舰炮可以改装火力或恢复版本。原A15的周期召兵在舰炮固定能力中仍可独立选用，没有因改触发而丢失。

## 掉落与每次出征的收益

舰装独立于当前局内卡牌、矿气和正式单位奖励。随机任务仍获得指定农民、设施、精英或英雄；不会改成装备、材料等替代收益。舰装是在此之外设计的独立永久成长来源，拆解是玩家处理自己装备的用途。

| 来源 | 试玩舰装掉落参数 | 作用 |
| --- | --- | --- |
| 普通真实敌人 | 1%掉落一件，前期以白绿蓝为主 | 战斗中也有小惊喜，不全等Boss |
| 精英 | 35%掉落一件，至少蓝色 | 击杀精英有追逐价值 |
| Boss／领主 | 一件保证，至少蓝色；中后期提高紫、套装与橙概率 | 给一次战斗明确目标，原单位卡掉落另算 |
| 特殊敌人 | 独立50%一次舰装机会 | 原特殊收益保留 |
| 支线完成 | 独立25%一次舰装机会 | 完成身份收据一次，不能反复汇合刷奖励 |
| 每完整战斗分钟 | 10合金、1异构核心 | 提供独立基础进度，失败也留已结算收益 |
| 特殊挑战、困难与地狱 | 更高物品等级与高阶类型权重 | 收益效率更高，不锁住低难度玩家的全部制造上限 |

稀有发现词条只提高非保证随机触发率，不把Boss一件保证变成无限件。时间奖励按真实模拟战斗时间和唯一分钟收据结算，暂停、菜单、离线、诊断场景不计。无需等整局胜利才把已入库收益算给玩家。

普通战役先以每分钟一至两件舰装作为体验目标，表中概率需按实际敌量校准。高密度虫潮分批出现装备，传奇有短光柱、声音和约1.2秒名称提示，普通件轻提示；装备通知不捕获输入。

智能掉落初稿：60%通用模块、35%本族专属、5%其他种族专属。它有利于当前舰船，也保留换族收集目标。掉落类型与词条在实体生成时固定，读档不能重新洗出另一件；真实敌人的同一生命阶段只结算一次该掉落。由玩家创造的友军、幻象、复活复制和反复转化不组成材料循环。

物品等级初稿1—100，决定词条区间和底座强度，不要求先攒80点才能穿。品质、物品等级、词条契合度、固定能力与套装组合分别决定价值；低等级好传奇可以升级底座继续用，避免早期好掉落被后期数字直接废掉。

短局的战斗时间余量也保存到永久收益进度。例如一局打了40秒、下一局再打20秒，可完成一个材料分钟；暂停、菜单与离线不计。材料由实际战斗进度独立产生，任务指定收益仍按任务结算。该跨局进度是本稿新增候选。

## 改造与材料循环

永久材料先只设两种：舰装合金与异构核心。低品质拆解给合金，高品质额外给核心；不再为每槽、每族和每个词条另开一种货币。

| 操作 | 初始成本示例 | 保留与变化 |
| --- | --- | --- |
| 制作白色指定槽底座 | 10合金 | 补齐空槽，帮助初期进度 |
| 单词条重铸 | 20合金、1核心起，逐次最多涨到100合金、5核心 | 一件装备只开放一个选定随机词条；三选一或留原值，其他词条和固定能力不变 |
| 提升物品等级十级 | 50合金、3核心 | 保留随机词条在原区间的相对百分位，再映射到新等级；传奇和套装身份不变 |
| 登记传奇蓝图 | 首次获得自动登记，无需拆掉唯一在用装备 | 只解锁同类传奇的制造，不增加免费常驻技能 |
| 制作已有传奇蓝图 | 200合金、20核心 | 指定槽与能力，随机词条重新生成；保留掉落寻找好词条的价值 |
| 制作已登记系列套装部件 | 150合金、15核心 | 同族同系列收集三个不同槽后解锁该系列缺件制造；有定向成型路线，不能凭首件立即造全套 |
| 深层精铸 | 后续候选，用高成本合金／核心 | 优化已有区间，不能突破装备层上限或新增无限乘区 |

新账号先有一件基础舰载核心和基础舰炮，其他十槽可制作白件补齐。第一轮出征就能开始积累装备、材料与战斗进度；中期追固定能力和四／六件套；后期追适合不同兵种组合的词条和完整多预设。

“打多久都有收益”的具体承诺是战斗期间有独立材料进度、已入库物品永久保留、重复掉落可以参与改造与收藏，不是每一件都保证高于当前装备。满配后仍有新构筑、三族蓝图、词条精修和舰船外观收藏目标；数值有明确上限，不靠无限攻击百分比让旧关卡失去意义。

## 三族规则与随机事件联动

三族共用槽位数量与套装计数，能力使用各族自己的单位、武器、护盾、最终进化体与支援候选。

- 人族精英产线只使用原指定基础兵营兵种资格，工厂和星港不会因同名套装自动纳入。
- 虫族基础产线按最终真实身体结算，中间进化体不重复获得额外单位、来源属性或掉落。
- 神族原生盾、回盾和合法召回与其他种族分别处理，不把护盾恢复写成生命恢复。
- 普通军衔、永久精英等级、英雄等级和普通战术进阶分别显示；精英导师必须是活着的永久精英。
- 航母等子机仅继承明确允许的母体属性一次，固定能力不默认变成子机的额外掉落、召兵和培养来源。

随机事件继续按既定收益设计。护送获得农民；守卫修复建筑按农民数量守护回血并获得真实生产设施；情报解锁科技／兵种；营救获得精英与本关临时友军；成熟残忍母亲击杀保证英雄。舰装机会在这些收益之外独立产生。

医疗包、火力包、护甲包、核弹包、震撼弹仍为地图随机出现并拾取的道具；它们与永久舰装、关间购买的趣味道具分开显示。潘多拉与随机虫潮会改变战场压力，舰装掉落仍按明确敌人、事件与时间资格结算。

## 界面与动画表现

旗舰页分为三个较大的独立模块位、一个舰炮位和八组件区域。每个物品详情依次列出白字、绿字、固定能力或套装归属、适用单位与配装比较。套装详情列出已装备槽位和二／四／六件效果，重复同槽物品不增加件数。

仓库可按种族、槽位、系列、固定能力和收藏状态筛选。当前装备、已锁定物品和预设引用有明显标记，拆解时显示实际材料收益。比较优先展示属性差值和机制变化，避免只用一个战力数字掩盖失去开局英雄或精英产线的影响。

舰载核心采用工作灯／巢体脉动／灵能回路，反应堆展示供能与核武储备，MOSS展示控制数据，舰炮提供实际支援类型预览。套装激活用局外模块连接与短暂高亮。

战场装备掉落可用短光柱和名称提示；普通件轻提示，传奇与套装更鲜明，通知不占用操作输入。永久精英和英雄使用当前真实单位表现；晋升、救援、投送与折跃按实际发生的效果呈现，不新增战场或小地图辅助圆圈。

候选接入顺序为永久物品与仓库、十二槽与开局冻结、白字绿字结算、三大件和舰炮、套装和传奇、战场掉落、制造改造与结算。
