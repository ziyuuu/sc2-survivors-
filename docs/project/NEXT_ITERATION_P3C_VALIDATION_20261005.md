## 失败尝试及修复记录

初版浏览器诊断在战局开始前调用 `captureRun`，报“尚未开始战局”；第二次错误模块路径导致构建失败，均已修正为导入正式 schema 常量。第三次观察夹具在“受击一次”后仍继续让敌人射击，末尾布局测试英雄死亡；改为实际发射一次后停止该观察敌人，最终12状态均通过。原20项旧神族数值断言按批准的新标准更新，并补充真实机制/结算测试；其中剩余两项旧测试未计泽拉图+45%武器易伤/航母获得新友军攻速，修正为明确范围/裸值比较。新增测试首次四项使用未纳入普通家族的工人类型构造夹具、并错误期待手动发射不更新发射时钟，已修正夹具和时间断言；帷幕资格测试使用工人形状DTO验证守卫，真实工人仍属于独立经济目标，不把此DTO说成实际工人战斗用例。最终类型、917回归、独立浏览器、两组三英雄及Web/离线结果单独保存，不用先前失败或初步通过代替最终构建。
