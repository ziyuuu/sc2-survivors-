## 当前核心效果

**我方击杀敌人后，有一定概率将被击杀的敌人转化为一只友方毒爆。毒爆具有正常生命，能够受伤并被击杀，不具备不死能力。**

- 触发时点为敌人实际死亡后，不再采用对存活敌人的临时控制。
- 转化产物为毒爆，不保留原敌人的兵种或特殊技能。
- 按普通战斗毒爆处理：可移动接敌、自爆攻击，自爆后该身体消失。该商品不赋予不死或自动复活能力，也不使用扫雷关不可攻击的弹幕毒爆规则。
- 不自动沿用旧稿的3%概率、20秒临时控制时限、6秒冷却、最多5名或250矿100气价格；这些属于已被替代方案的数值，尚未为新效果定稿。

“友方、实际死亡后、可受伤死亡、普通自爆行为”是对本次商品语境和用户要求的明确落地表述；没有把未讨论的数值写成用户已确认。

## 数量上限与触发概率

用户补充：“场上最多10只这种，另外概率要高一点，不然根本触发不了。”

- **已确认：场上同时存活的本商品转化毒爆最多10只。** 只计本商品来源，不占用英雄技能或正常编制毒爆的独立限额；自爆或被击杀后释放名额。
- 达到10只时不继续生成；后续有空位时再由新击杀触发，不积存满额期间的转化请求。此为上限的具体处理说明。
- **助手建议：每次有效击杀独立以25%概率转化1只。** 用户已要求提高触发率，25%是本轮提出的首版候选，并非用户指定或已通过实战平衡的数值。数量有空位时平均约4次有效击杀触发1次，不是每4次保证触发。
- 建议不另加旧稿6秒冷却，以免高概率仍被长冷却压低实际出现频率。由10只同时存活上限约束数量；具体节奏后续实际验证。
