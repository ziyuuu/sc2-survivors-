### 采样修正与失败保留

最初工业R1的27条及2条pilot原样保留。R1第019条虽然P95约16.8ms且visibility/focus正常，却出现四段约1000ms回调间隔，实际只推进463 tick、丢弃3.0005秒模拟时间。当时每段CPU仅12–27ms，且没有对应long task，不能归因为游戏模拟耗时。

R2增加逐帧间隔核对：≥250ms的间隔须由相邻CPU工作或重叠long task解释，否则标为无效。真实、有归因的慢帧仍保留。GPU disjoint单独判GPU成本无效；窗口有效与性能达标分开。9项单元测试覆盖短暂1Hz突发、低采样、失焦、加载、暂停状态变化、慢CPU和GPU disjoint。

旧记录不被重写；`r1-reassessment.json`记录更正，`lab-r1`保留原构建。最终135条只使用R2，不能把R2变快称为优化收益，因为正式渲染器完全没改。异常与系统/浏览器调度的因果未确定，未加入后台节流绕过参数。
