# 九方向全量画面优化计划 · 2026-10-09

目标是在五张地图和全部138个单位身份上建立一致的材质、光影、动态清晰度与战斗识别质量。方案依据为 [本轮全量测试](VISUAL_PLAN_PRETEST_20261009.md)、逐身份覆盖清单和既有R15–R17独立样板。本文是可评审的实施计划，正式修复尚未集成；受浏览器呈现异常影响，部分性能参数保留为待复测候选。

## 1．材质与色彩：先恢复语义，再调美术

**证据／目标**：不朽者平白覆盖、毒爆白腹、精英紫色覆盖和小身体暗部。目标是亮部保留纹理，暗部有结构，金属／甲壳／软组织／晶体有不同响应，身份配色不遮蔽身体。

**方法与范围**：按204份已解析M3建立标准、复合、发光、透明、加色、裁剪材质分类；保留纹理通道、UV、原始强度与动画。稳定实体ID驱动护障、出生、变形和死亡材质状态；共享GPU定义，实例状态独立。修复已有非法unlit/specular组合。先用不朽者、狂热者死亡及坦克履带源适配贯通链路，随后对清单全部模型逐项处理。

涉及源转换工具、`sc2-materials`、`animated-batch`和新材质控制模块；原始M3/DDS只读。恢复现有PBR适配和源高光近似分别对照，再选择类别参数，不全局提高金属度、提亮或翻转法线。

**出口／回退**：全部206运行模型有材质分类、共享映射、动作阶段和缺口状态；138身份五图近／远、死亡和18英雄错峰事件均复查。原本关闭的附属层保持关闭，多个实例不串状态；故障模型可独立回退至旧导出和旧材质解释。来源问题未解决的条目保持开放。

## 2．分图光照、投影与接触

**证据／目标**：圆形软影不能表达实际身体姿态；V7真实投影增加约2.07ms GPU，接触组合增加约2.64ms。目标是落地／飞行关系清楚，并保持五图冷暖和明暗区的单位可读性。

**方法与范围**：一套分图光照配置、一个主方向光，实际GPU骨骼与实例变换用于阴影pass；1024级阴影为起测档，纹素稳定与偏移独立校准。先动态投影，再评估半分辨率接触遮蔽或静态烘焙；处理旧软影／地表暗斑的重复叠黑。

**出口／回退**：全部飞行／地面、转向／炮塔／变形／死亡及视口边缘无错位、悬浮、自遮斑纹；冰图不洗平、查尔不压黑。默认开关取决于有效的全矩阵成本；低档保留必要软影定位。单独关闭接触pass或真实投影即可回退，不改变World。

## 3．五图地表与材料层次

| 地图 | 美术方案 | 固定评审点 |
|---|---|---|
| 工业遗址 | 金属／混凝土／尘土区分，接缝磨损、基座污渍、碎石过渡 | 起点、道路转折、建筑脚、边界 |
| 玛萨拉 | 暖砂粒度、压实路面、岩脚碎屑、枯植被疏密 | 空旷区、岩群、植被边 |
| 查尔 | 焦土／裂纹／熔岩分层，热光局部化，保留黑灰细节 | 暗地、裂隙、岩群与三族身体同屏 |
| 冰封哨站 | 雪／岩石分开的粗糙度和法线，积雪方向与覆盖过渡 | 雪地、岩脚、蓝色身体、摆件上表面 |
| 边境矿场 | 矿屑／压实路线／机械区区分，接触尘土与尺度统一 | 矿区入口、运输路、机械摆件 |

**方法与范围**：在已有原贴图与真实地表起伏上恢复选层、混合、纹理密度、局部粗糙度与摆件脚边过渡。V7地表候选增加约0.06ms是单场景估计，不能直接外推五图。

**出口／回退**：五图起点／中段／晚期、空场和三族同屏均可审阅；重复图案、悬浮、接缝和大片无细节亮面修正。地表材质配置按地图回退。160×160、18阶段面积、出生点、通行／射线规则沿用现有身份；改变悬崖、坡道、碰撞须另立几何变更包。

## 4．环境构图与空间层次

**目标**：有可识别地标和前／中／远层次，主战场轮廓清楚。构图候选需逐图审图；同一摆件密度或相机参数不能直接套五图。

**方法与范围**：采用原工业、岩石、植被和机械资产，按视野和道路布置材质／纯视觉细节，限制近镜前景的遮挡高度、屏幕面积和数量。优先通过远景层、地标材质关系和基座连接解决空泛感。真实碰撞摆件的位置调整归入几何包；纯视觉配置不消耗玩法RNG。

**出口／回退**：五图阶段对照、四宽高比、全部巨大／飞行单位没有被前景系统性遮挡；路线和目标可辨，地图World指纹相同。环境配置单图可关闭，保持原地图。

## 5．战斗特效与反馈层级

**证据／目标**：护障／死亡源层异常和子单位血条拥挤。目标是发射、轨迹、命中、护盾、死亡各有清晰起止，混战中优先读到身体、危险和实际目标。

**方法与范围**：按真实World事件与稳定ID绑定，不改变伤害、范围、概率、死亡／拾取时刻或已批准英雄设计。源纹理／UV／混合恢复后校准局部峰值、半径与淡出；分清原模型附属层和重建粒子。血条与脚下圈的问题先与最新UI工作核对，避免重复整合。批处理、池化与装饰预算优先，核心命中／危险信息保留。

**出口／回退**：全部身份攻击／支持、18英雄技能、5形态、9敌方×3层级、建筑／工人／载体／子单位／死亡均有事件与画面对照；18／48／96合成密度记录遮挡、core dropped和资源预算。特效分来源独立回退；旧P6-V01不因单项修正自动关闭。

## 6．动态清晰度与动画稳定

**证据／目标**：V7 FXAA增加约1ms GPU，MSAA4约5.90ms；成本差异显著。目标是身体轮廓、高光、细线、地表与阴影在运动时稳定，不靠模糊掩盖错误材质。

**方法与范围**：先保证颜色输出与材质正确，比较原生、FXAA和MSAA4；高档可选MSAA，默认等待复测。按失败模型检查原始网格、法线、镜像UV、骨骼后法线、LOD边界和24Hz插值atlas；仅有证据的模型增加LOD／采样。动静、转向、镜头移动与错峰死亡用相同native ticks比较。

**出口／回退**：全身份运动和动作序列、细轮廓模型及四宽高比无明显闪跳／错帧／拖影；需要连续录像和人类判断，静态图不能替代。AA、单模型LOD与采样可单独退回。

## 7．镜头与战场识别

**证据／目标**：小模型暗／小、破坏者剪影比例和巨大模型的近景裁切已分开定位。目标是移动端能读身体和危险范围，巨大／飞行单位完整可见。

**方法与范围**：先材质，再校准presentation scale与相机。整场视距和单体检查镜头分别配置；竖屏按实际宽高比保持关键单位可见，横屏检查遮挡／输入空间。尊重批准HUD布局、原技能绑定、长按检查和摇杆规则。

**出口／回退**：四尺寸的普通／精英／英雄、巨大／飞行／子单位可识别，所有既有操作继续可达；真实战场与调试相机分开验收。镜头配置和显示标记独立回退，不改战斗半径、射程或移动。

## 8．氛围与环境动态

**目标**：玛萨拉／矿场有限尘埃，查尔局部热色／灰烬，冰图轻雪，工业局部烟尘；身体与危险效果仍处于视觉重点。

**方法与范围**：V7的60点氛围候选GPU增量约0.03ms仅是起测证据。将数量、透明叠加面积、视距和低档禁用作为明确预算；依靠渲染时钟或独立确定性装饰，不使用玩法RNG。不做全屏雾／过曝泛光的统一补救。

**出口／回退**：五图三族、亮／暗地表、持续战斗和移动端都有可看的样板；氛围不遮目标、不盖原特效，不增加输入捕获。此模块默认最后接入，逐图开关和reduced-motion／低档可回退。

## 9．性能、质量档与发行保护

**事实**：V7是有效暂停图形样本；V8部分连续样本有效；V9每秒帧回调和虫族96体的间隔未解释，不能归因为游戏CPU或算成通过。全矩阵性能门槛目前开放。

**复测方法**：真实可见／聚焦窗口，锁定GPU、浏览器、viewport、渲染分辨率、版本与World。每个五图×三族×18／48／96场景做基线→单项→基线重复、至少三次有效样本；10秒单项只用于筛选，60秒连续用于短时稳定，另做自然长时压力。计时窗口不截图／轮询；记录simulation、collector、CPU submit、GPU timer、rAF、tick数、丢弃时间、draw call、显存／堆和context loss。GPU disjoint或低采样样本排除，并记录理由。

**拟定预算**：60Hz目标16.67ms一帧，P95≤20ms、P99≤33.3ms为拟议筛选线；GPU≤12ms和CPU工作≤8ms各自留余量，二者不直接相加当总帧耗时。高档增量在最差有效场景控制≤3ms GPU；超过时先减阴影／接触／装饰，再评估分辨率。预算是实施目标，尚未验收或最终确定。

**分档**：性能档先保留核心反馈与正确材质，降低装饰和可选pass；均衡档候选FXAA、稳定投影、受控氛围；高档保留MSAA／更高阴影／渲染倍率作为单独候选。当前原生档不因样板默认替换。低档仍覆盖所有身份、技能和拾取信息。

**发行出口／回退**：全量身份矩阵、真实输入、精确save/load、World/Profile/RNG／地图指纹、原资产哈希、完整回归和包校验均通过后才正式集成。材质／地图／阴影／AA／FX／镜头分别有feature开关和旧资源清单；失败可逐项回退。物理设备、自然性能、人类美术判断、Science Vessel来源、生产/B4等既有门槛保持开放。

## 实施顺序与交付

1. R0：固定本轮证据、逐模型风险和真实原版匹配参考；恢复有效呈现后补齐成本矩阵。
2. R1：材质语义、实例时钟、输出和身份着色；交付全身份前后对照及分模块开关。
3. R2：分图照明、真实投影、接触候选及AA；以有效成本决定档位。
4. R3：五图地表、构图和基座；按每图阶段矩阵评审，随后补氛围。
5. R4：全量FX、动态稳定、镜头／识别；先复核并行UI最新成果。
6. R5：五图×三族×密度×质量档交叉回归、自然／物理／长时验收、打包和回滚。

每阶段交付具体源码／资源差异、精确版本、逐身份或逐地图证据、成本和开放事项。禁止把“可以正常加载”写成“画面已经全面修好”，禁止以少量材质样板替代全138身份的最终修复验收。
