| 用户要求 | 本轮实现与原游戏边界 |
| --- | --- |
| 强化一览和设施调整分开且独立 | 战斗上栏独立的“强化／基地”入口；关间独立的“强化一览／设施调整”入口。强化仅显示真实卡片累计加成及武器／防护研究，不复用设施列表。两种面板各自开关、返回并保留原暂停状态。 |
| 收起按钮跟随自己的面板，分清控制对象 | 移除负数偏移的绝对定位；“部队／指令”按钮始终在各自面板边界内。四种折叠组合分别检查；都收起时两个命名按钮留在底栏。上箭头展开、下箭头收起。 |
| 设施数量明显，显示解锁状态 | 兵营、重工厂、星港的真实数量用大数字和独立边框展示；每个原所属兵种均显示已解锁或未解锁。不是只列已有科技，也不是将当前五种兵当作全部科技。 |
| 去掉下次发展目标 | 样例移除控件与事件入口。原建设阶段的产线选择、报价、购买和阶段推进继续调用 World，完整游戏功能与规则不删除。 |
| 订单／部署不清楚 | 移除这两个样例标签，使用设施／训练／当前科技。当前科技逐项显示原兵种解锁、技能科技、攻防系统和研究等级。原付款记录不删除，训练页保留既有待救援状态。 |
| 英雄前置，同技能合并，无技能后置 | 三个英雄位排在最前，随后是兵种主动技能，最后是没有手动技能的单位。陆战队员和劫掠者共用一个兴奋剂按钮；只调用一次既有全体兴奋剂操作，人数／生命读取两族群实际部队。没有复制技能、改目标或新增技能。 |
