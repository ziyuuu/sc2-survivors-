# 人族第二分支「末日兵器」强弱初评

2026-11-11，BUILD-1.3 讨论稿。本轮评估玩家提出的 21 张牌，列出补牌候选。建议保留这条路线。枪兵与恶火让早期投资立刻有用，保住并养成多台正式重机后，持续输出可以超过武装支援。武装支援仍应在第一轮接敌、跨区投送和正式部队遭受战损时有优势。以下数值供比较和首测，玩家尚未确认，机械分支尚无同场实测。[三族设计稿](V1_3_FACTION_BUILDS_DRAFT_20261109.md) · [武装支援现行事件规则](V1_4_TERRAN_ARMED_SUPPORT_FEEDBACK_20261111.md)

## 一张蓝牌能换来多少伤害

比较 150 矿／50 气的「死亡弹幕」和同价候选「联发装置」首档。后者先试主炮照常发射，再追加一发原武器一轮伤害的 20%。固定 36 秒，取无甲、无盾、无重甲标签的地面目标。两边均无装备、英雄光环、研究、其他卡牌。只算买牌多出的伤害。[正式牌价和弹幕配置](../../src/data/terran-armed-support.ts) · [实际弹幕落点和触发](../../src/simulation/combat/armed-fire-plan.ts)

| 战况 | 理想增量 |
| --- | ---: |
| 死亡弹幕成功出勤一次，3 排 × 12 个落点，每点恰好打中一人 | 36 × 53.90625 ≈ **1941** |
| 1 台 V 级普通架坦全程有目标，同一轮副炮只中一人 | **889** |
| 2 台同样的架坦持续开火 | **1777** |
| 3 台同样的架坦持续开火 | **2666** |

架坦裸装单发 143.75、理想周期约 1.165 秒。一台的副炮增量为 143.75 ÷ 1.165 × 36 × 20% ≈ 889。这是连续射击近似，未计固定步取整、转向、移动和阵亡。弹幕按正式攻击事件抽取 25%，成功后进入 36 秒冷却。敌群扎堆可以让同一落点打中多人，散开也会让弹幕落空。这个例子能解释为什么两三台有射界的坦克就会改变选择，无法据此推断整队胜率。[架坦武器](../../src/data/sc2-units.ts) · [玩家统一适配](../../src/data/player-unit-adaptations.ts) · [武器数值与逐发扣甲](../../src/simulation/combat/expedition-combat.ts)

普通兵的 V→VII 已使护甲前武器秒伤由一级的 5 倍升到 9 倍，生命由 4.2 倍升到 8 倍。若四联复制四个完整武器周期，一台普通机械的理论单体输出已是原 V 级的 **7.2 倍**，尚未加入装填、穿甲、溅射或十级奖励。人族精英另用以普通 V 为底的曲线，当前机体成长封顶于精英 V。直接把雷霆支点的等级参数从 5 改为 20，机体生命、单击、攻速在现函数里完全相同。两条成长曲线需要分别定价。[普通军衔](../../src/data/ranks.ts) · [人族精英机体与成长](../../src/data/terran-elites.ts)

## 玩家提出的白、绿、蓝牌

| 品质 | 建议保留的效果与首测取法 |
| --- | --- |
| 白 | **重型枪械**先让开局陆战队员和死神的枪弹获益，含对应精英。**恶火**同时放大车身观感与实际喷焰覆盖，长炎沿原长线加宽，地狱骑士沿原扇面扩边，布雷车的地雷仍走自己的半径。**装填升级**加机械原生武器攻速，坦克、雷神及相应精英能吃到。**预警机改造**增加科技球实际修复量，沿用机械全效、生化三分之一和能量消耗。货架按已可生产或已在队的家族提供专属改装。 |
| 绿 | **穿甲弹**让直击枪弹忽略部分护甲，轻枪对厚甲受益明显。**纳米护盾**在各机体上提供有限护盾，停受击一段时间后回充。**履带提升**改善地面机械赶路与赶回射位的速度，架起的坦克仍须收炮才能走。**工程官兵**让附近生化战斗成员缓修受伤机械，建议每个目标最多两人同时修，收益按实际缺血量结算。 |
| 蓝 | **纳米护甲**让机身紧凑并增甲、增血。**幽能护甲**进一步缩实际移动占位，让原来堵在拐角的第二台车也能找射位，两张共同设最小通行半径。**威慑火炮**优先扩大既有溅射外圈，中心仍用原炮伤。**联发装置**试 2／3／4 联，主轮 100%，每个副段 20%，整轮 120%／140%／160%。每段真实发射、命中、扣甲。雷神原生的双炮或四枚对空弹按一个原武器周期计，副段共享该轮的击退、节点和已混买支援的触发机会。 |

科技球的铁幕研究员已经能把有效修复转为有限屏障。工程队修满、盾自己回充、屏障吸收伤害应保留各自的含义，否则高频空修也会维持护盾和攻击收益。恶火扩大的是喷焰覆盖，纳米／幽能改变的是机身与移动占位，买到两类牌时仍能清楚看到宽火线穿过窄路。[医修和精英技能](../GAME_DATA_REFERENCE.md) · [真实攻击轮次](../../src/simulation/combat/armed-procs.ts)

首测建议改装作用于正式成员，普通兵和同类常驻精英都能获得。临时外援使用自己的出勤配置。比如精英雷神「末日过载」已有 8 秒三倍武器伤害，连发能在这 8 秒吃到强主炮，但每段副弹各自再起一轮过载或召来支援，会把同一笔投资重复兑现。精英越鲜明，越需要保留它原先的交火节奏。[精英雷神](../../src/data/terran-elites.ts)

## 三张普通紫与三张紫节点

| 牌 | 战场动作与强度取舍 |
| --- | --- |
| **精英装甲** | 暂将“提高 2 级【2–4】”读作三个档位，上限总共 +2／+3／+4。普通机械与正式机械精英分别沿自己的军衔培养。提高军衔效果可先试“已获得的军衔生命和主武器增量额外 +20%”。只放大增量一次，保留原精英身份与专属技能频率。已有天赋、舰装提供的训练容量和预付席位继续有效。 |
| **特化火力** | 正式机械每个原生攻击周期有机会打退主目标。普通轻敌明显后移，重敌短移，首领保留攻击和阶段动作。给同一目标短暂抗击退时间，四联和整排快枪一起开火仍留有敌方接近的机会。 |
| **机械化** | 常驻非英雄生化成员含精英按原军衔换成金属外观与机械属性，保留原人、原枪、原精英技能。科技球转为全效修理，医疗运输机按机械效率工作。受过工程训练的枪兵保留修理资格，防止整队改造后工兵消失。卡本身可给改装者一层基础装甲，作为第一张普通紫也有收益。 |
| **纳米体系** | 建议有盾／甲和一种真实医修手段再出现。科技球或工程兵修到缺血机械时，本次治疗增强，短时加甲并加快纳米盾回充，修复目标的下一轮枪炮留下纳米持续伤害。连续小弹刷新本来源的持续时间。把修理束、盾面亮起和目标身上的残留伤害串成一次玩家能读懂的反击。 |
| **幽能怒火** | 建议有紧凑机身／幽能护甲和机械火力时出现。机械进一步收窄占位，实弹命中向周围溅射。首测把主轮对主目标的 10% 伤害转为真伤，原有坦克炮只扩同一次爆区。弹幕、溅射和持续伤害各按原来源结算，副段和每个受溅射者都不再派生下一层真伤或爆区。 |
| **精英极化** | 原案为再开 2 级上限、全场现役升 2 级、新兵从 V 起步，达到十级的部队与精英再获 30%。建议先试在本局正式机械和已机械化成员上兑现，英雄另由英雄装甲处理。现役 +2 一次，新到队者至少 V，两项按入队时点区分。以十级主武器与最大生命 +30% 为候选，不另乘攻速、技能频率、护甲与回复。复选可给下一名替补一次补训，永久上限与全场授级各只记一次。沿用原案全军受益时，应同时测满编枪兵开局和重机全灭后的替补强度。 |

普通军衔基础上限 V，培养天赋可把基础上限推至 VII，具体家族另计舰装；精英 I–V 另有曲线。超出原上限的每一级，建议先按各自原顶级机体面板加固定增量，例如每级加顶级主武器的 8%、生命的 10%。保留已有合法军衔带来的全部属性，再单算本分支超限收益。这样“升到 X”和“成为 XX 级等效机体”都有可以核对的标尺。[现行普通容量](../../src/simulation/world.ts) · [精英成长基准](../../src/data/terran-elites.ts)

## 三张橙牌

沿现有主分支的橙色三选一。三张各给一个无法从普通机械牌叠出来的动作。两台 XX 级等效重机按**一台专属常驻机体**估算，武器、有效生命和持续开火时间分别对照当前 V 级同族精英及武装支援「轨道远征军」的三台雷神、两辆精英坦克、一艘普通战巡。重机被毁时保留已学图纸，到下一次合法重型补员抵达再恢复出勤，使对手有消灭核心的价值。[远征编队及现行参数](../../src/data/terran-armed-support.ts)

- **英雄装甲**供生化英雄驾驶本族机甲，放大轮廓，按英雄配色和武器动作辨认驾驶员。机甲提供自身装甲和机械增益资格，英雄的技能、军衔与阵亡／复活沿本人记录。无生化英雄时可保留橙色选择机会，另两项仍可选。
- **高达**用巨型雷神推进。建议正常交火打弹幕，连续锁住重目标后接坦克轰击，完成一轮武器循环后在锁区落一枚小核。三种火力分配同一台 XX 等效重机的整轮预算。小核属于机载武器，玩家库存独立。移动与转火主要损失重炮蓄势，弹幕仍能随队工作。
- **绝望堡垒**用一辆大坦克正面压阵。首轮暂把“5×3”按前方五列、三排的长方形解释，炮线从近至远依次掀开三排。单个大目标在一次齐射中的承伤有整轮预算，体型跨格不会吃满十五轮。转向侧后重排射界，守住正面通道时火力最强。若玩家指的是宽 5 码、深 3 码，首测改用这一实际范围。

## 值得补的牌

| 品质 | 候选 | 买下后能看到什么 |
| --- | --- | --- |
| 白 | **短停点射** | 有枪炮的正式队员随队移动后停下，短暂瞄准，第一轮射得更快。开局枪兵就能用，机群成形后也能用。 |
| 绿 | **抢修拖索** | 受重创的地面机械撤向附近健康车辆，短时获得撤退移速和防护，工程兵能在第二排接修。每次真实重伤只起动一次。 |
| 蓝 | **余弹转火** | 原目标阵亡时，原生多段武器或已加装连发的未发子弹转给侧边的合法敌人。清杂时少打空炮，打单个首领时仍是原弹数。 |
| 普通紫 | **护航副塔** | 给一台正式机械装可独立转向的副塔。主炮仍盯原目标，副塔打靠近侧翼的敌人。单拿就能保护一辆车。 |
| 节点紫 | **接敌预热** | 短停点射配重型枪械或装填。队伍转场后的第一次停稳，已预热的成员打出一轮短促齐射，反复点停须重新积累移动距离。 |
| 节点紫 | **交叉校射** | 重型枪械配穿甲弹。第一名枪手命中给出方向，第二名从不同位置打中时，弹线短距贯穿到后排。一队普通枪兵可兑现，之后正式机械也能接力。 |
| 节点紫 | **阵地供弹** | 有装填与溅射／连发时，同一机体原地连续完成数轮攻击，装填手给下一轮补一排侧向火力。收坦或搬迁清掉未发储备。与接敌预热形成移动和固守两种打法。 |

前三张可用「重型枪械→穿甲弹→短停点射」验证没重机、没精英时也有三笔有效购买及两个可兑现的节点。后续再看重机加入时重新配队是否值得。按同种子、同预算、同阵容和同装备，对照武装支援在 3／6／9 个有效进度及一橙成形时的表现。测一轮密集小怪的清场时间、持续首领战掉血，以及主力折损到正式替补到场之间的损失。无精英和有精英各看一次。短战与折损后支援有利、满编长战机械有利，符合两条路线的取舍。当前只有源码数据与纸面换算，尚无机械牌胜率或实机结果。
