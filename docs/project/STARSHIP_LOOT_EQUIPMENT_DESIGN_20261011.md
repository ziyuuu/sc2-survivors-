## 当前天赋的设计依据

当前源码有 165 个天赋定义，每族 55 个，按语义整理为 55 类机制；资源、士兵、军队各 16 项，微操 7 项。每族四线共享 80 点投入上限，玩家等级就是当前投入点数，不是独立经验等级。永久档案 v6 按三族分别记录余额、实付账本和三个预设；战局开始后使用冻结天赋快照，后续局外修改不影响当前战局。

来源为 [天赋定义](../../src/data/mvp-talents.ts)、[165 个逐项定义](../../src/data/mvp-talents.generated.ts)、[效果聚合](../../src/simulation/progression/mvp-talent-effects.ts)、[永久档案](../../src/simulation/progression/permanent-profile.ts)、[当前永久奖励](../../src/simulation/progression/talent-rewards.ts)、[World](../../src/simulation/world.ts)。

当前效果既有普攻、生命、攻速、暴击、护甲和移动等连续数值，也有免单、扩编、保命、免费救援、临时援军、整队转移和进阶等离散机制。前者适合随机词条，后者适合固定能力与套装。不会把全部装备做成“某天赋等级加一”，也不要求玩家刷到前置节点才能使用一件完整模块。

种族差异保留在真实作用上。神族护盾织构增加原生盾，虫族共生甲壳使用独立缓冲；精英教室只作用于各族已规定的产线和兵种；虫族中间进化体不重复结算；航母子机只继承被指定的母体属性一次。具体差异逐项保留在 [165 项原始映射](STARSHIP_TALENT_MAPPING_R1_20261011.json)。

## 旗舰与永久仓库

三族旗舰分别使用人族战列巡洋舰、虫族利维坦、神族净化者旗舰的题材与外形。它们在局外承载模块和配置，不作为新增战斗英雄或可被攻击的本体。火控、维修和支援效果作用于符合资格的本族队员，沿已有武器、治疗和支援规则结算。

通用舰装与两种改造材料放入共享永久仓库；种族专属模块有明确种族标签。每族三个配装预设，保存装备身份引用，沿用玩家已有的三套方案习惯。同一件通用装备可以被不同种族预设引用，因为只有当前出征的配装生效，不能在同一配装占两个槽。

拾取舰装后加入永久仓库，失利保留已入库装备和材料。出征时冻结装备的完整属性、固定能力、套装计数和效果版本；当前战局只读此快照。玩家可在局外整理新装备，下次出征生效。这样军衔上限、家族容量、免费采购和付费订单不会在战斗或整备中因临时换装发生变化。

旗舰页以舰体和 12 个矩形模块位呈现。详情同时显示底座属性、词条、固定能力、套装进度、种族适用对象及真实总效果；不会只有一个笼统战力数字。当前本局天赋查询入口未来改成“本局舰装”，读取冻结快照。

## 一件舰装包含什么

一件装备由底座、随机词条和特殊属性组成。底座明确所属槽位与基础作用；词条决定同一底座的侧重；传奇固定能力或套装归属决定打法。

| 装备类型 | 随机词条 | 特殊属性 | 长期用途 |
| --- | --- | --- | --- |
| 白色基础件 | 无 | 底座属性 | 填补空槽、拆解合金 |
| 绿色精良件 | 1 条 | 底座属性 | 初期升级、拆解合金 |
| 蓝色稀有件 | 2 条 | 底座属性 | 初期主力、针对性词条 |
| 紫色史诗件 | 3 条 | 较强底座 | 前中期精修、拆解合金与核心 |
| 橙色传奇散件 | 3 条 | 1 个固定能力 | 改变玩法、登记蓝图、精修 |
| 套装件 | 3 条 | 指定套装归属，没有额外的独立传奇能力 | 激活 2／4／6 件效果、混搭 |

套装是装备类别，不把现有绿色精良品质改成最高品质。可以用青绿标志注明套装归属，同时保留物品自己的品质色。

传奇的能力类型固定，例如“扩大普通家族容量”或“允许整队转移”；随机的是数值词条，有些固定能力另有明确强度区间。同一传奇不会随机变成另一种技能。原有前后依赖机制应做成完整模块：降级存活模块包含基础存活条件和恢复比例；功勋模块包含晋升触发与合法目标；免费征召模块包含来源标签和生命增强，不能单独掉一件没有对应能力的无效加强件。

套装件不再附带独立传奇能力，避免“相同词条再白送套装效果”严格压过散件。六件套需要让出六件传奇能力的位置。允许六件主套、四件副套、两件传奇散件，也允许十二件散装；套装名单限定可出现槽位，实际搭配需检查槽位重合。

## 随机词条与强度预算

以下区间按物品等级 100 的常见高阶单条初值给出。低等级区间较低。生成时只从该槽合法池抽取，同件同类词条不重复；不会同时出现“武器升级”和“大火力”两条不同名字的同一属性。范围不表示装备能无条件叠满所有效果。

| 词条 | 高阶单条初值 | 作用边界 |
| --- | --- | --- |
| 普攻伤害 | ＋6%—12% | 合法直接武器伤害，不增加技能、持续伤害或治疗 |
| 攻击速度 | ＋4%—8% | 武器周期，不清冷却，不提高技能施放频率 |
| 暴击概率 | ＋2%—5% | 保留原主武器暴击资格和 1.75 倍，不新增技能暴击 |
| 原属性附伤 | ＋8%—16% | 只增已有轻甲、重甲、生物等附伤，不创造新克制 |
| 最大生命 | ＋8%—15% | 合法战斗队员，增加上限不补回伤损 |
| 原生盾容量 | ＋8%—15% | 有原生盾的对象；神族耐久池按双层生命设计 |
| 护甲后减伤 | 2%—4% | 沿原 S03，在转移伤害中不重复减伤 |
| 普攻闪避 | ＋2%—4% | 不闪避技能、地面危险、范围与持续伤害 |
| 移动速度 | ＋4%—8% | 不允许架起坦克或埋地潜伏者移动 |
| 武器射程 | ＋2%—5% | 不扩大治疗、技能或最小射程，不穿越遮挡 |
| 手动技能冷却缩短 | 3%—6% | 仅有计时 CD 的手动能力；不缩自动输血、胆汁等 |
| 合法治疗／回盾输出 | ＋8%—16% | 拆分生命治疗与原生盾恢复资格，不自动治愈感染 |
| 被动采集 | ＋8%—16% | 只增矿气被动收入，不增过关、拾取和退款 |
| 拾取矿气收益 | ＋10%—20% | 对真实拾取入账一次，不增掉落次数 |
| 过关矿气 | ＋6%—12% | 只增原阶段矿气奖励，不增永久舰材或舰装 |
| 建造及解锁费用降低 | 4%—8% | 保留原 R04 适用项目 |
| 普遍采购费用降低 | 3%—6% | 保留原 R12 适用范围与最低价格 |
| 刷新矿价降低 | 10—20 矿 | 保留共享刷新计数和最低矿价 |
| 矿气拾取范围 | ＋25%—50% | 延续 R08，只作用资源，不卡牌、救援、攻击 |
| 到队晋升概率 | ＋2%—5% | 真正接收的普通最终体一次判定，保留培养容量 |
| 战利品发现 | ＋5%—10% | 新增候选，提升普通舰装随机掉落触发率，合计最高＋50%；不加保证掉落件数 |
| 能量回复／能量容量 | ＋5%—10%／＋10—20 | 新增候选，仅本来使用能量的合法单位，不凭空给英雄创造能量系统 |

高级武装原来把多种属性打包。新系统把它拆到对应槽位和词条，不让每件装备同时随机到伤害、血、甲、移速、攻速和治疗全套。

装备层初始上限建议：普攻伤害＋90%、攻速＋45%、生命＋70%、原生盾＋70%、移速＋45%、射程＋15%、护甲后减伤18%、暴击概率22.5%、闪避13.5%、手动冷却缩短30%。这是起始平衡预算，不是当前满 80 点方案的等价结果；还需分别与实际旧合法配点、三族和难度对照。其他来源的冷却规则仍保留最低总倍率 0.5。

同属性在装备层内相加，再进入原单位计算；不把 12 件装备各作为独立乘区。传奇与套装带来的同名机制不重复触发，取较强完整效果。详情显示总值、上限和溢出，避免玩家看不见某条已经无效。

## 六条套装路线

每个系列有六个可出现的槽位，效果按 2／4／6 件累计触发。下表给出初始机制，数值没有通过平衡验收。

## 掉落与每次出征的收益

舰装独立于当前局内卡牌、矿气和正式单位奖励。前一份随机事件设计中的任务仍获得指定农民、设施、精英或英雄；不会改成装备、材料等替代收益。舰装是在此之外设计的独立永久成长来源，拆解是玩家处理自己装备的用途。

| 来源 | 初始舰装掉落方案 | 作用 |
| --- | --- | --- |
| 普通真实敌人 | 1%掉落一件，前期以白绿蓝为主 | 战斗中也有小惊喜，不全等Boss |
| 精英 | 35%掉落一件，至少蓝色 | 击杀精英有追逐价值 |
| Boss／领主 | 一件保证，至少蓝色；中后期提高紫、套装与橙概率 | 给一次战斗明确目标，原单位卡掉落另算 |
| 特殊敌人 | 独立50%一次舰装机会 | 原特殊收益保留 |
| 支线完成 | 独立25%一次舰装机会 | 完成身份收据一次，不能反复汇合刷奖励 |
| 每完整战斗分钟 | 10合金、1异构核心 | 提供独立基础进度，失败也留已结算收益 |
| 特殊挑战、困难与地狱 | 更高物品等级与高阶类型权重 | 收益效率更高，不锁住低难度玩家的全部制造上限 |

稀有发现词条只提高非保证随机触发率，不把Boss一件保证变成无限件。时间奖励按真实模拟战斗时间和唯一分钟收据结算，暂停、菜单、离线、诊断场景不计。无需等整局胜利才把已入库收益算给玩家。

建议普通战役约每分钟一至两件舰装的体感目标；表中概率需要用当前实际敌量回放估算后校准，不能宣称现已达到。高密度虫潮分批出现装备，传奇有短光柱、声音和约1.2秒名称提示，普通件轻提示；装备通知不捕获输入。

智能掉落初稿：60%通用模块、35%本族专属、5%其他种族专属。它有利于当前舰船，也保留换族收集目标。掉落类型与词条在实体生成时固定，读档不能重新洗出另一件；真实敌人一生只触发一次其装备收据。由玩家创造的友军、幻象、复活复制和反复转化不组成材料循环。

物品等级初稿1—100，决定词条区间和底座强度，不要求先攒80点才能穿。品质、物品等级、词条契合度、固定能力与套装组合分别决定价值；低等级好传奇可以升级底座继续用，避免早期好掉落被后期数字直接废掉。

## 改造与材料循环

永久材料先只设两种：舰装合金与异构核心。低品质拆解给合金，高品质额外给核心；不再为每槽、每族和每个词条另开一种货币。

| 操作 | 初始成本示例 | 保留与变化 |
| --- | --- | --- |
| 制作白色指定槽底座 | 10合金 | 补齐空槽，帮助初期进度 |
| 单词条重铸 | 20合金、1核心起，逐次最多涨到100合金、5核心 | 一件装备只开放一个选定随机词条；三选一或留原值，其他词条和固定能力不变 |
| 提升物品等级十级 | 50合金、3核心 | 保留随机词条在原区间的相对百分位，再映射到新等级；传奇和套装身份不变 |
| 登记传奇蓝图 | 首次获得自动登记，无需拆掉唯一在用装备 | 只解锁同类传奇的制造，不增加免费常驻技能 |
| 制作已有传奇蓝图 | 200合金、20核心 | 指定槽与能力，随机词条重新生成；保留掉落寻找好词条的价值 |
| 制作已登记系列套装部件 | 150合金、15核心 | 同族同系列收集三个不同槽后解锁该系列缺件制造；有定向成型路线，不能凭首件立即造全套 |
| 深层精铸 | 后续候选，用高成本合金／核心 | 优化已有区间，不能突破装备层上限或新增无限乘区 |

新账号先有一件基础核心和主武器，其他十槽可制作白件补齐。第一轮出征就能开始积累装备与材料；中期追固定能力和四／六件套；后期追适合不同兵种组合的词条和完整多预设。

“打多久都有收益”的具体承诺是战斗期间有独立材料进度、已入库物品永久保留、重复掉落可以参与改造与收藏，不是每一件都保证高于当前装备。满配后仍有新构筑、三族蓝图、词条精修和舰船外观收藏目标；数值有明确上限，不靠无限攻击百分比让旧关卡失去意义。

## 装备例子与实际取舍

### 雷诺的领袖授权

人族旗舰核心，橙色，物品等级60。底座为全军生命＋8%；随机词条可为英雄普攻＋9%、手动主动CD缩短4%、过关矿气＋8%；固定能力是开局从原五名人族地面英雄选一名以II级出征。

它适合尽早让英雄承担战场主力。选择它就让出同槽的战术进阶或精英成长传奇；开局英雄仍占三身份之一，不能因装备叫“旗舰”多送一名大和英雄。

### 诺娃的幽灵火控

人族主武器平台，橙色，物品等级72。底座普攻伤害＋8%；随机词条为暴击＋4%、原属性附伤＋12%、攻速＋6%；固定能力启用本族原APM追加直击。

适合真实直接射击部队。同样词条的范围伤害、治疗队和技能队未必受益；与移动输出六件套同机制不重复追加第三、第四枪，玩家应该更换重复机制的模块。

### 共生甲壳的生命维持舱

虫族医疗槽套装件，紫色，物品等级65。底座合法生命治疗＋10%；词条为生命＋13%、护甲后减伤3%、移动速度＋5%；归属生存坚守，没有独立传奇保命。

换上它可能从五件变六件，激活同族生命分担；同时失去原医疗槽的死战不退传奇。收益来自整套构筑取舍，不能仅比较单件分数。

### 折跃军势的兵员舱

神族兵员槽套装件，紫色。可以有到队晋升、原生盾和采购费用词条；二件联合援军提供有来源标签的免费救援与双层耐久，六件提供热能及回盾支援。

这会占用原本可装“扩编至七”的兵员槽。如果希望保留七名额，需要选择不同套装槽组合或用另一套路线，不能在一个舱位同时塞套装件和扩编传奇。

## 与随机事件方案的联动

酒馆告示与诱虫剂仍属于本局购买内容，影响本局遭遇；舰装是局外长期构筑。经济探索套可让玩家更愿意护送和守建筑，老兵培养套适合营救精英，移动输出套适合追黄金工蜂与逃跑跳虫，联合援军套适合虫潮与守点。

当关间色子或舰装战利品发现提高新舰装掉落时，需要给两者各自明确作用范围；初稿只把新增“战利品发现”用于永久装备随机触发，原色子仍按前稿局内卡规则。母亲的保证英雄、跳虫的保证蓝卡与鞘翅的指定效果不被装备品质抽签替换。

## 存档与接入边界

新系统需要永久装备实例、属性定值、材料、蓝图、套装收藏、各族配装与收益收据；当前战局需要完整冻结配装及固定机制的真实倒计时、次数和来源标签。装备属性不是对当前天赋树分配80点的隐式模拟，数值词条要直接进入新装备效果层。

掉落随机与战斗随机分离，装备生成与首次入库用稳定身份和收据；永久档案与战局仍按项目原子存档合同更新。局外同一装备升级后，旧战局继续用出征时的定值，不因引用一个已变化实例而偷偷变强。

现有三族余额、实付本金、预设、皮肤收据和原始存档都应保留。旧天赋投资如何兑换是后续单独的转换规则，本稿不设置一比一凭空发传奇、不修改现有档案，也不启动MVP确认前的旧档匹配／迁移。未来正式接入需要显式设计新数据版本和测试，不能直接写进当前run26/profile6后声称完全兼容。

## 建议的验证顺序

先验证12槽、永久仓库、拾取入库和开局冻结；再用少量随机属性与六个代表固定能力验证实际构筑：扩编、军衔上限、开局英雄、整队转移、保命、APM。随后加入两套对比鲜明的经济／生存套，测试散件取舍与材料消耗，再扩大六套及全部天赋映射。

正式验证需要旧零天赋／合法80点方案、新基础白装／成型套／高阶混搭，在三族与四难度下分别比较进度、伤亡、经济、合法容量、付费账本、子机继承和源伤害。刷装收益应测实际每分钟数量、重复件用途、第一件关键传奇和套装成型时间，不能用数据表宣称“已经更爽”。
