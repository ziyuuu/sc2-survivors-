# MVP 反馈 F01–F04 · 已批准替代基线

日期：2026-09-27。变更来源：本次用户对 [反馈计划 r1](MVP_FEEDBACK_PLAN_20260927.md) 的逐项纠正与最终实施确认。本文记录获准实施的最终规则；r1 中“全部敌人半血”、两种资源商品和品质保底等相反候选已被本稿替代。批准是实施授权，不是测试、视觉或完整阶段验收。

本轮顺序为血量纠正、动作播放、关间商店、Boss。F05／F06、三族农民／载体替换和英雄耐久／体型／技能数值不在本轮范围。保留单一 World、60 Hz 模拟、18关章节曲线、三族165节点及共享80点；不修改节点层价、前置、已付款账本或旧原始存档。

## F01 · 早期跳虫血量

18关配置的跳虫基础生命明确为第1／2／3关18／24／30、第4关起35，不能按旧12关时间轴插值。普通波次和空投守军使用同一基础值、出生关卡章节成长及难度压力；跨关落地守军取空投保存的关卡。

简单难度仍只减半章节成长增量，不将全部敌人的最终生命减半。Boss保留原始生命×简单0.5／普通0.9，再应用既有难度压力；其他普通敌人的基础值、精英成长、主巢和无尽成长均不因F01重算。读档保留原难度、实际HP／最大HP和暂停状态，不追溯给存活敌人升级或回血。

## F02 · 真实攻击动作与两个动作档

已有攻击片段由真实攻击事件启动并完整播放，不被下一模拟步的idle／move立刻覆盖；移动、普攻时机、伤害和冷却保持模拟合同。死亡、变形和恢复态有优先级，读档不重播已发生的发射特效。

“完整动作”为默认，保留现有24 Hz骨骼烘焙并按显示帧插值；“节能动作”使用同一片段、15 Hz姿态采样、关闭姿态帧间插值。两档均保留显示帧移动／镜头插值和真实弹道／命中／危险预警；事件首帧及时呈现，暂停冻结表现时钟。设置独立于清晰度和战局难度，不承诺源动作60帧或设备60 FPS。

## F03 · 方向、一次发展、付费商店

首次关间主动选发展方向，随后记住该方向并可改选；每窗口只执行一次发展动作，可跳过，之后进入三商品付费商店。三项可分别购买，每项每页一次，售罄不自动补货；可零购继续、买后刷新，刷新仅替换未完成的报价，已获效果保留。生产配置、维修、复活和A10精英特约保持独立入口。

取消零天赋免费商品和章免费刷新。R06每窗口提供1／2／3次发展与商店共享免费刷新；R09每窗口提供1／2次商店免单，购买时优先消耗并显示天赋来源，跨刷新页保留，离开窗口失效，不能抵扣A10。节点等级、层价和前置不变。

发展与商店共享刷新序号n；基础价为50＋40n矿，每次成功刷新（含免费）推进n，新窗口归零，读档不归零。发展购买前与购物均可无限递增刷新，不设每窗口付费次数上限。R03／R12后实付为 `max(10, ceil((50+40n−20×R03)×(1−0.1×R12)))`。免费次数优先并记来源，不消耗钱包。

每个商品独立随机折扣0／15%／30%／50%，权重50／30／15／5；与R12相乘，实体建筑额外与R04相乘。矿气分别向上取整，零基础价仍为零，正价至少1。报价与折扣在生成时保存，不随重入或读档重掷。

## F04 · 固定Boss、掉落与无尽池

恢复3／6／9／12关原四只固定Boss：跳虫、蟑螂、刺蛇、破坏者；15关增加潜伏者，原始生命24000、护甲3；18关增加雷兽，原始生命32000、护甲4。沿用F01的Boss难度倍率；不能把队长或主巢事件冒充固定Boss。

每只Boss真实死亡产生一件奖励：80%紫／20%橙，橙替代紫；由真实死亡收据防重，R14保持已确认的独立来源与概率，不为Boss另加R14掉落。掉落拾取无需付款，按本族合法奖励池生成；满额兑换沿反馈计划的250矿／100气，领取与放弃明确结清，读档和跨关不重复发奖。

无尽Boss池包含原四种，以及虫后、潜伏者、异龙、腐化者、雷兽，共九种，每第三只仍为领主。保持现有成长序列及60 Hz结算。第18关胜利必须同时满足主巢已毁、时限完成、最终雷兽Boss已死和原有友军存活条件。
