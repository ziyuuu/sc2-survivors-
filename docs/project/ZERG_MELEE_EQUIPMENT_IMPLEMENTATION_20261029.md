## 实际行为

| 范围 | 已实现规则 |
| --- | --- |
| 孵化场 | 基地建设与设施调整提供固定进化入口；选择具体孵化场后进行地面／天空进化。每巢显示两个方向的完成状态及当前产出。建新孵化场仅在基础方向；进化退出随机三选一卡池。保留地面“解锁蟑螂或虫后”、天空“至少一座地面进化”的前置。 |
| 进化交易 | 固定报价沿用原折扣、天赋、装备与付费回执，并占用原建设行动；不是额外赠送行动。切页不重抽，重复点击、旧版本报价、错误目标和资源不足不能重复购买。旧关间档首次补齐固定报价时通知保存，原卡牌／报价不重抽；恢复不自动补排已取消的生产。 |
| 近战接敌 | 己方近战提前选取可接触目标、绕过己方射击线，目标死亡后取消无效前摇并立即重选；不可达目标暂缓0.75秒，避免盯着围墙内目标原地等待。明确移动／撤退优先，保留离队距离与地形约束。 |
| 冲锋范围 | 当前地面攻击射程≤4、来源碰撞半径≥0.5的攻击单位，外加毒爆。普通例子为雷兽、蟑螂、狂热者、使徒、恶蝠；英雄／精英按实际家族形态与武器筛选。雷神、巨像、不朽者、坦克、破坏者、潜伏者、虫后等长射程单位不适用。临时毒爆保持一次性生命周期。 |
| 冲锋参数 | 一般6秒CD、当前移速×1.6、最长1秒或4格；毒爆4秒CD、×1.8、最长0.8秒或4格。CD从发动计时；只穿敌我战斗单位，墙、地形、建筑与地图边界仍阻挡。进入射程、目标失效、控制或撤退时停止，无额外伤害；结束恢复碰撞。已研究狂热者沿用专用冲锋，不叠加第二套冷却。 |
| 毒爆 | 己方永久普通／精英爆炸后休眠1.5秒；新生产基础20秒、基础移速4.2，科研、军衔等继续计算。已付订单时间不追溯；敌方原版数据及临时自爆生命周期保持。 |
| 跳虫 | 己方跳虫承受敌方毒爆的实际爆炸伤害减40%；不扩展到其他伤害、仅同名来源的技能或敌方跳虫。护甲后按同一伤害路径计算，避免先截断过量伤害再打折。 |
| 潜伏者 | 己方普通与三类精英在地上使用同款地刺，伤害为潜伏状态60%，包含科研附加值；潜伏后保留隐形并以正常70%移速移动。共用原攻击片段和地刺效果，模式转换、已承诺攻击时钟保持；敌方规则不变。 |
| 舰装 | 桌面槽56px／图44px，手机槽48px／图38px。加强空槽实底和边框，保留已装备品质底色；选中描边与装备成功短暂高亮，尊重减少动画偏好。沿用旗舰尺寸与原12槽避让算法。 |
| 局外装备 | 旗舰配装和完整仓库提供“一键装备”，从仓库选择本族更高品质普通散件，同品质保留现装。保护套装、模块、特殊、锁定、收藏及污染限制；旧装备回到仓库，整批一次账户修订及保存。关间仍用本局背包，战斗中不可换装。 |

## 代码和保存边界

- 数值适配集中在`src/data/player-unit-adaptations.ts`，不重写原版来源表。毒爆配方、潜伏者武器／移动和爆炸减伤分别接入已有生产、战斗与伤害路径。
- `movement/approach-charge.ts`处理冲锋资格、移动和接触豁免；`World`与`EngagementSlots`处理目标与近战接敌。不可达目标缓存可重建；冲锋意图和已花费CD随实体保存，`persistence/run-fields.ts`登记并校验，schema26保持。
- `building/rules.ts`从随机报价抽出共享报价函数，固定进化与原交易共用校验／回执；`hatchery-evolution.ts`使用实际报价及逐巢状态。新入口不另造资源结算。
- `quick-equip.ts`按是否有未结束战局选择仓库或背包，沿用`canEquip`和账户事务。当前旧档兼容范围、两份备份与失败保护不扩展。
