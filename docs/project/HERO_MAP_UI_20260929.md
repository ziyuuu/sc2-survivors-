## 研究依据与采用方式

- Riot的[VALORANT着色器与战斗清晰度](https://www.riotgames.com/en/news/valorant-shaders-and-gameplay-clarity)和[特效制作课程](https://www.riotgames.com/it/artedu/visual-effects)：用形状、时间节奏和明暗层次建立重点。本作把英雄主体弹体、真实命中和危险预警作为最高优先级，烟尘/外围碎片先回收；不将配色差异当作完整身份设计。
- [Xbox文字显示可访问性指南](https://learn.microsoft.com/en-us/gaming/accessibility/xbox-accessibility-guidelines/101)：文字大小、缩放与复杂背景可读性分别验证。本作16/14/12px、100/125/150%文字和44px点击区域是本轮批准的具体参数，不冒充适用于所有游戏的统一数值。
- 原SC兵种/英雄、动作、挂点和死亡主体从本地锁定来源读取，来源检查、运行表现、人工观感分别记账。未将素材或本地战斗画面发送给外部生成服务。

短横屏底栏实测采用142px，给44px顶部指令、两排44px头像和间距留出真实空间；战场投影与底栏联动，而非遮盖战场或缩小文字。
