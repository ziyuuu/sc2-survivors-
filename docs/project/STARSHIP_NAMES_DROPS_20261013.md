同一家族下位件可凑件数，但不能冒充高品质门槛。例如紫档六件可用4紫＋2蓝紫；橙档六件可用4橙＋2紫橙。4蓝紫＋2紫仍不满足至少4件紫色的条件。能否激活更低档效果取决于该家族是否存在该档，不能凭下位件自动创建未设计的低档套装效果。

## 三层掉落，互不替代

1. 基础层：普通敌人、精英、Boss原有概率掉落照常结算；基础掉率与池子尚未在本稿新定。
2. 必掉层：每个符合条件的精英或Boss额外产出一件，从对应难度必掉池抽取。斜线表示候选之一，不是每类各掉一件。
3. 无尽追加层：无尽Boss在前两层之外再判定一次额外掉落，概率随无尽关数增加。命中后从本难度追加池抽一件。

因此Boss基础层已有掉落时，仍有必掉装备，也仍可命中无尽追加；不是先看基础层是否掉落再补一件。普通敌人不因本表获得额外必掉。被召唤的小怪是否有精英奖励资格由敌人来源标签统一定义，不能仅凭外观精英化反复生成Boss级奖励；此为后续实现资格约束，不更改本表用户定义的正常精英必掉。
