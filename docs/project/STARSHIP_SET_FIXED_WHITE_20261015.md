## 固定方式

每套的四个进攻部位采用同一固定DPS／攻速组合，四个防御部位采用同一固定护甲／生命组合。八槽均可出该套，不限定必须收集指定部位才能激活。各部位有自己的名称和图片，但不再暗设不同白字抽签。

表中沿用机制名便于核对，UI仍用三族已定装备名。相应绿、独立蓝、高阶蓝紫、紫橙及橙档沿同一偏向，但不是合并家族或混用资格。三族数值预算相同，实际品质决定数值：蓝紫件用蓝表，紫橙件用紫表。普通污染不改变白字，清洗不重抽；污染英雄独立家族见专行。

白字提供通用属性，不把DPS白字改成技能、陷阱、支援或治疗增伤；攻速不缩技能CD。固定偏向表达构筑取舍，不声称所有武器上偏DPS一定比偏攻速更强。
