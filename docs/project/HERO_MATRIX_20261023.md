## 建议：先讨论定位，再分项调整

1. **暂时保留当前开放规则。** 本次直接获得英雄用于战力对照，并未验证自然获取概率；第12／15／18关不在本次矩阵内，不能据此判断简单12关门槛的最终平衡，更不能据此提前开放。
2. **如希望Boss仍有交战过程，优先调整英雄对单体的爆发与持续输出，不统一抬高Boss生命。** 432条英雄单独Boss样本的耗时见上表；无英雄小队本已有战败，统一加厚Boss会同时加重普通队伍负担。具体目标耗时和调整幅度属于待讨论的设计选择，本次没有预设削弱百分比。
3. **不要统一削弱18英雄的生命、伤害和技能。** 持续敌群表现分化，诺娃／斯旺等已有真实阵亡；对地英雄留下异龙属于能力边界。保留对空队伍和辅助分工，逐名判断需要削弱的通用输出、应保留的短板。
4. **泽拉图等地面残敌先核查追击／技能行为，再做数值判断。** 原生移动重放仍有地面残敌，尚不能认定是生产缺陷，也不能把超时直接当作伤害不足。
5. **两种可讨论定位：** 若英雄是后期强力奖励，可接受早中期Boss被迅速处理并保留当前数值；若英雄是队伍核心且希望Boss保有威胁，建议选择上面的逐英雄、逐输出通道调整。基于这批数据，更建议后者，避免一次奖励抹平多数早中期Boss交战，同时保留兵种互补。
