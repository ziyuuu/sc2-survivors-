- 删除左上角常驻白字；情绪文字随画面出现：激动处炮弹撞击与艺术字、悲伤处淡出、激战处血字。

三族开场为平行战场，不合成不存在的混编玩法。正常发展到翻盘优先一族连续讲完，另两族用独立段落补齐；最终主叙事族按实拍可读性选择。

## 包装与制作方法

文字只在情绪节点出现。燃点用粗重窄体、金属断面、橙白内光和炮弹冲击，先撞击再稳定可读约1秒；悲伤用淡灰、慢显慢隐及灰尘消散；激战用暗红粗笔、断裂笔触和短促飞溅。全片建议6–8处主艺术字，数字对比另计；不遮关键单位、掉落和操作。

保持无旁白；英雄原声必须匹配身份与情绪。配乐按压迫、静默、重建、危机、翻盘、装备节奏、终局七段重排。音效为炮弹、盾破、死亡、装备与到场反馈提供节奏，不以连续全屏闪白和震屏代替动作。

先按时间线确认素材缺口，再拍三族失败、一次完整成长翻盘、三族受控装备对比、既有Logo/载入动画。旧片仅复用符合新叙事和当前画面要求的素材。先剪纯画面与声音的四分钟粗剪，再做关键文字特效和精剪。

第一版验证记录注明重场景实际采样不足；重拍应核对动作连续性与实际采样，输出30 FPS本身不能证明流畅。装备比较核对真实数值与唯一装备变量；Boss击杀、拾取和到场要保持完整因果。以上为方案阶段验证要求；实际完成情况见 V2 制作记录。正式产品与公开发布保持原状态。
