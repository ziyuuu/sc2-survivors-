推荐先采用第12关Boss开放普通新英雄，保留已经确认的高阶装备赠送／进化和999击杀虫后特殊奖励；本批不削英雄基础数值。此方案能处理普通前期随机获得英雄，不能声称高阶装备开局也没有英雄。用户若要求前12关绝对无英雄，需要同时重写这些已确认装备／特殊奖励合同，另作明确选择。

第12关Boss开放不会自动把Boss奖励改成100%英雄；仍沿原20%橙英雄、紫精英及池耗尽保底，首个可得节点为第12关Boss。这一概率是否需要改为首个英雄保底，也应明确决定，不能从“开放”自行推断。

## 卡牌结算修复口径

1. 全军伤害／生命百分比覆盖同一单位适用的装备白字追加部分；不重复乘原生已算的卡牌、不把固定真实DPS或固定DPS再次乘攻速。
2. 核弹、地雷、轰炸、独立导弹／毒囊／破盾反击／棱镜扫射进入全局装备攻击百分比；提交时保存数值，延迟命中不补乘，弹射／回声／灼烧继承已增强的原命中，只算一次。
3. 固定一次性支援不把主武器“每秒伤害”直接当成单次伤害加上。白字DPS按既定武器周期合同分配；没有武器周期的核弹沿独立伤害通道。攻速／暴击／固定真实DPS不凭空追加给支援。是否另设“DPS转支援倍率”是新的平衡数值，当前未批准。
4. 恢复卡走目标防御等级对应的受恢复倍率；以最大生命／护盾比例计算的效果先读取已装备上限。临时虫群经实际单位创建继承舰装；空降地堡须单独核验武器与耐久，不按普通结构排除后漏掉全部加成。
5. 能量、生产、资源、门票、控制和升级卡各按自己的对应机制：没有对应装备属性的量不硬乘伤害；已付生产不回写，钱包不借战斗攻击放大，概率与数量不自行改变。现役池已排除旧单兵weapon／vitality／armor／cultivation卡，不恢复它们来充覆盖数。

卡牌修复已完成，详见[G01卡牌修复记录](G01_CARD_EQUIPMENT_20261022.md)：2190回归、310张功能／全队卡带装备实测、三族支援实际扣血与浏览器核弹链路通过。英雄来源／数值未修改；本文候选仍待用户选择，G01尚未关闭。
