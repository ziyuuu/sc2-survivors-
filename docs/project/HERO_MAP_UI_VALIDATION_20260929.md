## 检查中修正的问题与证据边界

- 地图摆件原材质引用完整加载，缺图即失败，不继续显示白模；静态摆件保留原Stand姿态。
- 战列巡洋舰普攻分别使用原左右炮位01/04，聚变炮用舰首09；利维坦普攻轮换02—05口器，技能使用01。挂点位置按实际开火姿态采样，不能使用出生姿态的t=0位置。
- 新SVG线框在离线包、HTTP清单和静态服务中统一为`image/svg+xml`。部署服务回归验证该类型及实际字节，避免开发版正常、发行版缺图。
- 最初英雄诊断直接调用发射入口，主体停在出生姿态；旧`playback-final`只作事件烟测。`playback-resolved`改用真实交战更新。沃拉尊只施加控制，因此III/V级应核对`skill-status`，而不是要求不存在的伤害事件；错误断言的失败报告保留。
- 录制工具原来只清除即时特效，前一个身份的真实残骸会留到下一段开头。已改为逐身份重置表现对象，另录`playback-clean`英雄片段；没有改变游戏中正常的残骸持续时间。普通/精英早期录像开头可能有上一段残骸，当前身份的完整固定步数据和后段画面分别保留。
- 早期地图截图夹具清空了全部友军，触发正常败北页面；其贴图检查有效，但遮挡画面不能作为地图观感证据。环境夹具现保留观察单位，重新采集三主题画面，并检查三英雄、五精英与真实Boss预警同场。
- 曾并行运行两组完整模型诊断，宿主可用内存降至约74MiB，随即停止额外窗口，恢复至约5.34GiB后改回串行。此段属于录制工具压力，未纳入自然帧时采样。
- 早期两组自然首关采样工具只记录声称的固定种子，未锁定实际开局随机数，不能用作同种子模式对照。报告保留为探索样本（其中人族节能P95为17.0ms，未过门槛）；工具已补实际种子记录与校验，后续数据另存，不能覆盖失败。
- 120普通/精英的基础烟测只覆盖发射及死亡；另行运行完整固定步诊断，分别触发自动治疗、输血、守护盾、风暴、护障、变形及实际交战，并为每个身份保存短片。影片与数值观察仍不等于用户视觉签收。
