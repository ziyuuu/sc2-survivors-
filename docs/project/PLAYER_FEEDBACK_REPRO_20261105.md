| 场景 | 手动资格 | 一键结果 |
| --- | --- | --- |
| 低品质普通散件 → 更高品质普通散件，局外/关间 | 可换 | 正常替换 |
| 普通散件 → 同品质普通散件，局外/关间 | 可换 | 保留现装，按钮禁用 |

- 特殊装备案例在局外和关间均可通过原控制器手动替换，一键计划却为空。
- 同时有一个受保护槽和一个可装备空槽时，一键操作正常填空槽，受保护槽保持；没有整页冻结。
- 已有普通散件升级成功；全部9组无浏览器脚本错误，8组模拟调用均正常返回。
