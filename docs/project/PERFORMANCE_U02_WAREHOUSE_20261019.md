# U02：旗舰配装与大仓库操作 · 2026-10-19

用户在确认下一项为 U02 后授权“开始吧”。本项修复 B03 复现的搜索／清空 DOM 重入异常，并减少仓库操作的整页重建。状态以[性能看板](PERFORMANCE_BOARD.html)为准；证据见 [QA 报告](../../reports/qa/performance-u02-20261019.json)和[逐项校验](../../reports/local/performance-u02-20261019/verification.json)。

## 实现与边界

- 搜索只在 input 值改变时更新列表；change 不再重复处理搜索。输入控件保持同一节点，保留光标、焦点及组合输入期间的控件身份。
- 搜索、筛选、排序和翻页只刷新仓库列表相关区域。舰船、装备详情、详情动效、顶部导航与搜索框保持；相同卡片复用图片节点。勾选只更新选择状态和计数。
- 缓存最近一份筛选／排序结果，按账户身份及版本、管理版本、阶段、种族、页面、查询、筛选和排序条件失效；单次计算内复用装备名称。翻页不再重新筛选／排序整个仓库。关闭窗口释放缓存和列表引用。
- 滚动位置保留到新内容允许的范围；结果变短时正常钳制到新最大值。过滤部位时，左侧槽位选中标记也同步。
- 活动出征的新局页改为说明“请先继续并结束当前出征”，与已有禁用按钮一致。没有开放覆盖活动出征，也没有改变出征／装备规则。

生产改动只有 `src/ui/starship/legacy-view.ts` 和 `src/ui/hud/m3-menu.ts`。没有改动样式、图片、五图、战斗模拟、伤害、RNG、经济、掉落、300 上限、4∶4∶1 或存档延期。

## 对照方法与结果

两侧均为 main `be9e2982944314194c6dcc9dcc535bc321749eb4` 加已验证的 F05；候选侧仅叠加本项两处 UI 源文件。438 个编译输入有哈希和内容归档；排除其他任务的 economic-egg 修改。CSS 字节一致。

串行 Chrome、1440×900、DPR 1、完整效果。用真实装备账户和扩仓规则合成空仓／1000 件合法满仓；通过现有普通入口挂载共享 UI。分别录制浏览器实际输入和同步事件派发。后者只衡量处理函数及同步布局成本，不是输入到画面延迟、GPU 时间或 FPS。

正式配对为 baseline-2／fixed-4、baseline-3／fixed-5。每个操作类型排除最初 3 次派发后取中位数；清空每轮出现两次，其余每轮一次。下表列两轮中位数范围，单位毫秒：

| 操作 | 旧版 | 修复版 |
| --- | ---: | ---: |
| 无匹配搜索 | 3.20–3.75 | 4.40–6.65 |
| 有匹配搜索 | 6.55–7.10 | 6.30–7.20 |
| 清空搜索（两类结果） | 9.80–10.10 | 8.70–9.40 |

收益主要来自翻页和勾选。无匹配搜索没有收益并出现处理耗时增加；有匹配搜索和排序的差值以原始数据为准，不宣称所有操作都变快。搜索修复的首要结果是异常消除和输入稳定。原始浏览器 input／change 到双帧回调的记录保留在校验报告中，不与同步计时相加。

旧版两轮各 22 次 DOM 重入异常；最终修复两轮页面／控制台／HTTP 错误均为 0。资源请求失败另列：baseline-2／fixed-4：0／8；baseline-3／fixed-5：0／0，具体 URL 和取消原因保留在原报告。
