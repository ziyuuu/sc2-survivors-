## 品质与套装命名层次

- 白绿：日常器件和初阶装备；绿套也用简短特色词区分。
- 蓝：专业军械、生体器官和灵能器件；独立蓝套与紫系列的蓝色下位件使用不同物件名。
- 紫：稀有精锐器件，例如锁定镜、泰坦骨架、先觉复眼、先知棱镜。套装的短特色词融入物件名称，不重复完整套装标题。
- 橙：传奇专属物件，例如裁决之眼、擎天骨架、万巢之瞳、创生之心。英雄橙装使用角色专属意象。橙系列的紫色下位件仍用紫装词汇，例如雷诺的星火追猎镜，不冒称橙装。
- 污染来源是状态，不能仅凭污染提高名称品质。普通英雄污染来源与污染英雄专属家族使用不同物件专名，净化前后只切换状态前缀。

八个部位都具备对应物件，不只改武器位。人族偏军械、工业构架；虫族偏感知器官、骨镰、母囊；神族偏晶体、锻炉、圣盾。命名是美术意象，不赋予额外武器、召唤单位或装备效果。

## 统一显示规则

1. 装备标题只保留具体物件名；英雄、精英、方向已明确绑定时加“名字的”。不增加跨族英雄或把随机赠兵套改成固定身份套。
2. 净化后的污染来源装备加“净化的”。未清洗时使用“污染的”标题并标注待清洗，仍不能直接穿戴；这次改名不会把物品自动变为已清洗。
3. `displayName`为正常装备或污染来源装备净化后的制图标题；污染来源的两种状态名称完整列在`displayNamesByPurification.unpurified/purified`，UI按实际状态选择。
4. 普通英雄套的污染来源件与污染英雄专属套使用不同专名，如净化的雷诺的星火裁决之眼／净化的雷诺的裂誓裁决之眼；家族与计数资格仍按既有ID，不靠名字合并。
5. “时光回溯”“康斯坦威”“虫群”等完整机制名、完整套装主题保留在说明字段。允许简短主题意象融入具体物件，如“星火裁决之眼”，不恢复“机制名·套装名·部位名”的冗长拼接。字典与表格分组标题不是装备标题。
6. 白字分配用`distributionLabels`显示“猛攻／均衡”等，不再挤进装备本名；原五分配及随机绿字、成色、继承效果不变，兼容字段`distributionNames`均返回同一精简物件标题。
7. 白绿无污染；冒险者仅普通紫套、不出污染。橙套六类、模块普通8＋污染专属4、无橙属性散件等边界保持。
8. 原品质、部位、绑定、机制与家族资格不变；明确允许混色的套装才可混用，其余上下位替代。命名目录不开放尚未定好收益的污染模板。

## 制图字段

| 字段 | 用途 |
| --- | --- |
| `id` / `imageKey` | 唯一制图索引，旧键保持，不使用显示名称定位资产 |
| `displayName` | 精简装备标题，文字在UI层绘制 |
| `displayNamesByPurification` | 实际清洗状态对应标题 |
| `baseArtKey` / `identityEmblemKey` | 族别部位底图／身份徽记，可复用 |
| `artVariantKey` / `artObjectName` | 候选制图变体与物件专名；实际图片按246张规则映射复用，不能据此逐条安排绘图。橙装与紫色例外另列 |
| `qualityFrame` | 实际品质边框，蓝紫／紫橙下位件仍是实际蓝／紫 |
| `appearanceByPurification` | 未清洗污染层与净化后来源标记分开；不把净化装备仍画成待清洗 |
| `effectKey` / `setName` / `lineage` | 独立机制、套装与系列说明，不并入装备名称 |
| `namingFamilyKey` | 命名模板索引，不是新建的游戏套装计数规则 |
