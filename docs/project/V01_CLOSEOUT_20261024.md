# V01 收敛与保留决定 · 2026-10-24

用户要求查询 GPU 性能对比、明确 V01 应保留的优化及保留方式，并在完成后推向 main。本轮结束 V01 的集中优化与本机极限压力专项；不把尚未达到的 60 FPS、偶发停顿或加载超时标成已解决。后续进入 V02/V03 的有限实际流程和体验验证。

## 保留候选与停止投入的范围

- 图片/贴图复用继续只保留为隔离候选和历史证据，没有接入正式构建。
- 整批首次战前准备、数值精度变化的粒子候选、接触计算候选和 `gl.flush` 探针不采用；模型替换、C++ 迁移、自动降档也不实施。
- 停止继续扩大本机 16＋300 压力矩阵，不追加管理员追踪或后台监控。将此场景保留为已有边界数据；后续只在真实内容、明确复现或直接改动相关路径时复测。
- `V01-SPIKE-001`：历史 410/502.7ms 共同停顿根因未确认，专项暂缓。
- `V01-SHADER-001`：刷新/恢复时既有着色器等待偶发超时，新旧版均复现、原生重试可恢复；根因和发生概率仍未确认。移交 V03 的既定恢复验证，若出现稳定复现或无法恢复，再处理对应缺陷。
- `V01-DENSE-001`：本机完整效果密集场景未达 60 FPS且持续积压。保留限制，由 V02 记录实际完整流程表现，不把理论上限达标作为无限优化前置，也不把功能通过改写为性能通过。

## GPU 查询结论

使用同一跨平台测试 **3DMark Wild Life Extreme**，查询于 2026-10-24。UL 将其用于 Windows 笔记本和移动设备对比；测试包含图形 API 与驱动差异，分数不能直接换算为本游戏的浏览器帧率。[UL 测试说明](https://support.benchmarks.ul.com/support/solutions/articles/44002201772)

| 设备/口径 | 分数 | 来源 |
| --- | ---: | --- |
| Ryzen 7 5800U / Vega 8，ONE XPLAYER 单次公开有效成绩，2022-10-08 | 2438 | [3DMark 原始成绩](https://www.3dmark.com/wl/225973) |
| POCO F6 / Snapdragon 8s Gen 3，UL 用户提交中位数 | 2985 | [UL 设备页](https://benchmarks.ul.com/hardware/phone/Xiaomi%2BPoco%2BF6%2Breview) |
| Galaxy A55 / Exynos 1480，UL 用户提交中位数 | 1001 | [UL 设备页](https://benchmarks.ul.com/hardware/phone/Samsung%2BGalaxy%2BA55%2Breview) |

POCO F6 的该分数比这条 5800U 样本高约 22%，A55 则明显低于它。因此“5800U 核显弱于部分性能型手机”有依据；“弱于所有主流手机”不成立。5800U 数据是其他整机的一条公开成绩，**不是用户笔记本实测或全部 5800U 的中位数**；内存、功耗、温度和驱动都会影响结果。手机设备页直接打开可能重定向到比较页，上述分数来自 UL 搜索索引中的设备正文；不混用 Wild Life、Extreme Unlimited 或 Steel Nomad 分数。

收敛的理由是当前优化已有明确收益、功能证据完整，而且继续扩大单机极端压力测试的收益有限；并不是认定这台机器没有测试价值，或手机一定能在本游戏跑满 60 FPS。
