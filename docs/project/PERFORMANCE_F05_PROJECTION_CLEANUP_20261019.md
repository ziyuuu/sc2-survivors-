# F05：装备投影退场与回收 · 2026-10-19

用户在确认下一项为 F05 后授权“请开始吧”。本项修复 B02 发现的投影死亡时间反复重置、尸体无法回收，以及投影专用登记在尸体消失后继续残留的问题。状态以[性能看板](PERFORMANCE_BOARD.html)为准；证据入口为 [QA 报告](../../reports/qa/performance-f05-20261019.json)。

## 实现

- `retireEquipmentProjection` 只在首次退场记录死亡时间，保留合法的 0 秒时间戳和提前战死时间；结束表现仅对仍存活的本体／子机发送一次。清空目标，继续使用原有的 1.5 秒尸体退出规则。
- 尸体消失后清理投影、成员身份、英雄副本、战斗来源及本体专用游标。仍被实际弹丸、技能、持续伤害、区域、状态或子机引用的来源记录保留到引用结束，避免伤害倍率回退为普通单位值。检查限定于活动战斗队列，不遍历装备历史／原始编制缓存；无待清理投影时直接返回。
- 死亡事件冻结“装备投影”标记，渲染端根据该事件请求原来的幻象死亡特效。特效不再依赖仍存在的投影登记，因此尸体／登记回收和 WebGL 重建不会截断效果。正常到期继续复用原有 `projection-end` 收据。
- 没有改变召唤数量、寿命、伤害预算、攻击时序、RNG、经济、300 上限、4∶4∶1、画质或五图。死亡尸体从错误的反复归零恢复为正常老化，因此不要求死亡阶段的尸体像素与缺陷版本一致。

生产代码仅涉及 `projections.ts`、新增 `projection-cleanup.ts`、死亡事件定义／创建和装备死亡表现读取。存档仍延期，没有扩展保存格式或跨页面恢复契约。
