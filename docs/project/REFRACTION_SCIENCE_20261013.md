# 原版折射与科学球来源修复 · 2026-10-13

本轮执行用户指定的两项：补齐原版 M3 的屏幕折射通道；核实并修复科学球来源缺口。这里的“1、3”指上一轮列出的四个表现问题，不是 MVP 建筑包和舰装包。密集遮挡优化按用户要求后移；地图、玩法与 MVP 范围不扩展。

## 实现

原版 type 2 材质进入独立的屏幕偏移通道。原有 15 个定义包含该材质声明，其中 14 个定义有实际可绘制的折射层：13 个定义的 14 个模型网格，以及 `ProtossShieldRipple` 的粒子四边形。`ThorHandGunAttackImpact` 只有未使用的材质声明，没有引用它的网格或发射器，因此不创造替代几何。

从已校验的原版 M3 提取独立 GLB，保留原始骨骼、动画、UV、法线贴图、强度遮罩与强度曲线。折射粒子沿用已有的原生时钟和确定性粒子采样。新增通道位于线性 HDR 场景绘制之后、Bloom 与 ACES/sRGB 输出之前；以当前场景深度阻挡背后的折射，并避免偏移采样拖入更靠前的物体。无活跃折射层时不增加全屏合成；缓冲区随现有分辨率和 WebGL 恢复流程重建。

三档精英科学球都使用 `Hologram_Skin_ScienceVessel`。原版 `PurifierHologram` 皮肤明确把 `ScienceVesselDeath` 替换为 `Hologram_Death_Large`，后者指向 `Generic_Purifier_Hologram_Death.m3`，原版比例为 2。现在用该原版网格和四个发射器替换旧的本地全息尸体消散与通用爆炸。普通科学球继续使用原版 `ScienceVesselDeath`；已批准的绿色治疗反馈不变。

本次新增状态只属于渲染实例、即时事件快照与 GPU 资源。World、伤害、攻击时间、随机数、输入、相机、地图、原有画质选项、后台和依赖不变，战局 schema 26／档案 v6／地图配方 v3 不变。死亡瞬态随原生时钟暂停、到时回收，不在读档时补播。

## 第四项的范围调整 · 用户后续澄清

用户明确本游戏不是 1:1 复刻 SC2，不需要细致的客户端短片匹配。原先提出的逐阶段实机对照不再作为独立工作项或 MVP 验收门槛，改为下列工程确认，沿用已有证据即可，不另开一轮全量截图／视频采集：

- 来源与绑定正确：单位／皮肤／模型映射可追溯，实际引用的网格、材质、动画通道已接入，没有用占位效果掩盖缺失。
- 运行链路正确：真实攻击、技能、护盾和死亡事件能触发对应效果；挂点、飞行、命中、暂停、回收与恢复符合本游戏规则。
- 玩法未受误改：伤害、攻击时间、随机数、存档及其他已批准规则保持一致。

代码与自动化不能证明主观观感，因此仍在正常游玩中排查缺失、黑块、闪烁、挂点错位、明显失常的尺寸或持续时间；已有有界画面检查可复用。只针对实际发现的问题修复，不要求与原版逐帧、逐像素或折射幅度完全一致。密集遮挡继续后移，自然游玩、实体输入、用户试玩和完整性能等既定验收不变。
