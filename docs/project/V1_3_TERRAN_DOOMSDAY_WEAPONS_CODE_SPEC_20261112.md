## 普通牌、待领节点与唯一主分支

| 关间发生的事 | 成功时提交的状态 |
| --- | --- |
| 买普通牌 | 依 `offerId`、冻结报价、预期档位、当前关间与 `shopRevision` 校验。沿 `purchaseOffer` 一次提交扣款或免单、牌效、有效进度及回执。白牌首购 +1、同名复购只升档；多档非白牌每次有效升档 +1；一次性牌只记首购。通用牌只兑现自身。买普通紫「子母弹女妖」可立刻改装一架，`main` 保持原值。 |
| 某分支到 3、6、9……点 | 若 `main` 为空或等于该分支，以 `(branch, at)` 建立一次待领机会。两个分支都到 3，可各留一份。每支按门槛从小到大领。一支可兑现的节点少于两个时留权，另一支照常准备。此时生产上限、工时及分支权重仍取领取前的值。 |
| 生成或延后节点 | 在本分支合法节点中优先从未学项无放回抽两个，不足再取合法复选项。第一次凑齐时用现有种子冻结两个卡号和顺序。重开、读档、余额变化沿用原选择。延后只记录本机会的关间号，同一关间可处理另一支。冻结后若阵亡或编制变化使一项暂不能兑现，原选项保留，成交时重验。 |
| 第一次实际选择紫节点 | 验证关间、版本、机会、候选卡的类型和分支、真实前置及回执。若 `main === null`，同一笔领取同时写入 `main = milestone.branch`、本次所选节点和立刻发生的效果，关闭其他分支所有待领机会。选末日兵器时在这笔交易内分配强化席。显示、抽出、延后、失败都不写 `main`。 |
| 锁定后的购买和领取 | 只为 `main` 新建或兑现节点。副分支普通牌仍可买、可升级，分支格内权重从等权转为主 1、各副 0.5；已展示普通牌保留原报价。武装为主时，买蓝焰恶火只解锁一台特装，恶火家族沿原出战上限及原工时。机械为主时，混买武装普通牌可兑现原效果。 |
| 橙色终极 | 仅 `main` 本支达到 9 点，且已有本支三个不同里程碑的成功紫节点回执，才开放本支三张橙牌。成功成交一张后，本局橙机会用完。紫节点复选消耗一份新的里程碑，可计一次领取。跨支、重复提交、橙卡自身均不能补足三次。武装在 6、9 点继续选自己的节点。 |

**起手算例。** W01 重型枪械、G01 穿甲弹、W05 短停点射花 190 矿／20 气，机械 3 点、`main = null`。两名枪兵即可让 N04、N05 成为候选。玩家延后，再买足武装 3 点，若先选武装节点，已学的三张机械牌继续生效，先前冻结的机械节点也无法再领。反过来先选 N05 才启动机械家族整备；后续同族普通紫购买与所有已付订单均无二次入分支。标准基础价依次为白 50／0、绿 90／20、蓝 150／50、普通紫 225／90、紫节点免费、橙 325／140。三格、折扣、首次免单和两币余额仍走现有商店。

## 五台过渡到四席

1. **进分支的瞬间。** 在首张机械紫节点领取成功的交易里，逐个正式机械家族计算 `limit = max(1, 原家族身体上限 − 1)`。天赋 7 席对应 6、基础 5 对应 4、基础 1 仍有 1。分配优先级为已有专机、现役精英、较高军衔、较早入队、较小实体 ID。分配后持久化，平时升军衔不挤走在席者。超过上限的现役也保留 ID、生命缺口、原军衔、专长、此前已生效的改装档位与完整战斗能力。新领取的本体强化发给强化席，全军授级、队友掩护和治疗按各牌的实际受益者处理。
2. **只在承诺新身体前查空位。** 余量为 `max(0, limit − familySeatCount − waitingBodySeats − armedFormalReservations)`，三项以同一时刻的不同承诺为准。`familySeatCount` 已含救援及舰装复活预留。订单与其运输舱乘员是一份承诺。建筑新造、商店的直送／投送、支援转正式、救援和舰装新增机体都从同一余额预约；同一固定步按既有处理顺序每成功一笔即占位。锁主前已记录的身体乘员沿原 `(jobId, passengerIndex)` 或支援投送乘员号，按原工时和真实运输结果交付一次。锁主不会把身体改成培养、取消旧单或强制替换成员。保持原 `familyMemberCap` 供旧单、培养、替换与精英所用，另给新单查询有效身体余量。[名额和精英](../../src/simulation/world.ts) · [生产与乘员](../../src/simulation/expedition-production.ts) · [商店补员](../../src/simulation/progression/supply-plan.ts) · [支援预留](../../src/simulation/combat/armed-support.ts)
3. **自然减员。** 五辆现役坦克中有四个强化席。第 5 辆先死时，四辆照常作战；总量达到四，没有新身体单。强化机先死时，三台强化和一台普通继续打，下个普通关间让普通机原位接通用强化席。只有现役及已承诺的同族身体合计降到三，才允许再预留一台。锁主时若四辆在场、一辆已付在途，开舱仍可交付第五辆。已发起的救援／复活、精英转换、家族替换各按原回执核销。全队或其他家族不借用这个空位。
4. **工时冻结在开工。** 先算同一张正常生产单在现有建筑、天赋及武装 W03 下的工时，再乘机械主分支的系数。新机械身体／特装补造／原位重装 ×1.25，橙色巨械工序 ×1.50，两个系数互斥。培养和战术订单用原工时。已有 `DeliveryLedger.remaining` 为整批共用倒计时，混批次按相同工期的工位分账，保留 `facilityIds`、原乘员顺序及各自的费用／回执；原位工序只占合法工位，新增身体才占名额。开工后存剩余时长，锁分支、买卡和读档均沿原时长。基础配方女妖约 42.9 秒，机械主分支新单约 53.6 秒，排队和落舱另计。共用经济合流后矿气用于选牌，现有已付单仍沿原钱包／退款记录。[工时与同批工位](../../src/simulation/expedition-production.ts) · [共用经济](V1X_ROADMAP_20261104.md)
5. **哪些家族计入。** 以人族正式成员的基础家族与机械资格取数，普通和常驻精英共用本族席位。医疗机、科技球也是机械。持 P03 后，已纳入改造的原步兵家族按自己的上限过渡，满五时超出的现役保持其在确认前的形态。先买 P03 再锁主，已经完成的改造照旧。本局保留原生家族、武器与工程身份。英雄单走英雄名额，临援、投影、工事、敌军和限时成员各沿原来源。日后新家族第一次合法入队、天赋／舰装上限变动也用同一分配规则，只在可整备时升入空席，老成员照常作战。

**图纸与宿主。** G06 恶火、B07 维京、P06 女妖各开一种武器，每种同时一台。首次购买优先给现役同族，已入机械分支时限在强化席内；可选多人时依军衔、入队顺序、ID。无底盘时将图纸留给下一次合法到队的机体。原位改装保留当前血量缺口、精英身份和技能冷却。特装死亡时先记一次战损，已发弹继续按自身记录飞行，未发攻击随宿主取消。已在途的同族身体可承接图纸；否则安排下一笔合法新造。若身体席已被补满，则排同族底盘的等长原位工序。每图纸最多一个在途绑定或一道在制工序。工序目标再度死亡或离队时释放目标与工位，图纸回到待装，不生成退役、额外身体、补发伤害或二次付费。用 `entityId + bornAt` 区分新旧成员。转场和读档复用同一工序。副分支情形首测取原底盘工时 ×1，强化席减一和 ×1.25 都随机械主分支生效。

## 33 张普通牌的配置与验收

三档数字依次为 I／II／III 档总值，升档取新值。九白均三档；绿 G01–G03、蓝 B03、普通紫 P01 三档，其余普通牌一次解锁。按“为一台装配”取得的 G07、B09、P04 各对应一个宿主，选宿主时沿特装选人顺序，要求在队且适用。它们可以同车；选定后沿同族合法替补重新装载。G07、B09、P04 是模块，按图纸需排工序的三台特装另行记账。每一行末栏都是正式执行器须复现的独立断言。

## 专机、连发和巨械的固定步排程

**双模维京。** 每步分别用 `viking` 的对空轮（9 码、对装甲加成）和 `viking_assault` 的对地轮（6 码、对机械加成）判断目标。先保证可见／射程／射线／原有武器限制，再算有几路可打。飞行偏空、落地偏地；只有另一层有敌时该层作主路。各路在自己的 `nextReadyTick` 到期时开火并按自己的原生周期续订，切姿、换靶及 55%→100% 均不补发或清零时钟。双路同开时只有主路产生一般按原轮触发的机会，副路仍能驱动明确监听该通道的 N08。两个通道有独立武器快照，切换射击来源不得改写真机的 `flying`、碰撞、变形状态或精英动作。苍穹猎鹰保持对空锁定；钢铁落锤和双相王牌仍须真实变形才触发技能。[原武器](../../src/data/expansion-units.ts) · [实际变形](../../src/simulation/combat/expedition-combat.ts) · [精英模式](../../src/simulation/combat/terran-elite-runtime.ts)

**双母弹与连发。** P06 单卡沿现有女妖 `hits=2` 在途包，命中仍逐发扣甲；以原轮号记录 `splitSpent`。持 B05 需要可转移的原生未发段时，首版将女妖双弹拆为两次各一击，发射步为 0 和 `min(3, T−1)`，同一原轮号，保留未拆前两击伤害之和。双模导弹、原生多击还有其他已提交的整组时，依武器是否真有未发段处理；B03 为所有合法机械轮提供明确的可转段。按 B03 比例生成的笔数和威力在母轮启动时冻结；B03 的女妖副段也有双击预算，但不另行分裂。已击中 A 并击杀 A 可从 A 的实际落点向 B／C／D 发子弹。子弹速度首测 12 码/秒、寿命 2 秒，起点为落点，逐枚有 ID，原目标仍活着才可回落。已失锁的子弹遵循原弹道失锁规则；原机死亡不会抹去已发弹。低帧或恢复时按记录过的发射游标续排。[原弹道包](../../src/simulation/combat/weapon-flight.ts) · [同靶原型](../../tools/qa-doomsday-card-values.mts)

**军衔。** 对主武器单击和最大生命分别取同型、同武器、无机械牌的 I 级值 `A1`、原军衔上限处 `Ac` 和当前合法基础值 `Ar`。原上限内按原曲线；超出 n 级时，令 `Ar = Ac × (1 + n×0.08)`（主武器）或 `Ac × (1 + n×0.10)`（生命），攻速及其他成长延用原顶级。持 P01 的合格机体取 `A1 + 1.20 × (Ar − A1)`，随后才施加一次 X 级的 ×1.30 与适用的机体修正。原生精英以自己的 I 至 V 曲线计算，英雄沿英雄曲线。N03 对建成的新身体在原始入队军衔上执行 `min(新上限, max(V, 原入队级) + 本次补训)`；原位改装、恢复已有成员和培养单各保留原用途。单测分开计算裸装普通兵、精英和仅靠 N03 的生化兵。[普通军衔](../../src/data/ranks.ts) · [精英曲线](../../src/data/terran-elites.ts) · [培养](../../src/simulation/progression/training-cards.ts)

**橙色基准。** 从相同版本无装备／无构筑／无临时增益的 V 级「末日过载」未开过载的对地原轮、V 级「虎式」已架稳的主炮各取实际原轮普通伤害、实际周期和最大生命。令 `D = 原轮对无甲无属性加成靶的普通预算 / 周期秒数`、`H = 最大生命`。XX 等效面板取 `2.20D` 与 `2.50H`。参考身份只用于取得基准；专机使用下述自身武器表，不再叠一套精英过载／虎式主炮或再算十五级 P01 超限。牌与装备冷却、武器、HP 增益在相应基准上各应用一次。O01 的盾层沿 G02 的独立盾池原则，先扣英雄装甲盾、再扣纳米盾，两者同生命内各有自己的恢复规则。

- **高达的首测节拍。** 基础每 60 步一轮弹幕，9 轮为一个完整循环，裸装总预算 `B = 2.20 × D × 9 秒`。每轮在 0／3／6／9 步打四枚，各 `0.50B / 36`。第 3、6、9 轮各在最后一枚发出后 3 步发一炮，单炮 `0.30B / 3`，取合法地面目标锁点，原架坦爆区比例。第三炮成功发射后 6 步向已锁地面区域发小核，延迟 24 步命中，半径 2.5 码，预算 `0.20B`。副炮、小核都从这台雷神独立发射；武装 P01／N05、系统出勤和手动核库存各自结算。弹幕沿雷神两层合法目标和射程；炮位无地靶时保留一次待发炮，取得合法目标后发射才推进三炮计数。停火满 180 步清尚未完成的蓄势。已锁定并发出的弹保留原抵达时刻。攻速改变下一新轮的间隔，弹幕内偏移按新周期占 60 步的比例缩放。持续射击按每轮启动间隔计，已发弹结清后再核对总预算。
- **绝望堡垒的首测节拍。** 取虎式架稳时的原周期 T 秒，每轮预算 `S = 2.20 × D × T`。瞄定合法地面主靶，`f` 为开火时炮口正向，`s` 为其右向。中心 C 为主靶在炮口轴上的投影，需在原有最小／最大射程内。第 r 排、第 c 列落点为 `C + (r−1)×1.8×f + (c−2)×1.8×s`，r=0…2，c=0…4。开火时发出整批；首排起爆在 0 步，后两排为 +4、+8 步。每格半径 0.6 码。同一排先收集五格覆盖的合法地敌并按 ID 去重，再给每名 `S/3`；下一排按届时实际站位重查。落点在墙后、射程外或炮口后方时跳过该格，目标本身也须在正面且与原炮口有射线；越界或被挡的份额不分摊到其他格。架起前仍按坦克原来可用的机动行为。炮口转动、收架或专机阵亡只影响下一轮，已发出的三排沿冻结朝向继续。[炮列原型](../../tools/qa-doomsday-feasibility.mjs) · [架炮与精英参考](../../src/data/terran-elites.ts)

以参考值 D=100 的无甲算例，高达 9 秒共 1980，36 枚弹幕各 27.5，三炮各 198，小核 396。若堡垒的一轮 S=300，则覆盖三排的大目标按 100＋100＋100 扣血。真实伤害由基线面板、合法命中与逐击盾甲决定。这两个算例可直接发现“把整轮预算塞给每一枚弹”或“把一排五格全算在同一首领身上”的错误。

本轮隔离 World 读取这两个 V 级参考体。裸装末日过载的对地原轮为 828，面板周期约 0.4969 秒；据此高达的 XX 首测预算为 **3665.97／秒，19126.80 HP**。虎式架炮原轮为 1242，周期约 0.5823 秒；堡垒的 XX 首测预算为 **4692.44／秒，7903.09 HP**，单轮上限 2732.4，每排每目标 910.8。这是参考面板换算。单个小目标只覆盖一排时只吃该排，密集正面和大型目标才更能兑现堡垒的炮列。

**组合判定。** 实装时用明确的武器来源筛选受益项。短停点射认正式成员有瞄准前摇的原生远程直射，工程束、场地炮、机载小核单独分类。击退的重型目标首测取带 Massive 或 Armored 的普通地面单位，首领判定优先。机关挂上两种减速时，N07 查蓝焰自身的来源与期限。N04 已编入当前齐射的人不能用同一次停车再开一组。B05 可改派仍留在发射队列里的精英顺序段，已提交为同刻多击的原轮完整保留。
