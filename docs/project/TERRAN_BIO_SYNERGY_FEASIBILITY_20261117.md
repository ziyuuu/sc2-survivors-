# 生化协同：代码可行性与特效设计

2026-11-17 · BUILD-1.3 · 依据 [45 张审阅稿 R3](TERRAN_BIO_SYNERGY_DRAFT_20261117.md)。本轮核对源码、资源和隔离表现，不实施生化卡牌，不代表数值、补牌或组合规则已全部批准。

## 结论与最后统一确认

45 张牌均有明确的工程实现路径，现有固定步模拟、实体、武器弹道、状态、英雄和原版资源系统可以承接。没有发现必须更换引擎的障碍；这不等于只填卡表即可启用，也不等于所有规则已经闭合。

主要新增工作是：生化取得与保存接线、带来源的攻击／伤害／治疗事件、正式名额与多具身体的生命周期、持续毒与场地云、跨种族凯瑞甘的专用取得路径，以及丛林整编。王虫还缺正式运行资源登记。原版资源存在与正式接线完成分别记录。

**用户要求：人族三支最终一起确认共用规则与强度差距。** 已写入 BUILD-1.3 完成条件，单支审计、演示或局部测试不能提前关闭它。联合检查至少包括：

- 同一钱包、货架、普通牌升档、有效进度、首次领取锁主、节点冻结／复选／储备、橙牌唯一性和副支权重。
- 装备固定护甲底数、百分比叠加、光环阶段、原生多击、附加段、吸血、持续伤害和真实伤害的统一解释。
- 正式名额、随从、在途已付订单、免死／复生／补员、整编、转场、暂停、存档恢复和失败判定。
- 同预算、同局段、同装备和相同敌军条件下，分别比较起步收益、成型投入、对单／对群／对空、生存、单体战损、恢复成本及操作依赖。用多场景和少量固定种子比较，不把三支强行改成相同玩法，也不用单场最高伤害判定平衡。
- 主支与副支混买的边界，特别是机械改造步兵再吃生化增益、免费兴奋剂与退药、两种缩编规则及三类终极的互斥。存在待定规则时先列差异，再由用户最后确认，不静默统一。

### 建议的实现组织

继续沿 `data → simulation → render/audio` 分层；不把结算写入粒子播放器，也不大规模改造无关系统。建议新增生化卡表、状态／资格模块、攻击与毒、恢复与防护、名额与生命周期、节点、三橙、表现路由等职责，名称和拆分可随实施收敛。

- **身份**：正式名额与实体身份分开，实体引用包含出生标识。按原生兵种家族识别本体资格；血肉机械的治疗资格单独授权，不为吃治疗直接给所有机械追加整套生化权限。
- **事件**：用实际原生命中轮、有效生命损失、有效治疗、唯一死亡提交驱动牌效；附加段携带来源种类与允许触发项，避免递归。渲染消费已发生的结果。
- **死亡顺序**：现有免死 → 待确认的 N02 临终状态 → 最终死亡一次 → G01／N03 → 唯一复生预约 → 茧结果或正常补员。死神只有整对全灭才申请一个茧；装备未成功预约时才继续评估生化途径。
- **恢复**：读取当前状态继续播放持续效果；不通过播放入场动画再次生成身体、扣储备或回血。茧在建立时冻结结果，N07 预留与最终消费分开。
- **预算**：毒按来源／目标保存，N04 按目标全队共用；云按真实区域索引；皮肤／粒子去重只影响表现，不减真实结算。上限沿审阅稿，未批准的上限不当成已定规则。

## 资源与特效总方向

保留原士兵／英雄轮廓、原武器与语音。红色表示本支额外酸性攻击或临终爆发，黄色表示血肉机械的持续毒雾，低饱和青绿表示恢复，暗紫生物膜表示特殊保护／进化。色彩之外还用形状、位置和时序区分，不靠颜色独自传达效果。

原版模型、纹理和声音需保留来源。重新配色、组合雾材质和新增有机护膜都明确称为本项目改造表现，不能声称原作本来就有这些技能。

## 实施前仍需决定的具体问题

这些是实现范围／规则决定，不是“引擎做不到”。用户已接受护甲 R3；未明确接受的其余建议继续保留待审。

1. **丛林选留**：保留一个正式本体及其犬／副体，还是每个家族只剩一具实际身体；现役精英和后来在途精英用自动规则还是玩家选留。如果需要新增选择界面，先列具体交互再按 UI 规范确认。
2. **XXV 精英成长**：审阅稿提出的 V 级后延展是新建议，不是已有精英成长事实；最后三支联合时必须与机械超限成长对照，不能叠两条曲线。
3. **受益资格与复生顺序**：血肉机械不吃全部生化牌、随从白名单、装备／死神／茧优先级、死神共享成长和临终冷却，仍需要按完整审阅稿确认。
4. **新增特效**：本稿的有机薄膜、残质、接力弧和黄色雾组合是具体候选；正式实施前以用户接受范围为准。原型验证只确认素材可播放和局部配色可做。
