# F01／F04／F02：特效结束、事件保留与资源释放

2026-10-20。用户在三项合批提案后授权“开始吧”。本批完成范围内修复与验证，统一状态见[性能看板](PERFORMANCE_BOARD.html)。

## 实际改动

- **F01**：结束阶段不再继承持续光束的 hostedBeam 标记，原始 Death 动画决定条带可见性；已出生粒子保留原停止时间和自然尾迹。
- **F04**：普通医疗单位在短停、恢复等待和转移等提前返回路径清掉旧治疗目标；正常治疗目标滞后规则保留。英雄被动恢复在这些返回前已经执行，保留其本步新目标。精英蜘蛛雷移到 GPU 批次结束之前提交。
- **事件保留**：超过 768 条后仍按最多 256 条分批清理，但只移除早于半秒模拟时间的事件，保留尚可能等待下一帧的高峰。原生每帧最多推进 8 个固定步；墙钟卡顿不会自动变成半秒模拟跳跃。它不是任意长离线快进的无界补播队列。稀疏场景保留旧历史行为，持续产出时验证过期回收；不改 RNG、伤害与经济结算。
- **F02**：酸液过期、重置和地形失效时释放两个 InstancedMesh 的私有缓冲，再释放共用的单个地面几何体；不释放共享材质或贴图。据点活体和死亡克隆统一停止/解绑动画，释放私有材质、条带和去重后的骨架，最后脱离场景。主巢/扩张巢清理复用同一入口。

两侧基于固定 main 加已验收的本地 F05/U02/S03/L01/F03；只差 4 个生产文件及 1 个新增清理辅助文件。无关 economic-egg 修改排除，CSS 字节相同。300 上限、4∶4∶1、画质、五图、伤害和经济规则保持。

旧审计的混合条目按范围拆开：FX-015 的首次酸液几何创建/峰值分配仍归 X04；R06 的屏外 mixer 更新成本未改，保留给 A01 复核。本批 F02 完成不表示这两项计算成本已优化。

## 对照结果

| 场景 | 旧版 | 最终版 |
| --- | --- | --- |
| 持续医疗光束 | 20 个条带片段、2 个粒子 | 相同 |
| 满血停止医疗后的采样 | 20 个残留条带、1 个粒子 | 0 个条带、1 个自然尾迹粒子 |
| 短停 / 源或目标死亡 | 旧目标或结束条带残留 | 目标正确退出，结束条带归零 |
| 精英蜘蛛雷埋地 / 出土 / 追踪 | 两个子网格均 0 实例 | 各 1 实例；清空后均 0，再出现恢复 |
| 8 步间隔内 1200 条事件的局部压力回归 | 仅剩 688 条 | 1200 条均保留，随后过期回收 |
| 酸液 12 轮创建/移除 | 遗留 48 个 GPU 缓冲 | 遗留 0 |
| 据点活体/死亡 12 轮循环 | 遗留 42 张 GPU 纹理 | 遗留 0 |

另用真实 World.hit 对 300 个带护盾单位在 8 步时间间隔内造成死亡，最终版生成/保留 900/900 条事件，渲染收到 300 个受击记录和 300 个尸体；重复绘制不重复加入回响，完整诊断状态不因渲染改变。这是受控原生伤害高峰，不是自然波次或旧版同一场景的 FPS 对比。

实际 GPU 计数来自 create/deleteBuffer、create/deleteTexture，不只依赖几何体统计。12 轮据点与 3 轮主巢/扩张巢场景合计 72 张私有骨架纹理全部释放；每轮清理后资源回落。巢活体模板当前没有骨架纹理，巢死亡原清理已正确，本次统一入口未退化。共享模型、材质和贴图可继续创建下一轮；实际 WebGL 丢失/恢复后活动酸液及建筑重新绘制，time/tick/RNG 保持，contextEpoch 增加。
