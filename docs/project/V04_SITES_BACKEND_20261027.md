# Sites 游戏后台迁移 · 2026-10-27

原私有游戏站点已部署 Worker、D1 和独立 R2 删除记录；沿用玩家主动同意、反馈自愿提交、反馈凭据查看与删除、统计撤回和删除。管理页由 Sites 登录身份限制，仅站点所有者可看每日浏览器 UV 和反馈及玩家自愿填写的联系方式。管理入口改用 Sites 账号，不使用原服务器 admin 密码。原阿里云数据库访客、反馈、事件数量均为零，无历史玩家记录待迁移。

本机 SQLite 合约、Workers 本地 D1/R2、游戏设置中同意统计/提交及删除合成反馈/删除个人统计、游戏战斗及存档通过。独立私有云站点和最终站点均通过合成授权、事件、反馈、凭据错误、删除及撤销后拒绝；伪造 owner 头拒绝，真实站点所有者管理页可见。测试记录清除，删除摘要保留。删除记录回放通过本机模拟恢复演练。

限制：本版管理页面只提供用户要求的每日 UV 和反馈，不是原 PostgreSQL 全量分析界面；UV 是同意统计的浏览器数。自动独立备份尚未配置；到期数据由后续请求触发清理，长时间无访问可能延迟，说明已更新并重新版本化。仍是私有站点，没有对外发布；正式公开、权限策略和完整内容/听感未验收。质量对照三个单位界面素材，正常缩放差异较小，细节有损；不代表全模型或音效无损。
