# 1.1 固定脚本与逐步点击教学

2026-11-05 最新设计稿，**用户已批准实施；源码已接入，已完成三端正常速度录屏及交付验证**。本轮先将通讯恢复为已指定的固定右上面板，撤销关间左移／300×38横条；允许遮住矿气，不再为此改变面板位置或隐藏内容。保留竖屏12px、完整指令两行内。原游戏UI不搬动、不缩放。

本稿替代旧版“真实战役中自由操作、观察条件后自动衔接”的教学推进方式。仍然是新玩家第一次真实出征，使用真实部队、购买、掉落、背包、撤离与旗舰装备；不另建不结算的练习场。

## 已确认原则与设计边界

- 用户已确认：教学掉落固定、资源固定、用户选项固定；必须激活当前高亮目标，成功后才进入下一步。
- 每步只开放一个教学动作。其他购买、换页、刷新、撤离、装备、技能及对应快捷键不能绕过步骤。暂停、设置、静音和“跳过教程”始终保留；查看操作不推进教程。
- 不新增通用“下一步”按钮。点的是现有商品、装备、生产选项，或本步的战场目标标记。键盘确认高亮按钮、手机点按等价。
- 页面可由脚本预先打开或关闭，作为本步准备／已点击动作的结果；系统不能代替玩家购买、拾取、领取、穿戴或撤离。
- 计时结束、钱包达标、异步加载完成、鼠标划过、提前满足条件，都不能代替这一小步的点击回执。
- 静音可完成全程。声音和镜头不决定结算，三族共用一套步骤状态，头像、名称和短指令按族配置。

## 一个步骤怎样推进

`等待高亮点击 → 受理一次动作 → 执行真实流程 → 验证对应结果 → 同一事务保存 → 展示下一高亮目标`

| 状态 | 世界与输入 | 推进条件 |
| --- | --- | --- |
| 准备 | 准备固定对象、合法页面与唯一目标；不执行玩家动作 | 页面和必要资源就绪，进入等待 |
| 等待点击 | 战斗模拟及教学时钟暂停；只接收本步目标和全局退出操作 | 收到匹配run、step、target的激活事件 |
| 执行／等结果 | 按本步开放真实移动、交战、训练或载体流程 | 同一目标的权威回执成功；点击本身不能伪造成功 |
| 保存 | 暂停后续教学动作；沿现有保存失败保护重试 | 账户、战局、点击与结算回执一起成功提交 |
| 下一步 | 高亮新目标并再次等待 | 必须由下一次高亮点击启动，不连跳 |

一次点击不能同时算两步。连点、旧页面回调、读档和重复死亡使用同一命令／奖励身份去重。读取到同一步已受理的点击，就恢复等结果或已提交结果，不能重扣费、重发物品，也不要求玩家再次做已经持久化的同一步动作。

## 固定场景与资源建议

保留玩家选的种族、难度和既有地图。接受教学后，在当前地图预检可达的移动点、工蜂、落点和战斗区域，并冻结位置／对象身份；不为教学更换World、改变镜头角度或缩放。普通随机遭遇、额外掉落、被动矿气与自动追加订单在脚本期间不参与教学经济，避免等待时间改变预算。

拟定参数如下，**只在已接受的新脚本内生效**：

| 项目 | 固定值与来源 |
| --- | --- |

| 教学敌方工蜂 | 真实工蜂死亡后，地面资源合计最终入账100矿、50气；沿真实靠近拾取，不直接加钱包 |

补给实际效果、队伍席位和精英领取资格须在脚本预检中逐族验证。不能因满员而临时换随机奖励，也不能吞掉原本必出的首领奖励渠道。若原生奖励页有二级变体确认，该确认也必须列为独立高亮动作。

各族原生默认配置不同。步骤编译时必须确认目标点击后会得到预期配置，不能要求玩家点击一个已选中的切换项、反而将其取消；不需要的确认小步在该族固定脚本中不生成，而不是运行时自动认作玩家已点。全部原生子动作须在实现前展开并冻结。

### 固定面板与目标选择

面板位置、宽度和原UI维持本轮回退结果，允许覆盖矿气。**不能把面板下面的控件设为必点目标，也不能再次挪面板或藏掉指令来解决冲突。**

例如右上“设施调整／背包”入口被通讯覆盖时，由上一动作结束后的页面准备直接打开原生产页／背包，再高亮无遮挡的生产行、装备行或装备按钮。保持原控件位置，不复制一套按钮。准备页面不算玩家动作，也不能触发付费。

战场标记在教程模式支持原命令端口的点按／键盘激活；手机可点击标记发出正常移动命令，执行期间仍可用原摇杆辅助。它不是常驻的新移动控制。画面外目标用同一目标的边缘指示，结算仍验证真实位置和对象ID。

## 跳过、恢复和兼容

- **跳过即在当前关立即恢复正常游戏，不等下一关。** 立即移除全部教学输入门控、步骤等待、教学计时限制、通讯、声音、标记和临时镜头；停止整套后续教学，账户保存已跳过，刷新、续局、重开和换族都不再自动出现。
- 当前关立即恢复普通资源收入、正常随机掉落／遭遇、普通生产容量与规则、正常商店和合法选择。不能只撤下提示框、后台仍运行固定教学计划，也不能保留必须点击某项才能继续的限制。
- 保留已经实际获得的资源、装备、单位、地面物资和已付订单，不回收、不清零、不重开，不重新发一份普通奖励。未兑现的教学专用资源／奖励／订单许可取消。
- 首领死亡前跳过：取消尚未兑现的教学奖励方案，该首领按普通掉落；已经产生的物品照常拾取、带出。当前世界对象不重刷，已触发事件不重复执行；正常调度从当前关当前进度接续，不能堆叠补刷过去的杂兵，尚未发生的原关卡关键事件仍只安排一次。
- 正处于关间时，恢复当前回合的普通合法货架／选项；已经购买的项目、付款和每关购买次数保留。退出教学所需的货架转换只登记一次，不能通过连点或读档反复重抽或免费刷新。已经产生的奖励卡保留卡片本身，未作出的变体等选择恢复普通合法范围。
- 教学临时暂停、且玩家从未编辑过的生产配置在跳过时还原；玩家明确点过的开关保持。已付费订单继续原流程。下一笔普通生产恢复原容量上限。
- 每个动作保存`runId/scriptVersion/stepId/commandId/targetRef`及结算回执，与既有账户、检查点、两份备份和多页CAS同一事务。
- 成功撤离时，将末段步骤、源runId和同一模块ID同时交接到账户教学记录。返回菜单会重建出征对象，旗舰段不能仅依赖旧`expedition`；刷新后仍要点击当前高亮旗舰入口与装备，不能丢进度或自动当作已点。
- 读档恢复等待点击／执行／保存中的原状态；不能重发起始700矿补给、重扣购买、重生首领、复制掉装。保存失败沿原保护暂停，不推进到下一步。
- 新字段优先放现有`expedition.tutorial`的版本化结构，账户保存终态；是否需要schema调整由实现验证决定，不预先改全局版本号。
- 已有旧版已接受／待邀请出征不在半途强转新脚本；继续旧版或跳过。只有尚未开始的新资格出征采用新版本。老玩家、导入旧档、已跳过／已完成者不重新获资格；导入同一有效教学续档只恢复原进度。
- 战败、放弃、提前退出遵循既有真实结算和账户终态；不暗中复活或免费补发。恢复已有教学检查点仍使用原继续游戏入口。

## 源码对接与验收

必要改动为共享步骤控制器、命令门控、固定资源／奖励计划、真实生产的单席许可、固定商品货架、事务回执及恢复校验。渲染只显示目标与文案，不能决定伤害、消费和奖励。原普通玩法分支不变。

## 2026-11-05 源码核对后的实施校正

- 当前战役第1、2关并没有首领。前两次教学战斗使用各关原波次的真实敌军兵种与生成印记，绑定固定教学散件／卡牌；不新增前两关首领。第3关仍使用原战役首领及原事件印记、强度。
- 原生首领奖励在拾取卡牌时直接兑现，没有额外领取或变体确认窗口。教学将固定身份交给原领取事务，不虚构一层领取页。第二、三次固定免费空投另有高亮落点点击，直到实际乘员入队。
- 原生设施布置必须点“应用”。四次开启／暂停均展开为编辑与应用两个点击。新孵化场／水晶组先做无消费的教学暂停准备，点击开启才生效；水晶另需点击基础兵选项。人族合并兵营组沿用已有基础兵选择。
- 普通关末的99/46等矿气在教学固定账本中为0；永久进度仍走原流程。否则会超出已确认固定预算。跳过后只恢复当前及后续普通规则，不追补已经以教学回执结算的过去关卡收入。
- 正常脚本为41步（人／虫）或42步（神），另有邀请和3步旗舰操作。无通用“下一步”。
- 加载中的当前通讯仍提供跳过；跳过会取消资源准备和已排队的关间出发，留在当前阶段。
- 状态按步骤准备时冻结目标ID／位置，并与同一账户检查点提交。加载恢复沿用已经受理的点击。没有额外的独立存储标记，也未升级全局schema。
