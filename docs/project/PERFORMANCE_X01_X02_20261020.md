## 实现

- **X01 空层及精确姿态复用**：没有粒子、条带或投影的层直接返回；没有有效粒子出生、未激活条带、到期投影不预先求骨骼姿态。骨骼缓存仍按每个定义最多 512 项管理，满时淘汰最久未用项，保留近期精确结果。缓存键使用 clip 对象身份及原始秒数，不量化时间；缓存内容不依赖 GPU 上下文。
- **X02 实例池**：每帧、每模型和位移模型分别维护游标，按原来的首次未用顺序取实例。扩容、隐藏、两秒退场回收、保留首实例及 reset 规则不变。
- **X02 事件索引**：仅当本帧需要查询时构建索引，保留“数组末端向前找、时间不晚于当前回执”的攻击匹配规则；同时间的后置攻击／导弹回执仍可命中。受击去重按最小 serial，酸爆附近攻击按原时间阈值。索引不跨帧保存，不改变事件或 World。

额外关联审计 FX-005／FX-006：人族精英火焰改用当帧最新攻击表；三族备用弹道使用当帧首次 attackId 匹配表，原资格过滤不变。1／32 个火焰场景的 51／1,632 条绘制指令与挂点完全一致，密集事件访问从 40,448 降至 1,264；稀疏访问次数保持 1,202，不把受绘制指令记录影响的微计时当作额外 FPS 收益。

- 102 个源特效定义、3,264 组条件覆盖不同种子、循环、重复帧、倒退时间及跳帧；与旧版完全相同的输出为 77,552 个粒子四边形、33,510 个条带四边形、1,856 个投影四边形，包括矩阵、颜色、UV、材质和相位。最终报告为 `numerical-equivalence-candidate-r2.json`；较早同数值报告保留。
- 5 项新增边界回归覆盖缓存容量／热点保留、同名异源 clip、空层／未激活层、乱序／同时间／稀疏／密集事件、实例池缩容和 reset。完整回归 1,673 项、类型检查与数据参考检查通过。
- 200 个同模型请求的池读取从 20,100 次变为 200 次；计数与计时分开，正式计时没有 Proxy。组件测试中的选取及放置耗时约 0.224–0.273 ms → 0.098–0.119 ms。24 条稀疏和 1,200 条密集事件查询均保持结果；密集查询含索引构建约 8.48–8.64 ms → 0.45–0.53 ms。这些是 CPU 组件测试，不是整局 FPS。
- LRU 容量与热点保留检查通过，但单独的缓存微基准没有稳定耗时收益；不能把避免整体清空直接等同于整体加速。整体收益按真实渲染对照报告。

## 浏览器方法
