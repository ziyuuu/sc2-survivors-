# 普通坦克长线复核与第二轮修复 · 2026-10-30

用户观看 `Tank-Effects-Current.mp4` 后指出普通射击仍有很多线乱飞。上一轮 `V06-TANK-FX-001` 修正的是拖尾朝向，未解决全部轨迹问题；本轮以 `V06-TANK-FX-002` 继续处理，不能把原有回归通过等同于用户画面验收。

## 已确认原因与修改

- 普通命中 `Star2Part02bounce` 的骨骼明显倾斜。原实现把有符号重力加在发射器局部 Z 轴，再乘骨骼矩阵，形成水平加速度；火星因此越飘越远。现在发射方向仍继承骨骼，重力保持世界竖直方向，并保留效果的单位换算尺度。
- 原触地实现把低于地面的当前位置直接镜像到地面上方，使之后的下落加速变成持续上升。现在从出生时间重放碰撞点，按原反弹与摩擦参数开始下一段运动，衰减至静止后保留粒子直至原寿命结束。
- 静止拖尾保持确定方向和实际头部位置；自由/夹限拖尾在速度为零时收为粒子宽度，固定尾长仍保留。未调整源尾长、数量、颜色、纹理、寿命或爆点附近短时散射。
- 原版目录、World、攻击/伤害/冷却、随机顺序和存档保持。普通及精英坦克共用修正后的源粒子路径；本次新视频实际录制普通坦克的普通/攻城两种模式，未单独录三种精英。

M3 字段与类型核对参考 [M3Studio 粒子属性](https://github.com/Solstice245/m3studio/blob/main/m3_particles.py) 和 [尾长类型说明](https://github.com/Solstice245/m3studio/blob/main/bl_enum.py)。这些资料用于确认碰撞/摩擦/反弹及速度定向尾长语义，不是原 SC2 客户端逐帧对照。本轮没有凭视觉偏好另行缩短原尾长。
