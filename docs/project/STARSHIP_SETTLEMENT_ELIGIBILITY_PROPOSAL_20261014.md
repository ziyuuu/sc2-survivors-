战斗造成死亡、自然到期、关末清理、退役、自爆、身份替换分别记录。身份转换不是死亡，不触发康斯坦威；有本件明确到期爆炸的临援只触发该爆炸，不同时被算成永久友军阵亡。

## 三 套装计数与上下位替代

1. 计数键包括家族、绑定英雄／精英、绑定方向及合法种族。不同绑定身份不混凑；独立蓝与高阶蓝紫下位是不同家族；普通与污染英雄不混凑。单件仅有一个家族身份，占一个实际合法槽。
2. 已定4紫／4橙门槛不变；冒险者与三类新增污染紫套按已定直接2／4／6门槛，不能被通用4紫规则截掉。套装品质替换一次，达到高件数保留本档低件数；8件同一阶梯家族不重新触发一组。
3. 只有已明确允许混合的套装可以跨品质计数，并严格沿本家族已确认的品质门槛与总件数规则；不把这一许可扩展给其他两件套，也不因效果相似而允许蓝件向下补绿色件数。其他套装分别验证本档完整件数，上下位替代、类似效果只取最高有效档，不将低档完整组追加到高档收益。
4. “最佳选择”2蓝＋2绿只生效蓝档一组，每轮额外2次免费运营刷新，不叠绿色1次；1蓝＋3绿只生效绿色一组，每轮额外1次，余件不混配。同品质可重复两件套仍按已确认的完整组数结算，不撤销同品质多组资格；唯一套仍只生效一次。训练、团队以及狗哨／蟑螂拍、陷阱／地堡、特殊来电／我是谁等上下位对应款遵循替代规则，不将上下位奖励同时发放。独立蓝与高阶蓝紫下位仍是不同家族，不借相似名字混凑；不同合法独立来源原已确认的容量／军衔增量相加规则保留。
5. 所有发放来源在出征部署时冻结。虽然套装本来就不能关内换，仍保存实际参与配组和赠奖部件，避免复制存档、重复部署或以后规则调整时重领；不把没参与奖励的其他槽额外锁定。

## 五 招募 晋升与身份转换顺序

建议统一顺序：检查付款／配方／科技与最终容量 → 确定来源起始身体 → 计算适用交付军衔 → 付费精英学院转换 → 合法普通兵救援升衔 → 紫训练Ⅴ级转换 → 登记唯一最终身体与来源、锁定及统计。每个步骤重新检查当前身份，已转精英不再走普通兵专属步骤。

- 普通招募基准Ⅰ；军备＋4、橙士兵＋4及其他明确合法增量相加，再按最终普通上限约束。满员时的培养交易不是新招募，不重新领取这些起始等级。
- 付费精英学院成功时，最终身份是条目明确的Ⅰ级精英；普通招募Ⅴ／Ⅸ不保留成Ⅴ／Ⅸ精英。该转换只判一次、无合法精英则保留已算好的普通身体；不附送旧Ⅴ级回退。此顺序是建议，Ⅰ级精英核心不改。
- 紫训练建议把“达到Ⅴ”明确为当前军衔≥Ⅴ的合法永久普通成员，包含高阶直接交付；转同兵种Ⅰ级精英、每成员一次、整局最多6名。保留用户要求的Ⅰ级转换，不因原普通军衔高而另加保留军衔或选择按钮。无合法身份不消耗次数。
- 开场训练／团队／特殊来电沿人数→训练军衔→身份的既有联动方案：绿2人／Ⅱ、蓝3人／Ⅲ，唯一取高；特殊来电保留训练军衔。训练只扩大到已列狗哨／蟑螂拍，不扩到部队套7名Ⅴ兵、独立固定英雄或我是谁。
- 每条自然升阶／付费培养／套装培养都读取当前真实军衔；同一事件多个合法来源按来源固定顺序逐次处理，重新检查上限，不产生重复新身体。派生晋升不再重启同一事件的晋升抽样。
- 紫赏金1500水晶培养只负责到Ⅴ，科技奇点等可使同一英雄超过Ⅴ；赏金到其来源上限后停止提供升阶，不把英雄降回Ⅴ，不把无效进度存成将来的一次免费升级。已确认橙英雄套成长阈值和无硬上限不改。
- 正常升级／转换保持生命和原生盾比例、不免费刷新资源与冷却；旧上限为0而新身份有盾的转换，建议以新盾0起步并沿新身份自然恢复。真正首次新生交付仍按该来源初始状态，不能把首次赠兵和已有身体转换混为一事。

## 六 属性与攻击结算

先读取实际身份／军衔／形态和已完成科技的原生数值，绝对装备DPS、真实DPS、生命再按已选适配表加入；参考倍率不含装备自身、套装临时增益，避免反向放大。普通武器增伤、技能输出、治疗／回盾、生命、护盾、攻速分别走各自通道。

建议同类百分比加值相加后一次结算；明写独立倍率的身份专属强化、狂暴等保留独立通道。橙精英已确认全队1.5×绑定3＝4.5倍单击，不被“统一相加”改成3.5；绑定4件＋100%被6件＋200%替换，不重复乘。攻击频率只影响实际武器，不缩技能／支援计时。

固定DPS与固定真实DPS按最终有效周期分配，多弹、双武器、子机分摊一次。伤害百分比派生包用允许的原伤害快照；剔除不能复制的固定真伤预算，不从已经过敌方护甲的损血倒推基础伤害。每个目标独立应用其防御，不能把主目标护甲计算结果直接当副目标护甲前伤害。

正常攻击可同时开启不同合法装备分支；分支不重启装备攻击／复制／捕获链，已定义有限连锁照常。伤害快照、暴击结果共享与否沿本件明文：双重打击共享主击暴击，不给每个副目标重抽；其他未明写的武器派生建议继承所属主周期一次暴击结果，治疗不新增暴击。

弱点接管按已接受R3把符合资格的主武器普通伤害在暴击后转成真实伤害，不复制第二包；可以推进合法燃尽进度。技能／DOT／支援不因同一目标被解析就自动转真伤。燃尽已后续确认：本套首次命中后累计全队实际生命真伤达到目标最大生命快照40%时斩杀，普通／精英／Boss一致；2件灼烧为每正常武器周期主目标武器预算20%的真伤，均摊3秒。详见[灼烧与燃尽定案](STARSHIP_SPECIAL_ADDITIONS_20261014.md)。

## 八 单体救援 相位与全灭回溯

伤害资格／原生防御 → 铁卫分担 → 原生致死保护与合法狂暴 → 当前最高档保险 → 真实死亡，沿已确认顺序。保险成功没有死亡事件。以下是多来源竞争的新增建议：

1. 先尊重已经合法登记且覆盖该死亡的原生复生；不取消原生已承诺救援。其后优先相位继生，再用有资格的生存者救援，最后才进入全灭回溯；不让一个死亡生成两个永久实体。
2. 相位只能在本次真实死亡处理时启动双投影，计30秒；不得在尸体久置后由失败回退补造一轮投影。被前序原生救援占用时不另外生成投影。
3. 死亡时同时冻结可后备的生存者资格。独立蓝仍本局首名合格死亡一次；高阶蓝紫／紫／橙仍每关前1／2／3名合格死亡，同成员每关一次。按真实死亡顺序占定名额，不因为先由相位救回就把“前3名”偷改成任意3名；没有使用该后备救援不再额外复活一次。
4. 原生救援明确失败、或相位双投影提前全部死亡时，才转交当时已冻结且仍合法的生存者资格。等待从原死亡时刻起算，转交时若5／8／10秒已满且有合法落点，则可交付；未满继续等待。没有冻结后备资格的死亡不追认新名额。
5. 合法救援等待期间保留原席位和身份。暂停、关间冻结计时，正常恢复继续；无合法落点保持待交付，不消耗第二份来源或强塞进地形。相位一个投影存活到期只还原一个原体，其余投影共同清理。
6. 有已登记可完成救援或相位尚存活时，不提前判全灭。已失败且无剩余合法来源后，才判断回溯；不把永久不可复活成员变成可救援者。

回溯建议使用正式部队与永久独立战斗成员名册，包含英雄及终焉／净化天空，排除农民、临援、子机和投影。任一名册成员存活就不算全灭。回溯不复制我是谁等明确不可复活成员；其他固定不可升级者可恢复原军衔。

最近“满员”快照指当前名册成员均存活时的完整状态，不要求满血。新成员加入、永久移除、身份转换会改变名册版本；必须在新名册第一次齐全时建立新快照，不能用旧版本抹掉新增成员。若新名册从未满员，回溯暂不可用，装备详情显示该状态；不消费一次次数、不虚构不存在的满员快照。这一限制已随本轮统一方案获用户确认。

恢复快照生命／原生盾／能量比例、形态、合法位置和当时单位冷却；身份与实际军衔读取当前不可回退的成员账本，按新上限换算比例，保留已经支付或获得的培养成果。装备成长进度、一次性奖励、保险／复活次数、回溯自身消费、世界／敌人／资源／拾取均不回退。合法重建成功才一次性消费回溯资格；没有任何可恢复成员则不假报成功。旧地图位置无效时寻找原位置附近合法点，仍无位置则原子等待，不半队成功半队失败。

## 九 周期 时间与边界

普通周期均按有效战斗时间，暂停、决定界面和关间不推进，不补发离线时长。周期首轮等满周期，除非明确写开场奖励；成功交付后重计CD，无目标／无位置保持一份就绪，不储存多轮。

明确“无对象跳过”的紫精英学院120秒培养仍跳过；不是所有周期都改等待。触发抽样按固定战斗时钟，成功才进成功CD，无合法敌人不累积抽样。支援的6秒／8秒轮内序列沿原技能节奏，不把一次轮内3击算3轮奖励。

反应堆建议蓝／紫2／3枚仅限制自产库存，购买弹药另计；完整360／270秒后首次产出。到满仓停计时，消费自产优先，消耗后从保存余量继续；不积攒超过一轮的待产出，不改战略武器按钮或自动开火。库存、生产余量和已消费弹药随重载连续。

净化天空“每关”建议普通战役按正式关卡、无尽按每个正式轮次计一次，含首次进入；同关重载不重领。普通Ⅰ级独立随行、按已开放普通军衔合法培养，不给每条新舰无限军衔。临援跨关是否清理依各来源已写寿命／关末规则，清理不算战斗阵亡或死亡爆炸；相位的关间保留是已确认例外。

## 十 污染与继承资格
