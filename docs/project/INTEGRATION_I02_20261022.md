## 时钟与对象边界

| 对象 | 进入／返回规则 |
| --- | --- |
| 原场敌人、任务、生产订单、运输、地面物、持续伤害与在途攻击 | 原对象图冻结，原 time／tick 恢复；不把这些攻击复制到特殊关，也不把原场等待偷偷计时 |
| 参与者生命、护盾、技能／指令冷却 | 非毒爆挑战保留实际变化；将特殊关绝对时间换回原场时间。bornAt 身份、相对时长与帧计数不作为普通秒时间戳改写 |
| 特殊关新生成的攻击／空间支援效果 | 归当前挑战场景，返回时结束；不在原场坐标重播。实际有后续的相位复生投影单独随所属复生组返回 |
| 航母子机与横穿撤离者 | 真实子体随母体处理，已撤离成员不再受挑战伤害，损失、补造和伤势不回滚 |
| 毒爆挑战 | 沿用其原独立规则，只结算等级变化，原小队生命／模式和指令冷却保持 |
| 暂停、背包和奖励整理 | 原有模拟阻断保持；多次打开、关闭或领取不会推进冷却、订单、任务时间 |
| 图形上下文丢失／恢复 | 真实 WEBGL_lose_context／restoreContext，账户、钱包、实体、任务、订单、复生与奖励状态前后精确一致；不靠重建世界恢复画面 |

既有回归继续覆盖在途攻击、目标移除、死亡和效果清理；本批聚焦跨场所有权和时间边界，并非 T01 全动作／全特效目录验收。
