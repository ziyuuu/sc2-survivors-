## 巡检发现的容量修复

仅战斗单位锁血的三族巡检复现：守军降落路径未检查300敌人上限，人族可见敌人峰值412、虫族350，并可能阻塞最终Boss入场。守军沿用原数量，未入场部分由原guardTypes与持久化guardianIds数量推导，容量不足继续等待；待守军未全部入场/清除时不提前交付乘员。载体损毁后待守军仍按原数量入场，不删兵或退款。

所有非Boss出生路径使用300容量扣除尚未登场的战役Boss席位（含后续章节预定Boss）；无尽为下一Boss预留一席。Boss依旧按原时间、原地点合法性生成，剩余普通兵/虫海保留队列。此项落实原事件优先与300上限，不改波次数量、战力或奖励。守军的已生成ID保持在原Set中，可重建进度，不增加第二套状态或兼容格式。

守军队列按同一轮可用席位顺序释放，容量只扫描一次，避免每个已损毁载体在每个固定步重复全表数敌人；同一时刻的入场顺序与数量不变。
