# 原生战斗 HUD 与皮肤接入 · 2026-10-10

基线为 `613dac68b0d146f9cacaefbbdff60f91a7fde8ac`。用户要求按计划分阶段开发：设置中新增皮肤页，接入 PC、手机横屏和竖屏 HUD，修正数字显示并避免闪烁；小地图旁保留设置，并添加强化一览、生产管理和本局天赋按钮。每个候选由独立子代理审查。

## 皮肤和保存

使用原 UI 线程 R6 的六套原始框体素材，三族各两套。每族初始一套；该族在非沙盒模式完成困难或地狱战役后解锁第二套。困难以上通关只新增幂等外观凭据，不重复发放天赋点，也不改变原结算。解锁和选择使用永久档案 v6 原有 receipts，随正式导出/导入保存，不从旧点数猜测历史通关，不启动旧存档迁移。

本地继续使用准备票据时的当前永久档案，避免持久化延迟或写入失败导致已选择皮肤回退；显式导入仍以文件中经过校验的档案为准。准备后的票据保持冻结。

设置页沿用当前金色按钮、字体、细框和滚动结构，展示真实原图、使用状态和解锁条件。原有操作、音量、画质、独立档案入口保留。

## 战场布局和动作

- PC 为左下小地图、中下部队框、右下技能；横屏部队两行并根据实际宽度分页，竖屏为右侧单列及上下翻页，右下九格技能。
- 部队使用真实席位及原线框图，军衔置于角落。点击选中，右键或长按查看详情；右上生命、护盾、能量来自实际实体。双生跳虫沿用原成对席位。收起整个部队框后保留所选单位及页位置，展开恢复；不引入人数上限。
- 技能来自真实拥有英雄、全局能力和去重后的兵种能力；不足格子为空，超过容量时翻页。原冷却、目标选择、次数、快捷键与施放规则继续由 battle-actions 判定。手柄菜单可访问地图附近按钮，并自动显示当前选择技能所在页。
- 四个地图按钮调用现有设置、强化一览、生产管理，以及新增只读本局天赋页。本局天赋读取开局冻结配置，不提供购买或重置。
- 场景点击的友方检查只更新 UI 选择，沿用原检查动词优先级；不修改移动或指令规则。战场可见区域只扣除实际面板，透明全屏容器不算遮挡。
- 顶栏关卡采用罗马数字，资源和生命用整数，护甲和速度最多一位小数；不足一秒的短间隔可显示毫秒，避免正数显示为零。仅改变呈现。

## 更新与保护

部队和技能节点采用稳定键复用，分页/收起按钮比较自己生成的内容，尺寸变化只在容量改变时调整所需节点。数字、属性与样式值相同则不重复赋值。保留原模型、材质、攻击特效、地图、战斗数值和生产规则。新增 PNG 均逐字节取自获准的原生 UI 素材；原预览、其他线程目录和失败证据保留。
