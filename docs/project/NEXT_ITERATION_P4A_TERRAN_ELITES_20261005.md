# P4-A · 人族三十精英正式接入 · 2026-10-05

用户已要求“开始，人族30精英”并再次明确“Implement the proposed plan.”。本批落实已批准 P0/P4 的全部30个人族精英身份、I–V成长与机制，包含此前大型雷、医疗艇与科技球样本，交付正式完整游戏和共用引擎的独立演示。没有实现其他两族精英、普通兵种重做、24张趣味卡重做或 R7 静态界面全面替换。

## 数值与战斗

- 运行时值明确写入 `src/data/terran-elites.ts`，30个ID/名称/参数与批准快照一致；游戏不读取 P0/P4 文档 JSON。身体基准为普通 V 级，五个身体预设、固定伤害成长 1+.35×(rank−1)、生命成长 1+.30×(rank−1) 与医修成长实际进入共享 World。
- 枪兵预热／排热、身份伤害与闪避、全家族指挥；劫掠者减速／减攻／破甲与逐发三连溅射；死神六连、开场火力与单猎者吸收；长距离／扇面火焰及大型雷；机动攻城／远程驻扎／五倍爆炸面积；雷神震击／对空锁定／周期过载；维京开场导弹／实际降落／转换强化；女妖减防／污染／脱战蓄能；六种医修和辐照／EMP，均为实际规则。
- 医疗指挥覆盖普通、精英和英雄；机械护甲与脱战机动加成按永久战斗身体资格应用。航母的真实子体通过母体继承一次，进出医疗范围维持损失比例；不把友方光环传给敌方。女妖减防仅作用于敌人。
- 正护甲和原生护盾护甲进入同一减益链；减防作用于已有百分比与原生守护者固定减伤，免疫和有限屏障保留。Boss减速、污染身份分档与各自冷却按批准约束结算。
- 大型雷与趣味卡小雷分开：每12秒两枚，活动上限8，发现6、速度6、出土.25、触发1.2、实体半径.45；I级爆炸1200／半径4.2，随后两个每秒180火脉冲。布雷受合法落点与占用限制，欠发重试不补刷无限库存；每枚只爆一次，原始触发与残火收据保持。不同等级按固定成长冻结。
- 毁灭者只把面积扩大五倍，半径乘 sqrt(5)，不会扩大五倍半径或五倍伤害。同源火区对同目标每秒只取一次最强有效脉冲。
- 单猎者只限制死神家族；永久死神原ID、出生、军衔／精英和原始支付收据记录一次，按普通I等价DPS与生命均值累加。其他家族与英雄保留；不触发死亡／复活／返还支付。猎者死亡后正常后续死神交付恢复。
- 医修按实际缺失生命、目标上限、交叉类型三分之一、抑制与实际能量扣费；满血不刷恢复／屏障。微光、铁幕屏障各自按有效恢复生成，金额、时限与目标HP上限均有限。EMP通过正式有限屏障／原生盾链，不把溢出当生命伤害。
