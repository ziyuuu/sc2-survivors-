## 先统一阅读口径

### 复选、进度与名额

1. 普通白／绿／蓝／紫牌以及紫节点均设 **1／2／3 档**：首次取得为 1 档，再选一次为 2 档，第三次为 3 档。同张卡最多取得三次，表格是各档**最终值**，不把三个档位相加。橙节点只能取得一次，本局三选一。
2. 普通白牌复购不再加分支进度；其他普通牌复购沿用现行有效进度规则。第三个有效普通牌进度成交即锁定主支，必须立即选完免费节点。主支进度 3／6／9 各选一次紫节点，第三个紫节点领取后再积 3 点选一次橙节点。普通紫牌只出主支；副支仅混入白／绿／蓝。
3. 为使「复选三次王虫腺体」确实可选，本支第二、第三次紫节点候选，**至少保留一个已持有且未满档节点的升级位**，其余位置从合法未持有节点中抽取；有多个可升级节点时等概率抽一个，空缺由另一组补足。不沿用“优先塞满三个未持有节点、因此永远见不到复选”的抽法。候选一经生成即冻结，读档不重抽。
4. 腺体增强每次扩编一支不同部队，最多三支：基础 5→6；王虫腺体每次让这些部队再＋1，三次为 **6→7→8→9**。把三个紫节点全投王虫腺体，才有三支 9 席、两支 5 席，共 **37 席**；这时没有选其他紫节点。橙选基因突破后，六队为 9／9／9／5／5／9，共 **46 席**。
5. 上述 37／46 是无其他名额加成时的**正式编制席位**。现行跳虫一席是一对、两个独立身体；其他普通家族一席一只。不能把 37 席一律写成 37 只。英雄另计。现有天赋／装备名额加成保留且只计算一次。

### 军衔、伤害和时间

- **R**＝触发时当前正式普通／精英部队的最高军衔，包括正在保留原席位等待复活的兵员；不取英雄、临时兵、受控敌人或尚未取得的培养结果。死亡触发先在移除死者前取样。确实没有正式兵员时 R＝I。
- **M(k)**＝`min(R, k)`。例如 M(IV) 表示最多 IV 军衔，但当前最高只有 II 时就投 II；R 已经到 VII 时仍投 IV。表内 I／II／III 等罗马数字均为**单位军衔**，与左侧卡牌 1／2／3 档分开。
- **D**＝死亡正式兵员的军衔。**同源军衔**＝被复制的正式兵员军衔。高级虫巢 N01 将本支新生成兵员提高到 R，已有更高同源军衔不降低。
- **A**＝指定兵员针对该空地目标的原生主武器一轮伤害，含原生多击和军衔／永久装备面板，未扣敌方防护；不含暴击、额外弹、卡牌追加伤害、DOT 或短时状态。**H**＝受益兵员的最大生命。**Q**＝R 军衔普通刺蛇对地一轮普攻的 A，仅用作孢囊伤害标尺，按刺蛇适用的装备面板算一次，不要求阵容带刺蛇。
- 额外伤害均走对应普通伤害防护，不默认穿甲／真实伤害。W07、W09、B07 这三种条件增伤在同一栏相加；B08 提升原生伤害面板。追加段不能再次触发本分支命中效果。攻速指攻击频率增加，攻击间隔按 `原间隔÷(1＋攻速增益)` 计算。
- 所有秒数均为**实际推进的战斗时间**；暂停、商店和离线不计时。CD、临时兵剩余寿命、计数器均随合法转场／存档保留，不因新关卡重置。
- 表中 CD 是正常重复周期。第一次取得一张直接周期投兵的白／绿／蓝牌，首次等待 **5 秒**；普通紫牌首次等待 **8 秒**，之后开始表内运输／孵化过程。G01／N01 的满员溢出、N02 的周期分裂、正式生产和所有事件触发，首次均按各自完整 CD。G07 首次按完整 14／12／10 秒等待。复选不立即白送一批，保留冷却完成比例：旧 CD 已过一半，升级后仍剩新 CD 的一半。
- 军衔与寿命在实际出生时确定。复选不重置存活临时兵寿命／军衔，随后新生者使用新档；W05／W06 出生状态也在出生时冻结。常驻伤害／防护效果立即取当前档。B08、N08 的已有身体处理另见卡片说明。

### 临时兵、投放载体与科技

- 表内「只」都是实际战斗身体；「对」是两只跳虫；「席」按正式家族配方，跳虫两只、其他一只。临时跳虫虽然可按对投放，**不建立正式跳虫对的自动补生记录**。
- 临时兵满血出生，保留该兵种合法原生普攻和自动战斗技能，按自身兵种／军衔重新算面板，并应用适用装备／光环一次。复制体不复制施放中的弹体、短时增益、经济效果、编制效果、分支触发器或独立装备槽。卡牌生成的普通兵不凭空变精英；N02／N03 明确复制原兵员时可以保留精英身份与战斗技能。
- 全部分支临时兵免费，不占正式编制、不挤走正式补员，不培养、不取得正式晋级。临时兵战死、到期、退场都不会再触发 W04／G04／B02／N03，也不会作为 W03／B03 的播种攻击者。原生虫群宿主／巢虫领主子虫、感染虫控制仍按六单位规格工作。
- 临时兵击杀正常敌人仍按正常击杀结算原有奖励／任务效果；临时身份不削掉正常掉落，也不多发一次。独立体验敌人继续零掉落、零装备、不参与普通成长和救援结算。
- **本支临时母体／独立战斗兵全场上限 60 只，O03 提到 90 只**。该容量已确认，性能尚未实测。不是每张卡各有 60。蝗虫另守每宿主 8／全场 48、寿命 8 秒；巢虫另守每母体 6／全场 24、寿命 5 秒；受控身体另守每感染虫 3／全场 12、其中精英最多 2。这些池全军共用，不因获得一张新召唤牌再复制一份。
- 达上限时，周期投放最多保留一批等待，完全未入场不开始下轮 CD；开始入场后有 **6 秒**释放剩余兵员，剩余仍放不下则取消，下轮 CD 从本批第一只入场计。已有待放批次期间不能再积一批。死亡、复活、孢子等事件产生的额外兵员只放当前能容纳的数量，不积债。按就绪时间先后处理，同一时刻按牌 ID 排序。成对配方必须有两只空位才投一对。
- 主脑、坑道与虫卵在本稿中是**投放载体**：不占编制／临时战斗上限、不提供攻击／嘲讽、不被攻击，也不阻挡移动。主脑或坑道出现后 **1 秒**交付；虫卵默认 **1.5 秒**孵化，P02 为 2 秒。临时寿命从战斗身体孵出／落地开始。
- 点名固定兵种的牌可以借用该兵种，即使正式生产科技尚未解锁；不会因此解锁正式生产。G03 坑道虫、P02 遮蔽天空的**随机池只取已解锁科技**；P02 没有合法高级空军时不进入候选。B03 明确列出的孢子突变不要求正式科技。
- 周期投放选择队伍锚点前方最近合法位置，保持地空通行和安全出生检查；移动／撤离命令优先。所有单位技能自动判断，不增加手动单位技能按钮。

### 复活与战损只认原正式兵员

W04／G04／B02／N03 只接正式普通／精英兵的真实战斗死亡；出售、换族退场、任务撤离、传送、临时兵到期、载体消失都不是战死。每个真实死亡只给各已持卡一次事件，多个不同卡的效果可以并行，不能各自又给全队广播一次死亡。

本支复活规则：`概率＝min(75%, G04概率＋N03概率)`；`血量比例＝max(G04血量比例, N03血量比例)`；延迟统一 3 秒。两牌共用每席成功复活后 45 秒资格冷却，失败不消耗成功冷却；每次死亡也只能判定这一次，不逐帧重试。无论只持哪一牌，本支复活均保留死者身份／军衔／装备，护盾为 0，能量取死亡前值，保留技能到期时间，不视为新投兵。N03 的“复活后分裂／狂暴”另有每席 45 秒冷却，允许同一次本支成功复活直接触发。

原生复活／跳虫同伴补生、装备复活和本支复活若对同一死者同时有资格，使用一份死者与席位预留，**最早完成的合法复活执行一次**；同一时刻按原生→装备→本支排序，其余取消。只有实际执行的来源消耗其成功次数／冷却，不能先全扣一遍。原生跳虫 15 秒同伴补生遇本支 3 秒成功复活时，3 秒结果完成后必须取消原 15 秒待补，不能再造第三只。

### 生成、加量、军衔和寿命的计算顺序

1. 确认唯一触发事件和来源牌档位，确定基础配方；孢子先加 N05，N02 先处理本批 4／6／8 上限。
2. 若有 O03 且来源允许，数量增加 `ceil(n÷3)`，只做一次；N06 追加明确跳过本步。
3. 检查临时身体总上限和合法位置，创建实际身体。正常 CD 从实际投放起算，事件派生不无限排队。
4. 按来源规则确定基础军衔，再应用 N01；按单位原型、军衔、装备／光环计算面板一次。复制体从原型和永久状态重算，不能把已含装备／临时增益的最终值再次整体相乘。
5. 基础寿命乘 N08 一次，最高 60 秒；记录原始出生时间。加 W05／W06，适用时加冲锋／狂暴；相同出生攻速／移速取高值。
6. 出生批次按白名单通知 W08／G09／N06 一次；衍生生成不重新进入根投放循环。原生子虫／感染控制使用各自系统，不在这条卡牌递归链里增加一次卡牌事件。
