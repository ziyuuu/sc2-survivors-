## 当前规则方向

**骰子提高商店刷出紫卡、橙卡的概率；从白色档开始，沿白→绿→蓝→紫→橙逐步升级，档位越高效果越强。**

- 骰子自身采用现有五色品质序列，取代旧三档×1.2／×1.4／×1.6方案。
- 白色档即可进入购买／升级路线；按用户的“逐步升级”采用从白档开始逐档推进，不直接照搬酒馆可跳买最高档的规则。
- 增益只作用于后续生成的商店随机卡牌，包括新商店页面和主动刷新；购买或升级本身不免费重抽已经展示的卡牌。
- 不改变敌人掉卡率、Boss卡牌奖励或舰装装备掉落。非Boss不掉卡规则保持。
- 每档增幅、价格以及升级具体支付方式待配置。酒馆已确认补差价，但本轮没有把骰子的逐档升级自动写成已确认同一价格表。

## 实际商店源码核对

当前正式商店使用 `src/simulation/progression/expedition-drafts.ts` 的 `expeditionRarityWeights`／`rollTier`，五档顺序为白、绿、蓝、紫、橙：

| 关号范围 | 当前基础权重 |
| --- | --- |
| 1–5 | 45／35／16／4／0 |
| 6–11 | 25／40／27／7／1 |
| 12–18 | 15／35／35／12／3 |

这是抽卡前的品质权重，最终展示还受合法候选、同页去重和无候选回退影响；不能直接称为每张最终卡牌的保证概率。`src/data/rewards.ts` 的旧通用权重不是本商店的实际主路径，实施时不能只改该旧表。

**前5关橙卡基础权重为0，单纯乘倍率仍是0。** 增幅设计必须明确处理这个边界：助手建议骰子给紫／橙增加额外权重后归一化，使早期骰子也有实际效果，并继续尊重卡牌本身的合法购买资格；该具体算法及早期橙卡开放幅度尚未由用户定数值，不声称已经实现。

现有舰装免费刷新品质加成通过 `highQualityWeight` 接入，仅在其符合条件的刷新时生效。骰子需与其正确合成，避免重复乘同一收益或改动其他奖励入口，组合规则与实测在实施时补齐。
