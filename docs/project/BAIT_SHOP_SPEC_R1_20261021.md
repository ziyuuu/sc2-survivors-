## 已确定的核心机制

**原有刷新正常运行，诱饵另外进行自己的概率判定，成功时额外触发符合条件的出现事件。**

- 诱饵不再给原生概率乘×1.3／×1.7／×2.2，也不是在原生概率上加百分点。
- 诱饵的概率不依赖原生判定成功或失败；不能实现成只有原生失败才补判。原生已经触发，也不能因此把诱饵独立判定视作已经消费。
- 原生精英已有90%甚至100%出现概率时，独立诱饵仍有额外作用；原生概率封顶不消除诱饵本身的触发机会。
- 原生次数记录与诱饵额外触发须区分。原生每关最多一随机精英的记录不能直接吞掉独立诱饵的额外收益；诱饵自身的每关次数与冷却另行配置。

独立概率不等于忽略场面安全和容量。300敌人上限、原有合法落点、必要任务与Boss保护等仍需统一执行；原生与诱饵同窗冲突如何延后、每次触发的类型和数量，需在后续配置中明确，不能把无限积压当默认方案。
