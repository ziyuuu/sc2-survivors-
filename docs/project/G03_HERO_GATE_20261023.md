## 入场与毕业分层澄清

用户进一步澄清：困难蓝装加少量绿装是正常入场装备，不是毕业装。正常入场装备配合合理操作、培养和局内成长，应能顺利进入无尽；当前难度毕业装备则应能平推战役进入无尽。两个层级分别验收，困难毕业装的品质、词条和模块标准尚未确定，不把蓝绿装或全蓝装擅自定义为毕业装。地狱紫装为主的入场目标沿用，毕业标准也需另定。
