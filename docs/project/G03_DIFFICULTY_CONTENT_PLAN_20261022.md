当前生产源码的任务与特殊关入口主要按关段／参与者资格筛选，尚无上述完整难度目录限制；因此本文件不能作为已实现或已测试通过的证据。

## 设计建议，尚未作为具体名单定案

简单优先放目标清楚、可见风险直接、失败损失容易理解的任务和遭遇；普通增加护送、连续目标、主动风险选择等机制；复杂变身／感染、多阶段高压与多系统联动优先放入困难／地狱。具体条目必须按现有真实流程逐个比较，不能只凭名称判断难度。

普通特殊关建议在资源／弹幕之外先加入横穿虫群，竞技场从困难开始，形成可观察的新内容递进。这是候选建议，用户尚未指定普通最终新增哪一关；G03需要比较横穿的路线辨识、清怪能力要求和奖励价值后定案。

简单保留毒爆弹幕符合用户要求，但要单独比较弹速、密度、可通行宽度和普通操作下的容错。当前五段复杂弹幕不能因名称属于“简单开放内容”就自动视为新手难度适合。60秒、四人、五次机会、1秒保护和升降级规则仍作为现行基线；任何改变须明确列出理由和方案，不能暗中改为另一套玩法。

## G03必须一起完成的工作

2. 所有正式入口共同遵守难度目录：自然主事件、诱饵额外事件、酒馆影响的任务池、免费门票、战场传送门、关间返回进入和其他实际存在的生产调用点。生成和兑现两处均核验；简单／普通不能通过诱饵额外额度生成独立虫群，也不能领取低难度禁止关型的门票。诊断试玩／T01可以明确标记后单独选择内容，但不作为正式可达性证据，不能改变正常局。
3. 保留已经批准的安全窗口、Boss互斥、15秒喘息、每关一次自然主事件、特殊关每局三次与S+3间隔等现行基线。禁用类别后实际事件数、权重重算、无合法候选和额度消耗都要量化；不能不经评估就把所有被禁用机会转成更多任务／敌人，或累积到后续爆发。
4. 把缺少事件后的收入／成长纳入整局经济：任务、特殊敌人、虫群、特殊关的矿气、装备、生产机会、英雄来源及队伍损失分项记账。简单／普通既不能因缺少奖励而形成发展死路，也不能因只剩低风险高收益内容而过早滚雪球；不直接承诺等收益补偿，也不通过无依据奖励填平差额。
5. 全部道具可以接入，但必须核对各难度的实际效果与文案。重点检查诱饵的虫群分支在简单／普通不可用时，其有效收益、价格与说明是否合理；酒馆只影响当难度合法任务，魔盒风险要符合实际增强。道具不能绕过内容分批开放，不因某个子效果不可用就未经决定整件下架。
6. 将难度选择说明、商品详情、被拒绝／过期入口及必要首次提示交接给U05；保持已有HUD、任务文字、镜头和原鼠标／触屏操作，不扩建常驻说明面板。
