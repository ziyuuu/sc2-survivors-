## 装备各层的职责

本文的白字指装备基础属性，绿字指随机词条，二者不是白色、绿色物品品质。

| 层次 | 负责什么 | 示例 |
| --- | --- | --- |
| 白字 | 槽位的基础属性与物品等级成长 | 普攻伤害、生命、原生盾、护甲等合法基础属性 |
| 绿字 | 随机数值与条件属性，让同一构筑仍有刷取目标 | 攻速、暴击、闪避、移动、治疗；精英或英雄适用的数值；特定征召来源身体的耐久 |
| 固定能力 | 单件开启一种机制或改变它的运行方式 | 付费产线转精英、开局英雄、整队转移、生命分担、临时精英援军 |
| 套装 | 用二／四／六件建立获取、培养、联动的打法 | 精英产线→精英成长→教官带兵；英雄入场→英雄卡获取→精英护卫 |

生命、攻击、攻速等不再以单独的百分比加成占用套装阈值。机制仍需要概率、时间、容量等参数，例如20%产线转精英、120秒晋升、30秒临援；这些参数决定机制强度，不是把普通攻击＋15%换个名字继续放回套装。

白字、绿字按真实适用对象结算，普通兵、精英、英雄都有合法的数值收益。神族原生盾与回盾、虫族缓冲、子机继承等继续使用本族资格。传奇能力和套装决定能做什么，词条决定这套打法做到什么程度。

## 十二槽结构

| 位置 | 职责 | 套装计数 |
| --- | --- | --- |
| 舰载核心 | 农民、采集、建筑、解锁、科研、资源回收与过关收益 | 不计入 |
| 核心反应堆 | 随机商店、刷新、采购、普通强化奖励、核武供给 | 不计入 |
| MOSS系统 | 原七项微操能力及控制属性 | 不计入 |
| 舰炮 | 周期自动支援，火力、治疗、回盾；可有投送临时精英的援军弹舱候选 | 不计入 |
| 八组件 | 火控、动力、装甲、护盾、推进、兵员、医疗、协同 | 可装套装件或传奇散件 |

八组件名字只是底座和属性池的提示，不限制套装功能。例如“精英学院·装甲组件”仍能计入精英学院，不会因为占装甲位而被迫变成生命套。

三个大件的运营／商店／控制分工保持不变。原资源线的精英、英雄内容移到八组件的固定能力和套装；核武供给继续是反应堆的新设计候选，不能冒充已有天赋节点。

舰炮的临时精英援军版本可复用A15的真实临时身体和周期，表现候选为投送舱／虫囊／折跃；它不是永久精英来源。英雄六件的主动护卫是同一临援机制的另一触发版本，详见下文。

## 精英与英雄重新归位

| 当前天赋 | 装备中的位置 | 保留的内容 |
| --- | --- | --- |
| R15 精英教室／精英孵育／圣堂选拔 | 精英学院套装、精英产线传奇组件 | 正常付费的指定基础兵种身体，有概率成为合法同家族紫色精英 |
| A09 自我成长 | 精英学院套装、精英培养传奇组件 | 每隔战斗时间使一名活着、未满级的永久精英晋升 |
| A08 传授经验 | 精英学院六件、教官传奇组件 | 同家族永久精英成为普通兵培养的导师 |
| A10 寻找精英 | 战地搜寻四件、精英合同传奇组件 | 原指定整备窗口增加付费精英特约，不改为商店折扣 |
| A14 精英侦察 | 战地搜寻二件、救援信标传奇组件 | 真正救出一个农民目标时，有概率获得合法精英救援权 |
| A15 雇佣兵先生／原始猎群／圣堂卫队 | 舰炮援军弹舱固定能力；英雄套的护卫变体 | 保留Rank V临时紫色精英与80秒存活；护卫变体改为英雄主动技能触发 |
| R16 英雄支援／虫群领袖／达拉姆领袖 | 英雄统御二件、开局英雄传奇组件 | 从原本族五名地面英雄中选择一名II级英雄开局部署 |
| R14 出金大师 | 分成三个明确分支 | 普通强化归反应堆；紫色精英归八组件／搜寻套；橙色英雄归八组件／英雄套 |

R14当前紫、橙池含普通强化和身份结果。本稿拟拆开这些结果池；拆池后的概率需要单独校准，不声称额外精英／英雄卡的总产出已与旧天赋等价。它们仍是卡或救援权，不换成材料等奖励。

原Boss、任务、商店、救援的精英与英雄来源继续存在。舰装增加可选择的获取和培养路线。普通军衔上限可由原S14能力到VII；紫色精英、英雄仍上限V。原S14虽然叫“精英培训”，实际作用普通兵，不能用名称把它误算成精英升级。

英雄仍占本局三个身份席位；开局II级占第一席。后续英雄卡按现有合法获取、重复培养与容量资格使用，不增加第四身份，也不在本稿建立一个新的局外英雄收藏系统。

## 五套机制型候选

每个系列都提供八种槽位版本。一件只属于一个套装，阈值为二／四／六件；第七、第八件不设新的强制奖励。以下效果是重设计候选，不是用户已批准的最终能力表。

| 系列 | 二件：打开路线 | 四件：形成循环 | 六件：形成主要打法 |
| --- | --- | --- | --- |
| 精英学院 | 指定正常付费基础兵种有概率转为同家族永久精英 | 按战斗时间培养一名最低等级、未满V的永久精英 | 活着的同家族精英充当教官；普通击杀有概率培养同家族最低军衔普通兵 |
| 英雄统御 | 开局选择一名本族II级地面英雄 | 合格击杀开启额外英雄卡掉落通道，可获取新身份或培养已有英雄 | 已拥有英雄成功施放主动技能时，召来一名Rank V临时精英护卫 |
| 老兵进阶 | 普通合格击杀有概率晋升，优先同家族最低合法军衔 | 普通兵军衔上限开放到VII | V级以上普通兵可消耗正常付费同家族增援名额，完成原I—V战术进阶 |
| 战场征召 | 合格击杀有概率生成需解救的普通乘员 | 合格击杀有概率召来30秒Rank V普通临援 | 每家族身体容量由5开放到7，精英仍占家族名额 |
| 战地搜寻 | 成功救出农民目标时，有概率获得精英救援权 | 原指定整备窗口增加付费精英特约 | 合格击杀开启额外紫色精英卡掉落通道 |

精英学院与老兵进阶可以共享同一普通晋升机制，但不叠两次晋升判定。前者需要永久精英作为导师，后者自身提供基础培养、VII上限和普通战术进阶。重叠部分合并概率并遵循一次成功只培养一名的原流程。

### 参数与来源

- 精英学院二件可先以R15的20%试算；保留三族原产线与兵种排除、虫族最终体一次结算。四件先以A09的120秒、一名最低等级永久精英试算，无目标跳过不存次数。六件复用A02／A05／A08的合并培养，永久精英导师才有资格，临时精英不作导师。
- 英雄统御二件直接沿用R16。四件来自R14身份分支的重新分配，英雄结果池与掉率尚待独立平衡。六件是新增触发联动：成功开始英雄主动技能才有召兵资格，取消选点或非法目标不触发；全队共享90战斗秒冷却，一名护卫存活80秒，使用A15原本族已解锁候选。它不复制英雄技能、不自动施法，不消耗额外主动按钮。
- 老兵进阶二件复用A02／A05，四件复用S14，六件复用S16。战术进阶依然需要真实付款与五名额收据；它改变普通身体的战术方向，不变成紫色精英。
- 战场征召二件先以A03的2%和成功后45战斗秒冷却试算，仍需击败守军。四件先以A12的2%、30秒、同时两名试算，保留本族候选及临时身体的资源／培养排除。六件复用A16，不提高五家族或三英雄身份上限。
- 战地搜寻二件先以A14的10%试算，一个真实农民目标一次；核心额外获得的农民不再各自掷骰。四件先以A10每个原指定窗口额外一张付费精英特约试算。六件的精英池来自R14分流，概率单独平衡。

英雄护卫与舰炮援军弹舱共用同一个精英临援资格、冷却和容量，本稿暂定全队同时一名该机制的临时精英；装上二者不产生两套独立召兵。英雄六件让玩家用实际主动技能选择临援时机，选此路线时舰炮可以改装火力或恢复版本。原A15的周期召兵在舰炮固定能力中仍可独立选用，没有因改触发而丢失。

不再用“六生存＋二攻击”描述构筑。玩家在这些机制之间选配，攻防差异由同套装备的白字、绿字继续拉开。

## 传奇散件：机制也能单件启动

精英与英雄能力不只放在套装终点。八组件的传奇散件同样能开启路线，形成六件套加两散件或四件套加四散件。

| 传奇候选 | 固定能力依据 | 配装用途 |
| --- | --- | --- |
| 精英招生信标 | R15合法付费产线转精英 | 不凑精英套，也能获得精英来源 |
| 英雄指挥旗 | R16开局II级英雄 | 不占两件套位置，也能带开局领袖 |
| 教官履历 | A02／A05／A08组成完整普通培养能力，永久精英为导师条件 | 给其他套装接上带兵成长 |
| 精英培养舱 | A09最低等级永久精英自主晋升 | 给搜寻／英雄构筑接上精英培养 |
| 战地合同书 | A10指定窗口额外付费精英特约 | 以真实购买扩展精英来源 |
| 联队分担器 | S10同家族分担最终生命伤害 | 改变伤害承接方式，保留总伤害与原生盾结算 |
| 不归军令 | S15首次未被其他保护化解的致死，1HP坚持后必死 | 获得最后一段作战时间，期间不可治疗或回盾 |
| 家书信标 | S09普通身体一次致死保命 | 开启有资格限制的保命机制 |
| 战损重整器 | A04／A07同一次降军衔存活 | 消耗军衔处理致死，保留每关每身体资格 |
| 共生织构 | S06本族附加盾／独立缓冲／原生盾织构及其恢复规则 | 开启对应耐久机制；容量、恢复量可由合法词条调整 |

普通攻击、生命、护甲、移动、攻速、暴击、闪避、属性附伤、合法治疗等原连续数值，归白字／绿字。A01救援入场培养概率与A06征召来源身体耐久也可作有条件的绿字，不再独占套装阈值；有条件词条应标明需要的单位或来源。

同名传奇和套装的同一机制合并为一次完整效果，不额外掷骰、召兵、开局再给一名英雄或制造两套成长计时。套装件有白字、绿字和套装归属；初版不再同时附完整独立传奇能力，保证混搭散件需要实际让出槽位。

## 刷取和界面仍围绕装备

装备永久入库、失败保留已入库收益、重复件拆解、单词条改造、缺件定向制造，以及每族三个配装的方向保留。出征时冻结装备效果，本局军衔、单位身份和容量不因局外换装临时改变。

成长目标分为基础属性更高、绿字更合适、机制组件齐备三个层次。套装收齐后仍能刷同槽更好的白字与绿字，获取传奇散件扩展混搭。装备掉落与原卡牌／任务收益分别结算，原营救精英、修复建筑、虫后保证英雄等不改成材料收益。

装备面板分别列白字、绿字、固定能力、套装阈值。精英与英雄的来源和培养必须能直接看到，例如“付费基础兵种转精英”“开局II级英雄”“永久精英自主晋升”，不能只写“英雄攻击＋15%”。

局外激活可用模块连接与短暂高亮。战场能力沿用真实出生／救援、军衔变化、攻击和本族投送／折跃表现；不新增辅助圆圈。护卫触发动画、投送时序与平衡还没有实机证据。
