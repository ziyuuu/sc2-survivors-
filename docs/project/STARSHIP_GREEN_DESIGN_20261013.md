## 本轮确定的修正

- 普通英雄套两件效果仅提升对应方向士兵的数值，不提升实际军衔，也不换算成虚拟高军衔。
- 污染英雄套的随机精英移到四件效果：紫档2名、橙档3名。四件原有军衔上限＋1／＋2保留；六件获得绑定Ⅰ／Ⅲ级英雄并大幅强化其能力。
- 白字仍固定总强度、固定两条；本轮随机成色与保底只设计绿字。
- 污染装备的绿字必为极品；普通装备偏向优质产出，保留追求满值的空间。
- 普通兵Ⅵ／Ⅶ级需要加强，不把“仅数值提升”的英雄两件效果改回军衔效果。

### 进攻作用口径建议

1. **攻击加成**：增强合法主武器的普通伤害，包括白字DPS折算后的部分；不放大真实伤害、单位技能、支援或战略打击。各装备与同类套装攻击加成相加，再乘一次。
2. **真实伤害**：表内数值表示每秒附加真实伤害，按当前实际攻击间隔折算；与白字DPS共用身份／军衔适配系数。多段分摊，母体与子机共用一份，不给溅射每个目标重复附加。不暴击、不再吃攻击加成，忽略护甲，但不穿透无敌等明确伤害免疫。范围武器没有主目标时只选一个合法直接受击目标领取该轮份额。追加攻击不再额外领取这份固定DPS，以免概率追加又放大每秒定额。
3. **攻击范围**：本版建议明确为主武器射程＋X%，按该武器自身射程计算，近战也按自身基础距离计算；不新增攻击对象资格，不放大爆炸半径或技能范围。这个定义是本轮提案，不自动套用废稿的固定射程近战系数。
4. **暴击率**：给具备暴击资格的主武器增加暴击概率，各来源相加，最高100%；不能把每个溅射目标分别再滚一遍暴击。特殊武器资格在生产接入时明确，不凭装备赋予治疗暴击。
5. **暴击伤害**：增加暴击倍率的百分点；当前普通普攻实现为175%，例如＋90个百分点后为265%。不免费赠送基础暴击率。装备比较时显示当前全军合法暴击覆盖，暴伤可以为后续构筑保留；不会强制同件同时抽到暴击率，也不改变五种候选的等概率抽取。

### 防御作用口径建议

1. **防御等级**：本版建议统一三族，每10点＝已有护盾上限＋1%、受到的生命恢复／回盾量＋1%。它强化已有防护与恢复机制，不凭空创建新护盾。自然恢复也受益；按最大生命／盾量计算的恢复先用最终上限，再乘恢复加成一次。护盾上限与恢复速度是两项明确收益，不反向迭代计算。这样与白字护甲、生命及绿字免伤区分，三族无需各写一种新装备属性。治疗者与受治疗者不会对同一“受到恢复”词条重复结算。
2. **闪避率**：作用于允许闪避的敌方直接普攻；不闪避持续伤害、地面危险区或明确不可闪避攻击。同类概率相加，建议普通闪避总上限75%；特殊技能明确无敌不属于这条上限。
3. **移动速度**：对单位基础移动速度增加百分比，各装备同类加成相加。不缩短架起、变形、生产或技能时间；固定设施不变成移动单位。
4. **生命加成**：对已含身份／军衔与白字加值的生命上限增加百分比，同类相加再乘一次。不同时提高护盾。装备切换按当前生命比例衔接，盾单独按比例；不触发治疗／受伤事件，死者保持死亡，细则见[装备统一结算规则](STARSHIP_EQUIPMENT_SETTLEMENT_20261014.md)。
5. **免伤**：减少护甲结算后的可减免伤害。建议装备与同类套装免伤相加，上限70%；其他独立技能减伤按各自规则对剩余伤害结算。明确无视减伤的伤害与无敌技能各按自身规则。不给每件独立乘算，以免面板难以理解。

防御等级与攻击范围在此前新版只有名称，本节是给用户审阅的具体定义；不能将其记成此前已批准的机制。

百分比词条不乘英雄20倍：它们本来就作用于英雄更大的属性基数。真实DPS这类绝对加值才使用白字的身份与军衔适配。防御等级本质是百分比换算，同样不再乘身份倍率。

## 200分成色与组合

每件有普通绿字的装备满分200。这个分数评价“各词条接近本品质满值的程度”，不比较不同装备的总战力。橙色150分仍可能强于紫色200分，套装三绿字200分也不等于散件四绿字200分的属性总量。

每条分数q取100—200整数，实际数值＝本品质该属性满值×q÷200。整件分数Q＝各普通绿字分数之和÷普通绿字条数。套装效果不参与普通绿字评分，也不将占掉的格子补回其他属性；少一条仍真实少一条收益。评分使用内部精确值，UI可显示到三位小数，不能用四舍五入后的显示值重新计算评分。

生成步骤提案：

1. 按已定品质和是否套装确定普通绿字条数，从对应五种候选中等概率、不重复抽取。
2. 按下表抽成色档，再在该档整数Q中等概率抽目标分。
3. 给每条分配整数q，要求总和＝条数×Q；每条在max(100,Q－20)到min(200,Q＋20)之间。满足条件的有序分数组合等概率，词条种类没有暗加权。
4. 极品档额外要求每条至少180分。最后按各属性满值折算实际属性。

| 成色 | 整件Q | 无保底加成时概率 |
| --- | --- | ---: |
| 普通 | 100—139 | 10% |
| 优质 | 140—169 | 25% |
| 优秀 | 170—189 | 55% |
| 极品 | 190—200，且每条至少180 | 10% |

90%至少优质，65%优秀或极品。低值少量保留，但不会让总成色很高的装备藏一条极低值词条。不同品质共用成色分布，具体强弱由不同品质的属性上限决定；不再同时维护白蓝130／紫橙160等旧版规则。

例如橙色进攻套装三条取攻击加成、暴击率、暴伤：Q＝190，组合200／190／180，对应＋28%攻击、＋22.8%暴击率、＋81个百分点暴伤。也可以是190／190／190；两件都是极品但偏好不同。200分满装只能全部词条满值，不等于所有极品均满值。

## 保底与污染

建议普通掉落初始极品概率10%。每次产出非极品，同品质下次极品概率＋5个百分点；产出极品后回到10%。第18次连续未出后，下件必为极品，因此最多19件有绿字的同品质普通装备保底一次。

其余三档按10∶25∶55等比例压缩概率，不增加总掉落数量、不提高装备品质、不改变抽中什么词条。绿／蓝／紫／橙四个计数独立，普通散件和同品质套装共用；无普通绿字的装备不累计也不清零。跨局保留，以新物品实际生成登记为准，读档、移动、清洗不重复登记。

污染有随机绿字装备按2026-10-15定案每条直接取本品质满值，q与Q均为200，不再从190—200随机。生成时锁定，清洗不重抽；净化后合法洗练可换词条种类，仍保持满值和污染来源标记。污染掉落不消耗、不重置普通掉落的保底。普通掉落的极品档仍为190—200且每条至少180，不能把普通极品与污染满值混为一项。

污染资格以2026-10-15掉落定案为准：白绿、所有蓝模块、无随机绿字的属性特殊件和冒险者禁止污染；其余合法蓝紫橙模板按渠道资格生成。紫／橙模块沿已定完整效果及继承规则，不添加随机属性池。污染状态与污染专属身份分开，普通橙装污染不转换成污染英雄套。污染只能掉落，局外合成也不能直接生成污染专属的净化版。

污染装备须成功撤离后花装备粉尘清洗才能装备；清洗费为同实际品质随机合成基价的1/4（蓝25、紫100、橙400）。失联时背包内污染装备全部遗失。评分不改变装备上／仓库内物品的既定保全规则。

## Ⅵ／Ⅶ军衔加强

## 边界与下一步

四件橙色满值同词条合计：攻击＋112%、真实DPS＋200（身份／军衔前）、射程＋144%、暴击率＋96个百分点、暴伤＋360个百分点；防御等级1440、闪避72%、移速＋112%、生命＋180%、免伤56%。它们分别是该属性的极值，四绿字装备不能同时取满五种候选，不把这些数写成同一套同时达成。

目前暴击175%基础下，四条满暴伤可到535%暴击倍率；额外套装或技能可能触及闪避、免伤或暴击率上限，UI需要显示有效值和超出值。此为可预期的配装取舍，不是已证明的运行Bug。射程、速度及其对地图的影响，必须在真实规则原型实战调优；此稿没有证明这些高橙值已经平衡。

下一步先评审本表的十项定义、绿字成色和Ⅵ／Ⅶ提升，再做整套普通兵／精英／英雄的输出与承伤预算对比，然后进入非属性件与英雄套具体能力模板。无需为旧天赋兼容重新扩大属性池。
