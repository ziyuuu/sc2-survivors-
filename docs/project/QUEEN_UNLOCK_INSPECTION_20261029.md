# 虫后重复解锁反馈核查

2026-10-29，归属 `V06-QUEEN-UNLOCK-001`。用户要求查看“此前已经解锁兵种，升级后仍可以选到解锁建造”是否存在，补充兵种为虫族虫后。本次仅调查，没有修改游戏代码、文案、规则或交付包。

## 结论

**复现了相关的卡牌残留 bug，尚不能确认与原玩家的操作路径相同。** 不是已证明可重复购买/重复扣费。

在紫色“最佳选择”四件套的额外发展机会与紫色“建造承包”的建造免费科技同时生效时：

1. 将发展目标标记为“解锁虫后”，本轮候选包含它和“建造孵化场”。
2. 选择建造孵化场，免费科技顺带完成“解锁虫后”。虫后生产资格已经生效。
3. 因为本轮还有一次发展选择，原候选中“解锁虫后”仍然留下；卡面显示“待解锁”，购买按钮禁用。
4. 实际再次购买返回失败，矿气不变。保存恢复后仍残留；刷新发展候选或进入下一关间后消失。

根因是额外发展机会保留原候选时，只移除了主动购买的孵化场，没有剔除同时被免费完成的虫后科技。候选缓存读取也没有重新过滤资格；交易端则有实时资格检查，所以能拦住重复购买。相关入口为 `src/simulation/starship/economy.ts` 的 `equipmentDevelopmentCompleted`、`src/simulation/building/rules.ts` 的 `getOffers` / `purchase`；失效卡被表现层统一显示为“待解锁”。

另一个正常情况也能产生相似印象：商店“虫后 ×1”只给一名虫后，不解锁持续生产，因此后续“解锁虫后”仍可购买。当前实际卡面简述/详情都只说立即加入小队，底层原说明中的“不解锁持续生产”未进入最终展示。这是区别实际获取含义的证据，不据此认定原玩家看错，也未擅自修改文案。
