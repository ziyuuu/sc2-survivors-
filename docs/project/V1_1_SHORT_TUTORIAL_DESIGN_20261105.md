# 1.1 短版教学（2026-11-05 最新用户决定）

当前实施方案。替代三关观察版及三关固定操作版；旧候选与证据仅用于比较。

2026-11-06 用户审阅修订：资源与装备拾取后先展示真实入账／入包结果约2秒再进关间；击杀、救援、入队、购买、修复和穿戴后留出可见结果。正常关间页面开始，通过原入口逐步导航，不自动打开设施／休整／背包／仓库。安全时短暂平移聚焦目标与战利品，再回小队，移动、切页、跳过立即取消；原角度缩放和个人偏好不改。三族重录采用新指令4至6秒、页面2至3秒、成功结果约2秒的演示节奏，发展说明允许更久阅读。

- 出发后先询问；选接受才加载独立训练场，选跳过进入普通战役。新客资格仍在第一次自动保存前判定；账户级终态不重复邀请。
- 三族不增加额外步骤：人族副官、虫族虫后、神族执行官，共用状态机、同样的操作数。虫族只播一次短促震动；人神配音缺口继续公开。
- 第一段：救出本族工人（移动时展示自动攻击）→击杀跳虫→击杀工蜂→观察地面资源→拾取100矿50气→显示真实入账约2秒后关间。
- 第一次关间：发展说明与一次基础设施建设→设施生产配置确认→购买基础兵补给卡（直接加入2席；虫族每席一对）→下一段。
- 第二段：10秒后真实支付一席训练矿气并准备载体→守护落点至真实入队→击杀原生精英蟑螂→同批固定两件白装（本族、无污染的 defense1 属性散件和 logistics 旗舰模块）→拾取后显示入包结果约2秒再关间。
- 第二次关间：原休整入口修复受伤部队→查看并穿散件→说明模块需撤离→原撤离入口→旗舰查看刚带回的同件模块并装备→结束。
- 原生确认/购买/装备操作均需点击高亮；页面导航保留真实控件。两页导航共享一句通讯，避免重复播报。发展界面允许阅读详情，不自动催促。满血时承认无需修复。
- 固定起始资源700矿200气，工蜂100矿50气；设施/卡/训练/修复仍使用现行原价，不改普通游戏参数。只有独立课程的一席训练在等待10秒后完成准备，载体下降、开舱、守护、乘员结算走原流程。精英使用原生早期 elite/captain 模板，强度仍由正常生成规则计算。
- 教程不发放关卡永久天赋与难度通关进度。角色、订单、资源、地面掉落、背包和撤离仓库沿用真实事务与检查点；不引入另一套奖励经济。
- 任一步跳过，取消通讯/声音/焦点/高亮和排队教学操作，保留已经取得的财产与已付订单，加载普通战役地图并在当前关恢复普通规则。若中途刷新，仍按账户跳过终态完成普通地图转场。教程完成停在旗舰；之后原入口开始正式战役。
- 训练场为96×96平地，只加载本族开局/救援、跳虫、蟑螂与已在场模型；复用正式地表与声音，不加载五图景物。地面使用统一的原版 `terrain.char` 无缝土壤纹理；不重复铺整张八层图集，不做格子拼贴或花哨地面（用户最新截图反馈）。保留原镜头角度、缩放和原HUD。
- 教学框固定右上覆盖层，桌面/手机横竖屏沿用用户已确认尺寸与小字双行；不挤布局，遮住矿气可接受，当前动作按钮必须可操作。
