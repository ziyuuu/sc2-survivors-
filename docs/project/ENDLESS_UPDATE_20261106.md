## 当前行为

每三轮一组，每轮依次为60、90、120、180、240、300秒，之后每组再加60秒。成长进度为 `轮次−1＋轮内秒数/轮长`；生命1.22、分段伤害1.10/1.16及攻速上限保持。第16轮开场生命倍率约19.74。

主波、自然精英和Boss使用 `F=1+0.15×floor((轮次−1)/3)`，间隔分别15/F、30/F、90/F秒，简单精英仍加倍间隔。进度跨轮承接；不叠加旧特殊怪20%提速。单波数量前5实际分钟最多增加20%、混合比例、300上限、Boss留位与领主轮换保持。

普通混合波整轮矿气总预算和基础轮末奖励按轮长/60同比增加，固定装备关末奖励仅一次。每轮购物、每4轮发展/精英特约；永久资源仍每完整实际分钟结算。生产、技能冷却、经济事件及地狱扩张仍用实际时钟，长轮次不会漏掉跨240秒周期的事件。

旧档本轮保留原60秒、波次、经济计划和既有结算；下一轮开始才迁移。现存敌人和待出生队列保留原属性。新出生记录分别保存实际秒数、轮次成长和出生轮号，跨轮排队/重试/恢复不重算。

UI仅更新原无尽整备时长标签、既有详情、当前倒计时和敌军轮号，保持布局和操作。
