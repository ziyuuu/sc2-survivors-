## 保留的候选和失败

`candidate-history.json` 区分“浏览器运行通过”和“审图接受”，不会把早期候选改名为最终结果。

- 工业首版砂层过亮，第二版降低覆盖并校准色调。
- 独立岩脚材质产生明显圆形色块，被否决；最终岩脚共用地表连续坐标和材质，外缘不规则且在原阻挡半径内。
- 过大的多尺度采样偏移造成涂抹状纹理，被否决；最终缩小连续偏移，保留原金属板直线采样。
- 第一次环境恢复检查误把原生“连接恢复”提示变化视为玩法变化。最终先验证原提示及到期时间，仅在克隆快照中归一化 `notice/noticeUntil` 后比较玩法；原始完整前后校验值仍保留。
- 第二次释放检查误把全局接触遮蔽纹理纳入地图拥有资源。最终仅观察地图拥有对象；实际五图恢复及四次地图切换释放通过，不据此宣称低内存设备已验收。
- 法线源 alpha-X 已正确解码，但初始来源元数据误标为未使用；只修正元数据，28组来源／PNG哈希及运行ID不变。初始元数据和修正证明保留。
- 第一次正式 Web 五图／无尽功能检查通过，但实际无尽截图暴露灰烬的灰色矩形。源 RGB 背景不为零，不能作为此素材的透明遮罩；最终逐像素保留原 DDS alpha，65,536像素核对一致，包含26,847个全透明像素。仅灰烬派生 PNG 增加9,055字节；首次 HTML／ZIP、Web截图和被中断的首次离线记录原样保留，未计入最终验收。
- 原环境材质名审计发现两组间歇泉的非目标气体层重名；五个实际修复的纯发光层名称均唯一，未修改重名的原基础纹理层。
- 初始源码准备／打包子进程权限错误、早期类型检查错误及全部原日志保留；不存在把这些失败计入最终成功的情况。
- 最终汇总脚本首次把解码记录数组本身与数量881比较，产生报告结构断言失败；修正为核对数组长度，881条原始解码证据与验收条件未变。该失败及一次未执行的Node命令参数错误另有本地记录，最终总检查通过。
