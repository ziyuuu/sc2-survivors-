# 神族发展方向 兵种解锁与折跃水晶规则

日期：2026-10-12。状态：核心规则已确认，折跃水晶配套细节待定，尚未实施。本次仅编写规格，不修改代码、资源或运行版本。

神族发展候选只包含本线路项目，兵种改为顺序解锁，刷新采用人族已确认标准。新增折跃水晶，一次建造两座，用于狂热者和使徒的生产，以分担传送门线路较多兵种的生产需求。关联规格：[人族](TERRAN_DEVELOPMENT_FLOW_SPEC_20261012.md)、[虫族](ZERG_DEVELOPMENT_FLOW_SPEC_20261012.md)。

## 1 发展方向与建筑前置

每个发展方向只出现本线路建筑。前置建筑和科技仅作提示，不作为其他线路的可购买项目混入当前候选池；本线路兵种解锁、专属科技与攻防研究仍属于本线路项目。

| 方向 | 本线路建筑 | 可购买的本线路项目 | 禁止混入的建筑 |
|---|---|---|---|
| 传送门 | 传送门、折跃水晶 | 传送门兵种解锁、专属科技、攻防系统与研究 | 机械台、星门 |
| 机械台 | 机械台 | 不朽者与巨像解锁、热能射线、机械台攻防系统与研究 | 传送门、折跃水晶、星门 |
| 星门 | 星门 | 凤凰、虚空辉光舰与航母解锁、星门攻防系统与研究 | 传送门、折跃水晶、机械台 |

保留建筑前置两支：传送门 → 机械台；传送门 → 星门。星门不要求机械台，机械台不要求星门。提示前置不取消实际建造资格检查。

例如，星门尚缺传送门时，提示“需要传送门，请在传送门方向完成前置”，不向星门方向补入传送门建造卡。已有传送门后，机械台或星门方向也不再出现增建传送门的卡片。

未满足前置的项目不能购买；锁定说明不占最多三张可购买候选的名额。合法候选不足三项时按实际数量展示，不跨线路补齐；没有合法候选时提示原因，不消耗免费次数或矿物执行无效刷新。

## 2 兵种顺序与前置

用户所写“阶圣堂武士”按本项目现有高阶圣堂武士对应，不新增另一种兵种。箭头表示解锁前置，方括号内为同级分支。

- 传送门：**狂热者 → 使徒 → 【追猎者／哨兵】 → 高阶圣堂武士**。
- 机械台：**不朽者 → 巨像**。
- 星门：**凤凰 → 虚空辉光舰 → 航母**。

后续兵种要求前置已解锁，不要求前置士兵仍在场、存活或正在生产。前置满足后，下一项才有资格进入候选池，不表示自动赠送或保证下一次抽取出现。

|---|---|---|---:|
| 传送门 | 狂热者 | 传送门；开局已解锁 | 100／0，开局不重复收费 |
| 传送门 | 使徒 | 狂热者已解锁 | 100／25 |
| 传送门 | 追猎者 | 使徒已解锁 | 125／50 |
| 传送门 | 哨兵 | 使徒已解锁 | 50／100 |
| 传送门 | 高阶圣堂武士 | 追猎者／哨兵所在层级完成，具体判定见下文 | 50／150 |
| 机械台 | 不朽者 | 机械台 | 275／100 |

追猎者和哨兵同级，两者之间没有先后前置，不自动认定互斥。高阶圣堂武士要求两者都解锁，还是任意一个解锁即可，用户尚未指定，实施前需明确，不能暗中选择AND或OR条件。

开局继续保留一座传送门、狂热者解锁及默认生产。机械台与星门首次建造不新增未获指定的兵种赠送。航母现有第10关生产阶段门槛暂保留；取得解锁与满足生产阶段分别判定。巨像不新增关卡门槛。

本次不改变兵种生产费用、时间、能力、身体数量、军衔或本局兵种席位。正常同线路最多两种输出轮流生产的现有规则保留；折跃水晶如何形成附加生产配置见第3节。

## 3 折跃水晶

新增可建造生产设施“折跃水晶”，归属传送门发展方向。一次成功建造操作交付两座水晶，是一个成对建造项目，不拆成两次购买。

水晶用于生产狂热者／使徒，不能选择追猎者、哨兵、高阶圣堂武士或机械台、星门兵种。水晶不是单纯装饰或人口建筑，应实际参与这两种兵种的生产。

建造水晶不绕过兵种解锁链。狂热者沿用开局解锁，使徒仍要求完成使徒解锁；建造水晶本身不自动赠送使徒解锁或实际士兵。折跃水晶不自动替代机械台与星门的传送门建筑前置。

一次成对建造仍按一个发展购买操作处理，不因交付两座额外开放第二次发展购买。现有建造天赋与成对交付如何交互，需要明确后再实施，避免把“原生一次两座”误当成已经触发双重建造天赋。

### 水晶配套待定项

| 项目 | 尚需明确的规则 |
|---|---|
| 建造价格 | 每对水晶的矿／气价格；不能直接沿用单座传送门价格作为已批准数值 |
| 建造前置 | 是否只需传送门，以及是否另需使徒解锁或专属科技 |
| 数量上限 | 按单座或成对计数；是否独立于传送门现有五座上限 |
| 输出配置 | 两座各选一种、每座最多两种轮流，还是整组共享两种输出 |
| 与传送门的生产关系 | 传送门是否继续生产狂热者／使徒，还是将两者迁移至水晶专用生产 |
| 训练与交付 | 生产时间、并行参与及交付表现如何沿用现有生产机制 |
| 建造天赋 | 免费建造和双重建造按一对还是单座计算；数量不足一对时如何处理 |

两座水晶用于生产狂热者／使徒是已确认用途；尚不解释成固定“一座狂热者、一座使徒”，也不擅自将两者从传送门可生产列表删除。

## 4 保留的建筑与科技升级

| 现有建筑 | 建造前置 | 每座基础价格 矿／气 | 数量上限 |
|---|---|---:|---:|
| 传送门 | 无 | 150／0 | 5座，含开局建筑 |
| 机械台 | 传送门 | 150／100 | 5座 |
| 星门 | 传送门 | 150／100 | 5座 |

增建仍增加设施数量，不改成单座建筑升级。折跃水晶价格与上限独立待定，不混用这张表。

专属科技保持一次性购买，基础价格均为125矿／75气，并要求对应线路建筑存在：

| 线路 | 科技 | 兵种前置 |
|---|---|---|
| 传送门 | 冲锋 | 狂热者已解锁 |
| 传送门 | 共鸣战刃 | 使徒已解锁 |
| 传送门 | 闪烁 | 追猎者已解锁 |
| 传送门 | 灵能风暴 | 高阶圣堂武士已解锁 |
| 机械台 | 热能射线 | 巨像已解锁 |
| 星门 | 无现有专属科技项目 | — |

上述科技不额外插入兵种主链。例如，使徒解锁不要求先买冲锋，巨像解锁不要求先升级不朽者科技。水晶生产狂热者／使徒时，不应因生产设施变化丢失对应已取得的兵种科技及线路研究效果。

三条线路保留各自独立的“对应建筑 → 攻防系统 → 武器／防护”分支：

| 项目 | 基础价格 矿／气 | 前置与阶段条件 |
|---|---:|---|
| 攻防系统 | 100／50 | 已有对应线路建筑 |
| 武器1级／防护1级 | 各125／50 | 本线路攻防系统 |
| 武器2级／防护2级 | 各200／100 | 对应研究1级，发展阶段≥6 |
| 武器3级／防护3级 | 各275／150 | 对应研究2级，发展阶段≥12 |

武器与防护独立升级，覆盖本线路普通兵与精英，新建同类设施继承效果。保留现有防护研究对护甲和护盾护甲的作用，不新增独立护盾研究。实际购买仍应用现有卡片折扣与购买天赋减价。

## 5 按人族标准刷新

神族采用 [人族规格第5节](TERRAN_DEVELOPMENT_FLOW_SPEC_20261012.md#5-免费刷新与付费计数) 的完整标准：

- 每个建设窗口提供一次基础免费刷新，传送门、机械台、星门共享；折跃水晶不产生额外免费次数。
- 基础免费仅用于建设，不转入补给、不跨窗口结转；切换方向、重开界面或重载存档不补发。
- “我就看看”额外提供每窗口1／2／3次天赋免费刷新，建设与补给共享。建设先使用基础免费，再使用天赋免费，最后付费。
- 基础免费与天赋免费都不推进付费阶梯。建设与补给共享本窗口成功付费刷新次数。
- 补给不新增基础免费次数。余额不足、无合法候选、失败或重复请求不扣款，也不消耗免费次数。

令n为本窗口已成功付费刷新的次数，下一次费用为：

`max(10, ceil((50 + 40 × n − 20 × 刷新爱好者等级) × (1 − 0.1 × 永久折扣等级)))` 矿。

无减价天赋时：建设首次免费，其后付费50、90、130、170矿……。从建设进入补给后继续使用同一付费阶梯，不重新从50矿开始。

## 6 界面 状态与后续验收

在现有发展与布置界面承载新规则，不在本次规格中另行批准整体视觉重做。前置提示展示名称、完成状态和所属方向；可购买卡片严格按当前方向过滤。折跃水晶建造卡明确标注“一次两座”，生产选择仅展示合法的狂热者／使徒选项。

同一窗口切换方向继续保留原选项，不能靠切换无限抽取。每窗口最多三项可购买候选、购买一项发展项目的规则保留。保存和恢复需保持解锁、成对设施、生产配置、支付账本及刷新计数一致，不能重送水晶或免费次数。

已有有效非连续解锁和已支付生产任务不因新顺序被撤销，不自动赠送缺失前置；新的未解锁项目按最终确认的前置检查。免费科研或其他合法解锁入口也须遵守相同资格规则，不能绕过新链。
