常用命令在根 README。不要默认运行 `npm run build`：其离线输出默认覆盖旧 Current 文件；本项目需显式设置 `SC2_DEMO_OUTPUT` 为新命名文件。`npm run build:web` 会重建 dist/web，运行前确认没有别的线程正在用它做同版验证。`tools/prepare-v04-application.mjs` 等是本批复现脚本，依赖指定输入和临时基线，不能在新克隆盲目当作通用发布命令。

## 保存与资源必须继承的约定

- D05 已替换旧“只在当前页面保留”的规则：初始及关间建立检查点，关间交易继续保存。关闭/刷新/崩溃后回最近成功检查点，当前关可能重打；实际战败仍按游戏规则结算。
- 账户、装备、待决奖励、购买及结算回执须一致保存，不重复发奖/复制物品。写入失败保留旧档并阻止继续出发；主档及两份备份、CAS 多页冲突保护保持。
- 新增 RunState 字段先在 `src/simulation/persistence/run-fields.ts` 明确保存还是重建；保留 Maps/Sets、共享身份、RNG 与已付订单，不能序列化 Three 对象和回调。
- 浏览器/来源之间存储隔离。迁移网址、浏览器或离线文件位置使用导出/导入，不承诺共享存档。不自动恢复旧开发版战斗或改变 schema 兼容范围。
- 原始资源、生成/提取的唯一美术源、真实用户存档保持。资源交付基于依赖闭包及内容 hash，发布只带应用需要的资源，不上传完整私有原始素材目录。
- `preview/` 混有实际原型源码和唯一原图，不能整目录清空。`assets/private/` 中有已跟踪历史文件，也不能只根据目录名推断 Git 状态。
- 可重建截图、视频、逐帧、日志、缓存及旧构建在对应工作结束后清理；保留简要结论和复现代码。当前交付与正在进行工作的必需输入保留，遵循 [保留规则](ARTIFACT_RETENTION.md)。
