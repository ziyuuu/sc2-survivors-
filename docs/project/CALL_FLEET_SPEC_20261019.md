# 谁在呼叫舰队：完整编码规格 R2

日期：2026-10-19。MVP 包 2。状态：READY（推荐编码基线，尚未实现／运行验收）。依据：[趣味原稿](RANDOM_EVENTS_ITEMS_CONCEPT_20261009.md)、[公共任务调度](ESCORT_WORKERS_SPEC_20261019.md)、[最新掉落规则](LOOT_ELITES_20261019.md)。R1 快照保留，农民修塔与一次性自动交舰方案撤回。

## 1. 用户决定与完整流程

用户确认：击败守军后点亮；点亮期间部队不能攻击 5 秒，受击不打断；8 塔后获得舰队光标技能，可呼叫 3 艘大和跟随部队协战，每艘 60 秒、技能 CD 5 分钟；每塔双精英＋混合小兵，守军不掉装备。所有任务不进入无尽。

沿上一轮提案：离开范围重置 5 秒；塔不可摧毁，不要求农民；首次技能立即可用、首舰实际入场开始冷却。第 10 关开放、半径、兵数、舰船属性等仍是推荐初值，不冒充用户逐项指定。

清掉当前塔全部专属守军→靠近连续停火 5 秒→点亮并开放下一塔→第 8 塔完成取得本局技能→主动选点呼叫。正常波次敌人不计入清塔要求，但可以在停火期间攻击玩家。

## 2. 准入、路线与接取

- 战役第 10—18 关，公共唯一槽、关初宽限 10 秒、每 15 秒 15% 抽签、任务终态 GCD30 秒。无需农民、设施或英雄席位。
- 本局已获舰队技能则本任务不再入池，不能重复解锁或重置技能 CD；其他任务仍正常出现。公共 GCD 与技能 CD 独立。
- 固定 8 座原 SensorTower，三族同一通讯设施。首塔距控制点地面路径 12—20 单位，邻塔路径 10—16、中心至少 6；碰撞半径 1.25。最多 32 组完整选址尝试，不堵必经路／主巢；失败不占槽。
- 整组塔同时出现，小地图显示顺序。塔全程不可攻击、没有 HP 或维修失败，不生产／扫描、不占设施名额；只有当前塔可激活，未来塔无守军，点亮进度永久保留。
- 原 SensorTower 在本地 UnitData 有定义，但运行时模型键仍需补原资源管线、预加载和视觉核验，不用任意建筑外形替代。
- 首塔启用即产生守军预警。首次正式队伍靠近当前塔外沿 6.5 单位且连通，或玩家归属攻击对其守军造成正伤害，即接取，不必等守军清光。
- 范围接取及激活要求控制点和至少一名活正式战斗队员均在同塔范围内、地面连通；临时兵／子机不能单独代办。未接取下一普通关失效，已接取跨关；没有总倒计时。

## 3. 每塔守军

| --- | --- | --- |
| 1—2 | 每塔 2 | 每塔 8 |
| 3—4 | 每塔 2 | 每塔 10 |
| 5—6 | 每塔 2 | 每塔 12 |

全程 16 精英＋92 普通，共 108 名。每塔一组、不周期补兵。该塔启用时固定兵种及当前难度／关卡／进度快照，旧兵不回填加强。

- 精英从当前已开放的现有敌方精英池取，优先不同类型，仅一种则允许重复。使用真实技能和最新精英生命／输出／护甲／技能上限。虫卵专属精英毒爆不自动加入本池。不消耗每关独立随机精英名额。
- 普通兵从当前最近已调度非空普通波成员顺序循环取足；无已调度波则用本关首个非空波。保留成员 density 和正常强度快照，不再把固定数量做一次 4∶4∶1 扩容，不扣原主波预算。
- 当前塔外沿 4—7 单位合法入口、0.5 秒预警、全任务每步最多 8 名，共用 300 上限与 Boss 预留，原主波优先。每塔固定有限队列，离开／暂停不重生。
- 清除要求所有成员已实际入场，且已死亡或经合法永久转化移出敌方；临时控制、隐藏、出视野、卡位和跨关清理不算清除。精英敌对战斗子代登记同塔，也须处理，纯表现不计。未来塔不提前投放。
- 守军正常攻击我方，不攻击塔。普通主波敌人不计任务清除条件；不得以塔附近暂时无敌人代替权威成员清除。
- 全守军及其衍生子代禁止装备和卡牌，覆盖精英保底、正常掉落和装备额外击杀奖励等旁路；创建时写权威来源标记。矿气沿守军表、原密度和精英资源倍率及地面气体规则，修正只应用一次。
- 未接取失效／整局取消清空未投放；在场敌人继续普通战斗或随整局正常退出。当前塔未清完绝不能点亮，因此不保留 R1 的点亮后守军余队方案。

## 4. 连续 5 秒停火激活

守军清除且正式队伍满足范围时自动开始，连续 300 个有效固定步（1/60 秒）点亮。无农民加速、维修费用或领奖按钮。

- 被打、掉血／盾不打断；治疗和护盾继续。离开范围、失去合法正式队员或连通性则计数归零，当步撤销停火；回来重新累计。
- 暂停／关间／特殊地图挂起冻结，不视为离开；恢复首步再检查真实位置。整局战败优先于点亮，临时兵不能替正式队伍保关。
- 停火覆盖正式小队、英雄、临时协战与召唤物：不启动普攻、伤害技能或新的进攻召唤，不提交新的攻击／即时伤害。开始时取消未提交蓄力；未提交技能不扣新费用和 CD。已发弹体、已生效持续区域正常完成，不吞掉旧伤害。
- 新的周期伤害／反伤也受统一门控；治疗、防护、移动允许。停火期间自动攻击或技能只保留一次就绪，不积累每个周期，解除后按正常频率执行，不瞬间补发多轮。
- 每步先处理已提交伤害与死亡，再查守军／范围，设置或撤销门控，然后处理新的攻击意图和激活累计。第 300 步点亮，本步仍停火，下一有效步解除并开放下一塔，避免最后一帧提前开火。
- 八塔纯激活共 40 秒，移动／战斗另计，不要求固定跨几关。每塔点亮只写一次收据。

## 5. 奖励：本局舰队光标技能

第 8 塔点亮时授予 fleetCall.unlocked=true，初始 CD=0，任务立即 succeeded；清理塔／雷达，释放任务槽，开始公共 GCD。此时不自动生成舰队，技能独立于任务生命周期保存。

- 主动按钮进入部署光标，点击／触控合法战场位置确认；Esc／右键／取消或无效位置不耗 CD。选点不同时下发移动指令。暂停／关间不可提交，进入菜单关闭光标。
- 落点在当前普通地图可见范围与地图边界内，能容纳 3 艘舰的合法空中位置；不穿场景实体、不跨特殊地图、不扩视野。确认前检查完整部署方案。
- 首舰在下一有效步于光标附近入场，第二／第三舰分别在前舰实际入场后 0.75 秒入场。落点被占用时只在原区域重新寻找合法点，排队舰不跟随玩家把落点移到远处。
- 首舰实际创建成功才扣 18000 有效步 CD（300 秒）。之前失败不扣；部分创建失败保留同次部署计划重试剩余舰，不重复创建已交付舰。部署中不可再次点击呼叫。
- 每舰独立收据；实际到队即视为交付，随后阵亡不补舰、不退 CD。每舰入场后立刻跟随队伍，60 秒寿命按各自实际入场起算。
- CD 从首舰入场起计，不是舰队结束后再加 5 分钟；首舰正常退出后约 240 秒再可用。CD 到零且无待部署舰即可再次呼叫 3 艘，本局不限总使用次数。
- 普通跨关保留解锁／CD／部署计划／舰队，关间／暂停／特殊地图挂起冻结 CD、入场间隔、舰队寿命与技能时间。战役结束、转无尽、撤离／战败清理本技能与舰队，不能把战役任务收益迁入无尽。

## 6. 舰队属性与战斗

沿 R1 推荐基础，未完成平衡验收：读取 SC2_UNITS.yamato_battlecruiser 的 rank1 身体，当前 1100 HP、甲4、攻击40、周期0.65秒、双炮、射程8、速度2.62、飞行与正常地空资格。不是 HEROES 的 22000 HP／660攻击英雄体，双炮不能再重复乘一次。

任务自动大和炮推荐每15秒一次，入场3秒首次就绪；射程11、蓄能1.25秒、提交后飞行0.25秒、单体基础300伤害，走真实伤害。优先范围内 Boss／精英，其次普通敌人，同级按最大生命降序／ID升序；无目标保持一次就绪。提交前源死或目标失效取消并进入本次CD，提交后沿原弹体命中／目标丢失规则收尾。

大和跟随小队自动战斗，不驻守光标，不提供独立手动技能，不占英雄三席／家族槽／生产订单，不登记 heroes Map，不触发同名晋升、光环、融合、永久成长或异族生产。固定任务属性不继承永久装备／天赋，正常合法治疗与战斗状态可生效。不能单独满足正式队伍存活，不复活／保险／继承，不伪装装备来源。

每舰实际入场起 3600 有效步；死亡不补舰，寿命到撤离，不走正式成员阵亡或击杀收益。取消未提交攻击，已提交攻击正常收尾。舰队击杀按敌人真实掉落资格处理，不冒充正式成员培养或递归任务。装备来源大和与本技能身份、收据、时长独立。

## 7. 数据与接点

```ts
type CallFleetTask = {
 id:string; state:'offered'|'active'|'succeeded'|'expired'|'cancelled';
 currentIndex:number; towerIds:number[]; litIds:number[];
 guardPlans:TowerGuardPlan[]; activationTicks:number; endReceipt:string|null;
};
type FleetCallState = {
 unlocked:boolean; unlockReceipt:string|null; cooldownTicks:number;
 castSerial:number; pendingDeployment:FleetDeployment|null;
};
type TaskFleetShip = {
 entityId:number; castId:string; ordinal:0|1|2;
 remainingTicks:number; yamatoReadyTick:number;
 pendingCast:TaskYamatoCast|null; deliveryReceipt:string;
};
```

TowerGuardPlan 固定成员／子代关联、强度、投放游标与清除收据；FleetDeployment 固定落点、三舰子收据和下一入场余步。光标仅 UI 暂态，不能以光标开启视为冷却开始。

- 范围／暂停校验可共享已有任务模块，删除农民速率和塔伤害入口；塔不能进主巢／扩张巢集合。
- 攻击、技能、周期效果、反击与召唤共用停火资格；模拟独立验证，不能只禁 UI，也不能暂停敌人／World 代替玩家停火。
- 现有敌人创建、精英技能、300容量复用，任务来源掉落禁用贯穿直接和额外奖励；不能改成普通身份规避精英掉装。
- 大和基础身体与原炮口／蓄能／弹体／命中资源复用；不调用 acquireHero 或填 heroId 借整套英雄机制。starship/advanced-support.ts 的装备临时实体关末清理不管理任务舰，另建跨关生命周期。
- 技能按钮复用现有战场目标选择输入并添加取消和禁用状态。解锁收据 runId:taskId:fleetUnlock，呼叫 runId:fleetCall:castSerial，每舰附 ordinal。先合法计划后提交；World.atomicMutation 没有回滚能力，部分失败用原计划分舰幂等重试。
- prepareStage／nextStage／挂起／终局同时管理守军、激活门控、技能与舰队；WebGL 只恢复表现。存档仍延期至 MVP 收尾。
