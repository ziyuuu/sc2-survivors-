## 已实现的规则

### 孤星猎手

已吸收的午夜死神、大枪管可以再次获取；仍检查同族、编制、待交付身份与付费/领取回执。孤星本体到V级后正常退出升级池，不无限刷新同一本体。

原始吸收记录保留贡献值、付款、实体身份和出生时间。有效成长为原累计值加上已吸收精英的原贡献，即普通贡献不变、精英贡献翻倍。旧局按原回执补算，不重复生成身体或奖励。读档后重算孤星属性并保持受伤比例；进入与返回特殊关时携带对应吸收记录。

设有效成长为G，属性在该军衔基础值上计算，再进入原装备和全军强化流程：

| 属性 | 本批公式 |
| --- | --- |
| 伤害 | `1 + 3G/(G+20) + 0.01G` |
| 生命 | `1 + 4G/(G+20) + 0.01G` |
| 攻击频率 | `1 + min(1, 0.005G)`，最高额外100% |
| 移速 | `1 + min(0.35, 0.0015G)`，最高额外35% |
| 额外护甲 | `10G/(G+20)` |

普通I级死神1点，军衔折算保持；精英在原折算后加倍。持续伤害/生命成长不以攻速、移速封顶而停止。吸收不继承其他精英技能，死神家族仍只保留孤星永久身体，其他兵种与英雄保持。

现有卡面、精英选择和详情更新收益与代价；简略层保留用途，详情保留数值/上限。孤星详情绕过通用一位小数格式化，准确显示`0.15%`，没有改布局或增加入口。

### 无尽

伤害改为累计战斗分钟x的连续式`1.10^min(x,5) × 1.16^max(0,x−5)`。生命仍`1.22^x`，攻速仍`min(1.25,1.025^x)`，护甲、数量、出生时刻与四难度基础差异保持。第16轮开场普攻DPS约为无尽开场8.88倍，第24轮约29.12倍；这不是实测存活率。

四难度在1/6/12/16/24轮检查普通敌人、首领和技能系数；另用实际酸液落点与虫后持续腐蚀结算核对伤害只乘一次。固定值、百分比或本身不引用无尽伤害系数的机制没有顺带改写。

### 掉落与旧奖励

自然敌人改为一次数量判定，成功后在同一件里决定品质。普通怪概率为简单0.35%、普通0.18%、困难0.12%、地狱0.10%；精英分别30%/16%/16%/16%；战役首领1件，无尽首领35%掉1件。高难度无尽的额外层成为同一件的品质升级分支，不另发一件、不降低已抽中的品质。

| 特殊来源 | 新生成计划的规则 |
| --- | --- |
| 黄金工蜂 | 简单首次/第二次/之后4/2/1件；其他难度8/4/2件。重复次数按本局成功发出过装备的黄金事件计算，使用已保存回执；只出现而未发奖不计次。 |
| 采集关 | 简单5件，其他7件；两个高级箱简单各1件、其他各2件。 |
| 虫巢任务 | 首个巢1件，全部完成50%再给1件；生成任务时冻结物品与完成奖励抽样。 |
| 白色虫群 | 累计第3、6只各1件，共2件。 |
| 感染陆战队 | 累计第3、6、10名各1件，共3件；治疗、死亡共用对象去重。 |
| 竞技场 | 每击败5只精英1件，每个首领1件；三个战役段分别合计2/3/4件。 |
| 巨型蟑螂 | 成熟档决定1–2件，每份不再叠加自然掉落层。 |
| 横穿虫群 | 保留3件动力槽奖励。 |
| 情报、残暴虫后、堕落神族等 | 保留对应有条件的单件奖励。 |
| 非装备玩法 | 保留原军衔、单位、矿气等收益，不额外补发装备。 |

简单品质使用批准的分段权重；高级箱和黄金高奖位置按60/40或60/38/2抽样，不再直接取池中最高品质。最终战役首领至少绿色。拾取的相对掉率、品质增益和掠夺的明确额外奖励继续生效，并进入总量统计。

旧存档中已存在的黄金/任务等物品计划直接交付，不重新抽数量/品质；旧白群与感染事件缺少新节点标记时沿用原逐体计划，旧虫巢任务缺少冻结计划时沿用原逐巢合同。新计划、里程碑回执及派生缓存的保存/重建归属已写入`run-fields.ts`。旧局可能同时包含两套时期的奖励承诺，不能拿混合规则总数与新局样本直接比较。

## 全来源有限重放

终点是**战役18关＋打完无尽16轮**，不是刚进入第16轮。16个固定种子×4难度×5种参与/装备配置，共320次；使用原生出生计划、事件准入、冷却/反重复、任务计时、特殊关资格、奖励和装备账户。所有新增装备先记生成账，再记拾取、销毁和带出；带入模块不计新掉落。

覆盖主波、自然精英/首领、救援守军、主/扩张虫巢守军、任务及增兵、随机遭遇、替代虫群、诱饵、酒馆、四类特殊关、掉落模块与掠夺。320次均满足：来源之和＝生成总量＝本样本拾取量；带出＋销毁＋分解＋丢失＝拾取。满包时脚本销毁最低品质物品后继续拾取，故不能把最多64格的最终背包当总产出。

**这是有明确假设的机会/结算回放，不是自然游玩或真人平均值。** 未模拟战斗承伤、移动耗时或实际养成成本；额外内容可瞬时接近，首领/虫巢按约定完成。仅固定人族4陆战队＋医疗运输机阵容。参与虫后按成功取得300次合格主力击杀处理；地狱无尽巢只打首批，不无限刷巢。种族/阵容资格与真实完成率仍有限制。

### 未关闭的平衡取舍

1. 简单/普通中等参与均值略超过候选常见区间，完成率和养成成本尚无玩家样本校准。
