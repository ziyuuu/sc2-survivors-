## 统一方向

纳米使用青绿、银白、颗粒和贴体网格；幽能使用炭黑、深靛紫、暗核裂隙、断续残影和向内塌缩；常规机械武器使用橙黄枪焰和实体弹芯。高达以蓝白红机械装甲配明亮粉红光剑。颜色、形状与动作共同区分。普通镜头下能从机体、发射、命中至少两个阶段辨认特殊牌。

当前缺口：B04 主要改变移动占位，没有对应机身表现；G02 走通用护盾受击；N01/N02 已有结算但缺独立的装弹／命中语言；O02 与 O03 都用 1.65 倍视觉缩放，高达没有独立蓝白红分区材质或光剑攻击。纳米／幽能改造沿现有伤害和触发条件；高达光剑属于用户新提出的战斗能力，须按下文单独接入和验证，不能当作单纯换色处理。

## 纳米：可见的组装、修补和附着

| 卡牌 | 新表现 |
| --- | --- |
| G02 纳米护盾 | 受击位置浮出一块青白六角盾片，冲击沿相邻网格扩散；破盾时碎成向外散开的细方片。回盾时颗粒从机身向缺口聚合，满盾后收起。避免常驻大光球。 |
| B01 纳米护甲 | 机体明显紧凑，银灰装甲表面出现局部青绿拼接纹；取得时从脚部向上扫过一次网格并完成收缩。受击处短暂显露紧密蜂窝，不表现成另一层可吸收伤害的盾。 |
| N01 纳米体系 | 有效维修流由离散粒子组成，真实获得的 3 秒护甲加固在伤处形成一块临时密集网格；真实装弹时粒子沿机身汇到枪口，留一枚青白亮点。带弹原轮附断续颗粒尾迹，有效命中并附上 DOT 后，目标出现三处小光点；三次真实 DOT 各亮一次并逐个消失。复选实际装给两人时，分别出现两条粒子流。 |

纳米攻击识别点是“颗粒弹芯→附着→三次脉冲”。B01、G02 本身不改变攻击性质，不凭护甲牌让全体普攻自动带纳米伤害外观。

纳米的颗粒采用有方向的碎片簇，普通镜头下先读到整束运动，再看到细颗粒。维修簇向伤处收拢，弹药簇向炮口聚合，伤害簇留在敌人身上。弹药按真实有效命中消耗；落空不熄灭待用标记。同源 DOT 刷新只更新当前剩余脉冲，不在目标上叠出第二套三点；目标死亡或离场时立即收掉。护盾回充与生命维修分别读取真实增量，不能互相冒充。

## 幽能：暗核、裂隙与相位机体

主体以近黑炭色、深靛紫和低饱和暗紫为主。装甲继续保留金属反光和明暗分面，暗效果边缘留细窄的灰紫轮廓以适应深色地面。R1 的白热核心、明亮紫球和大面积发光撤销；只在命中瞬间允许一小段灰紫刃缘闪亮，随后迅速收暗。

| 卡牌 | 新表现 |
| --- | --- |
| B04 幽能护甲 | 装甲偏炭黑和深靛，接缝保留细窄暗紫边缘。移动时在原轮廓后留下两段短促、断续的黑紫残影，狭窄处呈现机身边缘折叠后复原；停稳后收起，只留局部接缝。完整机体仍清楚可见，不表示传送、无敌或真正隐形。 |
| N02 幽能怒火 | 枪弹为黑紫短矛配细灰紫刃缘；炮弹为暗核配不闭合的深紫弧；喷焰为黑紫火舌配断续裂缝。命中当刻先出现局部暗色裂口，碎影向裂口收拢并塌缩，随后留一瞬沿真实伤害区散开的细裂纹。真实群伤才扩到周围，画面不铺满烟雾或黑幕。 |
| N02 复选 | 下一次实际强化原轮，暗核更凝实，出现两道错开的裂隙边缘，命中收束更锐利；用形状和紧缩动作体现强化，保持暗色基调。结算后恢复普通幽能版本，不加虚假额外弹数。 |

只有 B04 时呈现相位移动；取得 N02 后才出现幽能武器。同持纳米与幽能时，保留纳米装甲的拼接结构，底色压成深钢灰，配少量青绿节点与暗紫接缝；弹体以幽能暗核为主，只有真正装入纳米弹的那一发附带青绿颗粒，目标上的三次纳米脉冲独立可辨。

幽能的主要识别形状是“暗核、裂隙、向内塌缩”，纳米则是“片状颗粒、拼接面、向外分散／向伤处补合”。B04 相位残影只保留短轮廓片，不复制完整半透明模型；两段残影沿实际移动路径淡出，停下即收起。视觉收束发生在命中反馈内部，不延后真实伤害；不增加额外蓄力步骤。亮地面主要读暗核，暗地面主要读细轮廓和运动，验收时同时覆盖两种地面。

## 高达与体型

高达改为蓝白红清晰分区：白色覆盖头部、前臂、腿甲与肩甲主体；蓝色覆盖胸部、背包和肩部外壳；红色集中在腰甲、脚部与少量关节护板；关节内构用深灰。建议可见面积约白 55%／蓝 25%／红 15%／深灰 5%，以实际材质分区为准。保留金属明暗、法线、污损和原模型纹理，发光只给传感器、反应堆、炮口与剑刃。整机沿雷神底盘改装，光剑及新增挥剑动作属于本项目新增设计。

| 机体 | 建议视觉比例／区别 |
| --- | --- |
| 高达 | 相对普通雷神 2.15 倍，比当前 1.65 再增大约 30%；白色四肢、蓝色胸肩、红色腰脚。 |
| 绝望堡垒 | 相对普通坦克 1.85 倍，深铁灰主装甲、橙红炮膛，突出低矮宽重。 |
| 纳米普通机体 | 同身份普通模型的 0.82 倍，当前为 0.92；缩小后仍保持轮廓可读。 |
| W02 恶火 | I／II／III 档分别 1.10／1.18／1.25 倍，让车体与加宽火面同时可辨。 |
| 英雄机甲 | 保持当前约普通雷神 1.50 倍与五位驾驶员配色，蓝白红巨型高达形成更高一档轮廓。 |

以上都是表现比例建议，比例按同镜头下同身份无改装模型的最终显示尺寸比较；移动占位、受击尺寸和原远程武器射程保持当前规则，光剑单独使用拟新增的近战判定。巨械最终尺寸单独确定，取得纳米护甲后用装甲网格表达，避免乘法叠加把高达缩回普通机体。精英仍保留自身身份与原型。高达的蓝白红分区优先，纳米只叠局部网格、幽能只叠暗色接缝与残影，不能把整机改染成绿／紫／黑。

高达的三种火力分开：四枚弹幕用清晰的白色弹芯与青蓝推进尾迹；每第三轮的重炮出现短促炮口压缩光与橙白重爆；第三炮后的小核使用明显更粗的单枚载体、白热中心与短环状冲击。发射和命中仍沿当前真实时刻，不新增蓄力等待。步行仅在脚掌实际落地时给短尘浪。

## 高达光剑：近身切斩，远处继续炮击

用户已经明确要求加入光剑近战。以下给出一套完整接入建议供审阅，优先保留当前高达的大循环与原控制方式。

**武器与动作。** 右侧可动臂增加有实体剑柄的长光剑，剑芯近白、刃缘粉红，停用时剑刃收回；长度按实机近战范围校准。出剑时有清楚的抬臂与点亮，攻击按两轮交替采用横斩与反手斜斩，肩部、躯干、持剑臂共同转动，脚部有稳定重心。轨迹从剑刃真实运动采样，刀光短暂保留，接触处出现窄切口和定向火花。动作需要有起势、切过和回收，不能仅在仍用原开炮姿势的雷神前方画一个圆弧。

**建议规则。**

| 项目 | 首版建议，尚未写入正式配置 |
| --- | --- |
| 切换条件 | 每轮开始时，当前合法主目标是地面敌人且双方受击边缘距离不超过 2.5 码，则本轮用光剑；否则本轮用弹幕。选择在轮内冻结，不随距离来回切换，也不在挥空后改成远程补射。 |
| 移动与索敌 | 沿原移动指令与合法目标选择，不自动冲锋、跳跃或离队追砍。攻击起势后方向冻结，命中帧重查实际位置、目标层和地形；挥空不补射。 |
| 攻击形状 | 前方 120°、最大边缘距离 2.5 码的地面扇形。横斩与斜斩共用此判定，每个合法目标每刀只结算一次；刀光和接触位置要与该范围匹配。 |
| 伤害预算 | 一刀替换该轮四枚主弹幕，单目标普通伤害预算取这四枚合计；当轮不再补发被替换的四枚。近战改为一次命中、可覆盖多个目标，护甲与群体收益会变化，因此不能声称最终 DPS 或强度保持不变。具体近战平衡由同靶／密群实测后讨论。 |
| 大循环 | 一刀算一次主武器轮，与远程主轮共用节拍和累计计数；每第三轮接一次独立重炮，第三次重炮接小核。切换距离不重置或额外推进计数，肩背火力与手臂挥剑在动作上分开。 |
| 联发及其他牌 | B03 的真实追加段在近战模式对应较短的回斩，各仍为原轮预算的 20%，不多推进重炮／小核计数。适用于主武器命中的纳米、幽能、电容等沿原轮唯一触发；仅适用于枪弹的 W01／G01、远程首射类效果不因光剑外观而错误套用。具体受益清单随实现同步代码规格。 |
| 生命周期 | 挥剑起势、计划命中步、方向、轮号、已命中集合／结算状态随检查点保存；伤害由模拟层驱动。死亡取消尚未结算的挥剑，已发炮弹按现规则继续；暂停、恢复和重复事件均不重复砍击。 |

**资源核对。** 现有核验支持雷神底盘、炮口挂点、走路与开炮表现，尚没有雷神专用挥剑动作的来源证据。新增剑柄／剑刃和可动臂动作需明确标注为本项目制作，先核对骨架挂点与关节能否形成合格动作，必要时制作专用改装臂及动作。该缺口属于本次实现工作，不能用一条悬空激光或炮口刀光宣称已交付光剑近战；也不把新制作资源称作 SC2 原版光剑。

**对应卡面。** O02 简要拟改为“巨型高达以弹幕、重炮和小核交战，近身挥动光剑。”；详情补充近身切换、真实命中范围、预算替换和循环计数规则。沿现有简要／详细切换呈现，不新增操作按钮。

**实机验收。** 正常镜头看清蓝白红分区、完整剑刃和持剑动作；近敌进入／退出、远近交替、地空换靶、斩到多敌、挥空、联发回斩、死亡取消、命中前后恢复分别核对。九轮远程对照继续是九组弹幕；九轮纯近身对照应是九次主斩，两者均有三次重炮、一枚小核，不额外增加一套主攻击。

## 叠加与普通镜头的可读性

- 用弹体形状保持攻击身份：贯穿仍是直线，连发仍按真实段数，子母弹仍先母后子，范围炮仍以真实爆区为底。幽能／纳米附着在这些形状上，不能把所有武器都替成同一束光。
- 同一命中先保留主攻击的核心与轮廓，再出现专属附加反馈；幽能使用暗核与细边，不恢复为明亮爆球。纳米 DOT 的三次脉冲按自己的结算时刻显示；电容跳击、冷焰补炮和共振爆线各保留来源、方向与落点。
- 持有 N01 的常驻纳米弹只在真实装弹到消耗这段时间显示；拥有 N02 的幽能主武器持续生效，复选只增强那次实际兑现的原轮。这样能从画面区分“已有一发待用”和“常驻武器强化”。
- 高达弹幕亮核短、尾迹窄，堡垒逐排亮核快速退去、尘浪低矮；重叠时仍应看到敌我轮廓与后续落点。单次普通命中反馈初稿控制在约 0.15–0.35 秒，实际存续状态则按规则寿命显示。这些是后续调表现的起始值，不是已实测结论。

## 落地与审阅顺序

先做 G02／B01／B04／N01／N02／O02 六项同镜头对照，包含纳米与暗色幽能叠加、蓝白红高达的远近战切换，再铺开其余攻击。具体影响为正式战场机体材质／大小／攻击／受击表现、光剑近战执行器与现有逐卡展示。若采用 B01 的新视觉比例，现有卡牌详情“机体和地面移动占位缩小 8%”需同步拆开，拟改为“普通机械体型缩小 18%，地面移动占位缩小 8%；巨械保持专属体型。生命 +20%、护甲 +2。换装保留已有伤势。”，数值仍从正式配置读取；O02 卡牌两层文案按上节补光剑规则。商店卡槽、卡面布局、HUD 与镜头不在本次变化范围。所有新效果沿实际事件与已保存状态重建，视觉随机独立于战斗 RNG。

复用已核实的模型、火焰、炮击和核爆底层；纳米网格／颗粒、相位残影、幽能内爆以及新增光剑／动作属于本项目新设计，不能声称是原版专属效果。普通镜头下可辨别、组合不遮挡、换场无残留是表现验收条件；既有纳米／幽能结算保持，新增光剑单独验伤害、受益牌和恢复。新增透明层、粒子与动作开销实测后记录，不承诺尚未验证的性能。

R1 完成过 45 个卡号覆盖检查及 `npm run docs:check`；R2 在同一稿落实用户暗色幽能、蓝白红和光剑方向，并给出新的近战接入建议。未改游戏源码、未重建候选、未运行新的游戏测试或宣称画面通过；用户指定的方向与尚待审阅的具体规则已分开记录。落实时首批仍用现有正式场景，在同镜头下比较基础／纳米／暗色幽能／两者叠加，以及普通雷神／英雄装甲／蓝白红光剑高达。
