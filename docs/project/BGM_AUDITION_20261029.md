## 来源与使用边界

- 原作：Antonín Dvořák，Op.95，1893年作曲、1894年Simrock初版；作品与乐章事实见[德沃夏克作品资料](https://www.antonin-dvorak.cz/en/work/symphony-no-9/)。
- Largo 旋律实读 Rochester/Sibley 保存的1902年Simrock小提琴分谱，第2页；馆方将该项标注为公版。该旧编配署名 Leo Schrattenholz，版号11698。[馆藏记录](https://urresearch.rochester.edu/institutionalPublicationPublicView.action?institutionalItemId=16433)。仅摘取主题音符，伴奏、配器与节奏底层另行编写。
- 第四乐章旋律实读 Kennesaw State University 公开试奏资料的第4页，原始E调小号主题，转为实际音高；只读取德沃夏克主题，不重用学校文字、版式或文件内其他作品。[分谱节选](https://campus.kennesaw.edu/colleges-departments/arts/academics/music/docs/ensemble-audtions/f26-orchestra-trumpet.pdf)。
- [IMSLP原版目录](https://imslp.org/wiki/Symphony_No.9,_Op.95_(Dvo%C5%99%C3%A1k,_Anton%C3%ADn))将1894年初版总谱/分谱、版号10139/10140标为公版；本批只据其核对版本。直接PDF下载返回验证页，没有把验证页当曲谱使用。
- 所有声音由本地振荡器合成；未使用第三方唱片、采样库、SoundFont或现代MIDI。此次没有导入、上传项目私有素材。
- 公版作品与具体录音分别判断，不能将“古典作品”或“免费下载”直接等同于某张唱片或现代电子改编可自由使用。[美国版权局的作品/录音区分](https://www.copyright.gov/engage/musicians/)。本批不声称已逐一核验所有司法辖区，也不将新合成音频冒称历史公版录音。
- Mutopia对应现代转谱采用CC BY-SA 3.0，本批仅查到许可，未下载或使用其转谱/MIDI；因此不依赖该现代转谱来制作试听。

具体旋律、改编范围、来源链接及读过的PDF SHA256保存在 `preview/bgm-audition-20261029/arrangements.json`。这些小样是新制作的主题改编，保留作曲者、旧谱与本项目制作记录。
