# 微信小游戏适配研究与工程基线

状态：工程适配进行中；不改变 M0 r6 的三族、18 关、天赋或战斗数值。目标是保留原版 3D 模型和同一套 `World` 模拟，不能把诊断画面当作正式游戏。

## 已核实的平台边界

- 微信小游戏使用 `game.js`／`game.json` 和画布，不运行本项目的 HTML、DOM 菜单或 IndexedDB。原 UI、存档后端与资源 URL 必须抽成平台层。
- [Cocos Creator 的微信小游戏分包文档](https://docs.cocos.com/creator/3.8/manual/zh/editor/publish/subpackage.html)列出主包 4 MB、全部分包 30 MB 的限制。当前工程以主包小于 4 MiB 为保守构建门槛；最终可上传大小须以实际微信开发者工具和账号当时的规则核实。现有正式单 HTML 为 332.75 MiB，Web 目录资源原始闭包约 426 MiB，不能整体放进代码包。
- 远程下载资源需要使用微信小游戏后台认可的 HTTPS 合法域名；本机 IP、`localhost` 和任意未登记域名不能作为正式资源源。资源从发布时绑定的只读 CDN 按 ID／哈希下载到用户目录，缺失时停在加载页。域名登记和下载能力须在目标 AppID 下验证。
- 160 MiB 是**本项目自定的活动缓存预算**，并非已核实的微信小游戏文件配额。实际可用持久空间、单文件与内存限制须在开发者工具及目标真机上测量。完整发行资源约 426 MiB，因此不能在首次启动下载全部 751 项；存档目录独立，缓存淘汰绝不删除存档。
- 微信团队的[Three.js 小程序适配库](https://github.com/wechat-miniprogram/threejs-miniprogram)仍声明基于 r108，而本项目锁定 r186；不能直接替换并声称兼容。需要在真实小游戏画布上验证 WebGL2、纹理数组、骨骼动画、GLB／WebP 解码、音效和上下文恢复。
- 调研了现代第三方 Three 平台适配器；当前包元数据为 `Commercial License (Non-transferable, for use by authorized users only)`，未取得使用授权前不将其装入发行工程。开放源码旧移植的版本与当前 r186 不匹配，因此先建立本项目专用、可测试的微信平台桥。
- 此机器尚未发现微信开发者工具，也没有小游戏 AppID、已登记下载域名和真机测试环境。代码／资源构建可以本地验证；微信端运行、上传和真机帧率不能由浏览器测试代替。

## 单一玩法、两套宿主

`World`、固定 60 Hz、战役与无尽配置、卡牌、建筑、英雄和天赋保持共用。小游戏平台层只提供：画布／触控／可视生命周期；远程资源准备；原子存档文件；针对小游戏画布的 3D 渲染与非 DOM 的 UI。原浏览器版本继续使用现有 DOM HUD、IndexedDB 和 Web 资源。

资源发布路径为：`reports/local/asset-reachability.json` 锁定的 751 个 ID → `tools/build-wechat-assets.mjs` 校验源文件字节与 SHA-256 → 生成只读清单。主包只放代码和启动必需的极少资源；所有原 3D 主体、地图贴图、声音和后期精英按阶段下载。缓存的逻辑 key 是 ID＋SHA-256；下载只写临时文件，校验后才改索引。转场准备期间同时保护旧战场与新战场的资源，提交转场后再缩小活动集；两场工作集放不进预算时停在选择页并报告，不能先删除旧战场。任何资源失败均不启动或续跑模拟。

存档沿用 `writeArchive`／`readArchive` 的规则及校验，由微信文件系统在用户目录保存一个带两份备份的容器。先写临时文件，再原子替换；在隐藏／切后台时先暂停，保存成功后才显示已保存。读取失败只尝试备份，不改变内存中的 `World`。

## 工程门槛

1. 构建主包不超过平台上限，资源清单逐 ID 对应本地 Web 发行闭包且有哈希；无 CDN 配置时构建可做本地检查，但小游戏不应假装资源已就绪。
2. 在微信开发者工具和 Android／iOS 真机上，三个种族均能从选择、加载、战斗、关间、存读走到完整 18 关与无尽；模型、技能、输入与声音按原版验收。
3. 对比相同种子与输入的 `World` 快照，小游戏／Web 不得出现战斗、经济或奖励分歧；切后台、下载失败和读档不能推进固定步。
4. 测量真机前六关、后期与无尽的帧时、模拟积债、内存和下载量；沿用 M6 的自然游玩与高压夹具分开报告。

当前实现是平台工程基线，不是已经通过上述门槛的微信小游戏正式版。不能在未经模型与真机验证时把该任务或 M7 标记完成。

## 当前本地工程证据

- 已建立微信资源清单生成器、逐文件 SHA-256 下载校验、160 MiB 活动缓存预算、共享档案格式的微信文件存档后端、复用 `World` 与原地图的小游戏会话，以及可导入微信开发者工具的 WebGL2 预检包。
- 本地自动测试含真实地图上的虫族／困难开局、60 固定步、切后台保存和按档内难度暂停续局；亦覆盖损坏下载、缓存回收、两份备份。
- 全项目类型检查、460 项测试、数据文档检查和 Web 目录构建已通过；Web 目录在浏览器的虫族／困难读档烟测通过。以上均不等于微信开发者工具或真机验收。
