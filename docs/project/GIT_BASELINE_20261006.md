## 新检出后的开发与验证

```sh
git lfs pull
npm ci --ignore-scripts
npm run assets:restore
npm test
npm run typecheck
npm run docs:check
npm run dev
```

恢复脚本先校验全部资源，再恢复缺失的 `public/assets` 文件和生成的运行资源目录。已有不同字节的文件会被拒绝覆盖。恢复依据是 `deploy/runtime/source-assets.json`，不依赖 `.cache`、旧 HTML 或另一台机器的资源缓存；不转换、压缩或替换模型与纹理。原始素材的转换仍使用原素材管线。

GitHub 的 Simulation and web build 工作流在 main、codex 分支及 PR 上运行 LFS 检出、资源恢复、测试、类型检查、数据文档校验和 Vite 编译。它不发布网站。
