小地图只在没有加载/菜单/暂停/决策覆盖层的战斗中显示。标题、新局选择、天赋、读档、加载、关间发展/商店及结束界面隐藏，不为地图预留空白。战斗内地图保持左上、北向，收起后保留44px按钮；地图按钮的键盘空格/回车只切换折叠，不触发推进或战斗技能。

队伍默认展开，收起后保留恢复入口、三个英雄技能和普通指令。两组指令都有可用的横向滚动空间，放大文字时仍可访问。队伍恢复时保留原分页、查看对象与详情开合状态。查看/折叠不改变单位命令、伤损、武器、技能冷却、资源、随机商品或付款账本。

两个偏好存放于独立`sc2.hud.v1`，跨关间、标题、新局、旋转和页面刷新保持；不写战局、永久档案或资源缓存。没有可用存储时保留当页偏好，仍可正常操作。控制设置的`sc2.controls.v1`保留。

有效视口的宽、高、左/上偏移共同决定`#game-root`。背景覆盖整个游戏容器，界面内容避开安全区；菜单不继承战斗的顶部预留。响应布局和全队分页都依据该容器的实际尺寸。画布、单位/载体血条、拾取、小地图、相机与摇杆使用同一容器边界；控制台实际高度变化后重新测量画布与相机。

旋转、浏览器可见区域变化和全屏变化清理旧触点、拖动及输入墙钟基准，保留游戏暂停状态。持续变化合并到一帧，旋转/全屏另外复核稳定尺寸；视口平移也更新原点。布局不会自动执行移动、攻击、换兵或重新生成商品。

商店钱包独占顶部区域，标题、滚动商品/详情/整备与底部刷新/继续各自占位。品质编号、图标/名称、说明、价格及拥有状态使用独立网格行。短横屏内容可以滚动，底部操作区持续可达；展开详情不会盖住继续。正文16px、详情14px、标记12px，随文字设置放大，交互控件至少44px。商品摘要仅规范浮点数显示，实际价格、付款和效果不变。
