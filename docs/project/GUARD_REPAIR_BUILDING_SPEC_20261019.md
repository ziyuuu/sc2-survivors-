# 守卫并修复废弃建筑：完整编码规格 R3

日期：2026-10-19。MVP 包 2。状态：READY（规则与接入契约已整理，尚未实现或运行验收）。关联：[护送及公共调度](ESCORT_WORKERS_SPEC_20261019.md)、[趣味原稿](RANDOM_EVENTS_ITEMS_CONCEPT_20261009.md)、[虫族发展规则](ZERG_DEVELOPMENT_FLOW_SPEC_20261012.md)、[建筑规则定案](MVP1_BUILDING_RULES_DECISIONS_20261013.md)。

## 1. 最新决定与被替换的旧提案

用户明确：现有场上敌军优先攻击修复建筑；必须已有农民才允许生成任务；额外刷新两个波次，数量及组成按当前敌人波次，不固定小狗／毒爆数量；采用预留设施名额、成功后模型消失而生产设施保留；最新决定覆盖此前九种建筑要求：虫族统一使用孵化场，收益固定增加一座，不区分虫穴／主巢或进化方向。人族为兵营、重工厂、星港，神族为传送门、机械台、星门，共七种任务建筑，逐种使用正确原版外形。两波分别在启动守卫、首次修至 62.5% 耐久时触发，已确认。

R1 的“零农民也可生成”“每 6 秒固定 8 小狗＋2 毒爆”“普通波次不攻击建筑”“小狗／毒爆按建筑最大耐久百分比独立伤害”全部撤回。不能同时执行新旧压力系统。护送农民的专属 30/10 波次和 2/8 独立伤害保持，仅属于护送。

公共规则继续使用：战役第 4 关起，任务共用一个槽，未接取也占位，按 15 秒／15% 触发，结束后 30 秒 GCD；无尽不接入任务、不接续未完成任务。存档继续延期。

## 2. 完整玩法循环

1. 无任务、GCD 已结束且 workers≥1 时，检查本族合法设施与剩余容量，找到合法落点后才进入抽签池。
2. 生成一座 25% 耐久的废弃建筑，固定本次身份，预留一个真实生产设施名额，小地图出现雷达。待接取阶段受保护，不被攻击、不自然回血。
3. 玩家部队靠近建筑自动启动。范围内按已营救农民数修复，同时场上敌军将它作为优先目标；任务额外增加两波当前战役类型的敌人。
4. 离开停止修复，不重置 HP；敌军继续进攻。已启动跨普通关继续，关间与暂停冻结。
5. HP 归零失败；满耐久进入结算。成功授予真实生产设施、不送实际士兵或额外矿气。
6. 成功后播放工作反馈，1 秒后原场景模型及碰撞消失，已授予生产设施持续本局。任务结束清除建筑优先索敌规则，取消未入场增援，存活敌人正常攻击我方。

“场上士兵优先攻击”按语境理解为场上敌军，己方不会攻击正在修复的友方建筑。

### 资格与容量

- 每局只抽本族：人族三种、虫族一种、神族三种。合法类型等权，奖励身份在生成时固定；成对折跃水晶不纳入本任务。
- 人族／神族沿用现有设施前置、每类上限 5；虫族沿用孵化场总上限 15。
- 虫族只检查普通孵化场的合法获得资格与剩余容量，不增加地面／天空方向前置。
- 新孵化场通过共享初始化获得独立身份、基础生产选项，继承既有全局基础物种资格；方向为空，未解锁的物种不因任务解锁。其他已拥有孵化场、方向、配置及订单不改变。

## 4. 修复参数与移动范围

| 项目 | R3 值 / 设计取值 |
| --- | --- |
| 初始耐久 | 最大耐久的 25% |
| 修复条件 | 当前 workers≥1；控制点及至少一名活正式战斗队员在范围内 |
| 修复范围 | 建筑地面可见边界外 6.5 单位；必须连通、无隔墙作用 |
| 速度 | 每农民每战斗秒 1.5% 最大耐久，上限 6%／秒 |
| 出范围 | 回血停止，HP 不重置，敌军不停止 |
| 同步顺序 | 先受伤／死亡，再修复；已归零不被同一步回血救活 |
| 常规无受击时间 | 1 人 50 秒、2 人 25 秒、3 人约 16.667 秒、4 人以上 12.5 秒 |

农民使用当前已入账人数，不把已营救农民重新拉到现场，不暂停自动经济，不从人数中扣“维修工”。待接取期间如果由于将来新增规则使 workers 变成 0，接取也需重新校验；进行中变 0 则暂停修复并提示原因，不给无农民免费修复。

建筑落点距控制点至少 10 单位，按原建筑占地检查可放置地面、接近及退出通路；最多试 32 点，无合法落点则不生成，不毁已确认环境。任务建筑不生产、不加入已拥有设施列表，修复动画不直接发 HP。

## 5. 现有敌军优先目标与两波增援

### 场上敌军优先攻击

- guarding 期间，将任务建筑插入现有敌方单位的最高优先普通攻击候选；包含当前已在场及之后正常主波／任务增援入场者，不只是新增两波。
- 必须满足原攻击资格：对地能力、可达／合法射线、生命存活、单位自身模式等。不能让对空专用武器攻击地面建筑，不能瞬移穿墙追击。
- 普通索敌可向建筑移动并重新取得射线；本步已承诺的攻击、弹体和 Boss 技能按现有规则完成，不能每步硬取消造成无伤或打断所有 Boss 机制。优先级用于下一次合法索敌，不删掉固定技能。
- 统一走现有普通战斗伤害、护甲与范围伤害规则，不使用 R1 撤回的百分比伤害。表内统一任务耐久的基础护甲为 1，作为本任务明确适配值；原生神族盾已并入耐久，不再次扣盾护甲。
- 同关难度、弱兵密度、来源成长、资源身份保持。建筑成功／失败／挂起时删除该强制候选，现有敌人恢复普通索敌，不换 ID、不回血、不发死亡奖励。

### 两波如何按当前波次生成

用户已指定数量／组成随当前敌人波次，不固定 8/2 或 30/10。

- 使用当前普通战役的已实例化主波计划，选取最近已调度的非空普通波作为模板；当前关还无已调度波时取本关第一个非空普通波。禁止复制 Boss、精英特殊计划、主巢或扩张巢，也不推进原 stageWave 或消耗原普通波。
- 每个额外波在自身触发时，复制模板的 types、members、兵种、4∶4∶1 密度、成员间隔、成长 stamp 和资源系数；数量为一个完整普通波，不再另乘固定倍率。当前代码入口为 `campaign18Schedule`、`src/data/mixed-waves.ts` 以及 World.spawnWave / releaseAmbient 普通波分派逻辑；任务新增的复制／排队接口不能冒充已存在 API。
- 额外波单列 taskId／waveOrdinal／模板来源，独立记账，不能污染原战役总预算或误判强制 Boss 已完成。继承弱兵仅矿气的规则，不扩大发卡与装备奖励。
- 已确认触发时机：第 1 波启动守卫时，第 2 波 HP 首次达到 62.5% 最大值时（从初始 25% 到 100% 的修复路程一半）。
- 第 2 波阈值只触发一次；再次受伤回落再修上来不重复刷。先标记触发收据，再排入待入场队列。
- 从建筑附近合法入口按模板成员间隔进入，不从四面远距离奔来。300 上限与 Boss 预留保持；最多存两次已触发的有限波次及其剩余成员，无无限周期队列。每步最多释放 8 名，容量不足等待，不静默丢兵。
- 两波不是两波之外再循环刷怪。任务结束取消未入场成员，已入场者正常战斗。第 2 波触发后即使建筑很快修满也不延长任务强制等兵入场。

实际场上大量敌军同时攻建筑可能明显缩短生存窗口，必须真实检查；不能为了凑静态维修时长擅自缩减现有敌人、改伤害或把建筑改无敌。

## 6. 预留、授予与成功后消失

本轮采用预留设施名额。生成时：available=maxLevel－实际数－预留数≥1，虫族按共享孵化场计数。预留不提供生产、前置和科技。

所有共用获得入口（付费、双建、装备、任务）都尊重预留；商店显示任务占用。任务完成时，同一提交释放自己的预留并授予相应设施，其他来源不能抢占。失败、未接取失效及战役终止释放预留。

满血进入 resolving，冻结任务目标并停止增援，校验 key=`runId:taskId:facilityGrant`，调用 `grantProductionFacility` → `grantFacility` ，再记录 facilityId／groupId 和收据。校验前不消费预留、不播成功；异常失败保留 resolving 状态重试，不改发矿气。

World.atomicMutation 仅合并变更通知，没有失败回滚。设施奖励须先整体校验容量、预留归属与收据，再提交增加设施及消费预留；不能因重复回调多发一座。

- 不扣钱包、不占建设窗口、不消耗免单或双建次数。
- 首重工厂／星港依既有规则给恶火／医疗运输机资格；已有组输出、启停、游标不覆盖。
- 新孵化场独立 ID 和输出，不附带地面／天空方向；其他孵化场与全局已付订单不变。
- 神族不额外送物种、身体或家族位；重型单位第 10 关门槛保持。
- 工作反馈后 1 秒移除场景模型、碰撞和雷达，不发建筑被摧毁事件；生产账本保留本局设施。现有钱包支付、生产、运输及交付真实运行，不自动赠一批兵。

## 7. 生命周期与数据

状态 offered → guarding → resolving → succeeded；offered→expired；guarding→failed；非终态→cancelled。

未接取进入下一普通关失效；已启动保留 ID、HP、模板快照、两次波触发收据及剩余成员跨关。暂停、关间、特殊关挂起冻结，普通地图返回恢复；不搬进特殊关继续吸引敌人。

第 18 关结局先处理本步合法完成，再取消其余任务并释放预留。进入无尽前任务、建筑与预留全部清理，无尽无抽签无任务。撤离／战败不补发未完成设施。已获得设施按原本局与结束出征规则处理，不额外永久解锁。

字段：taskId、race、sourceStage、templateId（七种之一）、facilityKind、targetEntityId、maxHp、hp、reservedCapacityKey、state、extraWaveTriggered[2]、pendingWaves（上限 2）、enemyIds、grantReceipt、grantedFacilityIds。共用 GCD 在最终结束时只启动一次。

## 8. 必须验证

1. workers=0 不进池、不抽出修复任务；有农民和合法容量才能生成，满容量／前置不足不生成。
2. 七个建筑身份分别验证外形、损伤、维修、工作与死亡；虫族仅孵化场一种且固定＋1、不附方向；三族只抽本族。
3. 场上既有和后来入场敌军都按合法资格优先攻击建筑；对空单位不违法对地、Boss 原技能不中断、任务结束解除优先。
4. 额外波成员与所选当前波模板精确相符，4∶4∶1、成长与弱兵掉落保持；只有两次，血量反复过阈值不重刷，300 上限无越界。
5. 实际修复速度、出范围停止、真实受伤／致死优先正确；无伤 1/2/3/4 人时长符合公式。
6. 预留与购买／双建／装备竞争、失败释放、完成幂等、虫族总上限 15、只授予一座孵化场且不解锁方向，奖励不半提交。
7. 生产真实付款→订单→运输→交付；已有输出、ID 与付费预留保持；场景模型消失不删除生产设施。
8. 未接取失效、已启动跨关、特殊关挂起、暂停、退出、结局及无尽边界无残留。三族自然游戏完成与至少一次真实失败另验，不以文档或静态算例替代。

## 9. 规格状态与实施边界

本轮虫族统一一种及两波触发时机已定案，不再保留九种建筑或虫族方向奖励为待确认项。其余落点、伤害顺序、收据与数据契约按本文设计取值实施，平衡数值需在真实玩法中验证。
