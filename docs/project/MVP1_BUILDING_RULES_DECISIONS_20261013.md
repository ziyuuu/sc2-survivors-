# MVP 1 建筑对接模块与缺项定案

> 历史阶段记录：随后已获正式接入主游戏授权，当前状态见[主游戏接入](MVP1_BUILDING_INTEGRATION_20261013.md)。下文的“未挂载／只独立模块”是本文件原轮次边界，数值定案与旧验证继续保留。独立R5成品保留为`dist/mvp1-intermission-design-20261013/index-connection-r5.html`。

日期：2026-10-13。用户已允许进入缺失数值确定和原游戏逻辑对接，并已回复三组缺项。随后明确纠正范围：只做好独立对接模块，包括三族版本的UI对齐与逻辑一致，不接入主游戏。下列价格和上限按用户修订定案，其余沿用本次建议。UI依据已评审的R17原型；定案不代表已经实现或完成建筑包验收。

## 本次确认的规则

### 虫族

| 项目 | 建议值与语义 |
|---|---|
| 孵化场 | 沿用150矿／0气、最多15座，含开局一座；用户按三族设施总量明确提高上限 |
| 基础兵种 | 开局仅跳虫；爆虫单独解锁50／25；蟑螂75／25、虫后175／0，分别购买，不互斥 |
| 顺序 | 同级无内部先后；蟑螂／虫后需要跳虫或爆虫已解锁；地面方向需要蟑螂／虫后任意一种已解锁 |
| 地面进化 | 每座150／100，一次支付完成该座方向开放；包含刺蛇生产资格，不送实际士兵 |
| 天空进化 | 每座100／150，一次支付完成该座方向开放；包含飞龙生产资格，不送实际士兵；全局至少一座已完成地面进化 |
| 第二方向 | 按新开放方向的价格支付，无二次进化附加费；保留已有方向及输出 |
| 新孵化场先天空 | 满足全局地面门槛后允许，基础物种仍可选 |
| 共享边界 | 方向、两输出、启停与轮流游标属于单座；兵种解锁及兵种科技全局共享，本座仍须有相应方向 |
| 后续解锁 | 破坏者100／100、潜伏者150／150、雷兽275／200、腐化者150／100；沿用当前实际配方对应的基础解锁价格 |
| 刷新与动作 | 三族统一每建设窗口一次基础免费；其后沿用已确认的人族标准，免费不推进付费次数；每窗口仍只买一项发展 |

地面／天空费用是用户明确修订的方向开放价格。方向开放后首次解锁该物种；其他孵化场仍要分别付方向开放费用。已有生产单不因修改配置、进化或共享解锁变化而改价或改兵种。

### 神族

| 项目 | 建议值与语义 |
|---|---|
| 高阶圣堂武士前置 | 追猎者或哨兵任意一种已解锁，两个同级项目不互斥 |
| 折跃水晶价格 | 每对300矿／0气，一次交付两座 |
| 前置与上限 | 只需传送门；最多2对／4座，独立于传送门5座上限 |
| 输出 | 全部水晶构成独立生产组，最多选狂热者／使徒两种轮流生产；传送门保留原兵种列表 |
| 时间、费用与交付 | 兵种沿用原生产费用、时间、容量、付款账本及交付流程，水晶不自带额外加速 |
| 建造天赋 | 免费按整对判定；双建触发后按同一报价另付一对，须同时满足整对剩余容量和钱包；不交付半对 |
| 首建奖励 | 水晶不送使徒解锁或士兵；机械台／星门保持原有规则，不新增免费兵种 |

每座折算150矿，与传送门一致；用户明确指出200矿一对会导致前期比传送门过于划算，故改为300。2对上限让它有扩建空间，同时避免超过现有单批容量后出现没有收益的额外设施。这是接入初值，不是已经通过自然玩法的平衡结论。

### 存档延期

用户明确要求“MVP收尾前都不考虑存档”。本轮按新局实施，不编写旧局转换、不操作现有玩家档案、不将存档迁移作为建筑接入前置。独立入口只使用隔离的内存运行；正式存档和最终恢复验收留到MVP收尾。必要的版本隔离仅用于避免旧结构被误读，不代表已完成存档兼容工作。

## 已定案部分和共享接入边界

1. 人族／神族候选仅属于当前方向，前置建筑只提示；兵种顺序用已批准规格，兵种死亡不改变解锁前置。
2. 人族／神族每窗口建设基础免费一次，天赋额外次数与补给共享，免费不增加付费阶梯；无候选、过期请求、余额不足不消耗次数或资源。
3. 现有专属科技、攻防价格及阶段6／12、雷神／雷兽／航母第10关生产门槛、普通部队5个家族席位继续保留。
4. 新规则、命令和宿主适配器独立放在`preview/building-workbench/connection/`，三族独立入口共用它们。原游戏数据、生产报价、支付账本、训练和交付接口只读复用，在隔离World实例中验证；主游戏不导入、不挂载本模块，不改正式入口。R17样例原型保留，`review-flow.ts`不充当业务规则。
5. 设施初始化提供统一入口，供购买及已有事件设施收益调用；为后续舰装保留同一入口，本次不提前实现舰装系统。
6. 已评审的布置／科技／构建树、28像素图标、14／12像素文字、水晶数字费用与单一设施入口，统一应用于三族独立视图。操作需结果确认后更新显示；布置草稿提交时统一复核，失败不部分提交。
7. 独立入口使用隔离内存运行和可辨认的沙盒标记；不读取或覆盖正式玩家档案。验证涵盖真实购买、生产付款、交付以及失败／重复请求；按用户新指令，存档恢复验收延期。

## 对接模块顺序与验证

先实现已确认的路线筛选、前置与刷新，再实现逐座设施状态和水晶组；通过独立适配器验证原游戏账本与这些生产主体的衔接，最后统一三族评审UI。仅验证模块规则、原代码接口与独立UI；存档延期，不重做美术、地图、相机或性能专项。正式挂载与主游戏回归留到用户明确授权。价格初值仍需自然试玩评估，本轮不关闭MVP1或八包MVP。
