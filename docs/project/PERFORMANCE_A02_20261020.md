- **初始构建引用错误**：诊断入口误用不存在的starship/account，修正为inventory后才产生有效构建；终端原错误保留。
- **probe-1本机浏览器网络权限**：ERR_NETWORK_ACCESS_DENIED，未进入有效游戏；原报告/失败截图保留，获准本机浏览器重跑。
- **probe-2不完整技能夹具**：四技能因缺少战场视图、射程或治疗对象失败；旧12图/报告保留，只作部分先导。后续夹具提供真实合法条件，18英雄技能均成功。其局部时段与Node验证并行，旧计时不作最终收益。
- **静态精英目录缓存R1回退**：上下文计时有回退，Protoss300仅5/12对更快，中位约0.161→0.174ms；该生产文件逐字节撤回。最终仅单位子池保留。
- **一次性分析脚本字段错误**：误用timers/capacity/数组filter与ms字段，部分打印为空或报错；原始rows/capacities/totalMs未改。最终汇总使用实际字段并断言。
- **看板中途渲染失败**：进度记录误用summary而非change/evidence，渲染器报错；立即改正记录结构并成功重新生成两视图。
- **final-1响应哈希钩子漏匹配**：8英雄/18镜头/2据点、容量及实际恢复均已完成，最终校验因loadedMainSha256未赋值而失败。服务按Referer把根路径/main.js映射到当前预览，旧钩子误要求URL含预览目录；并非查询参数问题。final-1保留failed。binding-1独立浏览器重载两侧，核验200响应、Referer及实际响应SHA与未改构建相同；未冒充重复完整场景矩阵。
- **镜头CDP汇总过强断言**：首次汇总断言18组全0重排失败；实际仅窄屏0敌人fixed窗口出现1次layout/2次style重算，分别约0.207/9.888ms。fixed函数直接返回，这个跨CDP窗口包含UI工作，不能把它归因于cameraFrame，也不能抹除。12组auto/cinematic均0，报告改按原始计数。
- **收尾文件写入顺序**：首次收尾先渲染看板、后创建范围报告，链接检查因报告不存在失败；调整为先写报告再渲染，按原修订继续完成并另做最终哈希/链接一致性检查。未覆盖旧运行证据。
