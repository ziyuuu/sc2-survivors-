## 原生流程与规则边界

- 建设选择一项后进入补给；补给可购买多项后回战场。打开、关闭、翻阅或返回页面不重新抽卡，不收费，不改变发展方向与价格。
- 精英三选一、满编时选择被晋升老兵、取消、支付与就绪回调保留。取消不会扣钱、锁定变种或重抽商品。天赋产生的精英特约仍有入口；不是新增关卡。
- 新皮肤不掌管 World、钱包、报价、时钟、屏幕历史。点击详情仅切换同一等高说明区域。原指针提交保护、滚动/焦点恢复、原按钮和禁用状态继续生效。
- 两个已有 simulation 文件的变化仅实现原 UI 对话已明确批准的增援规则：先补空位，再晋升普通士兵；部分剩余容量可买，仍按整卡收费；空投到达/接收后生效。军衔/编制、已付预留、兵种轮换和跳虫成对同步沿用原逻辑。没有增加新规则版本或存档字段。
- 每兵种默认 5 人；原「扩充队伍」天赋可到 7 人。测试「满编替换取消」使用满军队天赋，因此截图有 7 个老兵；这不是本轮新增的上限。5 个兵种与 3 个英雄身份限制未变。
- 掉落概率、品质、拾取时机、自动入队/晋升逻辑未变。卡面与卡背统一新商店的薄框、米白标题带与稀有度色，原 logo/匹配立绘保留；沿用 R4 紫色 2400ms / 橙色 2900ms 翻转与泛光，不暂停、不领取、不拦截输入，保留减少动态效果模式。
