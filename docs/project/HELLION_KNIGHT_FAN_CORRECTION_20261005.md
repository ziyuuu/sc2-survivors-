# 地狱骑士喷火扇面修正 · 2026-10-05

用户在确认神族修正版“可以了”后，指出人族恶火地狱骑士攻击距离变长、扇面没有填满。本次只修正 `hellion.2` 的这一问题，保留已通过的神族英雄和人族三十精英其他内容。

## 原因与修正

原运行时恶火模式使用固定喷火长度6.5再乘2，得到13；实际武器射程却是源武器5乘批准倍率2，等于10。画面再从当前炮口位置按这段长度向外延伸，分段头部和粒子还有额外越界。九条独立火焰轨迹之间则留下很大空隙。单位在效果存续期间移动，也会使原终点到当前身体的距离发生变化。

地狱骑士现在使用真实 `u.attackRange`：恶火10、恶蝠4，保持批准的两倍射程及150°扇面，包含已有合法射程修饰一次。伤害、轻甲倍率、身体成长、武器周期和转换规则不改。范围从碰撞体朝向前缘起算，保证按身体边缘射程选中的主目标能实际受击；命中与显示都使用同一冻结原点、方向、半径，保留地面、视线、障碍及每目标一次命中的资格。

显示使用连续连接的扇面网格与原 `FireTile4` 流动纹理，覆盖角度之间的内部空间；两层火焰表面、内缩原火焰翻页粒子和柔化边缘共同构成火帘。所有顶点均不越过真实半径或150°边界，装饰粒子内缩。完整、均衡、简化均保持填满的两层扇面，仅装饰粒子数量下降。效果保留原.35秒，最后.1秒淡出，不增加伤害或火区。

已有 `Effect.x/z/end/radius/until` 保存实际原点、终点、半径及结束时刻；渲染不再从移动后的身体重复加距离。run schema21和profile v5保持不变，无兼容分支、额外资源或提案JSON导入。
