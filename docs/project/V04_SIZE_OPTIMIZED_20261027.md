本分支以 V04 本地交付为游戏基线，保留压缩实验脚本、核验方法和结果。完整 Sites 版本的 Git 快照位于本仓库 `sites/size-optimized-site/`，包含 58 个资源包、加载器、网站与统计反馈后台。快照来自本机独立仓库 `D:/星际/sites/v04-private-test` 的 `体积优化版` 分支提交 `1b81c97`；该独立仓库没有配置 Git 远端，其历史不随主工程推送，主工程保存的是该提交的文件快照。后续更改独立仓库后需重新同步快照。

## 压缩与范围

- 本版来自 `dist/V04-20261027/Web.zip`，3845 个资源记录、3742 个唯一资源；图片和模型贴图按 WebP 质量 70 有损压缩，音频采用目标 48 kbps Opus。模型传输用 gzip，浏览器解压后按清单校验。
- 资源包共 58 份，站点 `public/` 约 240 MB；压缩前资源约 1.42 GB。实际下载量取决于缓存和使用场景。
- 后台实现位于站点仓库，依赖站点所有者认证、D1 和 R2；数据库、对象存储和身份权限是部署环境，不在 Git 分支里。站点仍为私有，未因创建分支而发布。
- 陆战队员战斗画面、核弹爆炸、巨像与虚空辉光舰射线的少量样本已进行原版与压缩版对照；四组声音已制成 A/B 试听。压缩有损，样本不是对全部画面和音效的质量保证。

## 开局帧率抽测

2026-10-27 本机 Chrome 155 无界面模式，AMD Radeon Graphics / Direct3D 11 硬件渲染，1440×900、设备像素比 1；本地服务、相同随机种子和人族开局。两轮交换测试顺序，每个版本每轮预热至战斗第 5 秒后连续测两段各 12 秒，以浏览器动画帧间隔计算。原版各段 56.01、46.02、57.59、53.09 FPS；优化版各段 57.34、57.25、58.09、57.84 FPS。无页面错误或资源 HTTP 错误。

结果受浏览器刷新节奏和机器负载影响；两轮各只有一次开局，不可据此将差异直接归因于压缩。只覆盖开局、敌人较少的战斗，未覆盖密集后期、高特效、移动设备或真实线上访问。结果与逐段帧间隔统计见 `reports/qa/v04-sites-fps-20261027.json` 和 `reports/qa/v04-sites-fps-reverse-20261027.json`。
