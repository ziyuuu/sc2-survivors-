## 已实施规则

独立固定伤害支援使用：`基础伤害 × (1 + 全局攻击加成) × (1 + min(3, 全局普通白字DPS / 100))`。成长倍率最高4倍，覆盖核弹／生体巨爆／净化打击、轰炸、地雷、导弹、寄生毒囊、破盾反击、棱镜扫射和地堡射击。普通攻速、暴击和固定真实DPS不重复带入；突变、跳弹和相位回响仍继承原攻击，不重复套此倍率。

战略打击基础伤害从3000提高到6000，地面核弹拾取物也使用同一弹药规则。原325矿／140气价格、3秒预警、8米半径、一次性弹药、无友伤和在途伤害冻结保持。已经冻结伤害的旧在途弹不重新计算；没有显式伤害的旧格式在途弹仍按旧3000兜底，避免重解释历史提交。

## 修改前后证据

先比较3000旧版、3000加成长、6000加成长及9000加成长，共1152组。每组使用三族、四难度、四配装、六个Boss关卡的原生Boss与六类普通敌人，按实际计划出生进度计算生命和护甲。候选阶段明确替换提交伤害以比较；最终版本另做288组完全不改提交伤害的生产验证，全部精确匹配公式。冻结目标位置用于隔离伤害，不代表自然战役或实战命中率。

普通第15关Boss，蓝装一发实际扣血占比约13.29%→39.37%；紫装约72.18%，橙装可击杀该受控满血目标。地狱第18关Boss，橙装约1.92%→15.36%，蓝装约3.22%。9000候选会让蓝装对普通15关Boss达到约59%，因此选择6000基础。此取舍强调清理群体与有效削血，没有改成所有难度秒杀Boss。

重复前轮同配置的424组30秒输出、1256组逐卡属性／恢复／能量／生产通道、36组条件机制、183组原生Boss战及162组叠加／跨关记录。无卡和全军卡输出基线精确相同；1256组效果通道修改前后精确相同，1200条价格变更只对应300张批准降价卡的四配装样本。实际购买回执、钱包与重复购买拒绝一并核对。

一级超载在第15关人族、同种子八目标、30秒样本中，相对无卡输出增益：无装备4.65%→13.93%，蓝装0.61%→6.54%，紫装0.25%→6.52%，橙装1.60%→8.13%。这是包含施放窗口及冷却空窗的有界样本，不是长期固定收益百分比。

183组原生Boss战保留实际敌我攻击、移动、死亡和普通敌人护甲，修改前后均130组清除，未新增清除失败或更多死亡。人族蓝装第9关核弹样本清除时间5→3秒，第15关26.05→23.15秒；裸装后期战败仍保留。橙装早期部分样本在3秒落弹前已清场，一次性核弹在这些场景仍没有额外收益。没有把每张卡强制调成任何场景都值得买；完整经济／成长及自然战役仍交G03／V02。
