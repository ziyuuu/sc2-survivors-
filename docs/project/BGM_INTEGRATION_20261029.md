## 播放与设置

- 第一次真实点击、触屏或按键后启动；同类页面切换保持当前播放位置。菜单与关间共用一个媒体元素，切曲先短淡出再淡入，最多一个音乐声音源。
- 进入战斗淡出并暂停；战斗暂停或战斗中的设置不会启动菜单音乐。关间与结算使用同一首。
- 页面隐藏、离页或静音立即暂停，回前台尝试恢复音频时钟并续播。异步资源请求/淡出结束时复核当前阶段，旧请求不能在入战后重启音乐；播放失败保留下一次真实操作重试。
- 设置→操作现有音量区新增“背景音乐”，默认15%，0为静音，并受主音量控制。偏好沿用`sc2.audio-mix`，保留已有主音量/战场/界面静音值。其他界面不加新入口或说明。
- 两首是独立`kind: music`资源，按需通过媒体元素播放，不进入战斗音效的整曲`AudioBuffer`解码目录。音乐只读World阶段，不改模拟、RNG、结算或存档格式。

浏览器策略参照[WebKit用户手势说明](https://webkit.org/blog/6784/new-video-policies-for-ios/)；媒体元素音频接入既有混音通道参照[createMediaElementSource](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/createMediaElementSource)。实际设备策略以实机为准。
