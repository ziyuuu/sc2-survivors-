# 入场峰值、KTX2 与缓存释放

2026-10-28，归属 V06-MEMORY-003，延续 V06-SAFARI-001 / V06-MEMORY-002。用户授权按「峰值测量 → KTX2 对照 → 缓存释放」继续优化，尽量保持画质，验证通过后更新部署。已发布现有Sites第15版，原网址与公开权限保持；原iPhone实机验证仍开放。

## 本批实现

- 给43张三档内容相同的大型模型法线/高光贴图增加 KTX2 UASTC level 3 衍生资源，尺寸保持。仅在支持 ASTC 或 BC7 的设备使用；不支持、下载或转码失败时使用原图。地形、透明特效、界面、颜色贴图保持现有资源。
- 维持单个转码线程，在必要准备完成后释放线程及其内存。预下载包含适用的压缩衍生资源，逐文件校验长度和 SHA-256。
- 图片共享缓存使用弱引用；材质采样参数仍独立。必要准备入口清除失效绑定，保留仍使用同图的材质。
- 在后台与必要准备通道已排空的入口，把已解析模型的编码 Blob 副本限制在12 MiB（受限设备）或48 MiB（其他设备）。磁盘缓存保持，后续真正需要文件时重新校验读取。后台不再因原文件副本被释放而重复取回已经解析的模型。

玩法、随机序列、奖励、存档格式、镜头与UI未改。并非整个资源生命周期已重写：GPU模型/任务模板仍可能跨局保留，本批解决的是编码副本、转码线程、闲置图片引用及重复回填。

## 图像对照

当前中档真实尺寸，43张图逐像素对照：最低 RGB PSNR 39.34 dB，最大平均 RGB 绝对误差1.178/255；局部alpha最大误差35/255，不能称为无损。代表性法线、高光及游戏实际画面已查看，透明特效小样误差较大，因此没有纳入。原图保留作为不支持设备与失败回退来源。

这批贴图的含mip RGBA估算为157,985,439字节，桌面BC7数据39,497,552字节。新增下载22,644,988字节，14份静态包，另有转码器。不能把局部约75%的贴图缩减写成整个游戏或iPhone总内存节省。

贴图估算减少约21.1%。进程总占用的正常静置改善较小，JS/底层缓冲因压缩mip数据而上升；人工GC是诊断条件，不代表游戏会自动取得该收益。首轮样本曾出现候选后段进程占用更高，因此追加等静置条件核对，未将首轮结果隐去。

这些是单次Windows测量，private commit含浏览器及驱动开销；GL数字来自分配调用，并非驱动实测。堆、backing storage、GPU与音频口径存在重叠，不得相加。没有物理iPhone证据，仍不能宣称已解决Safari自动重载。

首次入口释放23,449,404字节模型编码副本。修正后台回填后，进入战斗的Blob总量约60.06 MB，静置后不增加；再次开局约61.26 MB，贴图估算454.76 MB，无context loss。此处Blob总量含非模型资源，不等于12 MiB的模型专项预算；两次开局不构成长时间无泄漏证明。
