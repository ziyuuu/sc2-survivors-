## 模块职责

| 模块 | 职责与对接位置 |

## 已落实的规则

三族每建设窗口基础免费刷新一次，显示矿物图标＋0；其后消耗天赋共享免费次数，再按50／90／130递增，免费不推进付费次数。购买每窗口一项。报价沿用原随机折扣及相关天赋，表内150／100等均为基础价格；详情显示本次实际报价。切换方向保留报价，刷新后旧报价失效，无候选、余额不足及过期请求不扣钱。

人族、神族仅产生所选路线的候选；跨线前置只作为图标提示和切换入口。顺序按已批准规格执行，分支前置用对应上一层任一物种，兵种存活数不影响解锁。

虫族孵化场150矿／0气，上限15座含开局；地面150／100、天空100／150。地面需要蟑螂或虫后，天空需要全局至少一座完成地面。逐座开放方向、双输出、启停、轮流游标；解锁和研究全局共享。本座缺少方向仍不能生产对应兵种。第二方向保留第一方向及现有输出，分别给予刺蛇／飞龙生产资格，不送士兵。

神族折跃水晶300矿／0气一对，最多两对／四座；只需传送门，独立生产组选择狂热者／使徒，保留传送门原输出。免费、双建按完整一对结算，额外一对检查余额和上限。高阶圣堂武士检查追猎者或哨兵任一解锁。

攻防系统与研究价格、6／12阶段门槛、雷神／雷兽／航母第10关生产门槛沿用。原订单的家族、设施、支付、剩余时间不随布置修改而重写。研究同步到隔离World的原属性计算，生产费用、时间和交付保留原游戏实现。

## 交接接口

| 输入 | 输出／责任 |
|---|---|
| `newBuildingState(race, wallet, seed)` | 建筑模块拥有的状态；宿主提供当前种族、窗口阶段、钱包和天赋 |
| `getOffers(state)`／`setDirection(state, line)` | 缓存候选及带窗口／版本的报价；UI不自行生成资格或价格 |
| `purchase(state, offer, target?)` | 再次验证当前报价、目标孵化场、余额和上限，成功才扣款并变更设施／科技 |
| `placementDraft(state)`／`applyPlacement(state, draft)` | 三个标签共享一份草稿；提交整体复核，取消不提交，不触碰已付订单 |
| `grantFacility(state, kind)` | 建造与后续事件／舰装共用的设施初始化函数；这是可信宿主的授予入口，不是UI免付费命令 |
| `refreshCost`／`refresh`／`nextPhase`／`nextWindow` | 同一份免费次数、共享付费计数和18关边界 |
| `NativeBuildingSandbox.sync/quote/tick/deliverReady` | 只用于隔离对接验证；`deliverReady`人工推进运输到达，实际付款、订单、容量、跳虫成对和士兵交付调用原函数 |

现有生产逻辑按研究线路阻塞生产；新规则允许同一路线多个生产主体。独立适配器为每个主体提供有边界的调度视图，仍保留全局付费预留与原账本；每次先只推进原订单一次，再逐组尝试开工。新订单仍保存原生线路与设施编号，额外的“订单→生产组”映射只在隔离适配器内存中保存。没有给主游戏增加保存字段。

以后正式挂载时，须由一个宿主统一驱动这套调度，不能同时运行原自动生产循环和模块调度；需要连接现有窗口／钱包／天赋、家族替换UI、事件与舰装授权入口，随后验证实际战斗和存档。当前达到家族席位上限会保留原待处理请求并停止自动推进，不擅自替换部队。这些是后续对接点，不是本轮已完成的主游戏接入。
