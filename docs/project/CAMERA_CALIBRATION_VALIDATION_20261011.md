## 保留的失败与候选

正式镜头说明已列出诊断方向偏好、原生滚轮事件差异、真实失焦语义、地图边缘命令结束及旧检查器选择器等候选问题。所有原报告与失败截图保留。身份r1进程退出码3221226505，未记录JS／渲染错误，原因没有确立；完整身份索引只继承完成组并对后续组重新运行，每张图仍指向原采集目录和哈希。

第一次应用准备漏带六份旧UI说明，已保留为 `Camera-Calibrated-Candidate1-Application-20261011`，最终应用重新包含这些文件。第一次更新检查输出目录不存在，最终写报告时报ENOENT；该轮不计通过，其沙盒保留。第二次预先创建独立输出目录后完整重跑通过。

边界检查 `perspective-edges-r1` 在首个完全出左边缘用例失败。诊断脚本按单个包围盒角点的深度计算一次水平相机平移；透视下平移后极值角点可能改变，另一个角点仍位于画内。新版只修改诊断取景，重复计算实际投影极值至目标位置，仍逐项断言完整身体边界与原生状态。`perspective-r3` 与 `perspective-r2` 的全部生产输入相同，唯一变化是诊断main.ts，证明见 `edge-diagnostic-delta.json`；正式Web／离线文件没有重建。

连续录像 `perspective-realtime-r1` 完成5段后，第6段触发真实可见／焦点断言，整轮未通过，原因未确立。前5段视频、截图及失败报告保留；旧脚本在断言后才保存视频，因此失败段本身没有被保存，不能补写其帧内容或事件细节。后续新编号运行在每段开始前请求前台并等待真实焦点；先保存视频与事件再做断言，便于保留再次失败的证据。原生节流、真实焦点和零丢弃断言均未放宽，不更改模拟计时器。
