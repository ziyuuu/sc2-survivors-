# Sites 游戏加载优化与后台适配 · 2026-10-27

私有站点已部署加载优化版。3742 个资源合并成 58 个数据包；浏览器按需解包并校验原资源哈希，资源准备并发由 4 提至 12。3845 资源条目逐项对应，所有唯一资源哈希通过；本机进入战斗及存档刷新通过。仅一组对照：同一机器无缓存 Chromium、每次服务器请求注入 150ms 延迟；菜单 32.0→15.1 秒，战场准备 191.9→40.8 秒。私有站点登录浏览器进入菜单；独立无缓存浏览器因 service worker 脚本不继承服务凭据而无法完成线上计时，不视作线上失败或冷启动通过。实际网速、负载及后续不同场景尚需测试；优化版线上战斗未覆盖，避免修改既有存档。

后台尚未接入。现有应用使用 Node HTTP 服务、PostgreSQL 专有 SQL、独立删除日志、账号和 CSRF；Sites 当前为静态部署，无法直接启动此服务，运行环境不支持直接原始 TCP。可行方向是将站点改造为支持 Workers 的全栈构建，并将数据契约迁移到 D1；实际适配需重新实现并测试统计授权/撤回与删除、反馈收回、管理权限、备份恢复和删除日志。D1 的存在不等于迁移已完成。现有阿里云服务仅本机监听，未经完成对外条件不应直接开放来连接。无新数据采集，无公共发布。视觉音频压缩质量未验收。
