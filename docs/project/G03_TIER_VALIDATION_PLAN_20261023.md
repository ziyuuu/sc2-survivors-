# G03 配装层级验证 · 2026-10-23

用户明确：简单毕业全绿，普通毕业全蓝；困难蓝绿开荒、全蓝加部分紫为farm、大部分紫为小毕业、最优解为毕业。地狱以此类推。开荒装配合合理操作、培养与局内成长应可顺利进入无尽；毕业装应能平推战役进入无尽。数值变更先提交数据和建议。

本批将原来的“入场/毕业”两端扩展为四档，避免把高品质等同最优解。困难实测候选为6蓝2绿、6蓝2紫、6紫2蓝、全紫优化候选；地狱对应6紫2蓝、6紫2橙、6橙2紫、全橙优化候选。属性分数按140/160/180/200分档，模块搭配及完整物品写入每条记录。所有账户为测量用合法预配装，不作为自然获得这些物品所需时间的证据。

毕业先比较实际可用的属性/套装/模块组合，仅称“毕业候选”；不宣称穷举了全目录、所有继承与污染组合，或已经找出全局最优解。简单、普通补属性装与成套协同对照；困难比较满词条属性装与6件生存者/双重打击组合；地狱没有橙色通用属性散件，使用真实橙色生存者套并比较两组橙色模块。

第一种子529覆盖三族各档，第二种子530重点复核开荒与毕业候选。正式开局、原生地图、生产、消费、Boss英雄抽选、掉落和换装保持；公开可见敌人靠近时优先战斗，避免控制器为可选事件连续穿越敌群。此策略仍非人类熟练操作认证，不把程序战败等同玩家不可能通关。

记录进入无尽、战败关卡、关末编队/生命/护盾/钱包、战损、实际换装、英雄、特殊关入场与越界。不得把截断算成战败或通关，不用途中升级后的结果证明仅初始配装足够。单种子不作胜率承诺；通关也不自动等于平推。新策略相对旧策略不是单变量配装对照，旧六条先导保留。

横穿修复先独立闭环：原五组复现、三族16/30/32/48/64人原生移动/完整撤离及冻结返回、原两条阻断配置连续路线重放、完整回归与源文件保护。当前英雄门槛已改变，连续重放采用现行规则，不声称与旧整局进入特殊关前逐状态等价。

## 测量中的口径补充

横穿入场和移动单位出口两处修复已独立完成，见 `G03_CROSSING_FIX_20261023.md`。现行规则人族路线未再抽到横穿，另以隔离旧英雄规则、仅加入两处横穿修复的配对路线完成重放；这条配对在首次横穿前的289个记录状态与原失败路线精确相同。

首种子原36条探索脚本在出口修复前已经加载，按入口修复版单列，不能冒称最终版本全量平衡验收。原死亡记录每15步采样并按实体去重，只是下界。后续最终版本采用原生死亡回调记录事件（含英雄复活后的再次死亡），保留原参数、返回值与玩法；不同计数口径不直接比较。

后续24条为简单/普通协同套装第一种子6条，以及第二种子开荒/毕业防御候选/低难度协同18条。出口保留明确移动命令；成套装备不因拾到高品质散件被自动拆套，其他散件仍正常换装。另追加24条进攻毕业候选：三族四难度两种子各12条；第二种子低难度6条因虫族绿色候选结果分化后补入。简单为联阵/训练/稀有来电各2件和2散件，普通为6英雄/2训练，困难为6英雄/双重打击/1散件，地狱为6英雄/2生存者，英雄绑定分别为大和战巡/利维坦/净化者旗舰。它们通过原生装备效果获得单位，不强制注入战斗实体；特殊装备及套装保持，散件允许原生升级。

当前计划共84条，运行完成与结果另在最终报告逐行核对。进攻与防御候选会同时改变套装、模块和起始单位，只能比较完整配装方案，不能归因于某一个词条。没有穷举全目录、污染/继承和所有绑定组合，仍不得将候选称为已证明的全局最优解。

## 异常与控制策略补测

原批暴露巨兽支援利维坦误入敌方技能分派并抛错，记为 `G03-BEHEMOTH-SKILL-003`，不计战败。先在隔离源中增加技能类型资格保护，保持攻击、触手、到期与爆炸，完成最短红绿复现后追加三族两种子的6条地狱生存者重放。原84条完成后才将同一修复并回主源码，避免混入未绑定的版本变化，并重新运行完整回归。

原控制器“附近有敌人先战斗”会覆盖地狱限时扩张虫巢的必做目标。星灵进攻候选529第6关失败时仍有11名存活单位，不能当作装备太弱的结论。另追加三族两种子、开荒与进攻毕业各6条，共12条必做目标优先重放，使用隔离巨兽修复源，保留原失败。新记录增加原生失败提示、扩张巢和目标处理次数。策略修正不改变游戏玩法或数值，仍不等同熟练玩家操作证明。

本批最终计划为84条原批＋6条缺陷修复重放＋12条目标优先重放，共102条。版本、策略、异常、战败和墙钟截断分列，所有开局装备逐件验证；进入无尽不自动等于毕业平推达标。

目标优先重放又暴露控制器在一名远程单位进入射程时就停止接近、且处理扩张目标时跳过英雄主动技能的限制。再补6条地狱开荒路线（三族两种子）：至少六成可攻击该目标的单位进入射程才停止接近，并使用原生英雄槽位技能及侦测；已有解堵、生产、成长、修理和购买保持。该策略仍不是人类熟练操作认证。新补测采用40分钟墙钟上限，旧20分钟截断保留，均不作为帧率或游戏难度失败证据。本批封定108条，不再把控制器优化无限扩为平衡调参。
