# 战斗与基地 UI 实机样例 · 2026-10-08

用户在确认问题后要求：只制作与此前英雄／精英演示相同性质的实机样例，取消“单位操作”，两排收起后用上箭头提示展开。这次不改完整游戏，不接入 main 游戏入口，不重做战役或调整战斗平衡。

基线为 `ed215df3e0b50ccf7c5bc04d06b99114514db43a`。独立源码位于 `preview/battle-ui-feedback-20261008/`，输出 `dist/Battle-UI-Feedback-Sample-20261008.html`，样例分支 `codex/battle-ui-feedback-20261008`。

| 已确认问题 | 样例行为 |
| --- | --- |
| 基地功能缺少清楚的入口 | 战斗上栏“基地”、关间“设施调整”进入设施／训练／订单／部署面板；保留原生产开关和关间建设购买。 |
| 英雄技能入口不清楚 | 三名英雄固定在队伍栏后面三个位置，点按直接调用原主动技能，显示真实冷却。 |
| 第一排重复列出士兵 | 五个不同兵种合并显示原有存活人数，有现成手动操作的兵种前置。 |
| 单位不应凭空拥有多种技能 | 一个兵种至多映射一个原有手动操作；雷诺、泰凯斯和诺娃各用原主动技能，详情仍含原被动技能。 |
| 左键／手机点按技能，右键／长按详情 | 使用真实鼠标、触摸事件；长按 480ms 打开原详情，阻止后续误施放。没有手动技能的医疗运输机点按打开详情。 |
| “单位操作”难以理解 | 样例不显示该按钮，O 不打开空操作面板；实际兵种操作已移入对应位置。全局推进、主动侦测保留。 |
| 折叠后箭头方向错误 | 两排各自收起／展开，收起为上箭头，展开为下箭头，名称及 `aria-expanded` 同步，战场尺寸随之更新。 |
| 累计升级结果不清楚 | 设施页与关间研究条显示原武器／防护等级；强化一览显示真实卡片累计收益。军衔与研究分别呈现。 |
| 满员仍出现增援报价且提示不准确 | 先生成真实合法报价再将诊断编制补满；保留该报价并显示“编制已满”，原容量判断阻止扣费。折扣不会覆盖满员原因。 |

使用原 `World`、`BattleRenderer`、技能执行、生产、报价和购买命令。发展目标仅在原有 menu／reward 阶段可修改；战斗时禁用，未放宽引擎限制。建设购买进入原补给阶段，没有新英雄招募关卡。立绘、模型、动画和特效来自当前原资源；额外装入普通人族立绘用于原生建设报价，未生成或修改图像。

五个诊断场景为战斗、基地建设、战备补给、满员增援、尚无英雄。场景资源、科技、设施、部队与静止高生命敌人由样例配置建立，不代表自然战役获得；这不是普通模式后期平衡或自然性能的验证。浏览器触摸不等于实体手机或人工验收。

构建、预览和检查命令见样例 README。原 Web、完整 HTML、应用包、部署、后端、原设计文件与素材均保持原样；没有 Coze 上传或 main 合入。具体检查与哈希见 `BATTLE_UI_SAMPLE_VALIDATION_20261008.md` 及 `reports/local/battle-ui-sample-20261008/`。
