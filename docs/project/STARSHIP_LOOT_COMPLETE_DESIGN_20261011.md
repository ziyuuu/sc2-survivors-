## 玩家的一次出征

1. 局外从仓库选择十二槽配装。英雄或精英来源物品已经写明绑定身份，出征时不再选五名英雄。
2. 进入战斗，舰装掉落拾取到64格背包。清洁装备可以关内装备，污染装备暂时只能携带。
3. 换装立即改变白字、绿字与套装效果。换下的物品进入背包，并开始承担背包遗失风险。
4. 关间可继续前线或按撤离按钮。继续可追求更高阶段收益，撤离可完整保住背包。
5. 成功撤离，普通装备入仓可用，污染装备入仓等待付点数清洗。
6. 局外清洗、拆尘、指定换取、精英绑定洗练，再开始下一次出征。

## 白字绿字与物品品质

白字、绿字是属性显示层；白、绿、蓝、紫、橙是物品品质。两套概念分开。

用户已确认装备不设等级，白字和绿字按品质定数值区间，并按部位与属性类型匹配。旧稿装备1—100级和提高物品等级的候选取消；装备详情无等级，原单位军衔、研究等级与急速／防御等数值属性保留。已确认同部位、同一种属性的高品质下限严格高于低品质上限，各品质区间不重叠；优惠、冷却缩短等负号属性按收益幅度比较。普通装备绿字在所属品质区间内按单条合法数值等概率抽取；白字采用下文已确认的总预算与整组抽值规则。不同词条组合的整件价值仍需按配装判断；37种白字的具体上下限与合法步长已确认；绿字取值、白字预算与折算权重、污染装备的优秀偏向尚待确认。

| 属性层 | 允许的内容 | 例子 |
| --- | --- | --- |
| 白字 | 各部件候选池中的1—3项不同基础数值，不含概率，优先固定加值 | 火控从武器DPS、射程、急速中取1—3项；装甲从护甲、生命、防御等级中取1—3项 |
| 绿字数值 | 随机数值与条件数值 | 精英生命＋12%、英雄普攻伤害＋9% |
| 绿字概率 | 触发率、暴击率、闪避率等 | 暴击＋3%、真实救援晋升概率＋4% |
| 绿字特殊效果 | 一项明确机制或联动 | 普攻命中积累印记、完成救援后产生短暂护障 |
| 固定能力 | 特定物品的标志能力 | 核武供给、整队转移、绑定英雄支持 |
| 套装效果 | 按所属品质与系列的件数激活 | 独立二件、独立四件、共用或独立六件 |

白字优先按部件使用基础加值，不把“非概率”直接等同于“任何百分比都放白字”。百分比增益主要分配绿字，确需白字百分比的部件另行明确；概率只进入绿字或明确机制。白字的属性种类、单位、对象、计算位置先逐项确认，再定各品质数值区间。

| 品质 | 单件绿字数量 | 状态 | 套装形式 |
| --- | --- | --- | --- |
| 白 | 0 | 既有规则 | 不设白色套装 |
| 绿 | 固定1条 | 已确认 | 独立二件套 |
| 蓝 | 固定2条不同绿字 | 已确认 | 独立四件套，或与紫共用的六件套 |
| 紫 | 固定3条不同绿字 | 已确认 | 蓝件可下位替代的共用六件套，或独立六件套 |
| 橙 | 固定3条不同绿字 | 已确认 | 独立二件套；也可有传奇散件 |

单件绿字数量已全部确认：白0、绿1、蓝2、紫3、橙3；多条时使用不同的合法词条。词条从本部位合法池抽取，固定技能与套装效果不占随机绿字条数；原有白字1—3项和MOSS／支援无白字、蓝色起的规则保留。特殊绿字可以存在于不同品质装备；套装件也可以拥有特殊绿字。单条特殊绿字、物品固定能力与整套效果分别分配强度，避免把完整六件机制无成本塞进一条词条。

## 英雄固定绑定与精英洗练

一个英雄套装系列绑定一个具体英雄。例如人族英雄统御·诺娃、虫族英雄统御·凯瑞甘、神族英雄统御·阿拉纳克分别绑定nova、kerrigan、alarak，不在出征时弹出五选一。

橙色领袖徽记也拆成固定身份系列，例如雷诺、扎加拉、阿塔尼斯各自的版本；其他已有英雄可以另设对应系列，不把任意两个英雄部件混成一套。英雄绑定不洗练。

精英学院的首批绑定示例为人族marine.1、虫族roach.1、神族stalker.1。精英绑定可以局外洗练，目标从同族、同机制许可的合法精英池选择。产线能力仍要求绑定精英对应的家族和原合法基础产线，不把工厂精英塞进兵营转化。

洗练可对单件或选定同系列多个部件操作，费用按件，统一转换目标后才重新组成一套。洗练仅改精英绑定，保留品质、部位、系列、白字与绿字。候选交互为合法池三选一；是否增加高成本完全指定身份换取另行讨论。

英雄与永久精英来自本局获得的单位资格，不是把舰装本身变成一个额外战场舰船。英雄仍占三身份席位，精英仍按家族容量部署。无合法席位时显示原因并保留待满足资格的来源，不换成材料。

首次成套授予固定英雄或精英要记录本局一次领取。关内反复拆套、重新穿上、换同英雄不同套装不能重复送单位、升军衔或免费复活。关内首次成套也可在合法位置部署绑定身份，不把刚掉落的关键套装强制等到下一局。

已合法获得的永久单位留在本局，脱装后失去相应套装联动，不逆向没收单位。已有军衔不因脱装倒退；降低容量后保留已有身体，暂时禁止超额新增。该换装边界为候选，需与军衔和付费订单一起验证。

## 关内装备与换装

拾取只进入背包，不自动替换。打开背包后可比较清洁物品与当前装备；建议打开装备背包时暂停战斗模拟，确认后继续。污染装备的装备操作禁用，显示“撤离后花点数清洗”。

换装把新物品从背包放入对应装备槽，把旧物品放回刚腾出的背包格，因此满64格也能一换一。主动卸下一件则需要额外空格；仓库物品不能直接传送到关内。

新白字、绿字、套装件数在下一个合法战斗步骤生效。切换MOSS不重置技能CD，切换支援槽不重新赠一轮支援，切换反应堆不重置免费刷新、免单或供弹计时。领取过的英雄、精英、救援目标与同关收益保持原收据。

生命与护盾上限变化不能通过来回换装制造免费恢复；伤损沿统一规则保留。降低容量不删除已有身体，后续接收按新容量检查。队伍、订单、技能施放和已经生成的临时单位都有明确历史来源。

已装备物品退出背包风险。玩家可以把珍贵清洁掉落立即装上保住，但替换下的旧装备会进入风险背包。污染装备无法通过关内穿戴获得这个保护。

## 撤离、战败与检查点恢复

**2026-10-23 D05 更新：** 用户已批准统一按最近成功保存的关间检查点恢复，允许重打当前关。本文其他位置旧“关闭／掉线即失联”描述不再作为当前规则；不尝试根据浏览器退出原因或短时宽限区分主动关闭与崩溃。实现及验证见 `D05_CHECKPOINT_20261023.md`。

战役完成第3、6、9、12、15、18关后的关间开放“撤退结算”，无尽阶段也可主动撤退；特殊关期间须先返回。每次关间都自动保存，不只在可撤退节点保存。选择撤退结束本次出征，成功带走背包物品，不要求完成全部战役。

正常通关后也进入成功撤出结算；进入无尽表示继续携带背包承担风险。自动通关入仓这一安排为候选，最终入口需与现有18关结束和无尽选择流程对齐。

| 结束方式 | 普通背包物品 | 污染背包物品 | 已装备与仓库 |
| --- | --- | --- | --- |
| 成功关间撤离 | 全部带走 | 全部带走，保持未清洗 | 保留 |
| 成功战役撤出 | 全部带走 | 全部带走，保持未清洗 | 保留 |
| 实际战败 | 随机遗失 | 全部遗失 | 保留 |
| 关闭、刷新、崩溃或进程被结束 | 恢复检查点内的背包 | 恢复检查点内的背包 | 随检查点／账户保留 |

关闭不会触发失败结算。恢复时账户、物品位置、部队伤损、订单、购买／奖励回执与关间状态来自同一份完整档案；尚未保存的当前关进度需要重打。新局先保存第一关入口检查点，特殊关使用进入前的关间检查点。关间购买、换装和实际结算会再次保存；写入失败保留上一份完整档案，阻止离开关间，并提供重试和导出。普通离线断网不等于战败。

普通背包物品沿已有每件独立50%遗失方案执行，按2026-10-15统一确认口径不再重复列为待审。遗失范围只看结束时物品是否在背包，不看它来自本次掉落还是旧仓库。被替换进背包的旧橙装也会参与随机遗失；已装备的旧或新物品都保留。

实际战败后普通背包中未被抽中遗失的物品返还仓库，沿已有方案执行，遗失项永久移除，污染背包物品无返还。遗失结果一次生成并记录，重新打开结算界面不会重新抽取；关闭检查点恢复不走这一分支。

撤离成功但仓库空间不足时，先进入待入仓结算，允许整理、分解或选择清洗，已成功撤出的物品安全保留。待入仓物品处理完成后才开始下一次出征，避免用结算页积累无限额外仓库。

## 污染掉落与粉尘清洗

**2026-10-15价格更新：用户明确清洗价格＝合成价格的1/4。** 下文旧清洗独立试算价不再作为当前价格依据。炉石式拆解／粉尘合成方向已有设计，继续沿用；此轮并未逐项批准旧粉尘数值、定向溢价或账户合并。比例按对应合成价格计算，计价档位已确定为同品质随机合成基价，用户已进一步确认清洗统一使用装备粉尘，旧独立点数方案撤回。

污染是物品状态，不是第六种品质。掉落品质先受简单／普通／困难品质池约束，再在同品质下生成优秀装备与更高合法套装权重。

| 阶段 | 可以做什么 | 物品状态 |
| --- | --- | --- |
| 关内污染掉落 | 拾取、查看品质和部位、丢弃 | 在背包，不能装备、拆尘、换取或洗练 |
| 失联 | 结算背包污染全部遗失 | 永久移除 |
| 成功撤离 | 安全进入仓库或待入仓结算 | 仍污染，不能装备 |
| 局外支付装备粉尘 | 完成清洗并揭示完整装备结果 | 转为正常清洁装备 |
| 清洗之后 | 装备、拆尘、换取、精英绑定洗练 | 按正常物品规则处理 |

污染物品成功入仓后不受以后其他出征失联影响，可以等粉尘足够再洗。污染不是装备负面战斗效果，因为未清洗装备根本不能上舰。

当前属性生成执行白字总稿、套装固定白字表和绿字稿：普通属性散件五种双白字组合各20%，套装按特性固定分配；普通绿字按已定成色分布生成，污染随机绿字直接满值。旧200分白字、污染70—100分位、额外提高套装权重及污染白装表述均撤回。污染资格、概率与合法模板分支只执行2026-10-15分层掉落定案，不叠加旧污染池。

物品品质、部位、套装归属、绑定身份与词条结果在掉落时生成并保存；清洗是支付与揭示，不重新抽奖。关内可显示品质、部位和污染标记，完整词条与套装身份在清洗后揭示为候选呈现方式。

| 实际品质 | 清洗费（装备粉尘） |
| --- | ---: |
| 蓝 | 25 |
| 紫 | 100 |
| 橙 | 400 |

白绿不可污染，不设清洗；蓝模块等禁止污染模板也不能使用本表恢复资格。

清洗、拆尘换取及合法洗练统一使用装备粉尘；旧独立清洗点数方案撤回。粉尘不占背包格，既有账户数据处理留到MVP收尾。

## 掉落来源与刷取节奏

| 来源 | 触发候选 | 收益边界 |
| --- | --- | --- |
| 普通真实敌人 | 1%一次舰装 | 从本难度品质池生成 |
| 精英敌人 | 35%一次舰装 | 可提高合法蓝、紫、橙权重 |
| Boss／领主 | 保证一件，品质至少蓝 | 简单上限蓝，普通上限紫，困难上限橙 |
| 特殊敌人 | 独立50%一次舰装机会 | 原资源、卡或趣味道具收益另算 |
| 支线完成 | 独立25%一次舰装机会 | 实际完成一次，不替代任务收益 |
| 污染来源 | 另定出现比例 | 同品质优秀结果与更高套装权重，须撤离清洗 |

掉落触发率为候选，需按真实敌量和64格背包节奏校准。拾取不再直接入永久仓库，低价值重复装备能否转成粉尘取决于是否成功带回或在失联结算中幸存。

可保留通用60%、本族35%、其他族5%的智能掉落候选，权重另行试算。品质、污染状态、部位和词条在生成时固定，重复载入不能重抽。玩家生成的友军、幻象、重复转化和临时援军不产生舰装收益链。

本版不沿用每分钟自动给合金、异构核心并保证失败收益的旧方案。长期进度由撤出装备、幸存物品、粉尘换取、清洗点数与新构筑积累；失联有真实代价，不另发装备或材料补偿遗失。

## 拆尘与定向换取

参考炉石“把不需要的物品拆为统一材料，再以更高成本制作需要的物品”的原则，采用舰装粉尘账户；绿色品质和定向套装溢价由本游戏自行设计。[炉石官方制作与分解说明](https://hearthstone.blizzard.com/en-us/news/10245930/hearthstone-crafting-in-dust-we-trust)

| 品质 | 单件拆尘候选 | 随机同品质换取基价候选 |
| --- | --- | --- |
| 白 | 5 | 10 |
| 绿 | 10 | 40 |
| 蓝 | 20 | 100 |
| 紫 | 100 | 400 |
| 橙 | 400 | 1600 |

以上为本游戏试算，不是照搬炉石的全部品质和比例。拆解销毁物品，所得粉尘少于大多数同品质换取成本。污染物品须先成功撤离并清洗才能拆解；精英或英雄单位本身、原任务奖励不拆成舰装粉尘。

| 换取选项 | 候选费用 | 能确定什么 |
| --- | --- | --- |
| 随机同品质 | 基价 | 品质，具体物品未知 |
| 指定套装 | 基价×1.5 | 品质、套装系列及其绑定身份；部位随机 |
| 指定套装＋部位 | 基价×2.5 | 品质、系列、绑定身份和实际部位；属性仍随机 |
| 未知橙色 | 1600粉尘 | 保证橙色，散件／二件套系列和部位随机 |

例如指定蓝色战地搜寻为150粉尘，指定该蓝套的兵员部位为250；指定紫色老兵为600，指定紫套加部位为1000；指定橙色领袖套为2400，指定该套加部位为4000。部位越明确，费用越高。

指定换取不要求先掉落该套或收集三个部位，旧稿的三件登记门槛与已持有传奇蓝图门槛取消。可选清单只包含已经正式定义的同品质系列；蓝紫共用系列可选择蓝或紫价格，紫独立套不生成不存在的蓝版本。

未知橙色暂按兑换前内容未知的随机橙装设计，不等于保证未收藏橙装；是否增加未收录保护待定。当前种族倾向可选，属性仍按合法生成池抽取。换取在局外直接产生清洁装备，不生成需要再洗的污染物品。
