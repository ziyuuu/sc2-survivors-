# 玩家数据与意见反馈说明（发布拟稿）

适用于联网Web版。版本：2026-09-30。发布前填写【运营者名称】【联系渠道】并使本文与实际实现、数据库、备份及平台配置一致；当前尚未启用采集。

我们希望了解游戏是否好玩、哪些关卡太难、加载是否重复，以及不同部队与卡牌是否有价值。

**是否参加体验统计由你选择。不同意或随时关闭，都可以正常游玩。**

### 选择参加统计后

我们会使用本网站随机生成的浏览器标识，记录访问和回访，以及以下游戏摘要：版本、手机/电脑类型、横竖屏、加载与缓存情况、种族、难度、等级、天赋与阵容、卡牌选择、关卡进度、战斗时长、输出/恢复/伤亡、帧率和错误类别。

这些数据用于改进加载、操作、性能、平衡和内容。浏览器标识用于区分访问，不代表你的真实身份；换设备、无痕浏览或清理网站数据后可能被统计为新的终端。

我们不自动上传完整存档、截图、回放或操作轨迹，不采集姓名、精确位置、通讯录、账号密码或本地文件，不使用设备指纹或跨站追踪。你的本地存档、永久成长和资源缓存与体验统计分开保存。

### 提交意见

“反馈”可以单独使用，不要求参加体验统计。提交时收集你填写的正文、分类，以及你选择附带的版本/种族/难度/关卡摘要。联系方式可不填写；填写后仅用于处理该条反馈，不用于广告。

请不要在反馈中填写密码、身份证等敏感信息。提交成功会提供编号及本机查看/删除入口。

### 数据如何保存

统计与反馈由【运营者名称】通过部署服务和数据库处理，不公开个人明细，仅授权管理员可以查看。联网请求会涉及必要的网络传输信息；应用统计数据库不保存IP，托管平台运维日志按发布时列明的平台规则处理。

拟保留期限：原始统计事件90天；可关联的战局摘要180天；浏览器去重记录在最后活跃365天后删除；不带浏览器标识的汇总最长730天；反馈及联系方式180天。到期删除或去除可关联标识。备份中的删除覆盖期限在正式发布时补充说明。

### 你的选择

在“设置 → 数据与隐私”中，可以查看说明、关闭统计或申请删除本浏览器可关联数据。关闭后停止采集并清除待发送统计；不会删除游戏存档、天赋、余额或下载资源。

反馈可以用本机保存的反馈凭据单独申请删除。清理网站数据会丢失本机标识与凭据；遇到问题可联系【联系渠道】。已经去除关联标识的汇总无法再定位到个人。

离线单HTML默认不上报，也不会在你后来联网时补传未授权的游玩历史。

首次提示按钮：**「参加体验统计」／「暂不参加」／「查看说明」**。不预先勾选，不以继续游戏视为同意。正式发布增加数据用途或字段时更新说明并重新取得相应选择。
