## 一 蓝紫幻影共用继承规则

蓝色与紫色幻影共用资格、能力与特效继承规则，仅各自已列数量、生成批次等参数不同。撤销蓝稿“一概不复制精英主动能力”的旧句。

幻影保留来源当前形态、合法普攻、被动、已解锁原生伤害／治疗／护盾／控制能力，以及适用暴击、吸血和装备攻击特效；沿实际目标资格、能量、冷却和存活条件执行。来源没有的能力不新增，生成时不将原本正在冷却的能力免费刷新。生命／伤害采用既定50%快照；原生治疗／回盾的输出量也按复制比例承接，不复制一份全额辅助输出，原持续时间／控制资格不额外提高。

幻影不复制英雄、临援或幻影，不触发捕获、再次复制、永久赠兵、军衔成长、经济收益／额外掉落或复活；到期不是战斗阵亡。其合法攻击造成真实敌人死亡仍只正常结算该敌人的基础奖励一次，不额外复制奖励。

原生有限造物不能一概删掉：航母使用所属真实子机通道，不能给幻影母舰制造假普攻；布雷等有限原生造物可沿原机制运行。幻影与它产生的造物共同承接同一份复制后输出，不能再乘一次装备加值；造物不产生新幻影、捕获或经济成长。数量沿该原生系统上限，寿命不超过幻影剩余寿命，母体消失后清理其持续造物；已实际提交的在途命中沿原生来源消失规则处理。幻影不能通过召唤复刻完整无限成长来源。

## 二 捕获按正常武器周期判定

一次正常武器周期最多对它的原主目标进行一次捕获抽样。多弹、多段、双武器和同周期重复命中共享该次资格；溅射、弹射邻敌、技能、装备追加攻击、DOT不另开捕获抽样。真实子机使用各自正常攻击周期，沿原实际攻击频率，不能再由母舰重复判一次；幻影及其造物没有捕获资格。

每次主目标直接命中先结算伤害。该周期首次出现“目标仍存活且生命低于30%、身份合法、尚有容量、共享成功冷却结束”的命中时，抽样一次并记录本周期已抽样；失败后本周期其他弹不重抽。不满足资格时不抽、不消耗成功冷却。致死命中先完成死亡，不能从尸体捕获或撤销击杀；后来别的合法正常周期仍可尝试。

成功时原子转换一次；同刻其他攻击重新检查阵营，不重复捕获或奖励。此前已在途的其他攻击沿原生敌我／失效规则处理，不为了捕获补伤或重发。保留捕获时伤势与合法战斗强度，不免费补满、不剥除既有难度强化、不随以后波次再次增长难度倍率。

简单／普通／困难／地狱10%／10%／7.5%／5%、成功冷却15秒及来源容量5（含开场2只）仍沿上轮数值提案；本次确认的是判定单位与轻量边界，没有新增捕获货币或操作按钮。

## 三 装备攻击分支不互相重启

一次正常攻击及其原生命中表现构成原攻击链。满足各自条件时，可在该链上启动多个合法装备效果；每个效果按自身原有次数／冷却结算，不因此让双重打击、分裂、过载变成只能三选一。

装备产生的追加命中、追击、爆点、弹射、旋风等标记为派生攻击。它们保留原条目允许的暴击、吸血和原生表现，但不得再启动任何装备追加攻击／复制／捕获分支，不仅是禁止同名递归。原效果明确约定的多跳或二次爆点仍属于同一有限执行链，按原次数执行，不被误删。

例如：正常主击可触发分裂，主击暴击击杀也可触发破阵；分裂杀敌不会再开启破阵追击，破阵追击也不会再开启分裂。暴击杀敌判定读取真实主攻击结果，不把派生攻击的击杀倒记给主攻击。原生单位已有的多弹、顺劈、回响和科技分支不因装备规则消失，但不能把派生命中伪装成新的正常武器周期。

固定装备DPS／真实DPS共用原预算。原生副击从已增强主包派生时不再次乘专属增强；已复制的单位快照也不二次领取全额装备属性。幻影自己的正常攻击仍可触发允许的有限攻击特效，唯独不生成更多幻影／永久成员等禁止来源。

## 四 保命与分担的固定顺序

1. 先执行原攻击资格、闪避、原生防护和护甲／减伤／护盾等已有结算，得到将进入本体生命的伤害。无敌或护盾已挡下的部分不再用于分担或“实际受伤”充能。
2. 铁卫将合格最终生命伤害的20%按既定同家族伙伴资格分担，原受击者承担余量。转移包不再次经伙伴护甲、护盾、普通减伤或再次分担；没有合格伙伴则原受击者承担全部。
3. 原受击者与分担伙伴分别判断剩余伤害。各自原有致死保护及紫肾上腺素濒死狂暴先处理；仅真实跨过触发阈值或满足致死条件时消耗该来源资格。分担不能绕过受伤者自身明确的无敌／最低生命保护，也不能因被保护而将伤害反弹回原受击者。
4. 前序保护仍未化解致死时，才判断本家族当前最高生效档的荣誉保险。紫档：合格永久普通兵军衔至少Ⅱ、当关未用，降一级后按新最大生命70%存活。已确认橙档：Ⅰ级亦可，每成员每关一次，不降衔、100%生命存活，并获得最大生命100%的专属护盾5秒，不额外回满原生盾。两档不同时触发，均不算死亡、不占生存者六件救援资格。
5. 仍然致死才登记一次真实死亡，随后根据生存者或其他合法复活来源登记救援。一个实际死亡成员不能被两个来源重复救回；双身体按已有成员／席位语义处理。自然到期、自爆及退役按原排除规则执行。

铁卫反击、受伤储能等只记各自实际损失的生命／护盾一次；转移前后不能重复记同一部分。保护次数与降衔是实际事件，暂停、读档、复活不回滚当关使用记录。复活源之间若同时满足，先保留已登记的合法救援，其他源不消耗次数；同刻无登记时按稳定来源顺序选择，不增加选择界面。

## 五 战斗换属性散件的连续状态

只有无套装身份的属性散件可关内更换，模块与套装仅局外更换，关间不例外；污染待清洗及既有来源锁定继续优先。更换是一次完整事务，旧效果撤下、新效果从原生基准重建后一起提交，不出现中间空装备帧。

| 状态 | 统一处理 |
| --- | --- |
| 当前生命／原生盾 | 采用原稿生命比例方案：分别保持各自当前比例，新值＝旧比例×新上限。死亡保持死亡；旧上限为0的池不凭换装填满。比例调整不是治疗／受伤事件，不触发吸血、反击、破盾、濒死狂暴或伤害统计 |
| 冷却／周期／次数 | 按同效果来源身份延续；同名副本和三族别名共用已有资格，不能换一件重置。离线槽不积累新的装备周期奖励；已有时间冷却随有效战斗时钟正常推进，暂停冻结 |
| 已提交弹道／技能 | 保留提交时的数值和来源快照，沿原生合法性处理到达；换装不删除已发射的攻击，也不把新装备补到旧弹道上 |
| 护盾反应装置的人／虫专属盾 | 卸下立即移除该装备自己贡献的盾，不触发“被敌人击破”或破盾奖励；其他原生盾／其他来源盾保留。重新装备须重新满足连续脱战5秒建立首盾，不能立刻领满或靠换装绕过紫档8秒再生条件 |
| 护盾反应装置的神族恢复 | 卸下即停止该件后续回血；此前真实恢复的生命保留。不会追回合法治疗，也不会补发离线期间回血 |
| 战场调控装置 | 成功召回的真实位置保留，原30秒成功冷却不刷新。紫件已生成的幻影按原寿命继续；按现有“成功赠送单位锁定来源”规则，该件生成幻影后本次出征不可换下，不另设新类型锁定 |
