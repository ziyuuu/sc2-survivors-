## 分支里的三种牌怎样取得

现有商店还有「全军火力」「全军防御」等全军牌，以及给合格兵种的训练周转、恢复增效等普通强化。它们与新分支牌共享货架和同一份矿气，按各自报价购买。通用牌买到即生效，各分支计数保持原值。每三张的紫节点只按同一分支的普通牌计算。

| 类型 | 品质 | 玩家的取得方式 |
| --- | --- | --- |
| 普通分支牌 | 白、绿、蓝、紫 | 首购给所属分支记一张。白牌同名复购只提升原牌强度。普通紫自带完成牌效的手段，作为本分支首张牌或降权后的副牌仍能完整生效。 |
| 节点牌 | 紫 | 每支有效进度累计到 **3、6、9……** 时可建立一次节点选择，锁主后只开放本支节点。节点可专精一类已有火力、援军或道具，也可联动多种支援。节点自身不推进普通牌计数。 |
| 终极牌 | 橙 | 只有锁定的主分支有资格取得。橙牌能打出这条路线的标志性战斗场面。首次出现的关段、取得方式和每局数量待定。 |

**玩家实际选下的第一张分支紫节点决定本局唯一主分支。** 三次买同名白卡仍是 1 个进度。某支达到 3 的那笔普通牌照常生效，并产生本支第一次待领机会。普通紫的购买、到达门槛、打开或延后节点均保持未锁状态，直至一次节点领取成功。另两个分支已购的普通牌继续生效，新货架里的副分支普通牌降权，紫节点与橙节点仅从主分支取得。已显示的普通牌保留原报价。

**一次混搭的例子。** 生化协同与武装支援各有 2 点。买生化的「嗜血」到 3 点，玩家延后领取，再买「蜘蛛雷」使武装也到 3 点。两张普通牌均生效。此时若选武装紫节点，生化待领机会关闭，本局只可取得武装节点和终极。武装自身累计 6、9 点仍可继续领。领取前后分别保存，可恢复当时的选择范围。

## 关间把资源花在哪里

**晶体矿和瓦斯都专供卡牌。** 钱包为空时，建筑发展、解锁兵种、训练、取得常规增援及战损补员都能照常推进。特殊身份牌可以解锁一项构筑能力，首次出兵和后续补员均无第二笔两币收费。样例按普通牌标价、里程碑节点直接领取演示。刷新若保留，可采用免费次数。具体牌价、两种资源各自的定价作用、橙牌如何取得仍待定。

11 月 10 日的武装支援试算先让玩家继续买通用牌，再看当局能取得几张分支牌。第一笔钱就可能要在全军加火力和提前一张进节点之间选择。武装暂以 3 张有特色、6 张能打出完整循环为试玩目标，继续投资可在第 9 张取得第三次节点选择。[武装支援的逐关混买账](V1_3_TERRAN_ARMED_SUPPORT_20261109.md#17-个关间的混买样例)

**这套经济排在 1.4 第一批，对三族生效。** 拟让基础发展随关段推进，由玩家选生产方向，日常增援按该方向自动到队。战场上仍能看见空投、出巢或折跃，重机阵亡后仍有补员等待和编制空缺。比如缺了劫掠者，可以安排常规补员，同时把存下的晶体矿和瓦斯留给「嗜血」或「烈焰升腾」。同批简化战斗投放与掉落获取，增加低血量小怪。1.4 第二批接入人族牌池时，就能检验这些牌在密集弱敌中的实际效果。[1.4 第一批安排与验收样例](V1X_ROADMAP_20261104.md#第一批-三族共用玩法)

## 九条分支的牌池样例

当前九条共列 **153 个分支卡位**。武装支援 45 张已有本地候选，末日兵器 45 张为设计候选，其余七条共列 63 张早期样牌。通用牌另算。逐支检验普通紫的独立战果、节点的协同、与通用牌混买的经济节奏。

逐支先设计玩家能看出的战场变化，再校准伤害。武装支援能看见空仓吸走虫群、枪兵接上压制炮火。虫族菌毯可以从主力脚下的卵相继成熟、爆虫接连扑出来读出繁殖强度。神族共享护盾时要看得出哪一名队友的盾先暗下去、谁接住了那次攻击。每处表现都对应一次真实的出勤、出生或承伤。

| 普通 · 绿 | 层生甲壳 | 虫体接战时先用外甲吸收伤害，脱离集火后可重新长好，老蟑螂的甲更厚。 |

| 普通 · 绿 | 孢子胆汁 | 破坏者的胆汁落点留下感染区，前排把敌群拖住就能多打几跳。 |

| 普通 · 蓝 | 迟发毒囊 | 目标离开感染区后仍承受最后一跳毒伤。 |
| 普通 · 紫 | 疫群传染 | 染病目标死亡时，把剩余毒效传播给附近的新目标。 |
| 普通 · 紫 | 深层寄生 | 强敌存活足够久时，成熟虫卵会在体内爆发，让首领战也有合法伤害。 |
| 节点 · 紫 | 混合感染 | 一名敌人同时受到两种不同感染时，会发生一次毒发，把两名后排的攻击合成一次实际收益。 |
| 节点 · 紫 | 前线诱饵 | 感染目标攻击己方常驻前排时，会催熟身上的毒效。前排多撑一个攻击周期，就给后排多争取一次爆发。 |
| 终极 · 橙 | 疫巢爆发 | 场上感染最深的敌人成为一轮疫巢中心，附近已染病目标依次毒发，成熟寄生囊在宿体真正死亡时出虫。强敌能承受毒伤，继续保有自身的控制限制。 |

关间可以免费把缺额留给蟑螂，把两币用于强化感染方式的牌。补员等待和后排暴露的风险仍然存在。

### 菌毯

主力聚集处形成繁殖菌毯，原地持续交战会越打越多。阈值按常驻主力名额计。试玩可先比较满速、减速、暂停三档，例如三席、两席、一席。已孵出的虫仍然战斗，本作已有菌毯移速只结算一次。

| 类型与品质 | 卡名 | 下一战的效果 |
| --- | --- | --- |
| 普通 · 白 | 行军菌毯 | 主力聚集处长出菌斑，持续孵出限时小虫。转场后旧菌斑渐退，新集结点重新生长。 |
| 普通 · 绿 | 随军育囊 | 蟑螂或虫后的育囊能周期产虫，在成熟菌斑上孵得更快。 |
| 普通 · 蓝 | 爆裂虫卵 | 队伍产下能孵出一次性自爆虫的卵，已有繁殖菌毯会把部分批次换成爆虫。 |
| 普通 · 蓝 | 应急孵囊 | 主力首次跌破阈值时放出一批储备卵，缓和眼前的断档。 |
| 普通 · 紫 | 迁徙虫潮 | 转场时主力携走一批接近孵化的卵，在新集结点接上虫潮。 |
| 普通 · 紫 | 爆裂孵床 | 在同一菌斑持续作战时孵出更大的爆虫批次，频繁搬迁会损失蓄积。 |
| 节点 · 紫 | 连片育床 | 主力维持满速档时，每孵完一批就给下一批多备一枚卵，直到在场上限。 |
| 节点 · 紫 | 轮孵 | 成熟菌斑交替孵出先行小虫和跟进爆虫。主力掉档后，两批之间的间隔都会拉长。 |
| 终极 · 橙 | 奔涌虫巢 | 达到阈值的成熟菌斑同时维持扑击与自爆两支虫潮。战线推进时新菌斑可接续，常驻主力跌破阈值仍会减产或停产。 |

新生体只贡献火力，不维持繁殖阈值。常规普通／精英爆虫的爆后休眠沿用自身规则，本牌的临时自爆虫在爆炸后结束。

## 神族

### 灵能掌控

普攻改变落点上的敌群，施法单位靠回能与真实施法增加爆发次数。玩家带队把散开的追兵引到一起，范围攻击的价值立即可见。

| 普通 · 绿 | 灵能蓄积 | 常驻攻击单位用真实普攻蓄能，蓄满后自动向合法敌群释放灵能爆发。 |
| 普通 · 蓝 | 圣堂导流 | 加快有能量单位的回能，满足条件后更频繁施法。高阶圣堂武士的风暴仍需已有科技。 |

| 节点 · 紫 | 交叠力场 | 两名队员的真实灵能落点相交时，在交界处形成一次短暂爆发，适合压迫密集敌群。 |
| 终极 · 橙 | 灵能风暴场 | 集中交战时，连续命中与真实施法共同张开一片风暴场，期间队员的范围攻击在场内接力爆发。衍生脉冲不能再次给自身充能。 |

### 辉煌神灵

用一代龙骑士和《母巢之战》的黑暗执政官（红球）提供远程火力与法术支援。两张身份牌购买的是持续可用的古代科技。首个个体及阵亡后的替补均按编制、到队时机兑现，不收晶体矿或瓦斯兵价。

### 意念合一

一处受击牵动周围队员的实盾，持盾又决定本体和幻象能用什么攻击形态。整队吃到范围伤害时最容易失去优势。

| 类型与品质 | 卡名 | 下一战的效果 |
| --- | --- | --- |
| 普通 · 白 | 护盾联结 | 受击者的盾不足时，一名邻近真队员用自己的现有护盾分担余量，双方的盾都耗尽后才伤及生命。 |
| 普通 · 绿 | 幻象协击 | 真队员完成一轮攻击后，周期性投出一道幻象，从侧面打出一次弱化普攻后消散。 |
| 普通 · 蓝 | 相位战姿 | 自身有盾时进入特殊攻击形态。狂热者双刃重斩，追猎者收束火力。破盾后恢复普通攻击。 |
| 普通 · 蓝 | 同步回盾 | 联结双方均脱离受击并开始自然回盾时，加快双方恢复。 |
| 普通 · 紫 | 镜像夹击 | 有盾成员的幻象与本体集中攻击同一个强敌。 |
| 普通 · 紫 | 护盾接棒 | 替前排分担伤害后仍有盾的供盾者可以还击一次。 |
| 节点 · 紫 | 折光编队 | 一次实际分担护盾后，在获救队员侧面生成供盾者的攻击幻象，把防守转成一次协击。 |
| 节点 · 紫 | 护盾轮值 | 联结优先由盾量较足的成员承担消耗，保住下一名友军的有盾战姿。供盾者失去最后一格自身盾，同样退出强化形态。 |
| 终极 · 橙 | 统一意志 | 联结成功时，仍有自身护盾的成员可以让幻象同步复现一次弱化的战姿攻击。盾线崩溃，齐射也会衰减。分担只扣一份真实伤害，幻象不递归生成幻象。 |

## 用一波敌人看出构筑差别

| 战况 | 观察点 |
| --- | --- |
| 人族遇到一群低血量敌人，随后损失一名主力 | 武装支援靠炮击与下一批空投补上火力。末日兵器能穿透清群，失去巨型重机后需要等待替补。生化协同实测虫先亡与宿主先亡两种结果。 |
