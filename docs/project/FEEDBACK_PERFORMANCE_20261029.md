## 本轮结果：重复音频解码

已复现的主要开销来自音效准备：当前范围需要预解码的声音超过手机预算下的32 MiB PCM缓存。缓存按预算回收前面的声音，但每次关间又要求把整批声音重新解码，因而在阵容未变化、没有新增模型时仍重复等待。

`src/render/effects/audio.ts`现记录本音频会话中成功校验和解码过的片段。关间不再强制回填已按预算回收的声音；实际播放仍检查缓存并补回缺失片段。读取或解码失败撤销对应记录，下一次准备可重试；取消不把未完成片段标为成功。跨局保留同一音频会话缓存，新页面或新的音频实例重新校验。

原音源、音量、变体抽取与播放规则、32 MiB预算、画质、RNG、战斗和保存机制均保持。此次没有修改加载页及其120毫秒显示逻辑。
