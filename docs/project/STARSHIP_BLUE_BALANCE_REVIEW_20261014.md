# 蓝装平衡与联动审查

日期：2026-10-14。审查当前STARSHIP_BLUE_ITEMS与STARSHIP_BLUE_EXPANSION两稿；不改用户已确认数值。本次只有文档比对、规则推演和有限算术核验，没有装备运行实现或实战平衡结果。

## 已能由设计直接确认

### 精英六件的获得成本明显不利，但不等于所有场景严格劣于两件

- 我是谁2件：随机Ⅲ级异族精英1名，不可升级／复活。
- 赏金猎人2件：达到建议500水晶后有Ⅰ级精英，累计2500后同一成员Ⅴ级，不再新增。
- 独立精英6件：绑定Ⅱ级精英1名，生命＋8%、普攻＋5%。
- 蓝训练2＋蓝团队2＋绿特殊来电2：3名Ⅲ级本族同类型精英，再余2槽可配其他套装。依据现有联动，确实合法；不得错误用“同名家族不能叠加”拒绝这三个不同家族。

确定身份、可正常培养／复活、随机异族与获得时间都是差别，所以不能只数军衔认定所有情况下绝对劣势；但六件精英缺少独有收益，单靠绑定身份难解释四个额外槽位及一次少掉四条随机绿字的成本。绿特殊来电极稀少是用户设定，稀有只能控制可得性，不能证明拥有后的比较平衡。

建议保留已定Ⅱ级、不继续抬初始人数军衔，将六件额外优势指向“本次出征己方精英整体强化”（例如全队精英生命／普攻＋10%—15%，包括合法异族精英，排除幻影复制后的重复增幅），使它可与我是谁／赏金构筑协作。具体增益尚未批准，并需控制低于同方向蓝紫系列。

### 精准六件在常见低中暴击条件下被4＋2方案超过

同样占6槽且损失6条随机绿字，比较：

- 精准6：射程＋5%、暴击率＋4个百分点、暴伤＋35个百分点。
- 破阵4＋精准2：相同射程＋5%、攻击＋8%、暴击率＋8个百分点。

取当前普通暴击175%，其余暴击率20%、无其他攻击与暴伤增益，忽略护甲／命中变化、无上限截断：精准6的护甲前期望普通伤害倍率1＋0.24×1.10＝1.264；混搭为1.08×(1＋0.28×0.75)＝1.3068，比前者高约3.39%。在同假设下其余暴击约34.76%以上，精准6才反超。这是条件明确的算术结论，不是全武器最终伤害实测。

因此精准可保留高暴击专精定位，但现有独立蓝暴击构筑是否易达门槛尚未验证。建议先调整六件自身临界收益，而不是全体蓝套再加码；可考虑暴伤从35改为55个百分点，保留2／4值。该建议未写入成品表。

### 赠送锁定与后续凑高件数存在碰撞

例：开场呼叫舰队两件赠送空军后，这两个具体部位锁定。途中掉落本系列另两件若刚好是相同部位，无法替换已锁物品；拿到高品质同部位也一样。用户不允许卸赠送装备，不能悄悄取消锁定；这是其确定规则的真实代价，不是代码Bug。

此外独立英雄6何时允许把4件精英变英雄当前仍是条件性提案；呼叫舰队已经建议可关内升级一次。建议统一“向更高阶一次转换同一来源成员”的资格，若用户要保持仅开场则两者都清楚写仅开场。不能复活已死奖励、不能重复发放单位。没有用户授权，不引入奖励债务转移或锁定部件自由更换。

### 来源标签决定联动，当前需要一张统一表

普通兵随行、永久精英、临时援兵、幻影、固定Ⅲ级异族精英含义不能混同：

| 来源 | 已定／已提议的联动 |
| --- | --- |
| 我是谁 | 不可升级、不可复活的明确例外；军衔套、猎蜂人不能绕过，仍可获得普通数值强化 |
| 赏金猎人 | 后续拾矿只培养其首次成员，不拿另一名同身份单位顶替；Ⅴ级封顶，不再次生新精英 |
| 狗哨／蟑螂拍 | 训练有素可强化开场军衔；不占名额，不被特殊来电全部改为精英 |
| 幻影 | 不可复制自身，不晋升、不复活、不再次生成奖励；到期不是可复活的普通兵阵亡 |
| 周期临援 | 不占名额，各自到期，不因生存者变成永久单位 |
| 普通招募成员 | 正常永久编制，可培养；生存者应只救此类合法永久普通兵，不抢救短时临援 |

建议生存者首次死亡资格明确排除临援、复制体与有倒计时的召唤物，否则出征仅一次机会可能浪费在临时单位，甚至绕过到期规则。此是设计作用对象需澄清，不以兼容旧代码为理由增加系统。

异族随行装备增益也需统一：建议全军通用词条按所属玩家旗舰应用，不因异族身体而丢失；方向／身份限定词条仍按合法目标筛选，种族特有生理机制按该单位自身规则。此建议不把本族方向强化变成无条件全队强化，尚未批准。

## 已成立的合理取舍／联动

- 部队6与军衔6分别强化数量与成长，是长期路线；训练2／团队2是开场路线，不能只比第1关判胜负。
- 训练＋团队＋特殊来电是用户要求的开场强联动，先承认其合法，再确定绑定精英6应有何独特价值，不私自取消组合。
- 火炮过载＋肾上腺素可以借自损进入低血量攻速翻倍，属于合理风险收益；不需因为存在联动就禁用。
- 幻影4＋其他2件会受“最多5只、30秒、共享生成CD、无递归”约束；已有护栏不是平衡通过证明。
- 常规4件可以作为主套，也可以4＋4；六件不应无条件胜所有组合，但必须在自身专长条件下有明确收益。

## 需要实战的风险，不提前判失衡

- 训犬大师的5只Ⅲ级跳虫可战斗补员，对比蓝训练＋蟑螂拍的2只Ⅲ级蟑螂：同4槽，兵种、生存与补员不同，不能仅按数量说哪套必强。
- 全8蓝最佳选择提供8次免费运营刷新，可能把运营随机性接近定向选择；需依据每轮候选池、允许重复与选择次数测算，不能把“刷新次数多”直接当无限领取奖励。
- 幻影可复制精英，即使50%也可能对普攻强精英极有利；需按真实兵种武器、子机预算与存活率验证。
- 生存者6从每关救一次降为整次出征救一次，长期收益显著降低；现阶段可能反而偏弱，但首个死亡成员价值与战损频率未知，不能凭感觉再次抬回原版。
- 自动战场调控是否把重型单位送进危险位置，需实际地图检查；30秒CD合法并不能证明落点总是合理。

## 审查结论

优先处理精英6的独特收益、精准6的收益门槛、赠送奖励的高阶转换口径与来源资格；不对整批蓝装再整体升降数值。蓝紫系列尚未全部数值定稿，独立蓝低于成型蓝紫目前是设计目标，不是已验证结论。


## 用户处理结论（2026-10-14）

用户仅批准以下四项，已同步至[蓝装扩展效果表](STARSHIP_BLUE_EXPANSION_20261014.md)：

- 精英六件保留绑定精英升Ⅱ级，追加全队精英最大生命、普攻伤害＋15%。
- 精准六件的暴击伤害加值改为55个百分点。
- 生存者六件仅救永久普通兵；临时援兵、复制体及到期召唤物不消耗救援资格，其余次数、延迟、军衔和生命恢复规则不变。
- 异族随行单位也享受所属玩家旗舰的通用全军装备加成；方向、身份和武器等限定仍按原规则筛选。

上文35个百分点的精准六件计算及旧版精英六件比较保留为调整前的审查依据；当前效果以扩展表为准。异族随行加成建议现已批准。其他建议、数值和待实战风险保持原状，不据此追加调整。本次仅同步设计文档，未修改运行实现。
