# 孤星购买与一键装备修复

2026-11-06，用户要求修复已复现的两项 bug。FB-20261105-02、FB-20261105-03 已本地实现并验证，未提交、推送、部署或更新既有交付包。基于 `体积优化版`、HEAD `6510fb2` 的共享工作区；既有教学等修改保留。本批不处理仍待细化的无尽参数。

## 孤星购买

关间橙色精英商品的目标军衔在精英进入队伍、属性刷新及吸收前生效，不再在吸收后查找已移除的单位。紫色仍按I级、橙色按V级计入原成长公式；已有孤星时只提升同一身体，不继承被吸收精英的技能。

购买沿用原扣费、售罄与回执路径。重复点击和恢复后再次购买均被拒绝，不重复扣费或成长。非孤星的现有精英升级、满队替换及取消流程也已覆盖。没有修改成长系数、存档格式或历史吸收回执；本次不会猜测并追扣旧版本已经产生的未付款成长。

## 一键装备

原来的“现装不是普通散件就跳过”改为只跳过独立受保护物品。局外旗舰、仓库和关间背包沿用原按钮，允许更高品质的合法普通散件替换旧功能装备。局外可换旧套装；关间的套装更换资格仍按原规则执行，不会阻止其他合法槽位换装。

同品质保留现装；主动锁定、收藏、来源锁定、污染、所属仓库/背包与战斗阶段限制继续生效。候选仍只选普通属性散件，不自动挑选新套装或模块。整批换装只更新一次账户版本，旧装备回到原候选所在的仓库或背包，不丢失、不复制、不消耗RNG。

替换旧功能装备或含继承效果的物品时，现有操作提示显示“已换装，原装备效果可能变化”。复用原提示样式和时长，不增加确认弹窗、入口或页面布局。
