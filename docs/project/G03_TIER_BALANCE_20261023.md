3. **不建议统一降低全部敌人或直接增加矿气。** 本批同时存在毕业候选余量较大、开荒补兵未到位及目标处理不足；全局修改可能掩盖这些差异，且本批未测出可靠的统一调整比例。

## 配装与控制方式

原生开局/地图/生产/购买/培养/掉落/换装/英雄抽选/特殊关及18关到无尽转场；无锁血、强制击杀、战中注入单位或钱包补款。原批公开可见敌人接近时优先战斗；这会覆盖地狱扩张巢必做目标，因此追加12条先处理扩张巢再战斗的控制策略重放。又追加6条地狱开荒对照，让至少六成有效火力进入目标射程并使用原生英雄主动技能。原批与先前补测20分钟墙钟截断保留，新6条上限40分钟；均不作为游戏战败或FPS证据。特殊关保留出口移动命令；横穿修复版保留成套装备，进攻版还保留独特装备，其余散件正常升级。

进攻候选：简单联阵/训练/稀有来电各2件加2散件；普通6英雄/2训练；困难6英雄/双重打击/1散件；地狱6英雄/2生存者。三族分别绑定大和战巡、利维坦、净化者旗舰，由装备原生开局效果获得。简单模块为农民/补给/移动射击/风蛇，普通最后一项训象人，困难最后一项联合支援，地狱为悬赏令/满编军备库/弱点接管/大和扫射。候选均经两种子；不宣称穷举污染、继承和全部绑定后的全局最优。

不同候选同时改变套装、模块与起始单位；只能比较完整方案。原36条脚本在出口修复前加载，未嵌入每条运行SHA，以冻结脚本与批次记录归类，不能冒称最终版本；后48条逐条绑定横穿修复版游戏和工具SHA；24条额外重放绑定隔离巨兽修复源，并在收尾与最终主源码逐SHA核对。探索版死亡为15步采样并去重的下界，最终版为原生死亡回调事件（英雄复活后可再次计数），不能直接比较。关末生命快照也不是战斗中最低生命。
