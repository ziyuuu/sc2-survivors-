## 已批准：腐化星灵据点

上限以用户最后决定为准：同时20，整个事件累计40，覆盖原“同时30、无限累计”。用户接受本版建议：初始20（13狂热者、7追猎者），剩余严格少于10时启动一次5秒增援；到期补回20，受累计剩余额度、合法空间和全场上限约束。等于10不触发，不周期盲刷。累计40后不再补员。任一步活体归零优先结束并取消待补员，完成奖励一次。

补出可见腐化星灵据点，复用原生星灵建筑表现；是集结／增援标识，不新增拆建筑领奖玩法。未交战成员在据点附近小范围巡逻。附近普通虫族同样是敌人；玩家进入约8米或主动攻击后才对玩家交战。范围外玩家自动索敌不擅自挑起战斗，显式攻击仍可触发。追击最多约18米，越界撤回，保留实际伤势、死亡、累计出生和奖励回执，不借撤回回血或重置。实际建筑占位与巡逻路径须五图合法。
