## 修改

`V06-TANK-FX-001`：普通坦克命中火星下降或反弹时，原实现仍用初始速度决定拖尾方向，造成反向长线。`src/render/effects/source/particles.ts`改为从同一位置轨迹计算当前运动方向，包含阻力、重力、速度变化、噪声和现有局部力积分结果；触地反射同时反射拖尾方向。

修改仅作用于速度定向的拖尾类型1/6/10。原粒子位置轨迹、发射数量、寿命、纹理、颜色、原始长度及固定/夹限规则保持，未按主观偏好缩短或删除散射层。没有改变World、炮弹、伤害、冷却、RNG、保存或资源清单。

独立[M3Studio字段定义](https://github.com/Solstice245/m3studio/blob/main/structures.xml)和[尾长类型说明](https://github.com/Solstice245/m3studio/blob/main/bl_enum.py)用于核对固定、夹限和自由尾长的区别，不作为已复刻SC2完整粒子引擎的证明。本轮针对已复现的方向错误；未重写重力坐标或地面碰撞算法。
