3. 对简单／普通的三族三装备阶段，按相同种子及相同策略与G03分档前的冻结生产源码对照，共18条。配对中事件和RNG分流会继续改变战斗，整局差值不伪称单一事件的纯因果效应；另按事件来源记录直接矿气、装备及损失。
4. 每条连续路线以十八关结束后无尽前6分钟为目标；单条限制固定步数和墙钟上限，超限标为截断样本，不记作战败或通过。没有连续抵达的后期阶段／无尽，另用明确标注的受控生产样本补查机会、投入和压力，不冒充自然抵达。
5. 诱饵按三档真实价格、四难度、前中后期合法窗口检查原生付费、额外事件、完成收益和风险。先比较可用窗口与实际触发，再用有限配对战斗测量；不能将额外出现次数直接换算为已获得奖励，也不能把实验准备金算作收益。
6. 简单毒爆弹幕按三族合法四人阵容，比较静止、固定移动、可见弹体反应策略及不同输入间隔。只走原始移动和碰撞／机会规则，不锁命、不改弹速、命中或寿命。记录首次命中、第五次失败、完成率、移动距离、输入频度及成功／失败实际升降级；程序控制结果不代表人类容错。

## 账本与样本边界

- 每关记录起止矿气、被动／掉落／清关／卡牌等原生收入、生产／发展／商店／维修／复活／刷新支出及未归类差额；记录购买可选与实际购买、产能等待、席位与发展路径。
- 记录实际掉落、拾取、品质／槽位、背包装备替换、被清除或战败损失，以及粉尘、拆解和工坊真实报价。区分局内矿气、装备粉尘和永久资源，不把可拆解价值当作已经收到粉尘。
- 事件记录自然／诱饵来源、类型、开始／完成／失败／过期、直接收益、召唤敌人和友军损失；注明受控位置、装备和策略。
- 使用已有生产路径，测量脚本不修改游戏源码。读数／记账探针先与相同无探针路线比对状态，证明没有改变数值和RNG。保留先导失败、截断及未覆盖内容。
- 当前候选已通过2264回归；本批若只有测量脚本和文档，不重复把旧回归写成本批新验收，不制作重复整包。若发现并获准修改生产逻辑，再做对应回归和同版验证。

本计划是执行范围，不是完成结果。最终样本数量、限制与结论以本批报告为准；不预先承诺全部裸装难度可通关，也不以本轮结果关闭MVP或自然／人类最终验收。
