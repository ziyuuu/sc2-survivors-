# 护送农民：完整编码规格 R1

日期：2026-10-19。MVP 包 2。状态：READY（规则与实现契约齐备；未实现、未做运行验收）。依据：[趣味原稿](RANDOM_EVENTS_ITEMS_CONCEPT_20261009.md)及本轮用户逐项决定。下一步是按本文实现生产规则与真实入口验证；本轮只整理设计。

## 1. 决策归属与范围

用户确认：第 4 关开放；随机 3—8 名农民；罩保护、靠近解罩；自主行走约 15 秒至本族原版主基地；未接取下一关消失，已接取跨关；每 3 秒附近生成 30 小狗、10 毒爆，首波第 3 秒；任务阶段专攻农民、独立伤害；普通农民血量；普通营救收益外，每名成功农民固定 50 矿／10 气，不吃资源加成；小地图雷达；任务结束不再出兵，在场敌人转攻我方；主基地无敌，接收结束消失。

用户另批准初值：公共 GCD 30 秒、每 15 秒以 15% 概率检查、小狗每击 2／间隔 1 秒、毒爆每次爆炸 8。用户随后明确：无尽模式不接入任务。以下未逐项口头确认的落点、结算顺序、数据结构等，作为本次授权整理完整规格的设计取值，供直接实施；不伪称全部是用户逐字批准。所有初值允许后续依据实际玩法调优，不代表平衡通过。

不新增独立操控农民、领奖窗口、农民培养、永久设施或存档实现；不改已确认五图环境及普通敌人全局数值。

## 2. 共用任务调度

- 所有普通随机任务共用一个 activeTask 槽。待接取也占用；实现护送时仅有护送一个合法候选。后续修复等加入同一个候选池，不为每种任务独立抽一次。
- 仅战役普通战场、实际推进模拟且存在正式战斗队伍时推进。无尽不接入任务：不抽签、不生成、不推进任务与 GCD。暂停、后台不推进模拟、关间、结束画面、特殊关挂起期间不推进任务计时。
- 第 1—3 关不抽；从第 4 关起，每关前 10 个战斗秒为生成宽限期，不抽新任务，但已接取任务及 GCD 正常推进。
- 宽限结束、空槽且 GCD=0 时开始累计检查时间，满 15 秒才做首次 15% 抽签。失败后再等 15 秒；成功只生成一项。跨普通关保留不足 15 秒的进度，下一关宽限期内冻结检查进度。
- 有任务或处于 GCD 时不抽签、不累计下一次检查、不积攒待触发次数。任务结束统一设 GCD=30、checkRemaining=15；GCD 与检查倒计时不能同一步重复扣完整 dt，精确消耗剩余步时间。
- 原稿未来酒馆告示：p=min(1,0.15×最高档倍率)，作用一次；当前不提前实现商品。合法任务类型等权，生成合法性检查通过后才抽具体类型。
- 只有已经找到合法目标与通路的任务才能入池；无合法候选不启动 GCD，等待下一次检查。生成以一个事务提交，不能出现空罩、缺基地或半生成任务。
- 使用 World 既有种子随机源；模拟抽签不由渲染调用。候选按稳定 ID 排序；人数、落点与路线生成后固定，不因菜单开关、跨关或表现重建重抽。
- 任务跨关不产生第二次接取或刷新。未来长任务是否使用同一槽，在其详细设计中按用户“同一时间仅一个任务”约束处理，不恢复旧稿默认独立长任务槽。

## 4. 场地、主基地与移动

1. 候选起点须为地面可占用区，距当前控制点至少 8 单位，可容纳全部农民与罩；不与建筑、悬崖、水面、出生身体重叠。
2. 选择本族原版主基地：人族指挥中心、虫族孵化场、神族星灵枢纽。它是本任务临时接收目标，不是敌方主巢、兵营、水晶塔，也不增加生产账本。
3. 主基地与罩同时生成。主基地无敌、不参与索敌、不生产、不阻挡已选接收路线；保留建筑自身合理碰撞，接收区放在外沿。
4. 按真实地面寻路选择起点→接收区路径，目标长度 59.0625 单位；允许一个固定步的行程误差。最多尝试 32 组候选，无合格路线则本次不生成，不拉直穿崖、不临时造地形。
5. 多名农民围绕同一行进路径形成紧凑小队；生成时分别校验可行走路线及接收可达性。15 秒是无阻挡基准，不是强制时间限制。单位拥挤会延长行程和增加出兵机会。
6. 接取时解除保护，农民立即自主行进；不等玩家确认，不在玩家离远时停下。用现有碰撞／通行系统分离实体，不越墙、不瞬移、不给强制无敌穿越。
7. 每 0.5 秒检查卡路；连续 1 秒前进不足 0.1 单位时对同一终点重寻路，最多每秒一次。无法前进继续保留任务，不以脚本判超时死亡或自动成功；合法生成与三族实际行进验收必须排除常见永久卡路。
8. 防护罩按真实存活农民包围盒包裹；待接取农民不可受伤、不可被索敌、不可提前营救。解罩后不恢复。

## 5. 战斗、刷怪与 300 上限

- 任务敌人以正常同关、同难度小狗／毒爆实体创建，记录生成时的源关卡与难度快照，正常本体 HP、移速、受伤与被击杀行为保留。任务身份单列 source=task、taskId，不改原主波 4∶4∶1 配比。
- 任务进行期间只索敌本任务活农民，按最近可达目标、实体 ID 打破平局；目标抵达或死亡后立即重选。普通敌人不主动索敌护送农民，我方可正常攻击任务敌人。
- 仅任务伤害路由替换为上表参数，不叠加敌方章节伤害、轻甲加伤、潘多拉、攻速成长或装备派生伤害；探机先扣盾再扣血。任务毒爆范围不伤我方战斗部队、其他任务目标或主基地。
- 毒爆保持真实接近、攻击触发及死亡时是否爆炸的生产规则，不能仅播放动画；每个真实爆炸只结算一次。爆炸到最后农民死亡仍先完成该爆炸的目标快照，再结束任务。
- 每波在当前农民群附近 1—2 个合法局部入口出土；预告放在到期前 0.5 秒，首次实际入场为第 3 秒。没有合法落点时重试同一待入场批次，不退化成四面地图边缘出兵。
- 共用现有敌人硬上限 300 及非 Boss 预留容量；强制 Boss 优先，其余来源按现有顺序后再给任务空位。每步最多释放 8 名，按小狗、小狗、小狗、毒爆循环，共 10 组，最终数量严格 30/10。
- 任务最多一波待入场，不生成无界队列。到期批次可部分释放，剩余数量保留。无阻塞时各波从首批入场时刻按 3 秒间隔调度；若到了下一波时刻上一波仍未释放完，则冻结为“下一波已到期”，等上一波全部入场后才允许开下一波，不额外积累第三波。容量／落点恢复后从新波首批实际入场重新计算间隔，不追补几百个敌人。
- 正常情况下第 3、6、9、12 秒四波、总数 160。第 15 秒如果还有农民在途则可出现下一波；如本步已全部处理完抵达／死亡则不出新波。
- 整个任务结束后取消未入场数量；已入场敌人保留 ID、HP、生成快照，解除专攻农民限制，清除已承诺但未命中的农民攻击，下一次正常攻击转向我方。转攻后使用生成快照的正常战斗伤害与攻速，不继续以 2／8 对我方结算、不按新关卡回填强化。
- 任务敌人真实击杀使用现有守军资源掉落，不另给每波奖励，不额外抽装备／Boss 卡；正常玩家击杀效果按既有资格执行。它们不会递归触发新护送、虫潮或营救。

## 6. 状态机与结算顺序

状态：`offered → escorting → succeeded | failed`；offered 还可到 `expired`；任何非终态在整局真正终止时到 `cancelled`。

- offered：罩和基地存在，占公共槽；进入下一普通关前失效并清理，进入一次 GCD。只是打开关间菜单尚不失效；正常关卡推进转入下一关时才执行。
- escorting：农民自主移动；暂停与跨关不改变状态。每名农民独立为 active / arrived / dead，不允许 dead→arrived。
- arrived：活农民进入接收区，立即完成一次营救事务并隐藏模型；无需等其余农民。所有农民均不再 active 后，只要 arrived>0 即 succeeded，否则 failed。
- succeeded / failed / expired：清理罩、雷达、基地及待入场批次，转移现存敌人战斗规则，释放公共任务槽并启动一次 GCD；结束收据保证重入不重复清理或启动冷却。
- cancelled：战败、主动撤离、结束出征时不奖励未抵达者，不等待任务完成，不阻塞结算；整局销毁时敌人一起回收，不在结算画面继续战斗。第 18 关战役结局先处理本步合法抵达，再取消未完成任务；进入无尽前必须清空任务槽、任务农民、罩、基地、雷达及待入场波次，不跨地图搬运农民。已入场任务敌人按任务结束规则解除专攻、转为普通敌人，随后服从原战役到无尽的场地生命周期，不额外强制搬运或发死亡收益。

每个固定步顺序：现有战斗伤害／死亡 → 活农民移动与抵达判定 → 逐名奖励事务 → 任务终态／敌人转攻 → 若仍在进行才到期出兵 → 若仍空槽才调度新任务。死亡和抵达同一步时死亡优先；任务最后抵达和关卡结束同一步时先结算抵达再进入关间。新生成的任务不能在同一步立即接取或累计出兵时间。

## 7. 奖励事务

每名到达者 key=`runId:taskId:workerId:rescue`，在统一任务收据集中检查。已有即整段返回；否则计算后一次提交：

1. 以 1 名实际农民为输入，复用现有 `scv_savior` 的普通营救规则，再调用共享救援装备效果。增加 workers，统计 workersRescued 加 1（实际获救身体数量，不把增益人数重复当现场身体）。
2. 钱包直接加 50 矿、10 气，记到新增 taskReward 经济分类；不走普通资源掉落乘数、难度收益、拾取暴击／回收、关卡奖励加成。
3. 固定矿气只按实际抵达身体发放，救援天赋／舰装额外增加农民数不额外产生 50/10；装备救援触发仍按既有规则一次。
4. 写收据、抵达状态及事件，再通知 UI；表现不得修改钱包。死亡统计每个实际农民仅加一次 workersLost。现有虫卵的精英营救权若由普通农民营救触发，抽出与虫卵内容无关部分复用；不调用卵专属转化或虫卵增援效果。

`equipmentWorkerRescue` 当前仅防止其内部装备效果重复，不防止外部 `workers +=` 再入；必须由新统一营救事务包住整个修改。World.atomicMutation 仅批量通知、没有回滚：提交前完成所有校验，不将它误当数据库事务。

## 8. 数据与模块契约

以下为待新增接口，不是当前已存在 API。

```ts
type TaskScheduler = {
  activeTaskId: string | null;
  gcdRemaining: number; checkRemaining: number;
  nextSerial: number; endReceipts: Set<string>;
};
type EscortWorker = {
  id: number; hp: number; shield: number;
  position: {x:number; z:number}; pathIndex: number;
  state: 'active'|'arrived'|'dead'; lastDamagedAt: number;
};
type EscortTask = {
  id: string; race: 'terran'|'zerg'|'protoss'; sourceStage: number;
  state: 'offered'|'escorting'|'succeeded'|'failed'|'expired'|'cancelled';
  baseEntityId: number; workerIds: number[]; enemyIds: number[];
  path: {x:number; z:number}[]; destination: {x:number; z:number};
  waveRemaining: number; pendingWave: {zergling:number; baneling:number}|null;
  waveSerial: number; rewardReceipts: Set<string>;
};
```

实体完整 HP、盾、动作、攻击冷却由模拟侧持有，任务表仅引用共享实体数据，不维护两份会漂移的生命值。快照需包含路径、源关卡快照、GCD、检查余量、批次余量、收据与卡路重寻路计时；渲染重建只消费快照。

建议新增 `src/data/random-tasks.ts`（配置）、`src/simulation/tasks/scheduler.ts`、`escort.ts`、`rewards.ts`。在 `World` 更新、`body` 查询、索敌／伤害、`endStage`、`nextStage`、`prepareStage`、结束出征及 HUD / 小地图处做最小接点。敌人创建继续复用原生产工厂；农民单列护送实体，不能复用敌方 `EconomicTarget.kind='drone'` 冒充友军。

跨关在 prepareStage 清理前提取已接取任务及其实体，清理后原身份挂回；不能新建 ID、重置敌人或重放解罩。普通地图永久替换时明确取消；特殊关插入时挂起整个普通战场任务及关联敌人，返回才恢复。存档工作继续按约定留到 MVP 收尾，不编写迁移。
