## 2. 高级普通兵、90精英与高级卡的实际能力预算

普通军衔公式保留：等级r的理论主武器DPS为I级的r倍，周期因子为`1+0.15(r−1)`，单发因子`r/周期因子`，HP/原生盾因子`1+0.8(r−1)`。V与VII分别为5/7倍基础DPS、4.2/5.8倍基础HP。培养解锁、五家族/名额、跳虫双身体等现有条件仍须满足；没有新价格、免费升阶或全系点满。

精英以普通V为起点，I—V独立成长。[能力对照](NEXT_ITERATION_P0_CAPABILITIES_20261003.md)保留当前运行数值；[r2重设计](ELITE_HERO_REDESIGN_20261003.md)逐款提出新HP/盾/普攻/医修、循环与实际表现，替换旧模板和旧独有效果。新数据不可与旧精英收益再次连乘。90款覆盖预热/散热、首十周期、吸收成长、长炎/大扇面、布雷、范围减益、攻城/机动炮击、多目标治疗/护盾、虫群/生体/毒囊、原生盾/相位/子机等不同打法；条件反甲、范围覆盖、法术、控场与支援分别核算。

用户明确数值完整保留：枪兵预热5秒、攻速+300%、满速10秒、停火2秒；杀手精英/Boss总伤3/5倍；指挥官枪兵属性+20%；死神每周期6发、前十周期3倍主伤＋50%溅射；长炎长度+300%、地狱骑士150度/长度+100%；布雷每12秒两雷/2秒残火；虎式架炮伤害/攻速+100%、射程+200%；精英救护五体。毁灭者依用户最后纠正为**爆炸面积5倍，半径√5约2.236倍**；孤星只限制死神家族，不消费其他家族/英雄。未给定参数均以提案标记。

高级普通兵的强项来自职责：重炮/穿刺/风暴负责密集清杂，反甲负责重甲，航空与地空单位负责对空，医修/护盾/控场负责延长有效作战时间。高价不保证同目标裸DPS全面更高；高级兵不能因缺有效命中、能量、出手时机或到位而空有账面倍率。对照表列出各家的代价和反馈，后续发现真实弱项时单独记录旧值/拟值/原因，再复审数值。

全队火力卡先累计伤害和攻速加值，最终分别应用一次。橙火力3张在其他零加值时理论DPS为`1.48×1.24=1.8352`；不是1.16和1.08逐张连乘。橙防御3张HP/原生盾+60%、护甲原加值+2.1，保留既有适配，不免费补满身体。家族恢复/能量/生产牌保留真实通道和上限。

每族8张趣味卡逐一列0/1/2/3层、触发、对象、限制与反馈。固定伤害卡保留固定量；比例卡只继承合法主击一次；火力超载改变真实出手密度，孵育改变真实临时身体数，棱镜逐脉冲结算。特效不能制造额外伤害、递归链或虚假受益者。
