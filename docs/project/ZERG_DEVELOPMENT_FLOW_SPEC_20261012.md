# 虫族孵化场生产与进化解锁规则

日期：2026-10-12。状态：用户已确认核心方向，部分语义待澄清，尚未实施。此次仅编写规格，不修改代码或运行版本。人族规则见 [人族发展流程规格](TERRAN_DEVELOPMENT_FLOW_SPEC_20261012.md)。

虫族可以建造多个孵化场，以每座孵化场为独立的发展与生产单位。孵化场分别选择生产物种、开放进化方向并推进解锁；每座最多同时配置两种单位，按现有两种输出的轮流孵化方式生产。多座可以配置不同物种，也可以配置相同物种。UI保持现状，只调整布置部分以支持单座配置。

## 1 已确认的生产规则

每座孵化场独立选择最多两种已具备生产资格的物种。选择一种时持续孵化该种，选择两种时轮流孵化；“同时配置两种”不表示新增两个并行生产队列。两种输出的轮流生产语义与其他种族现有规则一致，但配置归属改为每座孵化场，而不是整条虫族线路共享。

生产选择需要明确绑定孵化场身份。修改一座的输出不自动修改其他孵化场；多座选择同种时，各座仍保留独立配置。五座可以分别配置五个不同物种，也可以每座配置两种；输出配置能力不表示增加部队家族席位、身体数量或军衔上限，实际生产仍受已有部队容量规则约束。

示例：孵化场1轮流孵化跳虫和爆虫，孵化场2轮流孵化蟑螂和虫后。两座的选项和轮流进度分别记录。双方向均开放且相关兵种已解锁的孵化场，可以配置刺蛇和飞龙并轮流孵化，不要求两种输出属于同一方向。

本次未调整孵化场数量上限、建造费用、生产费用和时间、兵种能力或部队容量。新进化操作及其价格需要另行确定，不能把旧价格直接称作已批准的新进化价格。

## 2 孵化场方向与进化

用户确认：孵化场解锁自身的地面／天空方向，并给出该方向的初级兵种；第二次进化开放另一个方向。

方向及进化操作针对具体孵化场，不能通过给某个全局线路分配一座建筑就把所有孵化场同步改线。每座界面需显示自身已开放方向、可选物种、当前输出及下一步进化前置。

基础虫群、地面进化、飞行虫群是下文的兵种进度层次，不据此增加三种生产建筑。物理生产建筑仍以孵化场为主体。用户未指定是否要采用虫穴、主巢等建筑形态名称或模型，本文不新增对应形态。

### 天空方向的防速飞龙前置

全局至少有一座孵化场完成地面进化，才允许任一孵化场开放天空方向。检查的是已经完成的地面进化，不是仅拥有孵化场、选择过地面按钮、正在进化或已经得到某个地面士兵。

前置未满足时，天空入口说明“至少完成一次地面进化后开放天空”，不能支付进化或直接获得飞龙。该条件不要求五座全部完成地面进化，也不额外添加未获指定的关卡门槛。

### 第二次进化与双方向选兵

同一座孵化场先开放一个方向，第二次进化开放另一个方向，两个方向均保留。第二次进化不替换或关闭第一次开放的方向；此后可从两个方向已解锁且满足生产条件的兵种中选择最多两种，轮流孵化。可以两种都选地面、两种都选天空，或地面与天空各选一种。

全局地面前置满足后，新孵化场是否可第一次直接选天空，以及孵化场最初的基础虫群阶段与首次地面方向开放的具体关系，仍需明确。

## 3 用户指定的兵种路线

箭头表示先后解锁层次；方括号内为同一层次。平级兵种之间没有额外先后链，不把蟑螂改成虫后的前置，也不把雷兽改成潜伏者的前置。

| 进度层次 | 第一层 | 第二层 | 第三层 |
|---|---|---|---|
| 基础虫群 | 跳虫／爆虫 | 蟑螂或虫后，两者平级 | — |
| 地面进化 | 刺蛇 | 破坏者 | 雷兽／潜伏者，两者同级 |
| 飞行虫群 | 飞龙 | 腐化者 | — |

对应路线：

- 基础虫群：**【跳虫／爆虫】 → 【蟑螂或虫后】**。
- 地面进化：**刺蛇 → 破坏者 → 【雷兽／潜伏者】**。
- 飞行虫群：**飞龙 → 腐化者**；先满足至少一次地面进化的全局门槛。腐化者对应现有兵种 `corruptor`。

地面方向开放时给出该方向初级兵种，地面进化路线初级为刺蛇；天空方向开放时给出飞龙。基础开局如何处理跳虫与爆虫的同级开放，见下文待定细节。

新路线替代当前没有顺序前置的并列兵种解锁。不能因为原始生产配方写有变异来源，就额外插入用户未指定的跨路线前置；例如本文不添加“破坏者必须先购买蟑螂科技”的条件。

后续兵种如何推进必须以解锁或进化进度表达，不能因前置士兵死亡、退役或停止生产而倒退。已经支付的生产任务保持原兵种、支付金额和进度，切换方向或输出不改写历史任务。

## 4 尚需明确的细节

以下细节不以实现方便为由自行决定，也不阻碍记录以上已确认路线。

| 项目 | 需要明确的内容 |
|---|---|
| 初次天空进化 | 已有其他孵化场完成地面进化后，新孵化场是否可以直接选择天空 |
| 基础第一层 | 跳虫／爆虫是否同时可选；是否都自动解锁；是否仍保留开局只给跳虫 |
| 同级后续兵种 | 蟑螂／虫后及雷兽／潜伏者是分别购买解锁、一次开放两者，还是单座二选一分支；“平级”不等于已经确认永久互斥 |
| 解锁共享范围 | 每座独立选输出和方向已确定；后续兵种科技是逐座解锁还是同方向共享，尚需明确 |
| 费用与奖励 | 建造、首次方向进化、第二次进化和后续兵种解锁各自的价格；给出初级兵种是开放生产资格，还是另送实际士兵 |
| 雷兽阶段门槛 | 现有第10关生产限制是否继续保留；本次未指定取消，也不宣称已完成新路线适配 |

## 5 科技升级与刷新边界

本次指令调整孵化场生产、方向进化和兵种路线，未指定专属科技数值或攻防升级重做。现有代谢加速、离心钩、胶质重组、沟槽脊刺、适应爪及三组攻防研究作为后续适配输入保留，不把它们自动插入新的兵种主链。

后续需要明确兵种升级绑定物种、方向还是单座孵化场，特别是单座开放两个方向后的科技界面。科技不能让未满足进化前置的孵化场提前选择高阶兵种。

本次未单独确认虫族的基础免费刷新；人族规格中的一次基础免费刷新不能未经说明扩展为虫族已确认规则。虫族刷新方式留待其孵化场发展操作与候选卡结构确定后适配。

## 6 布置界面与跨线路问题

UI整体保持不变，只改变现有布置部分的UI，不另做发展页或重排其他界面。布置部分以具体孵化场为配置对象，展示编号或可辨认身份、已开放方向、当前一至两种输出和轮流顺序，并支持逐座选择兵种。进化与解锁沿用现有界面承载方式，适配本规格的规则，不扩大UI改动范围。

在某座孵化场选择发展操作时，候选或操作必须属于该座当前可执行的进化步骤。未开放天空不能出现可执行的飞龙解锁或生产；缺失的地面进化前置仅显示说明，不通过跨线卡片绕过。

孵化场在地面或天空入口出现，本身不应被当作跨线错误；需要判断它实际绑定哪座孵化场、准备开放哪个方向以及前置是否满足。当前“通用孵化场＋全局线路共用输出”的结构需要替换，不能只修改线路名称。

本规格未要求改为全项目直接购买，也未批准增加每窗口购买次数。随机卡片还是直接进化操作、一次操作结束发展还是继续选择兵种，需要后续结合上述进化细节确认。

## 7 后续验收要求

以下仅列待实施的验收场景，不代表运行测试已经通过。

| 场景 | 应验证的结果 |
|---|---|
| 五座孵化场各配置不同物种 | 可同时保留五种独立输出，不受旧线路两输出限制 |
| 建造多个孵化场 | 各座可以独立配置，数量上限沿用现有规则 |
| 单座选择一种或两种物种 | 一种持续孵化，两种按现有语义轮流孵化，不新增并行队列 |
| 两座孵化场配置相同物种 | 允许，各自生产配置和轮流进度不会互相覆盖 |
| 修改一座孵化场输出 | 其他孵化场配置与已付费任务不被改写 |
| 尚无完成的地面进化 | 天空方向不可开放，不能提前获得飞龙资格 |
| 至少一次地面进化完成 | 天空全局前置满足，其他单座条件仍须检查 |
| 基础同级分支 | 蟑螂与虫后没有额外先后链；具体开放方式按后续确认验收 |
| 地面顺序 | 刺蛇在破坏者之前；破坏者在雷兽／潜伏者之前 |
| 飞行顺序 | 先飞龙，再腐化者，不能跳过前置 |
| 第二次进化 | 同一座保留两个方向，可从两边已解锁兵种中选择最多两种轮流生产；其他孵化场状态不改变 |
| 双方向选兵 | 可以地面与天空各选一种轮流孵化；切换输出不关闭方向，也不改写已付费任务 |
| UI范围 | 只调整布置部分以支持逐座双输出配置；其他界面的布局、视觉风格和交互结构保持不变 |
| 暂停、存档与重载 | 单座方向、进度、输出和支付账本正确恢复，不重送奖励 |

## 8 现有实现与目标差异

当前代码按基础虫群、地面进化、飞行虫群组织共享生产计划，每线路最多两种输出；孵化场仅有线路分配字段，兵种解锁为本局共享科技。目标要求把最多两种输出的配置、轮流进度和方向进化建立在单座孵化场上，保留既有两种输出的轮流生产语义；UI仅改布置部分。不能用修改现有家族数组顺序代替实际行为调整。

主要后续核对入口：`src/data/expedition-buildings.ts`、`src/simulation/expedition-state.ts`、`src/simulation/expedition-production.ts`、`src/simulation/expedition-economy.ts`、`src/simulation/progression/expedition-drafts.ts` 和相关孵化场界面。持久化字段与存档版本须在实施时评估，本次不添加字段或迁移。

既有代码、数据参考、正式交付物及验证证据保持原状态。本文是后续修改依据，不覆盖已经交付版本的运行规则或验收结论。
