## 已实现

- 英雄头顶 DOM 仅保留 46px 细生命条及有护盾时显示的护盾条，护盾含原生盾与天赋盾；删除槽号、姓名、技能文字和悬浮标题。根节点明确 `pointer-events:none`，现有固定英雄技能 HUD 不变。ARIA 生命／护盾 meter 保留。
- 玩家英雄通过现有原模型材质 shader 的窄橙金边区分，使用原深度测试，只作用于可见表面；无附加外壳网格、无额外全屏 pass。移除原先未使用的英雄光圈批次。英雄普通模型大小仍采用原既定规则；仅大和／利维坦使用以下固定系数。
- `weaponWorldPoint` 统一原武器挂点的朝向、表现尺度及飞行高度，修复原先空中英雄炮口落在地面高度的问题。缺少挂点时明确使用本体前方 0.6、高度 0.6 的回退位置，再经过同一变换。真实在途技能从对应模型挂点发出，仍由已保存 cast 的未来时间决定进度。
- 18 名英雄沿现有普攻／技能事件接入各自配色和原特效纹理。瞬时攻击显示同帧曳光与静止命中核心，不新建慢弹道或延迟伤害；近战增加短刀痕。真实飞行技能优先显示主弹头，技能命中使用一个稳定核心与较小外围碎片。治疗、回盾、控制、火焰、冰霜技能有分别的核心配色。
- 斯旺／妮雅德拉仅在实际恢复 HP 后发出 `skill-impact`；阿塔尼斯在实际回盾的受益单位上发出同一事件。渲染从真实英雄到实际受益坐标显示短治疗／回盾线。此接线不改恢复量、受益人数、目标合法性或技能周期。
- 净化者截击机只在渲染适配中取得旗舰配色，仍使用子机的真实事件 ID／位置／挂点；普通航母子机不受影响，不把子机写成英雄或附加攻击。
- 友方英雄命中后的通用大爆炸／胆汁圆环不再作为主体；范围预告只保留未发射的短施放阶段。敌主巢、领主、战役 Boss、特殊敌方施法／酸区预警先分配有界线段／环实例。
- 粒子池仍为 1280、每纹理批次仍为 256；不新增常驻粒子网格。满池时高优先级核心可替换装饰；绘制按真实在途主弹头、核心、刀痕、装饰次序。`effects.droppedByClass` 累计记录全局池丢弃，`culledByClass` 记录当前帧纹理批次裁减，`projectileCulled` 记录当前帧主弹头裁减，原总丢弃数仍保留。
- 视觉数组继续属于 rebuilt 字段；恢复存档不重建已结算事件，仅重建仍影响未来的在途 cast 表现。
