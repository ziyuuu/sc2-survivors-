## 采用的修改

1. **关闭效果后释放专用缓冲。** 接触阴影、折射与泛光在关闭时释放独占目标，解除失效采样引用；预热和缩放不会重新分配已关闭效果，再次开启按当前尺寸恢复。主画面颜色、深度和输出链保持。B 的独立提交为 `c1b0dea`。
2. **同一依赖清单约束入场和后台。** 根据种族、当前/存档身份、订单与装备效果准备原版战斗特效。保留所有本族普通兵种、虫族敌人、独立装备/生命周期效果和合法即时遭遇；第3关起保留本族全部英雄候选。未抽奖的内容不提前抽取，不消费RNG。快照保留原有较宽的本族模型准备范围。公共准备及预热标记随图形上下文失效。
3. **安全边界回收闲置部队资源。** 等旧后台工作排空后，在菜单/入场边界按最近使用顺序回收；当前必需阵容、暂停单位、死亡动画和共享使用者受到保护。闲置资源按唯一CPU数组与解码图片估算，受限设备高/低水位为64/48 MiB，其他设备192/144 MiB。预算不代表全部浏览器或GPU占用；公共特效、英雄及地图仍有有限常驻部分。
4. **移除已转换模型的多余CPU持有者。** 普通单位转换为绘制批次后，只保留需要的动画元数据，不继续持有GLTF解析器和原始场景。当前绘制几何、姿态、LOD、图片与压缩mip数据保持，继续支持重新上传和图形恢复。没有采用上传后统一清空数组/ImageBitmap的方案。

玩法、结算、保存格式、画质档、镜头、布局和玩家文案保持。优化同时进入共享源码；本批部署范围仍仅为现有Sites，Coze和阿里云不自动更新。
