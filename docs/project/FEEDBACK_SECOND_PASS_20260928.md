## 强度对照结论与设计边界

最早可查 `5d5fd90` 的枪兵45生命、6伤害、射程5、.8608÷1.4秒周期，与当前零天赋／零科技一致。历史 `08b8015` 的敌军更新没有当前原生生命恢复；当前虫族继承了已接入的原生恢复。因此18／24／30血的前三关跳虫在射击间隙恢复后，分别需4／5／6枪。简单站定从射程边缘测试剩余枪兵生命35／30／25；固定普通走A输入剩余35／30／20。这证明承伤现象存在，不能写成“已无伤”。恢复规则和数值本轮不擅改，是否让教学跳虫停止恢复／调整枪兵或死神定位需另行设计确认。

死神未计甲理论输出8÷(1.1÷1.4)约10.18，对比枪兵6÷(.8608÷1.4)约9.76，仅高约4.34%；双击面对护甲的损失更大。用户“作为后续兵种应有更好表现”首先落实为主动参战、停止踱步、双枪反馈。当前并未承诺普通死神在所有目标上都高于枪兵；若还需更明显战力层级，不能以此次修Bug名义静默加伤。
