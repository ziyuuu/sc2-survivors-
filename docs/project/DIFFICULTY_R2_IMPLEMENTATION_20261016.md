- 30%／50%只作用于最大生命、固定伤害和护甲。攻速、移速、射程、体积和机制资格保留对应主力值。实际普攻、属性加成、延迟胆汁和捕获后的刷新均验证；百分比伤害、技能预警和冷却不盲目缩放。
