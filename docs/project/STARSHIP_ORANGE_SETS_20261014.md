## 二 军衔、小队、人数叠加：用户确认规则

不再使用旧“同类只取最高”“普通兵绝不能超过Ⅶ／Ⅸ”的全局封顶。不同已生效来源对同一合法受益对象的增量相加，包括橙模块与套装；不能被旧总人数或旧存档数组上限再次截断。只对对应方向／身份生效，不能把一个方向加值复制给全队。

分别维护三条账本：小队／兵种槽数Q、每个小队编制人数N、对应身份可培养军衔上限R。任何一条变大都不是自动招满、自动升满；实际招募、培养和赠兵各结算。

- `Q = 不含装备增量的合法小队基础 + 各有效小队增量之和`。
- `N(兵种) = 该兵种合法基础人数 + 各覆盖该兵种的人数增量之和`。
- `R(身份) = 该身份合法基础上限 + 各覆盖该身份的军衔上限增量之和`。
- 公式的基础均为不含任何装备容量加值的本局合法基准，可包含原有合法种族／天赋规则。写成“开放7队／每队7人／普通Ⅸ”的模块以相对于该基准的非负补足量入账，然后继续加其他装备的合法增量，不拿7／7／9再截最终值。不得先把套装算进基础、再用模块补足抵消掉套装；处理顺序不能改变结果。多个合法补足型来源若可同时生效，也分别相对同一基准计算后相加，不取最高。
- 实际交付军衔也可叠加：橙军备“普通招募Ⅴ级”按常规Ⅰ级交付＋4；本版橙士兵2件按＋4。因此同时生效且方向匹配时，Ⅰ＋4＋4＝Ⅸ级新招募，而非取两个Ⅴ中的较高值。若已有其他合法交付加值，继续相加；仍受最终已算出的对应上限约束。
- 固定身份赠送是一次来源奖励，不是无限晋升事件。同一精英套2件给Ⅲ精英、4件改Ⅴ，合并为同一名Ⅴ级精英，不发两名、不把Ⅲ＋Ⅴ当Ⅷ。同身份英雄保持一个永久实体与独立来源账本；确实写明“军衔＋n”的一次奖励相加，固定英雄交付等级不因重载或重复合并凭空重领，已有更高军衔不降级。

**合法搭配例。** 无限编制＋橙士兵4＋橙部队4占8个属性位及1经营槽。对同时受两套方向覆盖的小队：人数7＋5＝12、普通军衔上限Ⅸ＋4＝ⅩⅢ，小队总数7＋1＝8；未覆盖的队保留自己的规格。不能宣称八个队都必然属于该方向，也不能把名额写成自动满员或自动升满。

无限编制＋橙部队6使总小队上限7＋1＋1＝9，并使该方向小队人数增加5；其他方向人数不跟着加。无限编制＋污染英雄6使绑定方向人数7＋4＝11、普通军衔上限Ⅸ＋4＝ⅩⅢ。橙军备与无限编制同槽仍不能同时穿戴；用户允许叠加没有增加第五个模块槽。

英雄、精英、普通兵的适用对象必须保留。污染英雄4件提高的是方向普通兵上限，不顺带给英雄本人＋4军衔；两类英雄套6件的新持续成长资格仅限各自绑定英雄。科技奇点依原范围开放其他英雄高阶，已有同名英雄卡等合法晋升也可提前提升绑定英雄；不另设培养收费服务；不能因此收回套装成长资格。终焉巨舰沿独立来源，不作为普通兵全军无限军衔许可。

## 六 精英90身份覆盖与高军衔承接

精英套不缩成只支持少数精选精英。[逐身份对齐表](STARSHIP_ELITE_HERO_ALIGNMENT_20261014.md)中三族各30、共90个ID全部沿同一固定绑定方案：2件Ⅲ并强化全队精英，4件Ⅴ并给绑定者专属＋100%，6件专属提升至＋200%及攻击频率＋50%。已列治疗／回盾量按相同输出倍率，复活次数、光环百分比、控制时长和召唤数量不凭输出倍率自动翻倍。无攻击的支援精英照样强化其已列支援量，不强塞假普攻，攻击频率不缩短治疗技能冷却。

绑定者主武器4件为1.5×2＝3倍单击、6件为1.5×3＝4.5倍单击，后者还有1.5倍攻击频率，未计其他来源时武器DPS为6.75倍；4件＋100%与6件＋200%不重复乘。绑定者生命为1.5×2＝3倍，原生盾只得绑定者2倍。其他精英只得全队该层，绑定者技能仅得自身输出层，不能把“主武器”加成错误套到技能。母舰／截击机共享所属输出一次，EMP不把盾伤溢出为生命伤，治疗按实际缺口结算；原生所有权、军衔、形态与冷却沿实际渠道。

上限可叠加后必须支持Ⅹ、Ⅺ等真实成长，不能截断成Ⅸ的数值。普通兵沿原Ⅰ—Ⅴ；已确认的Ⅵ／Ⅶ增强值为Ⅵ：DPS6.8／生命5.8／攻速1.85，Ⅶ：DPS9／生命8／攻速2.2。Ⅶ以上继续按每阶DPS＋2.2、生命＋1.2、攻击频率＋0.2、护甲＋0.5的绝对基准增量成长，治疗倍率沿DPS，能量沿实际阶数。例：Ⅸ为13.4／10.4／2.6，Ⅺ为17.8／12.8／3.0；每击伤害=DPS倍率÷攻击频率，避免再乘一遍攻速。这是已确认的设计曲线，当前源码尚未因此获得高军衔支持。
