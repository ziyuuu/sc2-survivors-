# 1.x 兵种目录与接入版本

2026-11-04 修订。常规兵种在人族 1.4、虫族 1.5、神族 1.6 接入。战役和合作模式按同样顺序排在 1.9、1.10、1.11。表中保留原调研编号，方便按身份核原作数据、动作、技能和声音。[现行版本任务清单](V1X_ROADMAP_20261104.md) · [10 月逐身份来源记录](V1X_ROSTER_AND_SOURCES_20261030.md)

兵种表负责回答一个单位从哪里取得、在战场做什么、占用什么名额。1.2 先确定自动战斗行为，1.3 由双方共同定好每族三条构筑方向和关间三卡规则。1.4 至 1.6 分族落实兵种、增益牌与核心技能。若要加强精英，按其为本兵种提供战力加成的方向另行设计。V 以后的晋升另列议题。

## 内容接入顺序

1. 1.2 建立兵种选敌、变形和召唤的验证方法。1.3 以这些行为为依据，共同确认三族九条构筑方向。
2. 1.4 人族、1.5 虫族、1.6 神族依次接入本族兵种和卡牌，核对生产、补员、名额、核心选择和恢复。1.7 补齐卡池、配装及跨族平衡。
3. 1.8 提供任务合同和章节分支。1.9 至 1.11 按上表接入特殊身份，1.12 对接传奇链。来源合同、变形与人格转移各自结算，三卡门槛只认符合条件的关间增益牌。七组战役品系及罕见剧情身份以固定版本资产再核。
4. 1.13 对照全目录检查正式流程可获得的身份、实际表现、归属、按需加载和检查点。原版单位的范围、社区交叉资料与待核身份见原始研究记录。[来源与调查边界](V1X_ROSTER_AND_SOURCES_20261030.md)
