## 执行策略

单元/规则矩阵覆盖三族×四难度和全部节点；浏览器用代表存档路径，不把所有组合都做成冗长无关长测。自然完整战役至少三族各一次零天赋普通；41/80点以代表章节和Build专项验证；九Build×三种子先跑经济/动作可达，不能称实战通关。缺陷涉及范围变化时扩大对应测试，不重跑整套无关基准。

性能阈值、机器和起止区间见[总计划第7节](../MVP10_ITERATION_PLAN.md)。普通实战与极端压力用不同报告；真实高刷新或未封顶环境缺失时不能宣称60+人工验收通过。物理手柄/触屏无法实测时保留待验，不用自动化图标代替设备证据。
