# 关内单位属性面板 · R12 · 2026-10-06

用户请求：「以这个为模板，制作关卡内，玩家查看单位的属性面板」。本次沿用 R11 静态卡片立绘、金属边框、系统字体和三族色彩，新增可操作的关内属性面板。

## 设计与交互

桌面面板靠右展开，左侧保留战场和小地图。面板使用 R11 的融合立绘；普通、精英、英雄分别使用冷蓝、淡紫、金色身份标记。核心数值采用明确的标签与等宽数字，按当前单位显示生命、护盾、能量、伤害、攻击间隔、护甲、移动、射程及攻击目标。医疗单位显示治疗信息，不以零伤害占位。

「属性」显示核心数值；「能力／技能」逐项展开简短游戏说明；「部队」直接选择当前部队中的单位。下方头像与前后按钮可连续浏览。关闭或 Esc 返回战场后，定位到所查看单位的分页并恢复头像焦点。左右键切换页签或相邻单位，Tab 在面板中循环。打开面板时将战场 DOM 设为 inert。

跳虫显示两条独立生命；再生示例显示一只存活立绘与另一只的倒计时。单体绘制尺度不随一只／两只切换改变。神族护盾、诺娃先天护盾及医疗能量均按数据条件显示。英雄主动技能保留冷却说明，精英展示自己的能力。没有新增光环文字说明。

移动竖屏将立绘与状态并排放在上部，下部切换信息。技能通过页签访问，省去重复快捷块。小屏内容在一个区域内滚动，标题、关闭和底部切换固定。窄屏使用三个邻近头像；移动关闭、前后按钮与邻近头像的触控区均至少 44 × 44。横屏采用三列紧凑属性。面板展开、立绘切换和数值条带有短过渡，支持关闭动效和减少动态偏好。

## 数据与范围

- 读取当前生产 World 的独立单位快照：138 个身份 × II／III 两个军衔，共 276 条。数据文件记录源文件 SHA256。没有将 P0/P4 设计 JSON 引入运行时。
- 实际可浏览的三族示例各为五类普通兵、五种精英、三名英雄，即 **39 个身份、每族 28 个部队条目**。不是声称已逐一制作所有 138 个身份的完整技能文案。
- 生命伤损比例、护盾余量、能量余量、技能剩余冷却、跳虫再生剩余时间属于静态展示状态；不是自然战局实录。基础／自有效属性取自独立 World，并不代表截图中所有部队在同一场战斗内结算后的团队属性。
- R7/R8 薄地图边框、凹陷小地图框、两行可折叠底栏、显式桌面／移动版本继续保留。战场区没有附加提示文案。
- 本次仅写入静态预览、数据导出工具、证据和本文。没有改生产 UI、战斗规则、模型、技能数值、存档或正式 HTML，也没有上传、提交、推送或部署。
