## 动画与真实命令

合成是光环聚合后显示实际新物品；清洗从污染物品过渡到同一物品的净化状态；洗练翻转三个候选卡后显示真实选择；扩仓展开格子并显示实际新容量。四者都在命令成功后开始，失败不播放成功动画。默认约 1.3 秒，关闭动效或系统减少动态时缩为短反馈。

动画只表现已完成的真实操作，不再付款、生成物品或改随机数。动画期间禁用重复操作；关闭／卸载会清理计时器和视觉效果，已经成功的付款不会回退。未选择的付费洗练仍保留在共用账户，重新打开时继续选择；保留原项仍按原规则扣费。

`view.ts` 保持公共挂载入口，转向恢复布局的 `legacy-view.ts`；`legacy-layout.ts`、`legacy-icons.ts`、`legacy-r12.css` 和 `polish.css` 提供旧版结构与适配。正式接入按顺序导入 `style.css`、`legacy-r12.css`、`polish.css`。旧预览相对图片 URL 已移除，实际图片由宿主解析；三份样式已通过真实 esbuild 导入检查。

## 满仓直接分解

共享结算先按原有成功／失败规则决定保留，随后按既有遍历顺序填入空仓位，剩余保留物品直接删除并按现有分解价格发放粉尘。白／绿／蓝／紫／橙仍为 5／10／20／100／400 粉尘，没有新增价格。成功带回的污染装备若溢出同样直接分解；失败必失的污染装备和未拾取地面物品不产生分解收益。

删除库存位置中的 `pending`、入仓命令与出征阻挡。新增结算分解回执，重复结算不重复发奖；结算页区分入仓、满仓分解及遗失，并显示粉尘总额。手动分解原有的清洗、锁定／收藏保护保持原规则，自动溢出结算按用户“直接分解”的决定执行。

内存宿主与真实 World 读取同一份结算视图；原失败 RNG 的调用顺序保持。专门比较 500 满仓和 700 容量账户的同一批失败结算，保留物品 ID 与最终 RNG 相同，满仓账户仅将本来保留的物品变成粉尘。
