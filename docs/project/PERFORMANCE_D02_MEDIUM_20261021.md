旧保存值仅在精确匹配旧中档组合（medium/native/complete、普通与英雄balanced）时迁移为新的low组合。其他自定义值保留。实际浏览器已验证迁移、刷新保持、自定义adaptive＋15Hz保留，以及无保存值时仍为桌面全档；窄窗口检查不等于物理触屏验证。
