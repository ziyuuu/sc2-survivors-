# UI 原稿逐页还原与控制锚点修复 · 2026-10-06

用户授权完整更新 UI，对照原稿逐项实现，必要时舍弃当前 UI。先完成 UI 与三项核查，再修复摇杆控制锚点的碰撞体积。不部署 Coze，不激活后端。

## 依据与顺序

起始 Git：`bba13399049dfa3e7c16621dc88decbc4a351a1f`。原设计聊天“重新设计星际游戏 UI”的16回合节录、14项用户要求、109项核对（83差异）位于 `reports/local/ui-fidelity-audit-20261006/`。视觉来源为完整 R12 预览，其中延续 R7/R8 地图/HUD、R11卡面及原菜单/天赋设计。原稿 source、图片、历史预览和原游戏资源保留。

1. 用原稿的结构、样式、图标、立绘合成、字体、布局和动效重建正式 UI；绑定当前 World/Profile/RunSession 的实际状态及原命令。
2. 逐页对照，核查同画幅截图与五类视觉表面；原稿假数值和与正式机制冲突的名词/说明不得写回玩法。必要的真实状态、存档保护和既有辅助功能以同一视觉语言容纳。
3. 核查 UI 未改玩法：战斗、经济、生产、天赋、地图、奖励、收据、持久化、资源指纹；同种子/同指令/同快照比较。
4. 核查玩家文案：不显示“席位/家族槽/三种型号/MVP版本/文档章节/内部ID/已批准提案”等开发语言；短游戏词语、明确对象和实际限制。不得为了短文案改变实际效果。
5. UI核查完成后独立修复控制锚点：无碰撞体积、不被障碍物/地形实体阻挡；地图的开放边界与有限速度保留，实际士兵碰撞/寻路/武器遮挡不变。具体改动与允许出现的行为差异单独验证。
