## 已确认与待定

已确认的优先级：污染英雄套最稀有且最强，普通英雄套第二，生存者套第三；其他系列为士兵、部队、精英、强化者。强度目标以同品质完整套装的综合预算比较，专项系列允许在其擅长方向有优势，具体结果仍需平衡。

普通英雄六件套经本轮回复确认：蓝档／紫档获得Ⅰ级绑定英雄，橙档获得Ⅲ级绑定英雄。污染英雄六件套紫档获得Ⅰ级、橙档按R2获得Ⅴ级绑定英雄。都不在开场让玩家重新选英雄。

用户最新确认：普通英雄两件套仅提升对应方向士兵数值，不提升实际军衔，也不按虚拟高军衔换算。具体数值待定；蓝／紫档为第一档、橙档为第二档的映射仍为提案。

## 套装件数与品质门槛

最新掉落与下位件定义见[三族部件命名与掉落](STARSHIP_NAMES_DROPS_20261013.md)：蓝紫固定是蓝色下位件，紫橙／橙紫固定是紫色下位件；白绿数值随实际品质，不能计入更高品质门槛。绿色独立两件套须另补模板，以承接简单Boss与普通精英必掉池。

八个属性栏位承载套装，四个非属性栏位不计件数。同一系列应提供八个部位版本，让玩家自由选六件，余下两件搭配其他系列；污染英雄和普通英雄视为不同系列，不互相凑件数。

件数门槛与品质门槛同时检查。建议同一套装家族中橙色可以向下计入紫档品质门槛：

| 装备情况 | 激活品质档位 |
| --- | --- |
| 同套蓝色或更高部件，但紫色以上不足4件 | 蓝档；仅适用于本身有蓝档的系列 |
| 同套至少4件紫色或橙色，橙色不足4件 | 紫档 |
| 同套至少4件橙色 | 橙档 |

满足品质档位后，再按同系列总件数激活2／4／6件效果。只使用最高生效档位，不同时叠加蓝、紫、橙三个版本。例如4紫＋2蓝为紫档六件；3橙＋3紫仍是紫档六件；4橙＋2紫为橙档六件。不同套装的紫／橙部件不能互相借用数量。

按用户“紫套至少4紫、橙套至少4橙”的字面约束，两件紫／橙小搭配只能触发该系列有资格的基础档，不能仅凭两件橙装获得橙档效果。污染英雄系列没有蓝档，因此2／3件暂不激活，凑到至少4件紫色以上时同时激活2件和4件。这里没有暗设两件套例外；若之后希望高品质两件小套独立成型，需另行定义该类门槛。

套装效果占一个绿字格，既定套装散件绿字数量仍为白／绿／蓝／紫／橙0／0／2／3／3。本文九个首批系列的品质按下表列明，不因为绿字数量表存在绿色一行就自动给每个系列添加绿色版本。

## 污染英雄六件套

每套永久绑定一个固定英雄及一个发展方向。例如污染的雷诺套绑定雷诺与兵营，不会换装后变成诺娃套。以下2／4／6件结构按用户原意整理，人数与获得时间的细化说明为本稿建议。

| 件数 | 紫档 | 橙档 |
| --- | --- | --- |
| 2件 | 对应发展方向普通士兵人数上限＋1 | 对应发展方向普通士兵人数上限＋2 |
| 4件 | 对应发展方向普通士兵军衔上限＋1；开场随机精英2名 | 对应发展方向普通士兵军衔上限＋2；开场随机精英3名 |
| 6件 | 开场获得绑定Ⅰ级英雄；英雄能力大幅强化 | 开场获得绑定Ⅲ级英雄；英雄能力大幅强化 |

人数加值建议按该方向每个已上阵兵种的普通兵名额计算，同时调整对应可用总名额，不能被另一层旧总上限完全抵消；不直接凭空生成普通士兵。军衔加值只提高上限，不自动把士兵升满。

精英优先从对应方向的合法身份中不重复抽取。橙档若该方向只能提供2名，则额外1名来自本族另一个方向；若缺少更多，按缺额补足，不只机械补1名。紫档同理保证合法2名。抽到的精英提案为Ⅰ级。跨方向精英是本次出征奖励，不代表自动解锁其整个建筑科技树；实际部署名额必须保障，不能名义发放后被旧生产条件拒绝。

“污染英雄”是套装系列身份，“待清洗”是物品状态。建议该系列只从污染掉落池产出，撤离后清洗方可装备；清洗后仍是污染英雄套，不降成普通英雄套。这样保持此前污染清洗流程，也允许污染英雄套实际穿戴。

生存者以全队持续作战体现第三强定位，不再免费送英雄。士兵套主要使部队成长到高军衔，部队套主要保证数量与补员，精英套主要让固定精英成为核心。

精英套仍绑定具体身份，洗练可转换绑定精英，但穿戴时不会随机换身份。2件、4件奖励合并成同一个绑定精英，不生成两名副本。金属风暴改为提高现有预热机枪伤害；原“满预热压制冲击”蓝紫示例撤回。

旧“同类军衔上限取最高、普通兵统一最多Ⅶ”的提案已被用户最新叠加规则替换：不同已生效来源按对象／方向相加，先验证件数与品质门槛，再计算人数和军衔。无限编制提供的Ⅸ可加橙士兵套＋4至ⅩⅢ；固定身份赠送的档位替换不重复发身体，未满足橙档门槛的2件仍只能拿合法基础档。完整公式与例子见[六类橙套设计](STARSHIP_ORANGE_SETS_20261014.md)。运行成长与容量尚未接入，不把设计数字当源码现状。

## 开场奖励与构筑搭配

建议“开场”指整次出征第一次部署，奖励每次出征发放一次，不在每关、重载或换装时反复发放。开场取得的英雄与精英按永久出征成员处理，不是几十秒临时支援；已有同身份单位时合并并至少达到套装给定军衔，不重复创建，也不降低原有军衔。

按2026-10-14用户最新确认，套装／模块只能局外更换，关间不可换；撤销关内首次凑套的旧提案。仅无套装身份的合法属性散件可关内替换。同身份英雄合并保留一个实体和各来源记录，不因合并复活、补血或多领一次奖励，详见紫装第十五节。

可用搭配示例：英雄6＋强化者2；污染英雄6＋生存者2；士兵4＋部队4；精英6＋士兵2。品质门槛按每个系列分别计算，因此6＋2的两件小套使用其可合法激活的基础档。全套强度排名是设计目标，不抹平这些专项取舍。
