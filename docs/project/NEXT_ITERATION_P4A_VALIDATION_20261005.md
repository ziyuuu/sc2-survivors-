## 已确认英雄强度保留

实际运行30个人族精英后，再检查原人族英雄；未改英雄数值来补齐比较。排除天赋、卡牌、科技及新旧英雄光环和精英自身光环。英雄普通输出来自正式World固定60Hz、60秒真实弹体抵达；精英V级上界来自实际运行时身体、原武器条件加成与固定机制的条件峰值包络。精英峰值包含轻甲／重甲／空军、雷神预热、死神吸收渐近值、开场伤害、大型雷、Boss污染和离战蓄能等适用条件，不把任意敌人数乘入单身体输出。此表把测得英雄输出与解析精英上界明确区分。
