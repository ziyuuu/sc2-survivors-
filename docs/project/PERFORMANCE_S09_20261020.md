# S09 爆虫混编主动接近 · 2026-10-20

用户要求爆虫像近战单位一样主动接近攻击。修复已本地验证完成，限定为玩家地面爆虫在自主作战时的接近路线，包含普通、三种精英和英雄临时爆虫。[看板](PERFORMANCE_BOARD.html) · [范围证据](../../reports/qa/performance-s09-20261020.json)。历史[S09诊断](BANELING_S09_DIAGNOSIS_20261020.md)保留其当时“未修复”的结论。

## 原因与实现

爆虫已经选中目标，但原 `avoidStationaryBodies` 只围绕最近阻挡体尝试有限的两段绕行。多排正在射击的友军会使这些候选都被占位检查拒绝，返回原位置；碰撞产生的小幅抖动又重置停滞计时，不能稳定脱困。混编12名刺蛇时，普通及三种精英爆虫15秒均未攻击，而空旷接近、贴身和追击正常。

`world.ts` 只为玩家地面爆虫、已有目标且处于展开接敌或自主临时单位模式接入 `movement/melee-approach.ts`。直线可达时继续使用原目标点；遇到成组友军，按当前地形、活体、活动运输舱和结构查找绕行路线。原队形接触点被封住时，尝试目标周围仍在原射程内的其他接触点。保持实际逐步移动与原碰撞求解，不瞬移、不穿友军、不扩大攻击距离。

采用0.5格、最多2048次节点访问的局部搜索，范围为起点与目标包围框外扩4世界单位，接触目标另加接触半径。路线最多复用0.4秒；每次仍验证下一段当前占位，目标、地图对象、关卡或目标位置明显改变即失效。路线是按实体身份存放的派生WeakMap，不写入存档；没有合法路线时等待再试，不保证任意迷宫都能走通。

原射程0.25、伤害、范围、移动速度、五秒恢复、选敌与起手规则均未改。显式移动命令、行军和硬牵引仍优先；飞行爆虫不使用地面绕行。敌方爆虫仍走原路径并一次自爆，英雄临时爆虫仍一次自爆后消失。其他兵种与原地形/碰撞求解器未改。
