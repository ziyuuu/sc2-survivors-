## 相位继生：两幻象与一次原体恢复

用户确定“两只强化同类幻象＋真伤＋30秒生存后复活”。已接受范围覆盖正式普通、精英、英雄及合法永久随行战斗成员，农民不按战斗单位处理；临援、子机和相位幻象自身死亡不再分裂，避免递归。英雄形成两个临时同类投影是本能力的明确例外，不沿旧蓝紫幻影“一概不复制英雄”把效果削掉，也不产生两个永久英雄。

每只幻象：以原体死亡前合法上限及能力为快照，最大生命／原生盾×2，原生伤害／治疗／回盾×2.5；另获得相当于原体未暴击主武器DPS的30%固定真实DPS，按实际周期分摊。两只各有自己一份强化输出，本能力明确就是双体，不套旧幻影50%输出或把两只合摊成半个人；原生母体与子机仍共享各自那只幻象的预算，不能无限复制子机收益。不会因为无普攻的治疗者或母舰没有假武器而凭空造普攻，母舰使用真实子机输出通道。

两只同时出现，共同30秒倒计时；可沿原有部队指令自动随行，不增加逐只幻象微操要求。至少一只存活到期时，原体恢复一次，所有本次剩余幻象一起移除。复活恢复原身份／军衔、100%生命及原生盾，能量和技能剩余冷却按原体死亡时状态继续真实计时，不因复制或复活免费重置技能。复活落点采用幸存幻象附近合法位置，原编制／英雄身份席位在等待期间保留，不被别的奖励占用后挤出原体。
