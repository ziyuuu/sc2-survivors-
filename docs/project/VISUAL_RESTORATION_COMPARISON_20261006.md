## 原附属材质控制

本地原始 `immortal_ex2.m3` 的 SHA-256 为 `d5f34c9efc37c120883764ca0dcc19162805afd707f7404f083fa98260c454e1`。`Mat_Immortal_Shield` 是复合材质，引用标准材质5，子层 alpha 默认值为0，动画引用为1095849030。原 Actor 用 `Behavior.ImmortalOverload.On` 启动 Cover，Off 停止 Cover。源 Start 曲线166ms内从0到1，End曲线166ms内从1到0。

当前 `tools/m3-scene.mjs` 第11行把所有复合材质取成第一个标准子材质，并按菌毯层解释。这丢失了该护障的复合透明度与控制。没有漫反射的发光附属层又落到了白色底色，导致当前待机不朽者被白块盖住。

实验保留三个原附属网格与原纹理，恢复复合 alpha、源曲线、UV、双发光层和边缘适配。实际护障启用来自既有 `World.barrier`，开始时间读取真实冷却记录；不另造战斗护障。诊断存档由真实 `World.step` 受击激活后再推进12个tick，记录为barrier84、time0.8166666666666667。靶标生命被明确设为诊断高值，不能当作自然战局。

待机白块消失，实际受击的格栅护障仍可见。复合 alpha 和 Cover 曲线有原始来源；发光和Fresnel仍是适配。目前材质动画采样基本姿态轨道，攻击叠加轨道没有正式整合。实例通过冻结坐标匹配，仅适用于本轮暂停实验；正式接入必须改为稳定实例ID。不能写成所有M3材质与攻击效果均已恢复。

源读取器固定在 `sc2-arcade-watcher/star-tools-three-m3-loader` 的 `ee0eff037e2e40d2aad72f4f856af0710b8a44e5`。工具只读原 M3、ActorData、LightData，写出元数据，不重新导出或覆盖资源。

## 真实投影和遮蔽

使用单张1024 PCF阴影贴图，覆盖当前相机附近。阴影深度材质复用现有GPU骨骼和炮塔回调，避免投影使用绑定姿态；只让实体表面投影与接收，保留原脚下光环和技能特效。

冰封岩石和玛萨拉石柱的落地感改善明显，飞行器的高度关系更直观。投影分支停止绘制原圆形软影，A/B仍使用原圆影。Three r186会把旧PCFSoft枚举回退成PCF；最终实验直接使用同一PCF，消除弃用提示。测量与截图实际使用的滤波没有改变。

SSAO使用半分辨率、16样本和0.45强度，法线回调也复用当前骨骼姿态。噪声与采样核使用独立固定种子，不消费World随机数。地形遮蔽使用几何法线，未复制完整地形法线着色器。本次近景接触感改善有限，其收益小于真实投影。

正式接入前需验证移动、死亡、形态、飞行高度、镜头边缘、宽屏和低画质回退。冻结场景不能覆盖这些动态情况。

## 高光和地图照明

读取了陆战队员、掠夺者、坦克、蟑螂、狂热者、雷诺、菲尼克斯、不朽者共8份原始本体高光元数据。D Phong仅转换匹配的本体表面，保留现有发光强度、纹理与骨骼回调，使用RGB高光图和源高光参数。它是有限适配，不是原生SC2 BRDF。

D保留当前PBR，增加环境参考与两盏补光，并按五张地图调整色调和雾。五套色调是本轮调试方案；RoomEnvironment不是原SC2天空盒。原Kairos LightData的环境色、曝光、白点等已读取，但没有把不同引擎的数值直接当作等价参数。

工业和玛萨拉部分表面更容易辨认；冰封目前偏白，地面细节被削弱。D Phong改善部分人族高光，却让不朽者出现强亮斑。后续按材质类别校准响应、按地图校准照明，不能直接整体切换Phong或统一抬高曝光。

## 验证和保留

1157项回归通过，失败0；其中4项验证原复合层默认值、Cover边界、发光层区别和UV轨道采样。主项目与实验渲染模块类型检查通过。15份当前格式存档均生成并通过World恢复校验；39组截图和18组测量检查完整World/profile指纹，均保持一致，模型与着色器错误记录为0。截图覆盖五图、30普通家族、18英雄，属于固定工程对照，不是人工视觉验收。

所有现有`src`、`deploy`、UI预览、转换器和依赖清单未修改。当前647条资源、629个Web文件、648838732字节与647个开发资源路径逐一核对哈希；release仍为 `2848cfe41f50528ce1cc9128edd1e5ddccdf9bd7e889aa15af72df16f3fc287a`。原始899条资源／866文件及55份UI资源的恢复核验也通过，新增资源0。当前Web build仍为 `999dbb67982c4ed3660fb0be0fa444bee194f20948d92703726db89f51a7e049`。

## 建议正式落地顺序

1. 以B为第一步，正式绑定复合默认值、稳定实例ID和Actor事件；覆盖待机、攻击叠加、出生、死亡、护障开关及精英／英雄变体，保留原脚下效果。
2. 以C为第二步，加入可独立关闭的真实投影；按当前姿态绘制，验证移动、飞行和镜头边缘，保留低画质圆影回退。
3. 将D和D Phong作为逐模型、逐地图校准工具。固定当前存档和相机，比较源高光与PBR响应，冰封优先保留雪地纹理细节，再确定正式材质方案。
4. 将AO保留为可选高画质功能；完成自然大编制战局的视觉与性能复测后再决定默认值。

现有LOD、动画时序、地形几何和已批准特效保持当前逻辑，仍可能形成与SC2的差距。本轮不宣称原生SC2逐像素对齐，不关闭旧P6-V01来源／持续时间、自然性能、完整M6/M7或人工／物理设备验收。
