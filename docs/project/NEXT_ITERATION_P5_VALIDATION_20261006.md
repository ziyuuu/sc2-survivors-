## 保留边界

没有真实外部PostgreSQL/Coze生产环境可供检查。PGlite SQL/事务测试和打包安装检查不能替代生产连接池、TLS、并发、多副本限速、独立持久卷、平台定时任务或备份恢复验收。进程内全局限速在多副本部署下需由边缘/网关配套；账号失败限制存数据库。

浏览器测试用临时本机账号及反馈，未触达真实用户。截图中的1个浏览器样本是该次QA，非运营人数。18英雄/90精英的只读归因测试也不是自然长期平衡结论。

P4已有三族60秒自然首关帧时样本及诊断压力记录，详见P4-D/E验证；P5未借用它们宣称启用统计后的完整长期性能验收。完整自然M6/M7、实体设备/长期性能、人工视觉与原科学船死亡来源缺口继续开放。没有上传、推送、部署或清理旧产物。
