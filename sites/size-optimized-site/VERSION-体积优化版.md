# V04 体积优化版

本分支保存基于 V04 的 Sites 私有测试版，包含游戏静态资源、加载器，以及统计和反馈的 Workers / D1 / R2 后台实现。它与游戏主工程是两个独立的 Git 仓库：游戏主工程位于 `D:/星际`，本站代码位于 `D:/星际/sites/v04-private-test`；两处均使用 `体积优化版` 分支。本站的压缩前基线为游戏主工程 V04 交付 `dist/V04-20261027/Web.zip`，不是后续版本。

- `public/` 是当前测试游戏入口和 58 个资源包；约 240 MB。3845 条资源记录对应 3742 个去重资源。
- 图片和模型内贴图以 WebP 有损压缩（质量 70）；音频以 Opus 有损编码（目标 48 kbps）。模型传输使用 gzip，浏览器解压后按清单校验。资源包与 service worker 降低下载请求数；需要支持 service worker、WebP 和 DecompressionStream 的浏览器。
- `app/`、`worker/`、`db/` 等为站点与后台源代码。统计需玩家同意；反馈联系方式由玩家自愿填写；管理页需要站点所有者身份。部署环境、数据库与对象存储不由 Git 分支复制，不能仅凭此分支断言其他部署已连接或权限正确。
- 站点保持私有；创建本分支不等于发布。
- 压缩并非无损。已对陆战队员场景、核爆、巨像和虚空辉光舰射线的少量固定时刻做画面对照，并准备四组音效试听，不代表全游戏视觉或听感均经过验收。
- 原始 V04 成品与游戏源码保留。主工程包含压缩、资源对齐、打包和测试脚本；一些脚本引用本机暂存目录和工具，需按主工程版本说明准备输入后运行。
