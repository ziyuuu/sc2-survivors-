# 战斗与基地实机样例 · 2026-10-08

这是独立交互样例，不是完整游戏，也不接入 main 游戏入口、存档或后端。

复用当前 `World`、`BattleRenderer`、真实主动技能入口、原模型／特效／立绘和批准的 R12 样式。仅本目录提供 UI 提案与诊断场景；`src/`、正式 Web、完整 HTML、部署包和游戏数值保持原样。

样例场景：战斗、基地建设、战备补给、满员增援、尚无英雄、满编部队。人族五个兵种为陆战队员、劫掠者、恶火、坦克和医疗运输机，三名英雄为雷诺、泰凯斯和诺娃。

- 桌面按本轮批注及补充：部队栏铺满底部宽度，实兵按顺序紧凑排列，不显示任何空位。一排放得下时仅一排且不出现折叠按钮；实兵超过一排后才出现第二排并可收成一排，收起仍能翻页查看其余单位。实际士兵保留各自军衔、生命、护盾及原图标。有手动技能的普通兵在前，医疗运输机在后。
- 桌面上方依次放已有英雄技能、推进、主动侦测。本场景最多五个按钮，技能区取消外围框与独立折叠，始终贴紧部队栏上沿随动；保留原 1／2／3／Space／G 快捷键。
- 手机按后续竖屏批注：部队同样铺满底部，以实兵紧凑排列，每排六个，超过一排才出现第二排；没有空位或占格子的“部队”按钮。折叠改成栏外 44px 小圆箭头，不足一排时隐藏。更多部队左右滑动翻页，底边小圆点标示当前页。右侧 44px 等大圆按钮以中央探测、雷诺正上、泰凯斯右上、诺娃正右、加速右下排布，折叠圆钮在探测正下，和左侧摇杆的中心高度对齐，均在部队栏上方并随其行数移动。没有英雄时只显示两个全局按钮。
- 鼠标左键／手机短按施放；鼠标右键／手机长按 480ms 查看原单位详情。冷却时详情仍可打开。详情保留所有士兵和三名英雄的切换。
- 取消样例里的“单位操作”按钮；全局推进、侦测等仍单列。
- 仅部队栏保留带“部队”名称的折叠按钮，收成一排后箭头向上，展开后向下；技能按钮始终可见。
- 战斗中“基地”和关间“设施调整”直接进入设施／训练／当前科技面板。设施数量突出展示，所有所属兵种逐一显示已解锁或未解锁。当前科技列出原攻防系统、研究等级和技能科技。训练复用原开关与待救援状态；去掉样例里的订单／部署标签和“下次发展目标”控件，建设购买仍只发生于原建设阶段。
- “强化”与“基地”独立进入各自面板，关间“强化一览”与“设施调整”也互相独立。武器与防护研究另设独立页面；商店强化提供“总体加成／已购卡牌”两个页签，不混入攻防研究。来源记录实际完成的原生卡牌购买，保留名称、稀有度、原说明和真实支付金额；不根据聚合数值编造卡牌来源。
- 满员场景先生成真正合法的增援报价，再用诊断场景补满编制。原报价保留，但按现有容量规则显示“编制已满”，禁止购买；不改抽取概率、扣款或人口规则。

场景由固定诊断种子 10812 建立：已解锁科技、设施、资源和高生命静止敌人不代表自然战役获得。样例起始四项商店强化走原随机报价、扣费及购买凭证流程；补给与满员场景也使用原生空投报价。购买来源只在样例 UI 内记录，不添加正式存档历史或 schema。战斗没有完整关卡推进；不检验普通模式后期平衡。显示和操作走正式引擎，游戏素材原字节保持。画布铺满顶栏下的区域，不通过压缩画布给 HUD 留空；仅在样例竖屏镜头维持至少 20 世界单位横向视野，减少原诊断部队的左右裁切。

“前往补给”“返回前线”使用原关间推进命令；订单、扣费和强化保留。只有工具栏的场景切换与“重置”重新建立诊断配置。
