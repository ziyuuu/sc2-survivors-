# Development contract · V17

- The latest user-confirmed rules are in docs/DESIGN.md. Read it before gameplay edits. It supersedes historical four-type rosters, individual production pods, timed construction and earlier difficulty budgets.
- Work in D:\星际 on v3/playable-sc2-demo. Update PR #2 without changing its base v2/sc2-assets-ui. Never force-push main. Run npm test before commits.
- Normal start is exactly one Rank-1 Marine, one completed Barracks, 50 minerals and no gas. Diagnostic overrides must be explicit.
- Five Terran families: Marine, Marauder, Hellion, Tank, Medivac. Five Zerg combat families: Zergling, Roach, Baneling, Ravager, Hydralisk. SCV and Drone remain economic actors.
- Five family seats and five ordinary ranks each. Fifteen unique replacement elites use same-card-only ranks and permanent death. Raynor, Tychus and Nova occupy three additional seats; same-name rewards recruit/promote. Revival is paid only during intermission and deploys next stage. Never discard prepaid ordinary capacity to replace a unit.
- Three building groups train paid whole batches, one passenger per eligible participant snapshot. Barracks alternates Marauder/Marine after global research; upgraded Factory alternates Tank/Hellion. Expensive batches wait for funds. Group reservations rotate; other groups may spend only actual surplus.
- One completed batch produces one multi-passenger pod. Same-family unresolved pods block another batch. White reinforcements merge while pending, never into landed pods. No manual in-battle production/shop. Buildings and production unlocks complete immediately; training retains original duration.
- Pods have no timeout. Clear threats to release passengers individually through collision-safe exits. Destroying a pod kills remaining passengers without refunds; already released units and surviving guards remain. Preserve guard-origin drop rates.
- Green/blue veterans directly grant ordinary Rank 3/5; cannot promote elites. Purple replacement cannot consume prepaid capacity. Orange heroes never occupy ordinary seats.
- Twelve stages last 60/120/180/240 seconds in groups of three. All pauses, reward menus, elite selection and required model decoding freeze simulation. Preserve HP, enemies, Bosses and unresolved pods across stages. Stage 12 requires destroying the hive and surviving the timer.
- Easy/Normal runtime only. Normal waves and guards use 90% of the locked original budgets with per-type/source cumulative rounding; first Normal pod still has two lings. Easy stays at 50% of the original budget (not half the new Normal), with 1.25 economy. Elite conversions preserve the ordinary budget; Easy halves elite events separately without double-scaling. Four fixed Bosses use the same stats on both difficulties. No army-strength adjustment or free safety nets.
- Award clear resources once, then building and random rounds; multiple purchases, optional Continue, random discounts, shared 50+40n rerolls. Never filter by wallet. Resource-card profit is intended gameplay. Intelligence changes only future rarity rolls, not drop frequency or already generated cards.
- Preserve fixed 60 Hz World as truth, independent HP, armor, legal target layers, cooldowns, healing energy, finite movement/turns, collisions, local avoidance and spatial hashing. Render events cannot deal damage or award drops.
- Manual squad siege only. Movable actors follow current commands, never old anchor loops. Left/right hostile focus pursues into range and has priority when legal; ground movement permits short-stop attacks en route. Medivacs heal biological allies, or mechanical allies after Nanite Repair, never self/structures.
- Keep wider firing deployment on open ground and distinct reachable slots in passages. Units use 0.8 model/body scale, original map/range/speed scale, catch-up at most 1.22. No teleport or automatic unsiege to unjam.
- Preserve original Kairos Junction LE connected map slices, actual ground/cliff/ramps and Crystal/GasCanister/SpaceMineralCluster resources. High ground can shoot down with obstruction checks; melee cannot cross cliffs. Air collision is separate.
- Mouse, touch and PC gamepad remain interchangeable. Heroes use keyboard 1/2/3 and gamepad up/left/right; menu direction inputs only navigate. Preserve legacy controller calibration. No physical-phone testing this iteration.
- All numeric SC2 data requires locked version, source and speed conversion. New hero/elite/Boss values are explicit Survivors tuning. Analytical economy assumptions, fixed-rule flow, scripted input observations and human playtests are separate evidence. Automated victory is never a Normal difficulty acceptance gate.
- Post-victory endless is optional and retains stage-12 terrain/state. Separate 240-second rounds preserve debrief/economy/revival. Wave/elite/Boss cadence accelerates every 30/60/90 combat seconds. New specials grow monotonically across archetypes; existing actors never retroactively scale. Endless reuses the current difficulty-adjusted stage-12 budget.

- Original asset bytes, conversion, animation playback, visual inspection and permission to distribute are separate statuses. Never replace missing authentic units with geometry, generated art or another unit's effect. Report missing exact source/install paths.
- Follow local-only artwork processing. Keep screenshots and original assets on disk, never upload through image/model-return services. No credentials, private caches, proprietary archives or generated demo in the public repository. Font files must not be downloaded or packaged; retain system fallbacks.
- Ordinary UI contains gameplay information only. Source reports, asset diagnostics and implementation notes belong in documentation or development-only F1. Development and standalone HTML share World and assets; production Demo has no state-changing debug API.
- Report actual commands, tests, build hash/size, browser/viewport evidence and performance environment. Headless rendering is not human visual approval; emulated mobile is not a physical phone.
