# UI 收口与战斗反馈 · 2026-10-09

基线：ae4c2ac。用户本轮批准旧清单 7、12，以及截图中五项 UI 修复；补完此前已指出的资源不足提示缺口。证据放在 `reports/local/ui-battle-feedback-20261009`。

## 实现边界

- 作战部署的天赋预设、初始部队沿用原数据、立绘、按钮和流程，改用本轮关间 UI 的细框、间距和对齐规格。
- 主操作与选中状态统一金色，次操作为深蓝灰；保留获批卡面标题的浅色条和品质色。面板尊重 100/125/150% 字号，窄屏允许正文区域滚动，避免文字压住操作。
- 真实 `flow-continue` 按钮水平居中；只有原加载协调器达到 ready 才可操作，完成后常驻金色高亮及两次柔和提示。关闭动态或系统减少动态时保留静态高亮。
- 用户随后指出加载页的竖屏立绘把人脸裁到边缘；窄竖屏将原横版背景的取景焦点移到人物，原图和桌面构图保留。
- 强化来源只展示属性、全军和持续战术强化；排除增援、单位解锁、军衔晋升、资源、设施和英雄等购买。相同效果、兵种、品质和单次强度合并，同品质重复购入显示右上角 `×N`。折扣不拆组，花费为实际支付总额。原逐笔购买凭据与实际累计效果不变。
- 补齐刷新、单兵种修复、精锐确认及详情的资源不足文字，保留原报价、可购买条件、扣款和撤销语义。
- 去除敌方身份、状态、扩张警示与技能预警的黄红地面圈/线；小地图继续显示敌人、救援、扩张，并显示既有攻击预警、敌方扫描范围。实际弹道、火焰、爆炸、酸蚀伤害区域、友方技能范围和移动/目标反馈保留。
- 真实永久队员阵亡触发 2.4 秒衰减红边；Boss/Lord 在场增加低强度边缘压力，减员时加强，多个 Boss 不累加到全屏遮挡。新 Boss 首次入场触发 0.85 秒轻微镜头震动，镜头位置每帧恢复。HUD 和小地图在红边上方，效果不接收输入。
- 原镜头震动设置继续控制震动；从未设置的本地浏览器默认开启，明确关闭的值继续有效。系统减少动态或关闭界面动态时，新 Boss 震动关闭，Boss 红边不呼吸。暂停/关间隐藏，首次显示已有 Boss 不重放登场效果。临时兵、载机子单位、主动替换和敌军死亡不触发减员提示。
