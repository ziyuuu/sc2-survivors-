# 上一轮 UI 流程与立绘核查 · 2026-10-07

对照 UI 接入前 `edb1848`、上一轮已推送 `fdd37fa`、原 UI 对话16回合，以及本轮实现。不能用模拟文件未变或测试通过，替代对玩家入口和实际画面的检查。

## 发现与修正

| 项目 | 实际问题 | 修正 |
| --- | --- | --- |
| 独立英雄待命页 | 从静态展示原型带入额外入口，标题和步骤会让人误以为存在英雄招募关卡 | 删除入口与页面；原有开局英雄、真实随机补给报价、培养和复活保留；资料在图鉴查看 |
| 原有档案操作 | 免费奖励、精英救援、免费/付费满编晋升、结算和无尽准备界面漏了部分现场操作 | 恢复原有保存/导出；无尽准备恢复直接导出与返回标题，保留整备状态；不是新增领取或购买条件 |
| 九位封面英雄卡面 | 素材身份正确，但接入遗漏原稿的 `im-painted` 缩放和裁切，按原图尺寸显示局部盔甲/背景 | 恢复原稿图像布局；按实际图像字节核验，支持资源准备后生成的 Blob URL |
| 初始部队 | 部署页使用模型图标；有开局英雄时只展示英雄，遗漏仍然存在的普通部队 | 使用现有立绘；人族/神族一名、虫族两只始终显示，有天赋时额外显示Ⅱ级英雄；开局规则不修改 |
| 首页附加行和重复Logo | 上一轮带入原型方案/续局整行；本轮最初替换Logo时首页重复展示同一图像 | 删除用户明确不要的整行与首页小Logo，保留主Logo和原有首页操作 |

此前验证没有完整发现上述玩家入口和英雄图像问题，不能继续把旧记录的“通过”解释为这些问题不存在。旧原稿、包、截图和失败证据保留。

| 生产、已付订单、孵化、修复 | 原生产面板和 World 命令；移到整备服务/战场控制台，功能保留 |

| 首领/天赋/救援奖励、增援换兵 | 原队列、收据和待选状态；只恢复遗漏的档案操作，领取/拒绝/延后规则不变 |
| 胜负、撤离、无尽准备和返回 | 原阶段/令牌；补回原有直接档案操作与保留整备返回标题 |
| 局外天赋与钱包 | 用户要求的多级菜单；165定义、价格、前置、三方案及分族已付账本保留 |
| 图鉴与详情 | 原 R11/R12 的展示导航是新增 UI 层级，不能当作新增玩法；图鉴只读，实际报价的详情确认仍调用原购买命令 |
| 保存、设置、资源、全屏、手柄、反馈/隐私 | 一部分入口从旧工具栏移到设置/整备菜单，另一些直接入口本轮补回；不是删掉底层功能 |

首页删去附加行不会删除天赋方案、读取存档或档案设置。新的自动封面、上方锁定和开屏来自用户明确要求。
