# 玩家数据与反馈：实际实现口径 · 2026-10-06

声明版本 `2026-10-06.1`。本地交付默认关闭服务，尚未上线采集。本文件描述已实现字段；正式发布时还须填入实际管理方、联系渠道、平台日志与备份设置。

## 自主选择

标题页、暂停页和关间提供“反馈”和“玩家数据与隐私”。拒绝统计不影响游玩、训练、保存或独立反馈。只有明确选择“同意并启用统计”后，才生成本域随机浏览器标识、上传凭据和隐私凭据；不追补同意前游戏历史。变更声明版本后停止采集并要求重新同意。

随机浏览器标识是可关联的假名标识，不是准确自然人数，也不宣称绝对匿名。清除数据、不同设备或无痕浏览可能算不同浏览器，共用浏览器可能算一个。没有暗中统计拒绝者的持久ID或全站同意率。

## 统计白名单及来源

| 组 | 实际字段与来源 |
|---|---|
| 授权与访问 | 随机浏览器/会话/战局ID、授权版本、事件ID、客户端发生时间及服务端接收时间 |
| 环境 | 应用构建和资源发行ID、移动/桌面大类、横/竖屏、完整/节能动作模式、开发/锁血/关闭自动刷怪的诊断标记 |
| 战局 | 新开局/继续、种族、难度、战役关或无尽轮、结算状态、授权后观察的战斗秒数；中途同意或重载标记为部分观察 |
| 成长构筑 | 本局冻结的已分配天赋点数0—80（不是未花费资源折算等级）、天赋语义ID/级数、路线攻防科技；实际拥有过的家族/90精英/18英雄军衔及24支援卡层数 |
| 卡牌与经济 | 实际展示/购买/领取的卡ID、品质、当时层数或军衔、战役/无尽位置，购买凭据矿气，生产账本训练/增援付款、刷新消耗。观察记录不替代权威交易账本 |
| 实际战斗 | 按阶段累加实际生命/原生盾扣除、有效治疗/回盾、永久身体死亡/复生；真实子机输出归属母舰一次。无法追溯来源的恢复单列，增益/减速不虚构伤害 |
| 加载与性能 | 授权后加载耗时、下载字节、命中/未命中/失败计数、解析与编译的累积耗时；每阶段帧时P95/P99、>20ms帧、总帧数、单位峰值、模拟欠账增量 |

不自动上传完整 World、存档、截图、回放、键盘/触摸轨迹、姓名、精确位置、通讯录、设备指纹、完整 User-Agent 或 GPU 型号。应用数据库不保存 IP；应用限速仅用进程内带随机盐的地址哈希。托管平台自身请求日志仍须由实际部署方说明。

仅在实际阶段/交易/加载节点记录摘要，战斗心跳最多每60秒一次。传输最多32事件/64KiB；队列上限200条/256KiB，24小时到期，溢出优先丢心跳并计数。网络失败静默重试，不改 World、RNG、奖励或付款。极端超限记录会被白名单拒绝并计为丢弃，不伪造数值。

撤回立即停止本机采集、取消上传、清空未发送队列和本机统计观察摘要；联网失败时显示服务器尚未确认，保留隐私凭据重试。可删除此浏览器可关联记录。本地游戏存档、成长与资源缓存不删除。多个标签页共享授权、合并有界队列；读档沿用战局ID，不重复计算新开局。

## 独立反馈

统计未授权也能提交反馈。分类为问题/性能/平衡/建议/其他，正文10—2000字；联系方式选填，仅用于反馈处理。版本/种族/难度/关卡摘要在发送前可见并可取消。提交必须另行勾选同意，默认不勾选。

反馈不附浏览器统计ID，不上传附件。草稿与失败内容留在当前标签页；重试使用固定编号，仅入库一次。成功返回编号及本机查看/删除秘密凭据；服务器只存其哈希。本机保留最近10条凭据，清理浏览器数据后不能找回。查看和删除使用同源 POST 请求体传凭据，不将秘密放在 URL 中；这替代旧计划的 GET 凭据查看接口。

管理员可改变状态、标签、备注、优先级；联系方式不进入默认列表或普通CSV，需要单独权限和明确导出动作并记审计。应用不会自动发送邮件、私信或以其他方式联系玩家。

## 保留与报表解释

原始事件/会话90天；可关联战局/关卡180天；浏览器索引在最后活跃365天后清理；不含浏览器标识的日汇总730天；反馈/联系方式180天；管理员审计90天。保留期是本产品设置，不称为统一法律规定。

关联数据可以凭本机秘密删除。删除同时写独立持久删除清单，恢复备份前必须重放；备份期限来自部署环境，不能用本地测试30天代替正式承诺。无法关联到个人的既有汇总不重新识别浏览器。

报表按 Asia/Shanghai 日期。明细可选1—90天，历史日汇总可选1—730天；同一日不同版本的浏览器数不能直接相加去重。DAU/WAU/MAU只在所选区间内计算；D1/D7/D30只显示已完整成熟的新增浏览器同期群。未结束战局为未完成。战局面板为所选区间有活动战局的累计观察值，关卡按最后收到的摘要时间归属；不能将跨日战局全部时间解释为单日在线时长。

搭配表示同一观察阶段出现，不保证全程同时在场；各身份/组合显示战局数与分母，最多500组。军衔、卡层数、到达战役关和无尽轮分开，零样本不生成强弱结论。帧时分位数是阶段分位数汇总；并行解析/编译用累积耗时，不等同于加载的墙钟总时长。没有战局上下文的加载样本不能按种族强行归因。诊断会话/战局会持续标记，默认排除。客户端数据可被修改，仅用于运营观察，不是防作弊战绩或因果证明。
