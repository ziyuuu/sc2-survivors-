# 第一批材质与单位修复 · 2026-10-10

用户批准基于 `3b2ad8bf42bad588ee5ebbc620fc80499b3961ed` 正式修复不朽者护障、狂热者死亡及基础颜色输出。整体性能、帧数优化和画质分档放到下一阶段。本批只做运行检查和短时渲染成本记录。

## 正式实现边界

- 四个现有 GLB：`immortal`、`elite.immortal.1`、`zealot.death`、`elite.zealot.1.death`。三个精英身份原本共享各自精英模型，身份、成长、尺寸和规则保持原样。
- 从四份原 M3 提取材质标志、发光强度、透明通道、UV 轨道及护障复合材质曲线；元数据包含源 M3 和目标 GLB SHA-256。加载这四个模型时检查实际 GLB 哈希，拒绝错误绑定。读取现有 GLB 内的原始贴图，不改写 M3、DDS、GLB、几何或骨骼。
- `AnimatedBatch.add` 末尾增加可选的内部材质上下文。实体 ID、战局 ID、战局时间、护障阶段、死亡时间显式传递；动作时间由当前骨骼采样值驱动。每个原材质面共享 GPU 状态纹理，容量与原实例批次同为 1024，无每实体材质或绘制调用。
- 自定义采样器登记到原纹理过滤和预加载路径，沿用原来的 8/4/1 各向异性上限及硬件能力限制；不新增或调整档位参数。
- 渲染器在视野裁剪前观察所有非英雄不朽者的真实 `barrier`、`barrierReady`、`lastDamagedAt`。未激活复合层为零；恢复原开始、保持、结束曲线；暂停不推进，重排按实体保持，重载从现有冷却时间恢复。
- 死亡材质使用现有 `deathPoseTime` 和原一次性死亡动作时钟，恢复发光、遮罩和 UV 消散；不改尸体寿命、骨骼播放或回收规则。
- 每帧统一使用半浮点线性场景、现有 Bloom（强度 0.32、半径 0.5、阈值 0.8）、一次 OutputPass（ACES、曝光 1、最终 sRGB）。英雄是否在场不再决定输出链。灯光、阴影、抗锯齿和画质档位参数不变。
- World、Profile、玩法 RNG、数据、存档版本 26/6、地图配方版本 3 不变。其他模型的材质与命中/精英光效算法沿用原实现。

## 源核对与计划修正

在此主线中，阿塔尼斯、阿拉纳克、沃拉尊各自的 GLB 都包含原生 Death 动作，资源清单没有三者的独立 `.death` 别名；它们并未共用狂热者死亡模型。保留各自原动作，并单独检查死亡时间序列。不得为了符合计划中的错误假设替换英雄模型。

源格式枚举按 [M3Studio bl_enum.py](https://github.com/Solstice245/m3studio/blob/main/bl_enum.py) 核对：Add 与 Alpha Add 区分，Fresnel 类型 2 为反向；层的环绕、取反和限幅位按现有原格式结构解析。该映射不代表原 SC2 客户端逐像素验收。
