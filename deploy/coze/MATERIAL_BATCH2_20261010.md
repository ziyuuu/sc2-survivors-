# 第二批：全单位材质与精英视觉特色

基线为 `b56201c57092386ff795db04ba46a507b427d621`。用户批准覆盖 30 普通兵种、90 精英、18 英雄及关联变形、子单位、死亡模型。整体性能、帧数优化和画质分档在**全部画面修复结束之后**进行；本批仅记录运行异常和短时渲染成本。投影、五图场景、特效完整复原与动态清晰度仍为后续批次。

## 实施

- 重新读取现有 204 份可追溯 M3 及配套 M3A、DDS；475 个原始材质描述按 GLB 哈希、原始材质编号和名称绑定。外置动画只接纳相同动画引用编号；雷兽外置动作完整接入，原有 SCV 刚体死亡导出的重命名沿用其原死亡材质轨道。
- 原始 GLB/M3/DDS 不改写。9 个非法 `unlit + specular` 组合只在经哈希校验的内存副本中去除无效扩展。精英毒爆白腹来自 M3 v20 明确关闭显示的材质；恢复源可见性，不删除网格、不改技能。
- 维持 PBR 主路径；恢复队色、源高光、双发光、双透明度、裁剪、复合透明度、法线 UV、贴花、光泽、环境图及遮罩、AO、常量颜色、亮度、UV 与翻页轨道。高光的法线方差过滤只作用于局部高光瓣，不模糊漫反射、不统一提亮或压暗。
- 160 个派生 PNG 共 91,935,430 字节，绑定原始 DDS 哈希，其中 98 个恢复原始队色 RGBA。相同 DDS 内容的两个文件名别名只生成一个资源身份。独立资源目录与清单加入已有 Web、离线解码、资源恢复及应用更新流程；不重新编码已有资源。
- 新增 90 项 `eliteId` 显示配置：小中型 1.25、巨型 1.12、飞行优先 1.15。先将特殊皮肤体高归一到普通同兵种，再乘一次批准倍率。英雄既有倍率保留；身体、武器挂点、尸体、检查视图共用配置。显示状态不写回存档。
- 全体精英保留已验证的同兵种原身体，没有引入未经动作、挂点和死亡检查的替代模型。六个精英恶火／维京身份改为解析实际原生形态：恶蝠、维京突击及对应死亡模型；其他变形继续原路径。
- 净化者旗舰与精英航母共用原画模型，但使用独立显示缓存，避免精英归一化改变英雄体型；预载、挂点、舰载机演出与尸体均解析回同一原始 GLB，不增加模型、不改存档身份。
- 移除普通精英统一紫金表面覆盖；身份配色限制在源队色区域。15 个机制状态将微弱活动反馈加在已有原生发光层，其余沿用真实技能／武器事件效果。缺失状态不初始化；未激活时不添加光团。受击保持原 0.2 秒触发，改为低幅局部边缘反馈，保留表面纹理。
- 最终触发复核修正精英追猎者：闪现护盾使用原 `barrier/barrierUntil` 的五秒状态与剩余量，而不是该身份不会设置的 `boostUntil`。补测原生闪现、保持、部分消耗、耗尽、到期、暂停、重排和续局。既有全量截图仍保留 R7／R9 编号；R10 的两个文件差异有反向文本证明，其余 174 个生产输入完全相同，旧未闪现场景不受影响。
- 第一批线性半浮点场景、原 Bloom 参数、一次 ACES/exposure 1/sRGB 输出及稳定实体时钟继续使用。固定画质设置、碰撞、射程、伤害、技能范围、玩法 RNG、World/Profile/schema、UI、输入、地图规则和后端逻辑不变。
- 完整离线 HTML 新增材质后超过 JavaScript 单字符串上限，因此 HTML 容器改为分段 JSON 脚本，构建逐段写出并增量计算文件哈希。运行时校验每段编号与元数据后继续原 v2 Base85/gzip 按需解码；旧单段容器仍可读取。这是交付容器修复，没有存档匹配、迁移或画质缩减。

## 来源与限制

源语义以本地原始结构和 [SC2Mapster 材质定义](https://raw.githubusercontent.com/SC2Mapster/m3addon/master/cm/material.py)、[枚举定义](https://raw.githubusercontent.com/SC2Mapster/m3addon/master/__init__.py)、[通道定义](https://raw.githubusercontent.com/SC2Mapster/m3addon/master/shared.py) 为依据；六面 DDS 解码遵循 [Microsoft DDS 立方环境图布局](https://learn.microsoft.com/en-us/windows/win32/direct3ddds/dds-file-layout-for-cubic-environment-maps)。描述和实现独立编写。源文件参数不能替代同镜头、同光照的 SC2 客户端参考验收。
