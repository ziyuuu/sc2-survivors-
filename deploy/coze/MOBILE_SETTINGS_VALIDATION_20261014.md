# 设置、全屏、预下载与横竖屏切换

日期：2026-10-14。范围来自用户确认：“3就不用了。你做好1.2即可。开始吧”。本轮只实现[原计划](MOBILE_SETTINGS_SAFARI_PLAN_20261014.md)的第 1、2 项。Safari 入场循环重载、资源分阶段加载和内存治理专项未执行，不作为本批验收条件，也未宣称已修复。

## 实现结果

- 设置统一为“操作｜画面｜皮肤｜预下载”。标题、暂停和关间整备复用同一页面；正文滚动，标签与返回按钮保持可触达。手机尺寸下控件至少 44 CSS 像素，覆盖 150% 文字与减少动态效果设置。
- 画面标签提供原生全屏。点击中直接调用标准或实际存在的 WebKit 接口，进入、系统退出和失败状态依据浏览器结果更新；失败提示不改变 World。无法原生全屏时提供主屏幕网页 App 指引，区分独立窗口与全屏，不承诺共享浏览器缓存、战局或隐藏所有系统栏。旧战局档案入口保留。
- 预下载支持本族与全部资源、停止后补齐、缓存容量提示和清理。资源按 SHA 去重，完成量仅计入已校验且写入成功的文件。本族包含共用地图、敌人、音频、特效及实际模型／死亡／形态依赖，因此不等于仅下载该族模型。当前人族为 532.0 MiB，全部为 785.3 MiB。
- 下载状态由 HUD 持有；切换设置标签继续任务，关闭设置、进入加载／战斗或页面隐藏后停止新请求，完成当前请求。回到前台时立即刷新设置可用状态，无须切换标签。手动缓存暂缓新的可选模型准备，必要入场不等待整批预下载。缓存配额失败不阻断必要资源正常加载。清理仅针对资源缓存，不清除存档、天赋、设置或已载入对象。
- 横竖屏与全屏变化通过统一视口提交更新根节点、画布、镜头、HUD 和输入。尺寸稳定 80 ms 后提交，连续变化最多等到 240 ms 发起提交；方向切换有有界补测。这是调度策略，不是跨设备耗时保证。无变化的重复 resize 不重建画布。每次真实尺寸提交使用一次 drawing-buffer 调整；保留各方向镜头偏好，清除未完成的摇杆、拖拽、捏合和小地图输入，不重建 World、不重新导航。

战斗数值、随机规则、五图内容、原始资源、建筑与舰装规则、镜头模式、依赖、后端和存档格式保持；run 26、profile 6、map recipe 3 不变。用户已确认的五图环境基线继续有效。

最终 Web 实测中，全量预下载先停止于 32.6 MiB，随后模拟真实 Cache.put 配额拒绝，再恢复至 1,168 个已验证缓存文件。清空资源缓存时已载入战场继续存在。暂停状态下经过设置、旋转、缓存清理和可见性事件后的原生 World、Profile、RNG、时间完全一致，没有归一化 notice 字段。可见性由测试适配器修改 document.hidden 并派发事件，实际游戏监听器处理；不等于操作系统真实挂起／恢复。

最终 Web 入场阶段仍记录 76 条资源 HTTP URL 请求事件，未采集其实际传输字节，不把请求事件等同于重新下载。此前 r2 的 0 次请求只属于该次旧构建记录；本批不承诺预下载消除全部网络请求。磁盘资源缓存也不包含网页离线启动能力。

Web 的 10 次方向变化覆盖标题／下载、入场、暂停及活动战斗，每次观察到一对画布 width/height 属性变化，20 个同尺寸 resize 事件观察到 0 次。自动化端观察耗时 125.6–484.6 ms，包含工具等待及入场同步工作，不是物理旋转延迟、帧时间或 240 ms 硬保证。横竖屏镜头偏好独立保留；活动触摸摇杆在旋转后归零，返回竖屏后点击移动产生真实原生命令。Chrome CDP 触摸与方向模拟不等于实体设备验证。

早期 `ui-r3` 在 375×812、812×375、1280×720 三种尺寸检查了实际全屏、拒绝 Promise 和同时禁用标准／前缀接口后的指引，9 张截图。它的布局先于最终两处排版调整；仅复用未改变的功能证据，不把旧截图标作最终构建。最终截图的人工模型查看清单另记 `visual-review.json`。

- 保留最初立即 resize 的旧测试预期、两处测试夹具问题、早期不可见设置按钮定位失败，以及真实窄屏 CSS 溢出。修正最终选择器和设置布局后重新运行，旧记录未改写为通过。
- 保留沙箱启动子进程／构建时的 EPERM 日志；经许可在本地正常执行后通过。构建大包体积提示仍存在，未以此扩展为代码拆分或 Safari 加载专项。
- 首个应用包运行检查通过，但漏带 4 份历史性能／UI 说明，保留原包及其证据；R2 补齐文档并更新本轮交付路径。游戏 Web／HTML 字节不变。旧候选公开目录的 `build-inputs.json` 不再随包复制，本批保守输入清单单独记录在 `binding.json`，没有沿用旧构建的依赖身份。
- R3 修复暂停设置从后台返回后下载按钮可能继续禁用的问题。相对此前运行源码只改 `src/ui/hud.ts` 的可见性恢复监听器，见 `binding-r3.json`；重新构建并运行回归、Web、桌面和离线检查。R1／R2 原文件、截图和同步记录保留，不改写成 R3 证据。
- 未取得 iPhone／Android 真机、物理触摸／旋转、目标 Safari 版本和主屏幕入口的验证证据。没有浏览器完整离线 PWA、浏览器关闭后继续下载或缓存永久保留承诺。
- 不以本批 UI、缓存和旋转测试关闭整个 MVP、自然长流程、全内容 60 FPS、低内存／高刷／实体输入或生产/B4 验收。
